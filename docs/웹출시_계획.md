## Phase 0 — 출시 전 코드 복원 (P0 · 법적/기능 필수)
> 출처: 플랫폼_분기_매트릭스 §2. 이거 안 하면 웹 출시 불가.
- [ ] **로그아웃 + 회원탈퇴 웹 복원** (`MyPage.tsx` — `!isAppsInToss()` 분기). 탈퇴 = Firestore 데이터 삭제 + Auth `deleteUser`. (개인정보보호법)
- [ ] `.env.example` 에 `VITE_TOSS_PAYMENTS_CLIENT_KEY` 등 웹 필수 키 명시.

## Phase 1 — 외부 콘솔 설정 (P0 · 준기 수동 · 런칭 블로커)
- [ ] 도메인 구매 (브랜드 도메인) + Firebase Hosting custom domain 연결 + SSL.
- [ ] Firebase Auth → 승인된 도메인에 새 도메인 추가.
- [ ] 토스페이먼츠 콘솔: 웹 도메인 등록 + successUrl/failUrl 허용 + 라이브키.
- [ ] 카카오·네이버 OIDC: Firebase provider + 개발자콘솔 redirect URI(새 도메인).

## Phase 2 — SEO 기반 (P1)
- [ ] `public/robots.txt` + `public/sitemap.xml` 생성.
- [ ] index.html: `og:image`·canonical → 새 도메인. viewport `user-scalable=no` 완화 검토.
- [ ] JSON-LD 구조화데이터(Organization/Service/FAQ).
- [ ] 라우트별 동적 메타(title/description) — react-helmet 류.

## Phase 3 — 프리렌더링 (P1 · 최대 작업 · 네이버 색인 핵심)
- [ ] SPA → 정적 HTML 프리렌더 (홈·랜딩·주요 정적 페이지). react-snap / vite-plugin-prerender / SSR 중 택1.
- [ ] 색인될 실제 텍스트 콘텐츠 확보 (빈 `<div id=root>` 만으론 네이버 색인 안 됨).
- [ ] 타깃 키워드 랜딩: "AI 사주", "무료 사주풀이", "사주 보는 법" 등.

## Phase 4 — 검색엔진 등록 (P1)
- [ ] Google Search Console 등록 + sitemap 제출.
- [ ] 네이버 서치어드바이저 등록 + sitemap 제출 + 사이트 소유확인.
- [ ] Core Web Vitals 점검.

## Phase 5 — 정책 결정 (P2)
- [ ] 웹 런칭 프로모: 토스콘솔 프로모는 앱전용 → 웹은 서버 지급경로 구축 or 데일리 0.1운만.
