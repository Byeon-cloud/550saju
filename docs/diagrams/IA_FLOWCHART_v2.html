5 잔액 3-bucket 시스템

localStorage 키 saju500_balance_v2. localStorage Tier 1 (마스터) · Firestore Tier 2 (백업).

버킷충전 경로환불 가능소비 우선순위
paid토스결제 / IAP (확정 금액)O (전자상거래법)3순위
bonus충전 보너스 (1500원→4운 +0)X2순위
reward공유·출석·3원·streak·초대X1순위 (최우선 소비)

spendBalance(amount) 알고리즘

total = paid + bonus + reward if total < amount → return false (잔액 부족) remaining = amount 1. fromReward = min(reward, remaining); reward -= fromReward; remaining -= fromReward 2. if remaining > 0: fromBonus = min(bonus, remaining); bonus -= fromBonus; remaining -= fromBonus 3. if remaining > 0: paid -= remaining return true

refundBalance(amount) — paid에서만 차감 복원

2026-05-07 이전엔 7개 페이지에서 import 안 되어 있었음. 이제 모든 paid 콘텐츠 페이지에서 AI 실패 시 호출.

6 결제 원자성 (E13)

sequenceDiagram
    participant U as 유저
    participant C as 클라이언트
    participant FN as Cloud Function
    participant T as Toss API
    participant FS as Firestore

    U->>C: 패키지 선택 후 결제
    C->>FN: confirmPayment(orderId, amount)
    FN->>FS: payments/orderId status pending
    FN->>T: POST v1 payments confirm
    alt Toss 승인 성공
        T-->>FN: 200 OK
        FN->>FS: TRANSACTION balance += un, status confirmed
        FN-->>C: success true
        C->>C: localStorage 동기화
    else Toss 승인 실패
        T-->>FN: 4xx
        FN->>FS: status failed
        FN-->>C: error PAYMENT_FAILED
        C->>U: 결제 승인 실패 토스트
    else Toss OK + DB 실패
        FN->>FS: status needs_reconciliation
        FN-->>C: error NEEDS_RECON
        C->>U: 고객센터 문의 토스트
    end

Firestore rules: payments 클라이언트 write 차단. balanceService.spendUn() deprecated (2026-05-15 삭제 예정).
