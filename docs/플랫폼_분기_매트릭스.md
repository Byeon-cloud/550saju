> **새 기능 추가 시 체크**: "이게 결제·로그인·저장·공유·네이티브에 닿나?" → 닿으면 이 표대로 분기, 아니면 그냥 공유.

## 2. 🔴 웹 출시 전 손봐야 할 것 (앱정책 무관 · 2026-06-03 조사)

### P0 — 코드 복원 (법적 필수)
- **로그아웃 + 회원탈퇴**: `MyPage.tsx:199`에서 "앱인토스 런칭 정책"으로 전 환경 제거됨.
  웹 단독 서비스는 결제+개인정보(생년월일시) 수집 → **회원탈퇴(계정삭제) 법적 의무** (개인정보보호법).
  → 웹 빌드(`!isAppsInToss()`)에서 **로그아웃·회원탈퇴 복원**. 탈퇴 = Firestore 유저데이터 삭제 + Auth `deleteUser` (5일내 삭제 정책 준수).

### P0 — 전자상거래법 (웹 단독 판매 = 준기가 판매자. 앱은 토스 우산이라 불필요했음)
> 현재 소스에 **사업자정보·환불·청약철회 0건**, `/terms`만 존재. 이거 없이 웹 결제 열면 위반.
- **사업자정보 표시**: 상호·대표자·사업자등록번호·주소·연락처·통신판매업신고번호 → 푸터 + 약관에 표시.
- **환불/청약철회 정책**: 페이지/조항 신설 + 결제 화면 고지. (운=디지털콘텐츠 — 사용 전/후 환불 기준 명시)
- **통신판매업 신고**: "운" 직접 판매 → 신고 필요 (준기 사업/법무 영역 · 코드 아님).
- 결제대행(포트원) 표시 + 전자금융거래 약관. (TermsPage 제9조는 아직 '토스페이먼츠' 문구 — 웹 열기 전 오너 확인 후 수정)

### P0 — 실작동 QA (코드 존재 ≠ 작동)
- 도메인+콘솔 설정 후 **웹 결제·로그인 end-to-end 실테스트**. 특히 네이버 OIDC(=non-native Firebase, 설정 누락 잦음)·카카오 OIDC.

### P0 — 외부 콘솔 설정 (코드 아님 · 런칭 블로커)
- **Firebase Auth 승인 도메인**: 새 웹 도메인 추가 안 하면 OAuth(구글/카카오/네이버/애플) 전부 실패.
- **포트원 콘솔**: 웹 도메인 등록 + 라이브 채널키. (토스페이먼츠 직결은 2026-10-14 삭제)
- **카카오/네이버 OIDC**: Firebase Console provider 설정 + 각 개발자콘솔에 새 도메인 redirect URI.
- **env**: 포트원 라이브키 웹빌드 주입. (`VITE_TOSS_PAYMENTS_CLIENT_KEY` 는 2026-10-14 삭제)

### P1 — 정책 결정
- **프로모 리워드**: 7일출석 100원·런칭프로모는 토스콘솔 고정형 = 앱전용. 웹은 데일리 0.1운만 동작.
  웹 런칭 프로모 하려면 별도 서버 지급 경로 구축 필요 (또는 웹은 프로모 없이 가기로 결정).
- **광고 수익**: 웹은 현재 0. AdSense 등 별도 결정 (런칭엔 없어도 무방).

### P1 — SEO/웹노출 (네이버+구글 · 별도 sprint)
- robots.txt·sitemap.xml **없음** → 생성.
- `og:image`·canonical이 `appintoss-saju.web.app` 고정 → 새 도메인 교체 + per-route 메타.
- viewport `user-scalable=no` → 웹 접근성/SEO 위해 완화 검토.
- 프리렌더링 (SPA→네이버 색인) — 최대 작업. (`docs/웹출시_계획.md` 참조)
- JSON-LD 구조화데이터 없음 → 추가.
