# 콘솔 가이드

## 프로모션 진행 전 준비

프로모션을 시작하려면 다음 항목을 먼저 준비해 주세요.\
이미 준비가 완료됐으면 바로 4번(프로모션 등록)으로 이동해도 돼요.

![](/assets/promotion_console_0.DNIPospT.png)

* 사업자 정보 등록 및 정산 정보 검토 (검토에 영업일 기준 1~2일, 정산 검토 2~3일 소요)
* 대표 관리자의 프로모션 기능 약관 동의 및 비즈 월렛 약관 동의
* 프로모션 예산을 비즈월렛에 충전 (최소 30만 원, 최대 3,000만 원)
* 토스 로그인 기능 연동 필요 (게임 앱은 게임 로그인 연동 가능)

***

## 1. 사업자 정보 등록

프로모션은 사업자(개인 또는 법인) 계정에서만 사용할 수 있어요.\
사업자 등록이 되어 있지 않으면 콘솔에서 ‘먼저 사업자 정보를 등록해주세요’ 화면이 보여요.\
‘등록하기’를 눌러 사업자 정보를 등록해 주세요.

* 사업자 정보 검토는 **영업일 기준 약 1~2일** 소요될 수 있어요.
* 자세한 절차는 [가이드](/prepare/register-business.md)를 확인해 주세요.

![](/assets/promotion_console_1.D2K5bkKW.png)

***

## 2. 정산 정보 등록

사업자 등록이 완료되면 ‘다음으로 정산 정보를 등록해주세요’ 화면으로 변경돼요.\
등록하기 버튼을 눌러 파트너 정보 메뉴에서 정산 정보를 등록하고, 검토 요청을 해 주세요.

* 정산 정보 검토는 **영업일 기준 평균 2~3일** 소요돼요.
* 정산 정보 등록 전에는 검토 요청이 불가하니 사업자 등록 상태를 먼저 확인해 주세요.

::: tip 정산 등록 시 주의사항

* 예금주명은 통장 사본과 **정확히 일치**하게 입력해 주세요.
* 업태·업종은 숫자 코드가 아니라 **텍스트**로 입력해 검색해 주세요.\
  예) ‘소프트웨어 개발업’ → 소프트웨어로 검색
  :::

***

## 3. 비즈 월렛 충전

정산 정보 검토가 완료되면 워크스페이스의 ‘비즈 월렛’ 메뉴에서 예산을 충전할 수 있어요.

* 충전 가능 금액: **최소 300,000원 ~ 최대 30,000,000원**
* 현재 결제 수단: 신용카드(인증/비인증 결제)
  * 인증결제 : 카드사별 결제 제한 없음
  * 비인증결제 : 하나카드 1일 100만 원 제한, 기타 카드사 제한 없음\
    (비인증 결제는 카드 번호 직접 입력 방식이에요.)

충전이 완료되면 상태가 충전으로 바뀌고 충전액이 반영돼요.

![](/assets/promotion_console_4.Cd0XPjwj.png)

## 4. 프로모션 허용/불가 유형 확인

### 허용되는 유형 (모두 1인당 최대 5,000포인트 이내)

* 회원가입/접속 보상 (예: 신규 가입 시 2,000포인트 지급)
* 거래/구매 유도형 (조건과 고지가 명확해야 함, 예: 5,000원 이상 결제 시 500포인트 지급)
  * 단, 한 번 지급된 토스 포인트는 회수할 수 없으니 프로모션 조건과 지급 기준을 충분히 검토한 뒤 신중하게 운영해 주세요.
* 이벤트 참여형 (설문·퀴즈·간단 미션, 단 과도한 시간·노동 요구 불가)
* 친구 초대형 (초대한 사람과 초대받은 사람 모두 보상, 어뷰징 방지 로직 필수)
* 비게임 앱의 확률형/랜덤 보상
  * 프로모션 기간은 1주일 이내로만 운영할 수 있어요.
  * 새로운 사용자 유입을 위한 홍보 목적으로만 가능해요.
  * 비게임 앱으로 등록 되었더라도 게임물로 분류된 경우 확률형 프로모션 집행 불가해요.

### 허용되지 않는 유형

* 게임 앱의 확률형/랜덤 보상 (룰렛·뽑기 등)
* 게임 결과 기반 보상 (점수·승패·등수 기반)
* 재화 환전형 리워드 (기프티콘·상품권 → 토스 포인트 전환)
* 현금 보장형·유사 수신 행위 (투자성·사행성 성격)
* 1인당 5,000포인트 초과 지급 (추첨형은 별도 검토)

## 5. 프로모션 등록

대표 관리자가 약관 동의와 비즈월렛 충전을 완료하면 프로모션 등록이 가능해요.

등록하기 전에, [프로모션 등록 허용/불가 유형](/promotion/console.html#_4-%E1%84%91%E1%85%B3%E1%84%85%E1%85%A9%E1%84%86%E1%85%A9%E1%84%89%E1%85%A7%E1%86%AB-%E1%84%92%E1%85%A5%E1%84%8B%E1%85%AD%E1%86%BC-%E1%84%87%E1%85%AE%E1%86%AF%E1%84%80%E1%85%A1-%E1%84%8B%E1%85%B2%E1%84%92%E1%85%A7%E1%86%BC-%E1%84%92%E1%85%AA%E1%86%A8%E1%84%8B%E1%85%B5%E1%86%AB)을 확인해 주세요.

* 경로: 앱인토스 콘솔 → 대표 관리자 로그인 → 워크스페이스 선택 → 미니앱 선택 → 좌측 메뉴 프로모션 → +등록하기

![](/assets/promotion_console_7.AvxApcyg.png)

### 혜택탭 노출하는 경우

![](/assets/promotion_console_8.DgDyECSt.png)

### 혜택탭 미노출하는 경우

![](/assets/promotion_console_9.BxqZ2r4u.png)

1. **프로모션 이름**

   유저가 어떤 조건을 만족하면 포인트를 받는지 구체적으로 입력해 주세요.\
   예) 서비스 로그인 시 10포인트 지급, 튜토리얼 진행 완료 시 20포인트 지급

2. **프로모션 종료일**

   희망 종료일을 설정해 주세요. 예산 소진 시 예정일보다 먼저 종료될 수 있어요.

3. **혜택 탭 노출 여부**
   * 노출: 토스 앱 → 혜택 → 새로운 서비스 써보고 메뉴에 함께 노출돼요.
   * 미노출: 미니앱을 통해 직접 접속하는 유저에게만 프로모션을 제공해요.
   * 주의: 미노출로 등록 후 나중에 노출하려면 **새 프로모션 등록**이 필요해요. (수정으로는 변경 불가)

4. **미션 이름** (혜택 탭 노출 시 필수)
   * 미션 이름은 ~하기로 끝나야 해요.\
     예) 튜토리얼 하기, 로그인 하기, 리뷰 남기기

5. **지급 방식** (혜택 탭 노출 시 필수)
   * 고정 금액: 정해진 금액 지급
   * 최대 금액: 1인당 최대 지급 가능 금액(랜덤 지급 범위 내)\
     예) 최대 100원 → 1회 참여 시 0~100원 중 지급

6. **이동 URL** (혜택 탭 노출 시 필수)
   * 형식: intoss://{{appName}}/ScreenName
   * 혜택 탭에서 이 URL로 진입하게 돼요.

7. **예산 정보**
   * 예산은 비즈 월렛 잔액보다 크게 설정할 수 없어요.
   * 진행 중 예산 증액이 필요하면 비즈월렛 충전 후 프로모션 수정으로 증액 가능해요.

프로모션 정보를 입력한 뒤 검토 요청하기를 눌러 주세요. 검토는 영업일 기준 2~3일 소요돼요.

***

## 6. 테스트 진행

검토가 완료되면 테스트하기로 테스트를 진행해 주세요. 테스트는 실제 포인트를 차감하지 않아요.

* 테스트 프로모션 코드는 실제 코드 앞에 TEST\_가 붙어요.
* 테스트 시 포인트는 차감되지 않고 실제 지급도 이뤄지지 않아요.
* 포인트 지급 API 호출 시 resultType이 SUCCESS로 응답되는지 확인해 주세요.
* **최소 1번의 포인트 지급 API 테스트**가 완료돼야 프로모션 검토가 승인돼요.

## 7. 프로모션 시작 및 운영

‘시작하기’ 버튼을 눌러 프로모션을 시작해 보세요.

* 예산 열은 { 실제 소진 금액 / 총 예산 } 형태로 표시돼 예산 소진률을 확인할 수 있어요.
* 프로모션 수정은 예산 증액에 주로 사용해요.
* 프로모션 종료 시 남은 예산은 비즈 월렛으로 환급돼요.
* 예산 소진 시 혜택 탭에는 더 이상 노출되지 않으니 예산 관리를 주기적으로 해 주세요.

![](/assets/promotion_console_12.BdtOKL-w.png)

캠페인 이름을 누르면 프로모션 상세 정보를 확인하고 수정, 종료, 일시정지를 할 수 있어요.

* 수정은 주로 예산을 증액할 때 사용해요.\
  예산 증액 방법 예시: 캠페인 상세 → 프로모션 수정 버튼 → 증액할 금액 입력 → 저장\
  예산 외 설정을 변경하려면 내부 정책상 제한이 있을 수 있으니 검토 가이드라인을 먼저 확인해 주세요.
* 프로모션이 종료되면 남은 예산은 자동으로 비즈 월렛으로 환급돼요.\
  환급 금액은 프로모션 종료 후 즉시 반영되는 경우가 많지만, 시스템 처리로 인해 반영 시점에 약간의 지연이 발생할 수 있어요.

::: tip 간단한 운영 팁

* 예산을 자주 모니터링해서 소진으로 인한 자동 종료를 방지해 주세요.
* 혜택 탭 노출 여부는 수정으로 변경할 수 없으니 노출 설정은 등록 전 최종 확인해 주세요.
  :::

## 8. 성과 대시보드 확인

프로모션을 시작하면 해당 프로모션의 성과를 대시보드에서 확인할 수 있어요.\
이 대시보드는 프로모션이 얼마나 효과적이었는지 한눈에 보여 주고, 이후 캠페인 전략을 개선하는 데 도움을 줘요.

* 접속 방법: 앱인토스 콘솔 접속 → 워크스페이스 선택 → 미니앱 선택 → 프로모션 → 성과 탭

### 기간 설정 및 조회 조건

성과 데이터는 다양한 기준으로 조회할 수 있어요. 분석 목적에 맞게 조건을 바꿔가며 살펴보면 좋아요.

* **일별, 주별, 월별** 단위로 데이터를 조회할 수 있어요.
* **운영체제(OS)별**로 나눠서 성과를 확인할 수 있어요.
* 현재 미니앱에서 운영 중인 전체 프로모션과 개별 프로모션을 구분해서 조회할 수 있어요.

다만, **혜택 탭에 노출하지 않은 프로모션은 성과 대시보드에 표시되지 않아요.**\
이렇게 확인한 성과 데이터를 바탕으로 어떤 프로모션이 효과적이었는지 파악하고, 다음 캠페인에서는 더 나은 전략을 세울 수 있어요.

### 최종 전환율

프로모션 성과 대시보드에서는 유저가 프로모션에 참여하는 흐름을 단계별로 확인할 수 있어요.\
이 흐름을 보면 **최종 전환율**을 알 수 있고, 어느 단계에서 유저가 많이 이탈하는지도 파악할 수 있어요.\
각 단계의 이탈 구간을 기준으로 프로모션 메시지나 참여 조건을 조정하면 성과를 더 개선할 수 있어요.

![](/assets/promotion_dashboard_1.DIIyr89p.png)

1. **혜택탭 진입**\
   토스 앱의 혜택탭에서 해당 프로모션이 노출되고, 이를 확인한 유저 수예요.\
   이 수치는 프로모션이 얼마나 많은 유저에게 도달했는지를 보여줘요.
2. **프로모션 클릭**\
   혜택탭에서 프로모션을 실제로 클릭해 상세 화면으로 진입한 유저 수예요.\
   혜택탭 진입 대비 클릭 수를 보면, 프로모션 제목이나 썸네일이 유저의 관심을 얼마나 끌었는지 알 수 있어요.
3. **포인트 획득**\
   프로모션 조건을 충족하고 토스 포인트를 실제로 지급받은 유저 수예요.\
   이 단계는 최종 전환을 의미하며, 조건이 어렵거나 과정이 복잡하면 이탈이 크게 발생할 수 있어요.

### 유입 유저

프로모션으로 유입된 유저의 성격을 기준으로 성과를 나눠서 확인할 수 있어요.\
이를 통해 이번 프로모션이 어떤 유저에게 더 효과적이었는지 파악할 수 있어요.

![](/assets/promotion_dashboard_2.DTkvKg-O.png)

* **신규 유저**\
  프로모션을 계기로 처음 미니앱에 유입된 유저예요.\
  이 수치를 보면 프로모션이 신규 유저 유입에 얼마나 기여했는지 알 수 있어요.
* **기존 유저**\
  과거에 미니앱 서비스를 이용한 이력이 있는 유저예요.\
  이 수치는 프로모션이 기존 유저의 재방문이나 재구매를 얼마나 유도했는지를 보여 줘요.

이 유저 유형별 데이터를 함께 보면,\
프로모션이 신규 유저 확보를 목표로 한 캠페인이었는지,\
아니면 기존 유저의 재참여를 유도하는 캠페인이었는지를 명확하게 분석할 수 있어요.\
분석 결과에 따라 다음 프로모션에서는 메시지 구성이나 혜택 조건을 유저 유형에 맞게 조정할 수 있어요.

### 기여 매출

프로모션이 실제 매출에 얼마나 기여했는지도 확인할 수 있어요.\
이 지표를 보면 프로모션 비용 대비 효과를 판단할 수 있고, 유저 한 명이 만들어 내는 가치도 함께 살펴볼 수 있어요.\
다만, 토스페이를 연동한 미니앱은 제약이 있어요.\
기여 매출은 워크스페이스(사업자 번호) 단위로만 조회할 수 있고, 미니앱별로는 조회할 수 없어요.

![](/assets/promotion_dashboard_3.CgGRyebl.png)

* **총 기여 매출**\
  프로모션을 통해 유입된 유저들이 발생시킨 전체 매출 금액이에요.\
  이 값으로 프로모션이 매출에 얼마나 직접적으로 기여했는지 파악할 수 있어요.
* **결제자 기준 1인당 평균 매출**\
  프로모션으로 유입된 유저 중 **실제로 결제한 유저만**을 기준으로 계산한 평균 매출이에요.\
  구매까지 이어진 유저 한 명이 평균적으로 얼마를 결제했는지 보여 줘요.
* **전체 유저 기준 1인당 평균 매출**\
  결제 여부와 관계없이, **프로모션으로 유입된 전체 유저(결제자와 미결제자 포함)** 를 기준으로 계산한 평균 매출이에요.\
  이 지표를 보면 유입된 유저 전체를 기준으로 했을 때 프로모션의 효율을 판단할 수 있어요.

## 사용자 안내 필수 항목 (프로모션 고지 문구)

프로모션을 안내할 때 반드시 다음 정보를 고지해 주세요.

* 지급 시점(예: 즉시 지급, 익일 18시 지급 등)
* 지급 조건(예: 최초 결제, 5,000원 이상 결제 등)
* 지급 제한(탈퇴·환불·부정 참여 시 지급 불가)
* “본 프로모션은 사전 고지 없이 중단될 수 있습니다” 문구 포함
* 랜덤 지급 불가(고정 지급만 허용)

## 정산 및 운영 원칙

* 프로모션 예산은 비즈 월렛에서 충전 후 설정하고, 예산 소진 시 프로모션이 종료돼요.
* 프로모션 중단 시 남은 예산은 비즈 월렛으로 반환돼요(잔액이 있을 경우).
* 중복 참여·어뷰징 방지 로직 적용은 필수예요.
* 클레임 발생 시 참여 기록 확인 후 파트너사에서 처리해야 해요.

□ 제공 되는 포인트가 게임의 결과 또는 등수 기반으로 산정 되는 것은 아닌가요?\
□ 유저가 보유한 재화를 토스포인트로 교환/전환 해주는 형태의 프로모션은 아닌가요?\
□ 진행 되는 프로모션의 조기 종료 혹은 중단 가능성을 사전 고지했나요?\
□ 중복 참여 방지 로직을 적용했나요?\
□ 사행성 또는 과장된 프로모션은 아닌가요?
