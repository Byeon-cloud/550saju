## Phase 1: 디자인 시스템 (페이지명: "Design System")

Figma에 "Design System" 페이지를 만들고 다음을 정리해줘:

### 1-1. 컬러 팔레트
라이트 프리미엄 방향. 밝고 깨끗하면서 고급스러운 느낌.
- 브랜드: 메인 컬러 + 보조 컬러 + 포인트(골드) — 사각형 스와치로
- 배경: 페이지 / 카드 / 서피스 / 오버레이
- 텍스트: primary / secondary / muted / hint / disabled
- 테두리: default / light / focus
- 기능: success(초록) / warning(주황) / danger(빨강) / info(파랑) / special(보라)
- 오행 5색: 목(초록) / 화(빨강) / 토(황금) / 금(회색) / 수(파랑) — 각각 light/main/dark 3단계

색상 선정 기준:
- 사주 앱이지만 무속인/점집 느낌은 절대 아님
- 토스처럼 깔끔하면서도, 운세 앱만의 특별한 분위기가 있어야 함
- 흰색 기반 + 미세한 그라디언트로 프리미엄 느낌
- 오행 컬러는 인포그래픽 전용으로만 사용

### 1-2. 타이포그래피
폰트: Pretendard
스케일 (전부 샘플 텍스트와 함께):
- Display: 26px / 900 — 메인 타이틀
- H1: 20px / 800 — 섹션 제목
- H2: 16px / 700 — 서브 제목
- H3: 14px / 700 — 카드 제목
- Body: 14px / 400 / line-height 1.8 — 본문
- Body-sm: 13px / 400 — 보조 본문
- Caption: 12px / 400 — 캡션
- Label: 11px / 600 — 라벨, 뱃지
- Tiny: 10px / 500 — 최소 텍스트

### 1-3. 간격 시스템
4 / 8 / 12 / 16 / 24 / 32 / 48px 박스로 시각화

### 1-4. 라운딩
6px (뱃지) / 8px (버튼) / 12px (일반 카드) / 16px (강조 카드) / 20px (모달) / full (원형)

### 1-5. 그림자
sm / md / lg / xl 4단계, 실제 적용된 카드 예시와 함께

## Phase 2: 컴포넌트 라이브러리 (페이지명: "Components")

Figma에 "Components" 페이지를 만들고, 재사용 가능한 컴포넌트를 전부 만들어줘:

### 2-1. 버튼 (4종)
- Primary CTA: 높이 52px (앱인토스 TDS 규격), 라운딩 12px, 전체 너비
  - 상태: default / hover / active / disabled / loading
- Gold CTA: 골드 배경, 프리미엄/강조 전용
- Secondary: 투명 배경 + 테두리
- Ghost: 투명, 텍스트만

### 2-2. 카드 (4종)
- 기본 카드: 흰 배경, 연한 테두리, 가벼운 그림자
- 강조 카드: 메인 컬러 테두리, 더 큰 그림자 (만세력 원국 등)
- 골드 카드: 골드 그라디언트 배경 (오늘의 운세 등)
- 경고/안내 카드: 4종 (성공/경고/위험/정보)

### 2-3. 입력 필드
- 높이 48px, 라운딩 12px
- 상태: default / focus / error / disabled
- 라벨 + 필드 + 에러 메시지 조합

### 2-4. 탭바 (하단)
- 4개 탭: ☯️홈 / 🔮운세 / 📁보관함 / 👤마이
- 높이: 56px + safe-area-bottom 영역 표시
- 상태: active / inactive
- 앱인토스: 커스텀 홈/뒤로 버튼 금지 주석 표시

### 2-5. 헤더
- 높이: 48px + safe-area-top
- 뒤로가기(←) + 중앙 타이틀 + 우측 액션
- 앱인토스: 시스템 백 버튼 사용 주석

### 2-6. 모달 / 바텀시트
- 오버레이 + 카드 (라운딩 20px)
- 핸들바: 40×4px, 상단 중앙
- 버튼: 52px (TDS 규격)
- 앱인토스: window.confirm/alert 금지, 반드시 이 모달 사용 주석

### 2-7. 뱃지/태그
- 기본 / 강조 / 골드 / 성공 / 경고 / 위험
- 라운딩 full, 패딩 수평 8px

### 2-8. 토스트
- 하단 탭바 위, 3초 후 사라짐
- 다크 배경 + 흰 텍스트

### 2-9. 만세력 카드 (특수 컴포넌트)
- 4기둥 (년주/월주/일주/시주) 각각
- 구조: 라벨(년주 年柱) → 천간 영역(한자+한글+십성 뱃지) → 구분선 → 지지 영역(한자+한글+십성 뱃지)
- 일주: ★나 표시 상단 바
- 시주 미입력: 점선 테두리 + 🕐 + "출생시간 미입력" 오버레이
- 천간/지지 배경: 해당 오행 컬러 그라디언트
- 4기둥일 때 한자 32px, 3기둥일 때 40px

### 2-10. 점수 링 (SVG)
- 원형 프로그레스, 6개 (직업/애정/재물/대인/건강/잠재력)
- 중앙에 이모지 + 점수

### 2-11. 대운 카드
- 간지(한자) + 한글 + 나이 + 기간 + 라벨 + 오행 이모지
- 현재 대운: 강조 테두리 + "현재" 뱃지

### 2-12. 스켈레톤 로딩
- 카드 형태 shimmer 애니메이션

## Phase 3: 화면 디자인 (페이지명: 각 화면별)

프레임 사이즈: 375×812 (iPhone 13/14 기준)
모든 화면에 하단 탭바 포함 (해당 탭 active 상태)
앱인토스 safe-area 상하단 반영

### 3-1. "홈" 페이지
이 화면이 가장 중요함. 유저가 처음 보는 화면이고, 여기서 이탈하면 끝.

포함할 요소 (위→아래 스크롤):
1. 상단: 로고 "550사주" + 슬로건 + 알림 아이콘
2. 오늘의 운세 카드 (골드 그라디언트, 탭하면 운세 페이지로)
   - 날짜 + 짧은 운세 미리보기 3줄 + "자세히 보기" 링크
3. 메인 CTA: "내 사주 보기 →" (52px, 가장 눈에 띄게)
4. 가로 스크롤 서비스 카드 (카드 3~4장):
   - 💕 궁합 (1운) 
   - 📅 대운 해설 (1운)
   - 📆 연도별 운세 (1운)
   - 🔮 AI 상담 (준비중)
5. 최근 분석 카드 (로그인 시):
   - 프로필 이미지/이니셜 + 이름 + 날짜 + 간단 요약
   - 여러 개면 세로 리스트
6. 이벤트/프로모션 배너 (가로 스크롤 or 자동 슬라이드):
   - "첫 사주 무료!" / "궁합 50% 할인" 등 (디자인만, 기능은 나중에)
7. 하단: "550사주 소개" 간단 텍스트 + 이용약관/개인정보 링크
8. 탭바 (홈 active)

핵심: 스크롤하면서 "와 볼게 많다" 느낌이 나야 함. 빈 화면 절대 안 됨.
참고: 사주아이는 홈에서 바로 입력 폼이 나옴. 우리는 콘텐츠 먼저 보여주고 → CTA로 유도.

### 3-2. "사주 입력" 페이지 (6단계)
각 단계를 별도 프레임으로:

Step 1: 이름 + 관계 선택 (본인/친구/가족/연인/직접입력)
- 스텝 인디케이터 (6개 바, 현재 진행 하이라이트)
- 이름 입력 필드 + 관계 선택 칩

Step 2: 생년월일
- 양력/음력/윤달 선택 탭
- 년/월/일 피커 (드롭다운 또는 스크롤 피커)

Step 3: 성별
- 남/여 큰 카드 선택 (아이콘 포함)

Step 4: 출생시간
- "알아요" / "몰라요" 큰 카드 선택
- 알아요 → 시간 피커 + "정확한 시간인가요?" (정확/대략)
- 몰라요 → "6글자로 분석합니다" 안내

Step 5: 만세력 미리보기
- 만세력 카드 4기둥 미니 버전
- 기본 정보 확인 (이름/생년월일/띠)
- "맞아요, 분석해주세요" CTA + "다시 입력" 링크

Step 6: 상황 질문 (선택사항)
- 연애 상태: 칩 선택 (솔로/연애중/결혼/돌싱/직접입력)
- 직업 상태: 칩 선택 (학생/취준/직장인/자영업/주부/은퇴/직접입력)
- 궁금한 점: 자유 텍스트 (100자)
- "건너뛰기" 옵션

### 3-3. "로딩" 페이지
- 전체 화면, 배경에 미세한 그라디언트/파티클
- 중앙: ☯️ 또는 오행 심볼 회전 애니메이션 표현
- 아래: 진행 단계 텍스트 (5단계 fade 전환):
  "만세력을 계산하고 있어요..."
  "사주의 구조를 분석하고 있어요..."
  "오행의 균형을 살펴보고 있어요..."
  "대운의 흐름을 읽고 있어요..."
  "리포트를 작성하고 있어요..."
- 프로그레스 바 (5단계)
- "약 15~20초 소요" 보조 텍스트
- 탭바 숨김

docs/550saju_result_v4.jsx 구조를 그대로 피그마로 옮겨. 스크롤 순서:

9. 납음 (아이콘 + 한자 + 설명)

14. 푸터
15. 탭바 숨김

### 3-5. "오늘의 운세" 페이지
1. 날짜 + "오늘의 운세" 타이틀
2. 감성 질문 3개 (선택지 + 직접입력):
   - "오늘 기분은 어때요?" (4지선다)
   - "요즘 가장 신경 쓰이는 건?" (4지선다)
   - "오늘 하루 어떻게 보내고 싶어요?" (4지선다)
3. 운세 결과 카드 (AI 생성):
   - 전체 운세 요약 (3~4줄)
   - 카테고리별 미니 점수 (연애/직장/재물/건강)
   - 오늘의 행운 아이템/컬러/방위
   - 한 줄 조언
4. "더 깊이 보고 싶다면" → 사주 리포트 CTA
5. 탭바 (운세 active)

### 3-6. "충전" 페이지

4. 선택된 패키지 강조 (테두리 변경)
5. "결제하기" CTA (52px)
6. 약관 안내 (11px): 유효기간, 보너스 환불 불가
7. 탭바 숨김

### 3-7. "궁합" 페이지

## Phase 4: 유저플로우 연결 (페이지명: "User Flow")

Figma에 "User Flow" 페이지를 만들고:
1. 모든 화면을 작게 배치
2. 화면 간 화살표로 연결

## Phase 5: 앱인토스 체크리스트 (페이지명: "AIT Checklist")

각 화면 옆에 앱인토스 규격 체크 메모:
- safe-area-top/bottom 여백 확인
- 버튼 높이 52px 이상
- window.confirm/alert 미사용
- 커스텀 뒤로가기/홈 버튼 없음
- 모달: TDS 규격 (52px 버튼)
- 아이콘: 정사각형, 배경 꽉 참
- 터치 타겟: 최소 44×44px

## 디자인 원칙 (모든 화면 공통)

1. 모바일 퍼스트 375×812px
2. "라이트 프리미엄": 밝고 깨끗하면서 고급스러운 — 무속인/점집 느낌 절대 아님
3. 캐릭터 없음. 비주얼은 오행 컬러 + 그라디언트 + 인포그래픽으로
4. 한자는 반드시 한국어 병기
5. 여백이 세련됨 — 빽빽하게 채우지 않음
6. 오행 컬러는 인포그래픽 전용 — 일반 UI에 섞지 않음
7. 사주아이보다 디자인적으로 확실히 우위에 있어야 함
8. 스크롤 시 "볼게 많다" 느낌 — 홈에서 특히 중요
