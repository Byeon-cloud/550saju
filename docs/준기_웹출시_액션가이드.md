# 준기 웹출시 액션 가이드 (직접 할 것 · 순서대로)

> Claude가 할 코드/배포 작업 말고, **준기만 할 수 있는 것**들. 위에서부터 순서대로.
> 막히면 각 단계 Claude한테 물어보면 됨.

---

## STEP 1. 통신판매업 신고 — 지금 바로 (승인에 며칠 걸림 → 먼저 시작)
**왜**: 법인이 웹에서 직접 판매 → 거래 50건 넘으면 법적 의무. 신고번호를 사이트에 표시해야 함.
**어떻게**:
1. **정부24**(gov.kr) 접속 → "통신판매업 신고" 검색 → 신청.
2. 준비물: 법인 사업자등록증, **구매안전서비스 이용확인증**(= 결제대행사가 발급. 토스페이먼츠 가맹하면 발급받거나, 은행 에스크로). 토스페이먼츠 계약 시 같이 처리됨.
3. 등록면허세 ~4만원대 납부.
4. 보통 3영업일 내 신고증 발급 → **신고번호** 나옴.
5. 👉 신고번호 나오면 **Claude한테 알려주기** → `businessInfo.ts` 한 줄 교체.
**소요**: 신청 30분 + 승인 3일.

## STEP 2. 도메인 구매 — 가장 먼저 결과 필요 (이게 있어야 3·4번 가능)
**왜**: `appintoss-saju.web.app`은 브랜딩·SEO 약함. 내 도메인 필요.
**어떻게**:
1. **가비아**(gabia.com) 또는 후이즈(whois.co.kr) 접속 → 회원가입.
2. 원하는 도메인 검색 (예: `saju500.com`, `saju500.kr`, `사주500.com`). 가능한 거 선택.
   - 추천: `.com`(글로벌) 또는 `.kr`(국내신뢰). 둘 다 사도 됨(.kr→.com 리다이렉트).
   - 비용: 연 1~2만원.
3. 결제 → 구매 완료. (개인정보 보호 옵션 ON 권장)
4. 👉 산 도메인을 **Claude한테 알려주기**.
**소요**: 15분.

## STEP 3. 도메인 → Firebase Hosting 연결 (도메인 산 뒤)
**왜**: 산 도메인으로 우리 사이트가 뜨게.
**어떻게**:
1. **Firebase Console**(console.firebase.google.com) → 프로젝트 `appintoss-saju` → **Hosting** → "맞춤 도메인 추가".
2. 산 도메인 입력 → Firebase가 **DNS 레코드**(A 레코드 2개 또는 TXT) 알려줌.
3. **가비아 → My가비아 → DNS 관리 → 레코드 추가**에 그대로 입력.
4. Firebase가 자동으로 SSL(https) 발급 (몇 시간~하루).
5. 막히면 Claude한테 Firebase가 준 레코드 보여주면 안내해줌.
**소요**: 입력 20분 + 전파 대기 몇 시간.

## STEP 4. 콘솔 설정 3종 (도메인 연결 후)
### 4-1. Firebase Auth 승인 도메인
- Firebase Console → **Authentication → Settings → 승인된 도메인** → 새 도메인 추가.
- (안 하면 구글·카카오·네이버 로그인 전부 실패)
### 4-2. 토스페이먼츠 웹 가맹 + 도메인 등록
- **토스페이먼츠 가입**(tosspayments.com) → 법인 사업자로 가맹 계약(심사 며칠).
- 상점관리자 → 웹 도메인 등록 + **라이브 클라이언트키** 발급.
- 👉 라이브 키 Claude한테(또는 직접 빌드 환경 `.env`에) 입력.
- (STEP 1 통신판매 신고용 "구매안전서비스 확인증"도 여기서 받음)
### 4-3. 카카오·네이버 로그인 도메인
- **카카오 개발자**(developers.kakao.com) → 내 앱 → 플랫폼 → Web 사이트 도메인에 새 도메인 추가 + Redirect URI(Firebase가 주는 OIDC handler URL — Claude가 알려줌).
- **네이버 개발자센터**(developers.naver.com) → 동일.

## STEP 5. Claude한테 넘기기
도메인·키 준비되면 Claude가:
- og:image·canonical·sitemap URL을 새 도메인으로 교체
- 결제·로그인 실작동 점검
- **배포** (hosting → ait 순서)

## STEP 6. 검색엔진 등록 (배포 후 — 검색 노출의 마지막 단계)
### 6-1. 구글 서치콘솔
- search.google.com/search-console → 속성 추가 → 도메인 입력 → 소유확인(DNS TXT, 가비아에 입력) → **sitemap 제출**(`도메인/sitemap.xml`).
### 6-2. 네이버 서치어드바이저
- searchadvisor.naver.com → 사이트 등록 → 소유확인(HTML 메타태그 or 파일 — Claude가 넣어줌) → **sitemap 제출** + "수집 요청".
**소요**: 각 20분. 색인까지 며칠~몇 주.

---

## 의존 관계 요약
```
STEP1 통신판매신고 ──(병렬, 며칠)──┐
STEP2 도메인구매 → STEP3 연결 → STEP4 콘솔 → STEP5 Claude(URL교체+배포) → STEP6 검색등록
                                    ↑ 토스페이먼츠 가맹이 STEP1 구매안전확인증도 해결
```
**가장 먼저**: STEP1(승인 오래걸림) + STEP2(나머지 다 막힘) 동시 시작.
