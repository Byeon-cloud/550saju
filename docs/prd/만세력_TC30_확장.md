# 만세력 TC30 확장 (Test Cases Expansion)

> **문서 성격**: 만세력 계산 엔진의 회귀 방지(regression prevention) 테스트 케이스 확장판. 기존 `만세력_30분보정.md` 의 핵심 로직 + 본 문서의 30개 TC로 계산 정확성 보장.
>
> - 구성: 카테고리별 30 TC + 기대값 테이블 + 회귀 방지 원칙
> - 사용: `src/services/saju/calculator.ts` 변경 시 전수 실행
> - 원칙: TC 하나라도 실패 시 배포 금지
> - 테스트 러너: Vitest 기반, `src/services/saju/calculator.test.ts`

---

## 0. 테스트 철학

### 0.1 TC 설계 원칙

1. **경계값 우선**: 자정·입춘·서머타임·윤달 등 경계에서 오차 발생
2. **실제 사례 기반**: 조작된 값 아닌 실제 사주 사례 사용
3. **다학파 교차검증**: 홍성민·박재완·대만식 등 여러 학파가 동의하는 결과를 기대값으로
4. **멱등성**: 같은 입력은 항상 같은 출력
5. **JSON 고정**: 기대값은 JSON으로 저장, 코드 변경 시 비교

### 0.2 TC 카테고리

- A. 기본 변환 (6 TC)
- B. 시간 보정 (8 TC)
- C. 경계 케이스 (8 TC)
- D. 시간 미입력 (2 TC)
- E. 음력·윤달 (3 TC)
- F. 해외·타임존 (3 TC)

## 7. 회귀 방지 원칙

### 7.1 TC 추가 규칙

1. 새 기능 추가 시 최소 1개 TC 추가
2. 버그 수정 시 해당 버그 재현 TC 추가 ("regression test")
3. 학파별 논쟁 케이스는 "note" 에 근거 명시
4. 기대값은 JSON 파일로 분리 (`src/services/saju/calculator.fixtures.json`)

### 7.2 CI 통합

- GitHub Actions에서 PR 시 `vitest run calculator` 자동 실행
- 실패 시 머지 차단
- 매일 자정 full regression run

### 7.3 수동 검증

- 분기별 외부 명리학 전문가 1명에게 샘플 10개 리뷰 의뢰
- 불일치 발견 시 TC 수정 또는 학파별 근거 추가
