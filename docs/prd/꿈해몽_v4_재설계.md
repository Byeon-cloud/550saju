# 꿈해몽 v4 재설계 — 무료 퀄리티 극대화 + 블러 잠금 전환

> DreamPage 전면 재작성. 무료부터 이미 "AI같지 않은 고퀄" → 핵심 알짜배기만 블러로 잠금 → 500원 결제 유도.
> **최종 업데이트: 2026-04-19**

---

## 1. 목표·원칙

### 1.1 비즈니스 목표
- 꿈해몽 페이지는 **무료 획득 → 유료 전환**의 3대 퍼널 중 하나
- 무료 체험만으로도 "이건 달라" 체감 → 사주 리포트 500원 결제로 연결
- 재방문 훅 (매일 다른 꿈, 바로 해몽)

### 1.2 퀄리티 바
- 무료 버전 출력 총 분량 **2800~3200자** (현재 ~1200자의 2.5배)
- 인포그래픽 4종 이상 삽입
- 인터랙션 5종 (P0) 전부 작동
- 사주 연동 시 사주 시각화 필수

### 1.3 원칙
- **무사주 유저**도 꿈해몽 자체는 고퀄리티 제공 (사주 입력 CTA는 별도 존재)
- **사주 있음 유저**는 사주 × 꿈 연결 해석이 절대적 차별화 포인트
- **블러 잠금 = 알짜배기만** — 전망/행동조언 구체/행운 프로필/주제 심층
- UX는 "점집 들어간 느낌"이 아니라 "좋은 앱 쓰는 느낌"

## 2. 유저 플로우

```
홈 → 꿈해몽 탭
  ↓
[Phase 1] 카테고리 선택 (자유입력 포함)
  ↓
[Phase 2] 꿈 내용 입력 + 요즘 머릿속 (선택)
  ↓
[Phase 3] AI 분석 중 (로딩)
  ↓
[Phase 4] 무료 결과 페이지
  ├─ (사주 있음) 사주 연결 해석 + 블러 잠금 2~3곳
  └─ (사주 없음) 꿈 상징 중심 해석 + 사주 입력 CTA
  ↓
[Phase 5a] 유저 탭: 블러 잠금 해제 → 결제 모달 → Firestore 1운 차감 → 심층 결과 페이지 (Opus 4.6 → Sonnet 4.6 로 조정 가능)
  OR
[Phase 5b] 유저 탭: 주제별 심층 카드 → 별도 주제 분석 페이지 (TopicAnalysisPage)
  OR
[Phase 5c] 유저 탭: 사주 리포트 CTA → InputPage (회원가입/프로필)
```
