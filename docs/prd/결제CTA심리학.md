## 1. 목적 (Goal)

**"클릭이 아니라 확신을 만든다."**

대부분의 결제 CTA는 "지금 구매하기" 같은 기계적 명령어다. 하지만 사주500 유저는 구매 전에 **"이게 진짜일까?"** "이 가격이 맞을까?" "나중에 후회하지 않을까?" 라는 세 가지 의심을 거친다. CTA는 이 의심을 **1초 안에 녹여야 한다**.

이 PRD는 사주500 전역의 모든 결제 CTA가 따라야 할 **심리 공식 · 카피 템플릿 · 색·위치 규칙**을 정의한다.

**성공 지표:**
- 주요 CTA 전환율(클릭→결제 완료) ≥ 40%.
- A/B 실험 통해 기본 대비 ≥ 20% 개선 카피 발굴.
- "광고 같다" 부정 피드백 ≤ 5%.

## 2. 심리 원리 (Foundational Principles)

사주500의 CTA는 아래 **5가지 심리 축**을 조합해서 설계한다.

### 2.1 구체적 가치 명시 (Specific Value)

❌ "지금 보기"  
✅ "10섹션 전부 500원으로 열기"

- 유저는 **"무엇이 열리는지"**를 1초 안에 알아야 한다.
- 모호한 "더 보기" 금지.
- 숫자 포함 원칙 ("10섹션", "12개월", "30분").

### 2.2 가격의 일상화 (Price Framing)

❌ "프리미엄 500원"  
✅ "커피값 1/5로 내 사주 전부"

- 500원을 "돈"이 아닌 "커피값·편의점 껌·버스비" 등 일상적 단위로 환산.
- 5,000원은 "한 끼 식사값" 수준으로 프레이밍.
- **"~도 안 되는 가격"** 공식이 강력.

### 2.3 단수 가격 + 리워드 차감 연출

❌ "500원 결제"  
✅ "497원에 시작하기" (리워드 3원 적용 시)  
✅ "지갑 500원으로 바로"

- 정확한 숫자는 "계산된" 느낌 → 신뢰.
- 리워드 적용 표기는 **"할인이 아니라 지갑에서 차감됨"** 톤으로 — "무료 같다"는 착각.

### 2.4 공백 공포 (Fear of Missing Info)

블러 밑 공백은 유저의 뇌에 **"저 아래가 내 인생의 답인데, 안 보여"** 감정을 만든다. CTA는 이 감정을 직접 건드린다.

❌ "결제하고 열기"  
✅ "블러 아래의 9섹션을 지금 확인하기"  
✅ "가려진 부분이 당신의 답입니다"

- 구체적으로 "블러", "가려진", "숨겨진"이라는 단어 사용.
- 단, 과장·공포 마케팅은 금지 — **"공백 + 호기심"** 수준 유지.

### 2.5 사회적 증거 (Social Proof)

❌ (없음)  
✅ "오늘만 324명이 확인했어요"

- CTA 바로 위 또는 아래에 **숫자 기반 소셜프루프 1줄** 필수.
- 별점 금지 (소셜프루프 PRD 참조).
- "~님이 방금" 미세한 실시간 신호가 효과적.

## 3. 카피 공식 (Copy Formulas)

### 3.1 기본 공식

```
[동사] + [구체적 가치 / 숫자] + [가격]
```

예:
- "10섹션 전부 **열기** · 500원"
- "내 사주를 **확인하기** · 497원 (지갑에서 차감)"
- "12개월 월운을 **보기** · 5,000원"

### 3.2 공백 공포 공식

```
[블러 아래 무엇] + [행동 유도]
```

예:
- "블러 아래의 답을 지금 확인하기"
- "가려진 9섹션을 전부 열기 · 500원"

### 3.3 가격 일상화 공식

```
[일상 단위 환산] + [우리 상품]
```

예:
- "커피값의 1/5로 내 사주 전부"
- "편의점 간식값이면 궁합까지"

### 3.4 비교 공식 (500 vs 5,000)

```
[저가 만족] + [10배 깊이 약속]
```

예:
- "500원이 마음에 드셨다면, 10배 깊이는 5,000원"
- "이 분석, 1년치로 보시겠어요? · 5,000원"

### 3.5 금지 패턴

| 패턴 | 이유 |
|---|---|
| "지금 결제하기" | 명령형, 압박감 |
| "놓치지 마세요" | 광고 같은 톤 |
| "오늘만 특가" | 거짓 긴급성 (프로모 기간 외) |
| "무료!!!" | 과도한 강조 |
| "결제 없이 바로 보기" | 모호 |
| 이모지 남발 🔥💰✨ | 브랜드 톤 파괴 |

## 4. 위치별 CTA 명세

### 4.1 홈 상품 카드

**위치:** 홈 상품 진열 각 카드.  
**크기:** 전체 폭, 52px 높이 (모바일).  
**색:** 골드브라운 #A08B6A 배경, 크림 글자.

**카피 (상품별):**
- 오늘의 운세: **"오늘의 한 줄 보기"** (무료 라벨)
- 꿈해몽: **"해몽 보기 · 500원"** (작은 블러 라벨)
- 심층분석: **"내 사주를 500원으로 열기"**
- 프리미엄: **"10배 깊이로 · 5,000원"**
- 궁합: **"그 사람과의 궁합 · 5,000원"**

### 4.2 블러 페이지 (최중요)

**위치:** 블러 페이지 하단 sticky.  
**크기:** 전체 폭, 52px 높이.

**구성:**
```
[ 지갑 500원 · 497원으로 시작 ]   ← 가격 정보 (12px, 연한 글자)
┌─────────────────────────────┐
│ 블러 아래 9섹션을 지금 열기 │   ← 메인 CTA (52px, 골드 버튼)
└─────────────────────────────┘
[ 오늘만 324명이 확인했어요 ]     ← 소셜프루프 (12px, 연한 글자)
```

**A/B 테스트 후보:**
- A: "블러 아래 9섹션을 지금 열기"
- B: "10섹션 전부 열기 · 500원"
- C: "내 이야기를 확인하기 · 500원"

### 4.3 리포트 하단 업셀 (500→5000)

**위치:** 섹션 10(개운법) 하단.  
**구성:**
```
┌───────────────────────────────────┐
│ 이 분석, 10배 깊이로 보실래요?     │
│                                   │
│ 500원 분석 + 월운 12개월 + 궁합 +  │
│ 대운 + PDF 다운로드               │
│                                   │
│ [ 프리미엄으로 · 5,000원 ]        │
└───────────────────────────────────┘
```

- 카피: "10배 깊이" — 가격 10배(500→5,000)의 정당화.
- 내용 나열은 **혜택을 부릉 나열**이 아니라 "+" 로 **더해지는 구조**.

### 4.4 대화 종결 후

**위치:** 사주대화 종결 카드.  
**조건:** 대화에서 언급된 주제 기반 추천.  
**예시 카피:**
- "직업에 대해 더 깊이 보시겠어요? · 500원 (직업·재능 심층분석)"
- "배우자와의 궁합을 정리해볼까요? · 5,000원 (궁합 리포트)"

### 4.5 꿈해몽 블러

**위치:** 꿈해몽 3줄 중 2줄 블러 아래.  
**카피:** "이 꿈의 숨은 해석을 500원으로 풀어보기"

### 4.6 관계망 "새 관계 추가"

**위치:** 관계 프로필 등록 완료 직후.  
**카피:** "○○님과의 궁합을 500원으로 풀어볼까요?"

### 4.7 절기 푸시

**위치:** 절기 인사이트 인박스 하단.  
**카피:** "이 절기의 전체 해석은 500원 · 읽기"

### 4.8 보관함 빈 상태

**위치:** 보관함 비로그인/빈 상태.  
**카피:** "아직 열어본 리포트가 없어요 · 내 사주 보기 500원"

### 4.9 런칭 프로모 기간 CTA

- 평상시: "500원으로 열기"
- 프로모: **"런칭 기념 · 무료로 열기"** (빨간 포인트 컬러 아님, 크림+골드 유지)
- 프로모 D-1: **"내일 자정까지 무료"**

## 5. 색·타이포·모션

### 5.1 색상 규칙

| 상태 | 배경 | 글자 | 테두리 |
|---|---|---|---|
| 기본 (평상) | #A08B6A (골드브라운) | #FFFFFF (크림) | 없음 |
| 호버/누름 | #8A7655 (딥 골드) | #FFFFFF | 없음 |
| 비활성 | #D7CFC0 (라이트 그레이) | #A89D8B | 없음 |
| 프로모 | #A08B6A (골드브라운 유지) | #FFFFFF | 골드 얇은 라인 애니메이션 |
| 위험/환불 | #FFFFFF | #D32F2F | 1px 솔리드 |

**절대 금지:**
- 파랑·빨강 CTA (브랜드 톤 충돌).
- 그라디언트 (AI 같은 느낌).
- 그림자 4px 이상 (과한 네온 느낌).

### 5.2 타이포

- 폰트 굵기: 600 (SemiBold).
- 크기: 16px (모바일), 18px (데스크톱).
- 자간: -0.01em.
- 줄간: 1.0 (1줄 기준).
- 버튼 내 텍스트는 **좌·우 16px 패딩** 확보.

### 5.3 모션

- 호버: 배경색 80ms 전환.
- 누름: scale(0.98) 100ms.
- 로딩: 버튼 내 은은한 스피너 (과한 회전 아닌, 파동형).
- **절대 금지:** pulse 반복 (어그로 느낌), rainbow 애니메이션.

## 6. A/B 테스트 프레임워크

### 6.1 테스트 우선순위

| 우선 | 대상 | 가설 |
|---|---|---|
| P0 | 블러 페이지 CTA 카피 | "공백 공포" 카피가 "가치 명시" 대비 +15% |
| P0 | 3원 리워드 표기 ("497원" vs "500원 · 3원 자동 차감") | 497원 명시가 +8% |
| P1 | 홈 카드 가격 노출 위치 | 상단 vs 하단 |
| P1 | 리포트 하단 업셀 카피 ("10배 깊이" vs "심화 분석") | 10배 깊이가 +10% |
| P2 | 궁합 CTA 단일 vs 분할 (500 vs 1500 별도 상품) | Phase 2 결정 후 |

### 6.2 테스트 운영

- 기간: 최소 7일, 샘플 1,000명 이상.
- 실시간 대시보드 + 슬랙 알림.
- 승리 버전 확정 시 전체 전환 + 카피 라이브러리 갱신.

## 7. 안티 패턴 목록

1. **Countdown 타이머** — 거짓 긴급성, 신뢰 훼손.
2. **"N개 남음" 재고 압박** — 디지털 상품엔 부적절.
3. **"가입하고 보기" 벽** — 로그인 전략 AC-02 위반.
4. **이모지 남발** — 브랜드 톤 파괴.
5. **빨간색 경고 톤** — 금융·공포 마케팅 느낌.
6. **"지금 바로"의 과용** — 1CTA당 1회까지.
7. **소셜프루프 과장** — "100만 명" 류의 비현실적 숫자.
8. **모달 팝업으로 CTA 강제** — UX 거부감.
9. **스크롤 제한으로 CTA 강제 노출** — 안티 패턴.
10. **구독 강매 (오토 리뉴얼 숨김)** — 사주500은 구독 없음, 향후 도입 시 투명 표시.

## 8. 유저 스토리

### US-01. 블러 + 공백 공포 → 결제
> *지은(27, 여). 블러 페이지에서 "블러 아래 9섹션을 지금 열기 · 500원" CTA 노출. "뭐가 있는지 너무 궁금" → 클릭 → 결제.*

### US-02. 가격 일상화 → 저항 낮춤
> *태현(33, 남). 홈 카드의 "커피값 1/5로 내 사주 전부" 카피. "500원이 커피값의 1/5이라니" 인식 전환 → 클릭률 상승.*

### US-03. 업셀 카피 성공
> *수아(24, 여). 500원 리포트 완독 후 "이 분석, 10배 깊이로 보실래요? 5,000원" → "10배면 대단하지" → 결제.*

### US-04. 단수 가격 신뢰
> *민준(29, 남). "497원으로 시작하기" CTA에서 "3원은 뭐지?" → 아래 "지갑에 3원 적립 중" 배너 확인 → "아, 진짜 할인이네" 납득.*

## 10. 수용 기준 (Acceptance Criteria)

## 13. 오픈 퀘스천

1. **"10배 깊이" 카피의 정량 근거** — 실제 10배가 되는지, 마케팅 문구인지. 내부 계산 근거 문서화 필요.
2. **"커피값 1/5" 비유가 너무 올드한지** — Z세대에게도 통하는 비유인지.
3. **"블러 아래 9섹션"의 "9"를 적나라하게 드러내는 게 좋은가** — 상세함 vs 단순함.
4. **프로모 기간 CTA의 긴급 컬러 전환** — 브랜드 톤 유지 vs 긴급성. 현재는 유지.
5. **소셜프루프 숫자가 매일 0부터 카운트되는지, 누적 기반인지** — "오늘만"은 일일, 누적은 별도 장치.
6. **AI 생성 카피를 도입할지** — 개인화 마케팅 가능하지만 브랜드 톤 위반 리스크.
7. **A/B 테스트 인프라** — PostHog 기본 기능으로 충분한지, GrowthBook 도입 여부.
