## 1. 목적 (Goal)

**"중독 없이, 의미로 붙잡는다."**

점신은 시간대 게이팅·미션 박스·카운트다운으로 리텐션을 만들지만, 그 방식은 사주500의 "정성·고전" 브랜드와 어긋난다. 대신 사주500은 **"유저의 데이터가 쌓일수록 가치가 커지는"** 구조로 재방문을 만든다.

**MVP 3대 장치:**

1. **운의 일기** — 매일 1~2줄 기록. 30일 누적 시 패턴 리포트 자동 생성.
2. **관계망 아카이브** — 가족·배우자·친구를 프로필에 추가. 새로운 사람 = 새로운 궁합 분석.
3. **24절기 자동 재해석** — 입춘·하지 등 절기 진입 시 "내 사주 × 이 절기" 인사이트 자동 발송.

**성공 지표:**
- 30일 후 리텐션 ≥ 25% (업계 평균 10~15%).
- 일기 작성 유저의 D+30 재방문률 ≥ 55%.
- 관계망에 프로필 1개 이상 추가한 유저의 LTV ≥ 2.5배 (미추가 유저 대비).
- 절기 알림 클릭률 ≥ 30%.

## 2. 핵심 결정 (Decisions)

### 2.1 왜 이 3개인가 (Why These Three)

| 장치 | 재방문 근거 | 브랜드 정합 | 운영 비용 |
|---|---|---|---|
| 운의 일기 | **내 데이터 축적** — 쓰면 쓸수록 내 것 | "내 인생 기록" 톤 | 저장만. AI는 30일마다 배치 |
| 관계망 아카이브 | **관계는 계속 늘어남** — 새로운 사람 = 새로운 분석 | "사주는 관계" 철학 | 프로필당 1회 AI 호출 |
| 24절기 | **자연 주기** — 15일마다 자동 트리거 | "고전·자연" 톤 완벽 | 푸시만. AI는 상품별 배치 |

**대안으로 검토 후 제외:**
- **상담 메모리** — 가치 있지만 유료 대화 확대 전 MVP에서는 Phase 2.
- **앎의 진척도** — 게임화 의심 소지. 신중 검토 후 Phase 2.
- **대운 전환점 알림** — 10년 주기라 런칭 직후 효과 미미. Phase 2.

### 2.2 장치별 우선순위

- **P0 (런칭 D0):** 관계망 아카이브 (프로필 확장 = 추가 결제 직결).
- **P1 (D+7):** 24절기 자동 재해석 (2026-05-05 입하가 첫 트리거 기회).
- **P2 (D+14):** 운의 일기 (UI·프롬프트 완성 후 합류).

## 3. 장치 1: 운의 일기 (Fortune Journal)

### 3.1 개요

**"매일 1~2줄, 오늘의 감정·사건을 기록한다. 30일 누적 시 사주500이 패턴 리포트를 자동으로 보내준다."**

일반 다이어리와 다른 점:
- 입력이 **극도로 가볍다** — 1~2줄, 선택 감정 태그 3개만.
- 사주500이 **명리학 관점으로 해석**해서 돌려준다 — "이 주의 당신은 水 기운이 약했어요".
- 30일 리포트는 **무료** 제공 (리텐션 목적) → 유료 전환 연결은 별도.

### 3.2 입력 UI

```
┌─────────────────────────────────┐
│  오늘의 한 줄                   │
│  ━━━━━━━━━━━━━━━━━━           │
│  [ 간단히 적어주세요… ]        │
│                                 │
│  오늘 내 기분은?                │
│  ● 평온  ○ 활기  ○ 답답       │
│  ○ 설렘  ○ 지침  ○ 기대       │
│                                 │
│             [저장하고 닫기]    │
└─────────────────────────────────┘
```

- 일 1회 저장. 수정은 당일 허용, 다음 날 잠금.
- 건너뛴 날은 "어제 한 줄 쓰시겠어요?" 푸시 1회.
- 7일 연속 작성 시 "보름 보기" 언락 (무료 중간 리포트).

### 3.3 30일 패턴 리포트

- **생성 시점:** 연속 작성 기간 무관, 30일 단위 누적 시.
- **형식:** 10섹션 리포트와 동일한 아코디언 구조.
- **섹션 예시:**
  - 이 달의 오행 균형 (감정 태그 → 오행 환산)
  - 가장 많이 등장한 단어 3개 + 그 의미
  - 사주 원국과의 상관성
  - 다음 달 주의할 날짜
- **무료 제공** → 하단 "이 패턴을 10배 깊이로 보기 (5,000원)" 업셀.

### 3.4 감정 태그 → 오행 매핑

| 태그 | 오행 | 이유 |
|---|---|---|
| 평온 | 土 | 중심·안정 |
| 활기 | 火 | 발산·열 |
| 답답 | 金 | 수렴·압박 |
| 설렘 | 木 | 생장·새로움 |
| 지침 | 水 | 흐름·피로 |
| 기대 | 木 | 펼침 |

### 3.5 데이터 모델

```ts
// users/{uid}/journal/{date}
{
  date: string,                      // 'YYYY-MM-DD' KST
  text: string,                      // 1~2줄
  moodTag: 'peace' | 'energy' | ...,
  ohaeng: 'wood' | 'fire' | 'earth' | 'metal' | 'water',
  createdAt: timestamp,
  editable: boolean,                 // 당일만 true
}

// users/{uid}/journalReports/{month}  (YYYY-MM)
{
  month: string,
  entries: 30,
  ohaengBalance: { wood: 0.2, fire: 0.3, ... },
  topKeywords: string[],
  aiSummary: { ... },
  generatedAt: timestamp,
}
```

## 4. 장치 2: 관계망 아카이브 (Relation Graph)

### 4.1 개요

**"가족·친구·배우자를 프로필로 추가하면, 각자와의 궁합·관계가 분석된다."**

- 프로필 추가는 **무료** (단순 저장).
- 각 관계 분석은 **5,000원 궁합 상품과 동일 로직** — 유료.
- 단, 가족(부모·자녀) 관계는 **첫 1명 무료** (신뢰 형성 훅).

### 4.2 관계 유형

| 유형 | 분석 깊이 | 가격 |
|---|---|---|
| 부모 | 부모-자녀 전용 관점 | 첫 1명 무료, 이후 유료 |
| 형제 | 형제·자매 동반 관점 | 유료 |
| 배우자·연인 | 궁합 전용 | 유료 |
| 친구 | 동조·갈등 관점 | 유료 |
| 동료·상사 | 업무 관점 | 유료 |
| 자녀 | 자녀 성장 관점 | 첫 1명 무료, 이후 유료 |

### 4.3 UI

```
┌─────────────────────────────────┐
│  내 관계망                      │
│  ─────────────────────          │
│  👤 나                          │
│   ├─ 👨 아빠 (1958-03-02)       │
│   ├─ 👩 엄마 (1960-07-15)       │
│   ├─ 💑 배우자 (1995-11-23)     │
│   └─ 👫 친구 지은 (1998-03-03)  │
│                                 │
│  [+ 관계 추가]                  │
└─────────────────────────────────┘
```

- 관계 카드 탭 → 해당 관계 분석 진입.
- 각 관계마다 마지막 분석 날짜 + "다시 분석" 버튼.
- 새로운 관계 추가 → **"아빠와의 궁합을 500원으로 풀어볼까요?"** 자연 CTA.

### 4.4 데이터 모델

```ts
// users/{uid}/relations/{relationId}
{
  name: string,
  birthDate: string,
  birthTime?: string,
  gender: 'f' | 'm' | 'x',
  relationType: 'parent_father' | 'parent_mother' | 'spouse' | ...,
  addedAt: timestamp,
  lastAnalyzedAt?: timestamp,
}

// users/{uid}/relations/{relationId}/analyses/{analysisId}
{
  productId: string,                // 'relation_parent_f_basic' etc.
  reportId: string,                 // 리포트 참조
  paidWith: 'free' | 'paid' | 'reward',
  createdAt: timestamp,
}
```

### 4.5 바이럴 고리

- 관계 추가 시 "이 사람에게 카톡으로 공유할까요?" 옵션.
- 공유 링크 수신자가 본인 사주를 등록하면 → 자동으로 양쪽 관계에 추가.
- 양쪽 모두 궁합 리포트 반값 혜택 (Phase 2).

## 7. 유저 스토리

### US-01. 일기 습관화 → 30일 리포트 → 5,000원 업셀
> *지은(27, 여). 구매 후 다음날 "오늘의 한 줄" 토스트 → 1줄 작성. 7일 연속 작성 → 보름 리포트 언락. 30일 누적 → 패턴 리포트 "당신은 11~15일 水 기운 하락"을 받음. 감탄. 5,000원 심화 리포트로 업셀.*

### US-02. 관계 추가 → 궁합 결제
> *태현(33, 남). 관계망에 배우자 추가 → 24h 내 "배우자와의 궁합을 500원으로" CTA → 결제. 만족 → 어머니 추가 → 첫 1명 무료 → 아버지 추가 (유료). 상품 소비 4회.*

### US-03. 절기 푸시 → 재방문
> *수아(24, 여). 6월 21일 오전 7시 "하지 夏至" 푸시 수신. 인박스 열어 짧은 인사이트 읽음 → 호기심 → 500원 하지 전체 해석 결제.*

### US-04. 일기 미작성 후 복귀
> *민준(29, 남). 5일간 일기 안 씀. 22시 "5일 동안 안 쓰셨어요" 푸시. "내일부터 다시" 의식 발동. 복귀 작성.*

## 11. 오픈 퀘스천

1. **일기를 30일까지 기다려야 리포트**라는 긴 주기가 중도 이탈을 부르지 않나 — 10일 "단편 리포트" 추가 검토.
2. **가족 무료 1명 정책**이 어뷰징 유인인가 — 생일 반복 입력으로 우회 가능, 제한 필요.
3. **절기 알림을 유저가 끄면 재활성화 훅이 없음** — 30일 후 자동 재질문 여부.
4. **관계 양방향 자동 연결** Phase 2 일정 확정 필요.
5. **감정 태그 6개가 충분한가** — "슬픔·분노"가 누락됨. 태그 확장 vs 단순성 유지 트레이드.
6. **일기 AI 해석 비용** — 유저당 월 최대 30회. Claude Haiku로 저비용화 필요.
7. **"운의 일기" vs "일기" 단어** — 브랜드 일관성 / 검색 최적화.
