## 1. 목적 (Goal)

**"무료로 끌고, 500원에서 ARPU를 만들고, 5,000원에서 마진을 만든다."**

가격은 단순 숫자가 아니라 심리적 티어다. 다음 세 가지를 동시에 만족해야 한다.

1. **무료 구간의 퀄리티가 유료의 근거**가 될 만큼 높을 것 — 무료가 싸구려면 유료는 의심받는다.
2. **500원은 "커피값도 아닌" 무과금 심리 구간** — 클릭 1회 = 결제 1회로 체감되도록.
3. **5,000원은 "가치 명시형"** — "왜 10배인가"가 구매 직전 1초 안에 설명되어야 한다.

가격 자체보다 **가격 사이의 간격**을 정당화하는 게 이 PRD의 본질이다.

## 2. 핵심 결정 (Decisions)

### 2.1 상품 라인업 (3층 구조)

| 티어 | 가격 | 운(運) | 상품명 | 핵심 가치 | 노출 위치 |
|---|---|---|---|---|---|
| 🆓 무료 | 0원 | — | **오늘의 운세** | 매일 1회, 영구 무료. 재방문 훅. | 홈 상단 |
| 🆓 무료+블러 | 0원 | — | **꿈해몽 티저** | 해몽 3줄 중 2줄 블러. 풀 잠금 해제는 500원. | 홈 2번째 |
| 💰 기본 | 500원 | 1운 | **주제별 심층분석** | 성격/직업/재물/애정/건강 중 택1, AI 10섹션. | 전용 카드 |
| 💰 기본 | 500원 | 1운 | **사주 원국 리포트** | 사주 8글자 + 오행·십성 요약. 입문용. | 홈 3번째 |

| 💎 프리미엄 | 5,000원 | 10운 | **궁합 리포트** | 2인 사주 결합 분석 + 공유카드. 바이럴 엔진. | 궁합 페이지 |
| 🎁 무료 개방 | 0원 | — | **런칭 프로모** | 런칭 D+14일 한정, 500원 상품 전체 무료. | 배너 |
| 🎁 리워드 | 3원 | — | **첫 방문 리워드** | 가입 즉시 3원 지급 (실결제 체험용 시드머니). | 온보딩 |

**폐기된 티어:**
- 250원 "초단타" — 유닛 이코노믹스 음수, PG 수수료 역마진.
- 1,000원 "미니" — 500과 5,000 사이에 이분감만 흐림.
- 50,000원 "전문가 1:1" — Phase 3에서 재검토. MVP에서는 자원 분산.

### 2.2 운(運) 충전 패키지

| 운 | 충전 금액 | 원가 환산 | 혜택 비율 | 비고 |
|---|---|---|---|---|
| 1운 | 500원 | 500/운 | — | 단건 결제, 기본가 |
| 4운 | 1,500원 | 375/운 | +33% | 입문 번들 |
| 7운 | 2,500원 | 357/운 | +40% | |
| 14운 | 5,000원 | 357/운 | +40% | 프리미엄 1회 + α |
| 30운 | 10,000원 | 333/운 | +50% | 헤비 유저, 공지 미노출 |

**운은 3종류**로 분리 저장 (어뷰징 방어):
- `paid`: 실결제로 산 운. 환불 가능.
- `bonus`: 충전 시 보너스, 프로모.
- `reward`: 공유·일일체크·첫방문 3원 등. 월 상한 엄격 적용.

**사용 우선순위:** `reward` → `bonus` → `paid` (유저에게 유리하게 먼저 소진, 환불 가능 잔고 보호).

### 2.3 블러 잠금 경계 (Blur-Lock Boundary)

무료·유료 사이는 **블러**가 CTA다. 로그인 아니고, 모달 아니고, 블러다.

| 대상 | 블러 비율 | 해제 조건 |
|---|---|---|
| 꿈해몽 | 3줄 중 2줄 블러 (66%) | 500원 (1운) |
| 500원 심층분석 | 10섹션 중 상단 1섹션(총평) 공개, 9섹션 블러 | 500원 (1운) 결제 |
| 5,000원 프리미엄 | 500원 버전 구매자에게 "심화 구간"만 블러 표시 | 5,000원 (10운) 결제 |
| 궁합 | 종합 점수만 공개, 상세 블러 | 5,000원 (10운) |
| PDF 미리보기 | 첫 페이지 공개, 나머지 블러 | 이미 구매자만 다운로드 가능 |

블러 규칙:
- **블러 아래 글자가 "읽고 싶게"** 배치될 것 — 랜덤 블러 금지, 의도된 첫 단어는 노출.
- 블러 해제 CTA는 **단일 버튼** — "500원으로 열기"만. 로그인 CTA 없음.
- 재방문 시 블러는 유지되되 "이전에 봤던 부분"은 자동 언블러.

**상세 UX는 `prd/프리미엄_티저블러.md` 참조.**

### 2.4 플랫폼별 결제 분기

| 플랫폼 | 결제 수단 | 수수료 | 심사 | 가격 제한 |
|---|---|---|---|---|
| 웹 | 토스페이먼츠 PG | 카드 3.3% / 토스페이 2.9% | — | 자유 |
| 앱인토스 | 토스 IAP | 30% 토스 수수료 | 토스 심사 | 100원 단위 |

**앱인토스 가격 표시 정책:**
- 동일 상품이 웹=500원, 앱=500원 동일가. 내부 마진만 달라짐 (웹 484원, 앱 350원).
- 앱 전용 가격 차별은 금지 (토스 정책 및 유저 신뢰 저하).
- **런칭 시 앱 우선**: 수수료 30%는 사실이지만, 앱인토스 트래픽·마케팅 슬롯 가치가 이를 상쇄.

### 2.5 3원 리워드 (런칭 프로모)

**"가입 즉시 3원을 지갑에 넣어준다."**

- 3원은 결제 1회 체험용 시드머니 → "내 돈으로 샀다"는 착각 → 첫 결제 허들 제거.
- 500원 상품은 "497원 + 3원" 구조로 결제 처리. UX상 "3원 할인 적용"으로 노출.
- 재발급 금지 (1계정 1회), 30일 유효.
- 어뷰징 방어: 기기 fingerprint + 토스 CI (앱) + 전화번호 (웹) 3축 체크.

**상세는 `prd/런칭프로모_3원리워드.md` 참조.**

## 3. 유저 스토리 (User Stories)

### US-01. 3원 → 500원 첫 결제 전환
> *지은(27, 여, 인스타 광고 진입). 가입하자 "3원이 지갑에 들어왔어요" 토스트. 꿈해몽 블러 해제가 "497원"으로 보임. 497원이 "무료처럼" 느껴져 결제. 지갑에 0원 남음.*

### US-02. 500원 → 5,000원 업셀
> *태현(33, 남, 500원 심층분석 결제 완료). 리포트 하단 "대운 10년 주기를 월 단위로 보고싶으신가요? 5,000원 프리미엄" 버튼. 500원이 "만족스러워서" 10배 가격에 대한 저항선 낮아짐. 5분 내 추가 결제 15%.*

### US-03. 궁합 바이럴 진입
> *수아(24, 여). 친구가 카톡으로 궁합 카드 공유. 링크 들어오니 "이 사람과의 궁합 점수 82점" 노출, 상세는 블러. 5,000원 결제 → 본인도 다른 친구와 궁합 시도. 1인 → 평균 2.4인 바이럴.*

### US-04. 4운 충전 유저의 분할 소비
> *민준(29, 남, 1,500원 = 4운 충전). 이번 주에 성격 1운, 재물 1운 소진. 2운 남아서 "다음 주에 또 와야지" 재방문 근거 자동 생성.*

### US-05. 리워드 악용 시도
> *공격자 X. 기기 10대로 가입 시도. 토스 CI 동일 → 2번째부터 3원 미지급. 알림: "이 계정은 이미 리워드를 받은 적이 있습니다."*

## 4. 화면/인터랙션

### 4.1 홈 — 상품 진열

```
┌─────────────────────────────┐
│  오늘의 운세 (무료)          │  ← 1열, 크게
│  [보기]                     │
├─────────────────────────────┤
│  꿈해몽 (무료+) ╱╲╱╲        │  ← 2열, 블러 티저
│  [해몽 보기]                │
├─────────────────────────────┤
│  내 사주 심층분석           │  ← 3열, 500원 뱃지
│  성격·직업·재물·애정·건강    │
│  [500원으로 열기]           │
├─────────────────────────────┤
│  💎 프리미엄 종합 리포트    │  ← 4열, 5,000원
│  월운·대운·PDF·궁합 전체    │
│  [5,000원 · 10배 깊이]      │
└─────────────────────────────┘
```

**순서의 이유:**
- 무료 → 블러 → 저가 유료 → 고가 유료. 눈높이가 자연스럽게 올라감.
- "10배 깊이"는 가격 10배의 정당화 카피. 숫자 옆에 가치 라벨 필수.

### 4.2 결제 전 블러 화면

- 상단: 총평(언블러 1섹션).
- 중단: 9섹션이 제목만 보이고 본문 블러 + 각 섹션 옆 🔒.
- 하단: 고정 CTA **"500원으로 전부 열기"** (단색 버튼, 52px).
- CTA 위: "지갑에 500원 있음 / 없음" 잔액 표시.
- CTA 아래: **별점 없음.** "이번 주 1,284명이 구매" + 후기 3줄.

### 4.3 충전 모달

- 1운 / 4운 / 7운 / 14운 4장 카드.
- **기본 선택은 4운**. "가장 인기" 뱃지.
- 14운 카드는 "프리미엄 1회 + 여분" 서브카피.
- 30운은 하단 "더 보기"로 접어둠.

### 4.4 리포트 내 업셀

- 500원 리포트 마지막 섹션 밑 카드: "이 분석, 10배 깊이로 보실래요? (5,000원)"
- 5,000원 구매자는 이 카드 미노출.

## 5. 데이터 모델 (Firestore)

```ts
// users/{uid}
{
  balance: {
    paid: number,       // 실결제 운
    bonus: number,      // 프로모 보너스
    reward: number,     // 리워드/공유/체크인
  },
  firstRewardGrantedAt: timestamp | null,  // 3원 리워드 중복 방지
  tossCi: string | null,                    // 앱인토스 유저, 어뷰징 fingerprint 축
  deviceFingerprint: string,                // 웹 유저 fingerprint
}

// users/{uid}/payments/{payid}
{
  type: 'charge' | 'spend' | 'refund' | 'reward_grant',
  amount: number,                // 운 단위
  krw: number,                   // 원 단위
  package: '1운' | '4운' | '7운' | '14운' | '30운' | null,
  channel: 'tosspay' | 'iap_tosspay' | 'reward' | 'promo',
  productId: string | null,      // 사용 시 어떤 상품인지
  bucketUsed: 'paid' | 'bonus' | 'reward' | null,
  createdAt: timestamp,
  receipt: { /* 토스 결제 원본 */ }
}

// products/{productId}
{
  name: string,
  tier: 'free' | 'basic' | 'premium',
  costUnits: number,             // 소모되는 운
  blurConfig: {
    unlockedSections: string[],  // 결제 전 공개되는 섹션 키
    blurredSections: string[],
  },
  availableOn: ('web' | 'apps_in_toss')[],
  active: boolean,
}
```

## 6. 엣지 케이스

| ID | 상황 | 처리 |
|---|---|---|
| E-01 | 결제 성공 but Firestore 업데이트 실패 | Cloud Function 재시도 3회 + DLQ + 관리자 슬랙 알림 |
| E-02 | 3원 리워드 이미 받은 유저가 기기 변경 | `tossCi` 또는 `deviceFingerprint` 매칭 → 미지급, "이미 받았어요" 메시지 |
| E-03 | 동시 2탭에서 같은 상품 결제 시도 | Firestore 트랜잭션으로 락, 중복 결제 시 자동 1건 환불 |
| E-04 | 프로모 기간 중 결제한 유저가 프로모 종료 후 환불 요청 | 프로모가는 환불 불가 (약관 명시), 무료 개방분은 환불 개념 없음 |
| E-05 | 충전 후 결제 전에 서비스 탈퇴 | 잔여 `paid`는 환불, `bonus`/`reward`는 소멸 |
| E-06 | 앱인토스 IAP 심사 거절 시 | 웹 전환 유도 배너 ("웹에서 이어서 구매") |
| E-07 | 5,000원 구매자가 500원 상품 재결제 | 이미 구매한 섹션 hit → 결제 차단 UI ("이미 보관함에 있어요") |
| E-08 | 앱인토스와 웹에서 같은 상품을 연속 결제 | 서버에서 동일 `productId + 24h` 감지 → 2번째는 확인 모달 |
| E-09 | 환불 후 지갑 잔액이 음수 | 0원 floor. 사용된 `reward`는 클로백 불가 → 후속 적립에서 상계 |
| E-10 | 가격 변동 시점 경계 | `products.active=false` 처리 + 스냅샷 가격 기록. 기존 결제는 이전 가격 유지 |
| E-11 | 3원 리워드를 쪼개 쓰는 경우 | 금지. 리워드는 1회 전액 사용. 497+3 분할만 허용 |
| E-12 | 토스 IAP 수수료 인상 시 | 앱 상품가 고정, 마진 조정. 유저 단가 변동 금지 |
| E-13 | 프리미엄 구매자가 500원 상품 페이지 진입 | "이미 프리미엄 구매자입니다. 보관함으로" 자동 리다이렉트 |
| E-14 | 운 충전 후 가격 할인 시 | 이미 충전된 운은 충전 시점 가격 기준 그대로 유지 |
| E-15 | 무료 "오늘의 운세" 2회차 시도 | 24시 타이머 표시 + 다른 무료 기능 유도 |

## 7. 수용 기준 (Acceptance Criteria)

| ID | 기준 |
|---|---|
| AC-01 | 500원 상품 결제까지 탭 수 ≤ 3 (입력 완료 가정) |
| AC-02 | 모든 가격 라벨에 "원" 단위가 명시되어 있을 것 (운 단위만 노출 금지) |
| AC-03 | 무료 상품에 "유료 유도" 문구가 있되 **상품 진입 버튼 자체는 비유료 CTA**일 것 |
| AC-04 | 500원 · 5,000원 간 가격 간격 정당화 카피가 1초 이내 눈에 띌 것 ("10배 깊이" 등) |
| AC-05 | 3원 리워드는 최초 가입 직후 3초 이내 토스트로 표시될 것 |
| AC-06 | 결제 성공 후 리포트 진입까지 ≤ 1.5초 (AI 스트리밍은 별도 PRD) |
| AC-07 | 환불 기간은 미사용 운에 한해 7일, "사용 후 환불 불가" 약관 동의 체크 필수 |
| AC-08 | `reward` 버킷 잔액은 상품 결제 시 자동 우선 차감, 유저에게 "3원 적용"으로 표시 |
| AC-09 | 블러 구간은 PNG 스크린샷으로도 해독 불가할 것 (CSS filter blur + 텍스트 셔플) |

## 9. 오픈 퀘스천 (Open Questions)

1. **4운 번들을 "가장 인기"로 밀면 500원 단품 전환율은 어떻게 되나** — 단품 유지 vs 4운 권장의 A/B 필요.
2. **궁합 리포트를 5,000원에 묶을지, 1,500원 별도 상품으로 뺄지** — 바이럴 가치 vs ARPU 트레이드. 준기 결정.
3. **500원과 5,000원 사이에 "2,500원 번들 (7운)"이 결제 갈증을 만드는지, 선택 피로를 만드는지** — 소비자 심리 테스트 필요.
4. **환불 정책을 "미사용 7일"보다 짧게 갈 수 있는가** — 전자상거래법 7일 청약철회 원칙 준수 필수.
5. **30운 번들의 존재 자체를 폐기할 것인가** — 고래유저가 실존하지 않으면 운영 복잡도만 증가.
6. **3원이 너무 작아서 "무시되는" 문제** — 5원·10원 테스트 필요. 단, 5원 = 1% 할인, 심리선 검증 필요.
