## 1. 목적 (Goal)

**"사주는 비공개, 궁합은 공유."**

개인의 사주를 통째로 공유하는 문화는 없다. 내 운명을 타인에게 노출하는 건 프라이버시 문제. 하지만 **궁합은 다르다** — 궁합은 이미 "나 + 그 사람"의 결과이므로, 공유는 그 관계에 대한 이야깃거리로 자연스럽다.

**2종 공유 포맷:**

1. **소름 카드 (Single Card)** — 개인용, 1페이지 요약. "내 사주의 한 줄"을 내밀하게 공유.
2. **궁합 카드 (Pair Card)** — 관계용, **바이럴 엔진**. 링크를 받은 상대가 본인 사주를 등록하면 자동으로 양방향 분석.

**성공 지표:**
- 궁합 카드 공유 → 수신자 가입 전환율 ≥ 15%.
- 바이럴 계수 K ≥ 0.8 (1명이 평균 0.8명 초대).
- 소름 카드 공유 수 ≥ 구매자 수의 10%.
- 공유 링크 클릭률 ≥ 25%.

## 2. 핵심 결정 (Decisions)

### 2.1 공유 상품 매트릭스

| 공유 포맷 | 대상 | 내용 | 저작권 | 프라이버시 |
|---|---|---|---|---|
| **소름 카드** | 개인 구매자 | 1장 요약 (720×1280) | 사주500 브랜드 | 본인 동의 필수 |
| **궁합 카드** | 궁합 구매자 | 1장 요약 + 상호 점수 | 사주500 브랜드 | 본인 + 상대 동의 |
| PDF 리포트 | 프리미엄 구매자 | 전체 10섹션 | 본인 열람용 | 공유는 부가 |
| 풀쿼트 | 모든 리포트 | 섹션 내 짧은 인용구 | 텍스트 공유 | 사주 정보 미노출 |

**PDF는 공유 주력 아님** — 너무 길고 개인적. 바이럴 장치가 아니라 소장 장치.

### 2.2 소름 카드 (Single Card)

**목적:** "나의 사주의 한 줄을 자랑·공감용으로 공유".

**포맷:**
- 720 × 1280 (세로, 카카오톡·인스타 스토리 최적화).
- 상단: 사주500 로고 + 크림 배경.
- 중앙: **풀쿼트 1줄** — AI가 리포트 전체에서 뽑은 가장 "소름" 포인트.
- 하단: 작은 브랜드 라벨 + QR/짧은 URL.
- **유저 이름 미노출** (프라이버시).
- **사주 8글자 미노출** (프라이버시).

**예시:**
```
┌─────────────────────────────────┐
│ 사주500                         │
│                                 │
│                                 │
│         "돈은 당신에게          │
│         오지만,                 │
│         머무르지 않습니다."     │
│                                 │
│                                 │
│                                 │
│    saju500.com                  │
│    당신의 사주를 500원으로     │
└─────────────────────────────────┘
```

### 2.3 궁합 카드 (Pair Card)

**목적:** "상대방과 같이 해보기" 유인 극대화.

**포맷:**
- 720 × 1280.
- 상단: 사주500 로고.
- 중앙: **두 사람의 관계 한 줄** + **종합 점수** (블러).
- 하단: **"◯◯님과의 궁합을 확인하세요"** + CTA 링크.

**예시 (공유자 → 상대 방향):**
```
┌─────────────────────────────────┐
│ 사주500 궁합                    │
│                                 │
│                                 │
│       지은님과 ▓▓님의          │
│       궁합 점수                 │
│                                 │
│           ▓▓점                 │
│                                 │
│       "서로를 ▓▓▓▓는 사이"    │
│                                 │
│                                 │
│   [사주 등록하고 확인하기]      │
│   saju500.com/c/x7k9p2          │
└─────────────────────────────────┘
```

- 상대 이름은 `▓▓` 블러 (공유자가 "지은" 이름만 공개).
- 점수는 블러 → 클릭 유도.
- 한 줄 요약은 일부 블러 → 호기심.

### 2.4 궁합 링크 플로우 (Viral Loop)

```
┌─────────────────────┐
│  지은(구매자)       │
│  5,000원 궁합 결제  │
└──────────┬──────────┘
           │
           ↓
┌─────────────────────┐
│  공유 링크 생성     │
│  /c/x7k9p2          │
└──────────┬──────────┘
           │
           ↓ (카톡·SMS 등으로 상대에게)
┌─────────────────────┐
│  수신자(잠재 유저)  │
│  링크 클릭          │
└──────────┬──────────┘
           │
           ↓
┌──────────────────────┐
│  사주500 링크 진입   │
│  "지은님과의 궁합"  │
│  "생년월일 입력하면 │
│   무료로 확인"       │
└──────────┬───────────┘
           │
           ↓
┌──────────────────────┐
│  수신자 사주 입력     │
│  → 무료 짧은 요약    │
│  → 전체 5,000원 CTA  │
└──────────────────────┘
```

**핵심 훅:**
- 수신자에게 **짧은 요약은 무료 제공** (점수 + 1줄 통찰).
- 심화 결과는 5,000원 CTA.
- 수신자가 결제하지 않아도 **익명 프로필**로 사주500 계정 생성 → 이후 리텐션 대상.

### 2.5 프라이버시

| 항목 | 공개 | 비공개 |
|---|---|---|
| 생년월일 | ❌ 절대 | ✅ |
| 이름 | 공유자만 (본인 동의) | 수신자 이름 블러 |
| 사주 8글자 | ❌ | ✅ |
| 종합 점수 | 공유 시 블러 | 클릭 후 노출 |
| 풀쿼트 | 공개 | — |
| 로고·브랜드 | 공개 | — |

**동의 절차:**
- 공유 버튼 클릭 시 **"이 카드를 공유하면 당신의 이름(1글자)이 공개됩니다. 동의하시나요?"** 체크박스.
- 동의 없이 공유 불가.
- 궁합 카드에서 **상대방 이름은 블러**, 수신자가 클릭 진입 후 본인이 맞으면 해제.

### 2.6 저작권·워터마크

- **모든 공유 카드 하단에 연한 사주500 워터마크.**
- 풀쿼트 텍스트는 저작권 사주500 보유. AI 생성물이지만 **브랜드 자산** 명시.
- 유저는 개인적 공유만 허용, 상업적 재사용 금지 (이용 약관).
- 스크린샷 기반 재가공 공유는 기술적으로 막기 어려움 → **약관으로 대응**.

### 2.7 단축 링크

- 궁합 링크는 짧은 토큰(`/c/x7k9p2`)으로 발급.
- Firestore에 `sharedLinks/{token}` 저장.
- 만료: 30일 (미접근 시), 365일 (접근 후).
- 만료된 링크는 "이 궁합 카드는 만료되었어요" 안내.

## 3. UI 명세

### 3.1 공유 버튼 배치

**리포트 페이지:**
- 섹션 10(개운법) 하단 액션 카드에 "공유하기" 버튼.
- 풀쿼트 호버/길게 탭 시 "이 문장 공유" 옵션.

**궁합 리포트 페이지:**
- 상단 고정 "카톡으로 공유" 버튼 (눈에 띄게).
- 하단에도 "링크 복사" 버튼.

**꿈해몽·오늘의 운세:**
- 공유 없음 (짧고 일회성).

### 3.2 공유 시트 (Share Sheet)

```
┌─────────────────────────────────┐
│  어떻게 공유할까요?              │
│                                 │
│  [카카오톡]                      │
│  [SMS]                           │
│  [트위터/X]                      │
│  [인스타 스토리]                 │
│  [링크 복사]                     │
│  [이미지 저장]                   │
│                                 │
│  공유 시 본인 이름 1글자가       │
│  상대방에게 보여요.              │
│  ☑ 동의합니다                    │
└─────────────────────────────────┘
```

### 3.3 이미지 생성

- 클라이언트에서 Canvas API 또는 html2canvas로 렌더.
- 서버 렌더는 Phase 2 (품질 향상용).
- 앱인토스는 `getTossShareLink` 병행 사용.

### 3.4 수신자 랜딩 페이지 (`/c/:token`)

```
┌─────────────────────────────────┐
│  지은님이 보낸 궁합              │
│                                 │
│  지은님과 당신의 궁합은…         │
│  (점수 블러)                    │
│                                 │
│  본인의 생년월일을 입력하면      │
│  짧은 요약을 무료로 확인할 수    │
│  있어요.                        │
│                                 │
│  [ 생년월일 입력 ]               │
│                                 │
│  입력하시면 자동으로 계정이      │
│  생성돼요. 언제든 삭제 가능.    │
└─────────────────────────────────┘
```

- 수신자 입장에서 "지은님" 이름이 먼저 보여서 진성 링크라는 확신.
- 입력 후 무료 요약 → 5,000원 CTA 또는 "내 사주도 500원으로 확인" 2차 CTA.

## 5. 유저 스토리

### US-01. 궁합 카드 → 상대 가입
> *지은(27, 여). 5,000원 궁합 결제 후 공유 카드 생성. 친구 유나에게 카톡으로 공유. 유나가 링크 클릭 → 사주500 진입 → 생년월일 입력 → 무료 요약 확인 → 호기심 폭발 → 5,000원 결제. 바이럴 계수 +1.*

### US-02. 소름 카드 → 개인 공유
> *태현(33, 남). 리포트의 풀쿼트 *"당신의 고민은 무엇을 택하느냐가 아니라, 무엇을 놓아주느냐입니다."* 를 카톡 상태메시지로 공유. 이름·사주 노출 0, 브랜드만 노출. 바이럴 부드럽게.*

### US-03. 공유 리워드 누적
> *수아(24, 여). 소름 카드 공유 → 0.5운 리워드 지급. 월 10회까지 누적 가능. 5운 상당(2,500원) 적립.*

### US-04. 인스타 스토리 업로드
> *민준(29, 남). 소름 카드를 인스타 스토리에 업로드. QR 코드 포함 → 팔로워들이 스캔하여 사주500 유입. 유기적 바이럴.*

### US-05. 만료된 링크
> *지은이 반년 전 만든 공유 링크를 오랜 친구가 클릭. "이 카드는 만료되었어요" 안내 → "새로 궁합 보기" CTA로 전환.*

## 6. 엣지 케이스

| ID | 상황 | 처리 |
|---|---|---|
| E-01 | 이미지 생성 실패 (Canvas 오류) | 텍스트+링크 공유로 폴백 |
| E-02 | 수신자가 이미 사주500 유저 | 자동 로그인 + 해당 궁합 결과로 바로 이동 |
| E-03 | 수신자가 사주 입력 거부 | 무료 요약 생략, "아쉬워요" 종료 화면 |
| E-04 | 수신자가 공유자와 같은 uid | "자기 자신과의 궁합" 방지, 다른 프로필 입력 유도 |
| E-05 | 공유 링크를 다른 사람이 제3자에게 전달 | 만료 전까진 누구나 클릭 가능. 동의 고지는 첫 공유 시점 |
| E-06 | 상업적 재사용 감지 | 약관 기반 대응, 기술적 차단은 어려움 |
| E-07 | 풀쿼트가 정치·종교 언급 | AI 필터로 생성 단계에서 배제, 수동 모더레이션 |
| E-08 | 수신자가 악의적 사주 정보 입력 | 공유자·상대 모두에게 영향 없음 (읽기 전용) |
| E-09 | 공유 링크 대량 브루트포스 | 토큰 충분한 엔트로피 + rate limit |
| E-10 | 수신자가 수신 확인 없이 링크만 폐기 | `visits > 0, converted = 0` 통계 집계 |
| E-11 | 이미지가 업로드 플랫폼에서 리사이징 | 원본 720×1280 유지, 리사이즈 견디는 폰트 크기 |
| E-12 | 앱인토스에서 외부 공유 제한 | `getTossShareLink` + TDS 공유 API 사용 |
| E-13 | 동일 공유자가 같은 카드 중복 공유 | 허용, 플랫폼별 1회 리워드만 |
| E-14 | 공유 리워드 월 한도 초과 | "이달 한도 소진" 안내, 공유는 가능 |
| E-15 | 이름 동의 철회 요청 | 해당 카드 비공개 전환, 기존 스크린샷은 기술적 회수 불가 |

## 7. 수용 기준 (Acceptance Criteria)

| ID | 기준 |
|---|---|
| AC-01 | 공유 카드는 720×1280 세로 포맷 |
| AC-02 | 소름 카드에는 **생년월일·사주 8글자 미노출** |
| AC-03 | 궁합 카드에는 상대 이름 블러, 점수 블러, 풀쿼트 일부 블러 |
| AC-04 | 공유 시 본인 이름 1글자 공개에 대한 명시적 동의 필수 |
| AC-05 | 궁합 링크 클릭 시 수신자에게 짧은 무료 요약 제공 |
| AC-06 | 수신자 가입 시 익명 프로필 자동 생성 |
| AC-07 | 공유 리워드는 0.5운, 월 10회 (5운 상한) |
| AC-08 | 카드 하단에 연한 사주500 워터마크 |
| AC-09 | 토큰은 충분한 엔트로피 (16자 이상), 브루트포스 방어 |
| AC-10 | 만료 정책: 미접근 30일, 접근 후 365일 |
| AC-11 | 앱인토스는 TDS 공유 API + `getTossShareLink` 사용 |
| AC-12 | 풀쿼트 공유는 텍스트만 복사 가능 (이미지 없이도 가능) |

## 9. 오픈 퀘스천

1. **공유자 이름 1글자 공개가 충분한 프라이버시 수준인가** — 주변 사람은 유추 가능. 완전 익명화 vs 진성 신호.
2. **궁합 카드의 점수·한줄 블러 비율** — 너무 가리면 매력 감소, 너무 덜 가리면 결제 욕구 약화.
3. **수신자의 익명 계정 자동 생성은 프라이버시 이슈가 있는가** — 개인정보처리방침 명시 필요.
4. **공유 리워드 0.5운이 너무 낮은지** — 1운(500원)으로 올리면 어뷰징 증가. 균형점 탐색.
5. **풀쿼트의 문학성 vs "짜집기" 인상** — AI 생성이라도 "브랜드 자산"으로 느껴지게.
6. **PDF 공유를 완전히 막을지** — 소장용이지만 유출 리스크. 워터마크 + 구매자 고유 표식.
7. **인스타 스토리 템플릿 개발 공수** — MVP엔 단일 이미지, Phase 2에서 템플릿.
8. **바이럴 측정 도구** — PostHog + UTM vs 자체 대시보드.
