# 업계 벤치마크 디테일 (Competitive Benchmark Deep-Dive)

> **문서 성격**: 사주500이 참고·우회·추월해야 할 국내외 현역 경쟁사의 **기능·UX·가격·AI 모델·수익화·마케팅** 을 필드별로 해부한 벤치마크. 전략기획서 v3.1의 경쟁사 섹션 소스.
>
> - 대상: 한국 3사(점신·포스텔러·헬로우봇) + 일본 2사 + 중국 2사 + 비교군(서구 관상·타로 앱)
> - 업데이트: 분기별 재검증 (기능·가격 변동 잦음)
> - 원칙: 스크린샷·카피·가격은 공개 정보만 인용. 비방 금지. 약점 기술은 사실 근거 기반.
> - 관련: `전략기획서 v3.1`, `가격_상품구조.md`, `리텐션_저널관계망.md`

## 0. 벤치마크 프레임

### 0.1 비교 차원 (7축)

1. **가치 제안 (Value Prop)**: 한 줄 포지셔닝
2. **핵심 기능 (Core)**: 무엇을 주요 상품으로 파는가
3. **AI 활용도 (AI Depth)**: AI 사용 깊이 / 사용자 맞춤화 수준
4. **UX 완성도 (UX)**: 유입 → 결제 → 재방문 흐름의 매끄러움
5. **가격 체계 (Pricing)**: 티어·단가·충전·구독·번들
6. **수익화 (Monetization)**: 주 수익원 · 광고 · 유료 전환율 추정
7. **마케팅·리텐션 (Growth)**: 유입 채널·바이럴 장치·재방문 훅

### 0.2 사주500 대비 관점

각 경쟁사의 **강점을 베낄 것**, **약점을 피할 것**, **공백을 점유할 것** 3가지로 정리.

## 1. 한국 #1 — 점신 (Jumsin)

### 1.1 개요

- 회사: ㈜운칠기삼
- 런칭: 2014
- 누적 다운로드: 1,500만+ (안드로이드)
- 포지셔닝: "하루 1회 습관처럼 보는 운세"
- 핵심 포인트: **하루 1회 오전 10시 오픈** 시간대 게이팅. 중독성 루프.

### 1.2 7축 분석

| 축 | 내용 |
|----|------|
| Value Prop | 매일 아침 오늘의 운세. 사주·타로·별자리 통합 |
| Core | 오늘의 운세 / 주간 / 연간 / 사주풀이 / 타로 / 별자리 / 꿈해몽 |
| AI Depth | **중간**. 사주 풀이에 일부 GPT/LLM 도입한 것으로 추정. 다만 템플릿 기반 요소 많음 |
| UX | 홈 카드 UI, 푸시 알림 과감, 시간대 게이팅, 미션·출석체크·뽑기 게이미피케이션 풍부 |
| Pricing | 부분 유료 + 광고. 프리미엄 풀이 건당 3,900~9,900원 |
| Monetization | 광고(AdMob) + 결제 풀이 + 제휴 커머스 |
| Growth | 푸시·리텐션·친구 초대 리워드 강함. 앱스토어 리뷰 100만 이상 |

### 1.3 강점 분석

- **시간대 게이팅**: "지금 확인 가능"의 희소성 심리. 매일 고정 시간 오픈
- **미션·뽑기**: 운세 보기 → 미션 완료 → 포인트 → 뽑기. 도파민 루프
- **푸시 알림 기민**: 매일 아침 + 저녁, 주요 시즌(설날·대학수학능력시험 등)
- **카테고리 풍부**: 사주·타로·별자리·꿈해몽·관상 등 다품종
- **출석 보상**: 7일 연속 접속 시 무료 풀이권

### 1.4 약점 분석

- **AI 깊이 약함**: 사주 풀이가 템플릿 기반 — 동일 사주에 같은 문구 반복
- **광고 과다**: 운세 페이지 1회당 전면광고 2~3회
- **비전문가 느낌**: 무속인·점집 톤 문구 다수 ("~하시면 ~하오니")
- **시각 피로**: 정보 밀도 높고 배너 광고 난무
- **결제 설득 약함**: "왜 이 풀이가 3,900원인지" 가치 증명 부족

### 1.5 사주500 대응

- ✅ **베낄 것**: 시간대 게이팅(오늘 운세) / 출석 보상 / 푸시 알림 템플릿 ← 이미 `리텐션_저널관계망.md` 에 반영
- ⚠ **피할 것**: 광고 도배 / 점집 톤 / 템플릿 문구 느낌
- 🎯 **점유할 공백**: "AI로 1인 1색 리포트 — 같은 사주라도 내 상황에 맞춤" 이 점신이 못하는 자리

## 2. 한국 #2 — 포스텔러 (Forceteller)

### 2.1 개요

- 회사: 포스텔러
- 런칭: 2017
- 누적 다운로드: 800만+
- 포지셔닝: "감성적 운세 + 타로 전문"
- 핵심 포인트: **감성 일러스트 UI**. 20~30대 여성 타겟

### 2.2 7축 분석

| 축 | 내용 |
|----|------|
| Value Prop | 감성적인 오늘·주·년 운세 + 타로 |
| Core | 오늘의 운세 / 신년운세 / 사주풀이 / 타로 / 연애운·취업운 별도 상품 |
| AI Depth | **낮음~중간**. 신년운세 상품화에 AI 일부 도입. 대부분 템플릿 |
| UX | 일러스트·애니메이션 강조. 공유 이미지 예쁨. 모바일 퍼스트 잘 됨 |
| Pricing | 상품 건당 2,900~19,900원. 신년운세 패키지 30,000원대 |
| Monetization | 결제 중심. 광고 적음 |
| Growth | 인스타·틱톡 마케팅 활발. 연간 신년운세 시즌 매출 폭발 |

### 2.3 강점 분석

- **감성 브랜딩**: 일러스트·컬러·아이콘이 다른 점집 앱과 차별
- **공유 이미지 예쁨**: 친구에게 보내고 싶은 결과 카드
- **신년운세 시즌 마케팅**: 12월~2월 집중 캠페인
- **여성 타겟**: 20~30대 여성 코어 유저 확보
- **카테고리 분화**: 연애·취업·재물 별개 상품으로 ARPU 상승

### 2.4 약점 분석

- **가격 부담**: 신년운세 30,000원대는 한 번 보고 끝나는 가격
- **AI 깊이 낮음**: 대부분 규칙 기반 또는 템플릿
- **재방문 약함**: "한 번 보고 끝" 구조. 리텐션 훅 부족
- **일일 운세 편의성**: 점신만큼 매일 오픈 욕구 못 자극
- **개인화 한계**: 같은 사주는 같은 답

### 2.5 사주500 대응

- ✅ **베낄 것**: 감성 일러스트·공유 이미지 예쁨 / 카테고리 분화(연애·취업·재물 별도 심층) / 신년운세 시즌 마케팅
- ⚠ **피할 것**: 고가 단발 상품 / 리텐션 약함
- 🎯 **점유할 공백**: "500원의 허들 없이 매일 볼 수 있으면서 포스텔러 수준의 감성 + 더 깊은 AI"

## 3. 한국 #3 — 헬로우봇 (HelloBot)

### 3.1 개요

- 회사: 띵스플로우
- 런칭: 2017
- 누적 다운로드: 500만+
- 포지셔닝: "AI 챗봇 운세 · 연애 상담"
- 핵심 포인트: **챗봇 대화형 UX**. "이여름 점신이·또또 점신이" 같은 캐릭터

### 3.2 7축 분석

| 축 | 내용 |
|----|------|
| Value Prop | 챗봇과 대화하며 보는 운세·상담 |
| Core | 챗봇 대화·오늘의 운세·연애·속마음 상담·사주 |
| AI Depth | **중간~높음**. GPT 기반 대화. 캐릭터별 페르소나 |
| UX | 챗 인터페이스. 카톡처럼 친숙. 캐릭터 아트 귀여움 |
| Pricing | 구독(월 6,900~9,900원) + 건당 상품 |
| Monetization | 구독 모델 + 결제 상품 |
| Growth | MZ 세대 타겟. 인스타·트위터 바이럴 |

### 3.3 강점 분석

- **캐릭터 IP**: "또또 점신이" 팬덤 형성
- **챗 인터페이스**: 일방향 리포트 대비 상호작용 즐거움
- **GPT 기반 대화**: 자연스러운 응답
- **구독 모델**: 월정액 구독으로 안정 매출
- **연애 상담 특화**: 심리 상담과 사주의 경계

### 3.4 약점 분석

- **전문성 결여 느낌**: 귀여운 캐릭터 → 진지한 답이 필요할 때 아쉬움
- **사주 풀이 얕음**: 챗 인터페이스 특성상 깊은 리포트 어려움
- **구독 모델의 가시적 가치 전달 어려움**: "한 번만 보고 해지" 많음
- **답변 일관성 부족**: 같은 질문 여러 번 하면 다른 답 나옴

### 3.5 사주500 대응

- ✅ **베낄 것**: 챗봇 대화형 보조 기능(사주대화) / MZ 세대 톤 / 인스타 마케팅
- ⚠ **피할 것**: 캐릭터 의존 / 전문성 결여 / 답변 흔들림
- 🎯 **점유할 공백**: "정통 명리학 + 모던한 대화 UX". 캐릭터 없이도 진지한 상담 제공

## 4. 일본 #1 — 占いTVnews / 占いサイト (복합)

### 4.1 시장 개요

- 일본 운세 시장은 **잡지·TV·웹 매체 기반** 다수 (월간 ananα·占いTVnews)
- 단일 지배 앱 부재 / 파편화
- 스타 점술가 기반: 이시이 유카리(石井ゆかり), Love Me Do 등 개인 브랜드
- 연간 시장 규모 1조 엔 이상 (점술·운세 산업)

### 4.2 핵심 특징

- **스타 점술가 중심**: 개인 브랜드 → 책·유료 칼럼·TV 출연
- **별자리·타로 강세**: 사주보다 서양 점성술과 타로가 주류
- **월간 구독 잡지**: ananα 운세 특집호는 매년 베스트셀러
- **신사·사찰 참배 연계**: 새해 첫 참배(初詣)와 운세 패키지
- **구독 미디어**: LINE NEWS · 야후 재팬의 운세 섹션

### 4.3 대표 서비스 — 占いTVnews

| 축 | 내용 |
|----|------|
| Value Prop | TV 스타 점술가의 칼럼·동영상 모음 |
| Core | 일간 칼럼 / 월간 별자리 / 타로 리딩 / 풍수 |
| AI Depth | **매우 낮음**. 거의 사람 작가 |
| Pricing | 부분 유료 + 잡지 광고 |
| Growth | 스타 점술가의 SNS·TV 노출 |

### 4.4 사주500 대응

- ✅ **베낄 것**: 스타 작가 브랜딩 → 사주500은 "작가 대신 AI + 학파" 포지션 가능 / 잡지 톤 감성 / 신년/절기 시즌 캠페인
- ⚠ **피할 것**: 사람 작가 의존은 스케일 안 나옴
- 🎯 **점유 전략**: 일본 시장 진입 시 "AI 스타 점술가" 포지션. 단, 사주보다 타로·별자리 강세이므로 현지화 필요

## 5. 일본 #2 — Zappallas / Cocoloni (대표 운세 앱)

### 5.1 Zappallas

- 일본 상장사. 운세 콘텐츠·앱·웹 포털 운영

## 6. 중국 #1 — 측쯔 (测字) / 易道 / 小程序 기반

### 6.1 시장 개요

- **WeChat 미니프로그램** 중심: 위챗 안에서 바로 이용
- 중국 본토 명리학 인구 방대 (수 억 명 추정)
- **맹파명리(盲派命理)** 등 전통 학파 + 현대 데이터 신파 혼재
- 유명 서비스: 测字 / 大师算 / 解梦解字 등

### 6.2 7축 분석 (평균적 대형 서비스 기준)

| 축 | 내용 |
|----|------|
| Value Prop | 간편한 사주·관상·측자·택일 |
| Core | 팔자분석·택일·관상·측자·해몽 |
| AI Depth | **매우 다양**. 일부는 GPT/통이치엔원 기반, 일부는 템플릿 |
| UX | 위챗 미니프로그램 → 설치 없음, 공유 쉬움 |
| Pricing | 건당 9.9~199위안 (약 1,800~36,000원) |
| Monetization | 결제 + 채팅 상담 + VIP 구독 |
| Growth | 위챗 공유 + 친구 할인 + "해석사(解师)" 라이브 방송 |

### 6.3 강점 분석

- **위챗 통합**: 설치 없이 바로 이용
- **채팅 상담**: 실시간 점술가 매칭
- **라이브 방송**: "解师" 라이브 사주 해석 → 팁 결제
- **사회적 공유**: 위챗 그룹 공유로 바이럴

### 6.4 약점 분석

- **품질 편차**: 저품질 서비스 난립
- **규제 리스크**: 중국 정부의 미신 규제 수시
- **개인정보 우려**: 한국 유저는 접근성 낮음

### 6.5 사주500 대응

- ✅ **베낄 것**: 미니프로그램 (→ 앱인토스와 유사) / 공유 리워드 / 라이브 방송(인스타 라이브로 대체)
- ⚠ **피할 것**: 품질 편차 / 규제 리스크
- 🎯 **점유 공백**: 한국 시장에서 "위챗 미니프로그램 급 접근성"은 앱인토스로 대체. 중국 진입은 Phase 3 이후

## 7. 중국 #2 — 大师算命 (Master App)

### 7.1 개요

- 중국 본토 대표 사주·택일 앱
- MAU 수백만
- **실시간 대사(大师) 상담** 강점

### 7.2 핵심 특징

## 14. 런칭 후 6개월 경쟁 대응 시나리오

### Case A: 점신이 가격 인하로 대응
- 점신이 기본 풀이 500원 수준 인하 → 사주500은 AI 깊이 차이로 대응. 2차 자기 리뷰·6대 원전 기반 차별점 강조
- 광고로는 못 이길 때 → 인플루언서 심층 리뷰·블로그 롱테일 SEO

### Case B: 포스텔러가 AI 업그레이드
- 포스텔러가 Claude/GPT 도입 → 사주500은 프롬프트 엔지니어링 깊이·프롬프트 v2.1·자기 리뷰로 답변 품질 유지
- 이원화 톤 정책·시간 보정은 기술 해자

### Case C: 신규 사업자 등장 (AI 사주 스타트업)
- AI 기반 스타트업 등장 시 → 이미 확보한 앱인토스 노출·브랜드 인지도·3원 리워드 프로모로 초기 cohort 확보
- 6개월 내 LTV 구조 고착화 목표

### Case D: 카카오·네이버 등 플랫폼 대기업 진입
- 카카오/네이버가 자체 운세 서비스 런칭 → 사주500은 앱인토스(토스) 생태계에 정착, **멀티 플랫폼** 전략 (웹·앱인토스·Phase 2 카카오 싱크)
- 법무·전문 콘텐츠 해자 유지
