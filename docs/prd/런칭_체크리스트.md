## 10. 롤백 계획

### 10.1 롤백 트리거
- 결제 성공률 < 90% 지속 1시간
- 에러율 > 5% 지속 30분
- 리포트 생성 실패율 > 10%
- 데이터 유실 의심
- 법적 이슈 (개인정보 유출 등)

### 10.2 롤백 절차
1. 프로덕션 DNS → 유지보수 페이지
2. Firebase Hosting 이전 릴리스로 롤백
3. Cloud Functions 이전 버전 복원
4. 영향받은 유저 조사·통지
5. 근본 원인 분석 (RCA)
6. 수정 후 재배포

### 10.3 공지 템플릿
- SNS: "현재 일시적 점검 중입니다. 약 30분 내 복구 예정."
- 이메일: "결제가 반영되지 않은 경우 자동 환불됩니다."
- 고객센터: 문의 접수 시 응대 스크립트
