# 사주500 용어집 (Glossary)

> **문서 성격**: 사주500 플랫폼 전반에서 사용되는 용어의 단일 진실(Single Source of Truth).
> 팀 커뮤니케이션·코드 주석·AI 프롬프트·UI 라이팅이 전부 이 용어집의 정의를 따른다.
>
> - 업데이트: 새 용어 등장 시 즉시 등록. 폐기 용어는 `(DEPRECATED)` 표시 + 대체 용어 병기
> - 한자 병기: 명리학 용어는 `한글(漢字)` 첫 등장, 이후 한글 단독
> - 영문 병기: 기술 용어는 `한글(영문)` 또는 영문 그대로

## 1. 제품·비즈니스 용어

### 사주500 (Saju 500)
500원에 제공하는 극상 퀄리티 AI 사주 풀이 서비스. 플랫폼 전체의 공식 명칭.

### 운 (運)
사주500의 가상화폐 단위. **1운 = 500원**. 영문 표기는 `UN` (필요시), 내부 코드에서는 `credit`.

### 티어 (Tier)
가격·상품 구조의 레벨. 무료 / 500원(1운) / 5,000원(10운) 3층 구조가 v3.1 표준.

### 블러잠금 (Blur Lock)
프리미엄 콘텐츠를 무료/기본 유저에게 일부만 미리보기로 제공하는 장치. CSS 블러 + 노이즈 + 서버 응답 차단 3층 보안.

### 3원 리워드 (3 KRW Reward)
런칭 프로모션으로 가입/공유 시 지급되는 소액 리워드. 결제 전환 심리학 근거.

### 앱인토스 (Apps-in-Toss, AIT)
토스 앱 내 미니앱 플랫폼. 사주500은 웹 + 앱인토스 이중 배포. `isAppsInToss()`로 런타임 감지.

### 프로필 (Profile)
한 유저가 저장한 사주 분석 대상(이름·생년월일·생시). 한 유저가 가족·친구 등 여러 프로필을 저장 가능.

### 리포트 (Report)
한 번의 AI 사주 풀이 결과물. 10개 섹션으로 구성. Firestore `users/{uid}/reports/{rid}` 에 영구 보관.

### 일운·세운·월운 (Ilun·Seun·Wolun)
**일운**: 오늘의 운세 (무료 콘텐츠)
**세운**: 올해 운세 (기본 리포트에 포함)
**월운**: 이번 달 운세 (프리미엄 전용)

### 궁합 (Compatibility)
두 사람의 사주 비교. 프리미엄 티어. 6단계 프로토콜로 산출. 백과사전 Vol 7 참조.

### 꿈해몽·오늘운세·사주대화 (Dream·Today·Chat)
무료 보조 콘텐츠 3종. 사주대화는 1일 1회 제한.

## 2. 명리학 용어 (Myeongri)

### 사주팔자 (四柱八字)
년·월·일·시 4기둥(柱), 각 기둥은 천간·지지 2글자 → 총 8글자. "사주" 또는 "팔자"로 줄여 부름.

### 천간 (天干)
甲·乙·丙·丁·戊·己·庚·辛·壬·癸 10개. 하늘의 기운.

### 지지 (地支)
子·丑·寅·卯·辰·巳·午·未·申·酉·戌·亥 12개. 땅의 기운.

### 60갑자 (六十甲子)
10천간 × 12지지의 조합 중 음양이 맞는 60개. 60년 주기의 근원.

### 일간 (日干)
日柱의 天干. 명리학 해석의 중심. "나 자신"을 의미.

### 월령 (月令)
月柱의 地支. 계절 기운의 핵심. 격국 판정의 1순위 근거.

### 오행 (五行)
木·火·土·金·水 5원소. 사주 해석의 기본 축.

### 지장간 (地藏干)
지지 속에 숨어있는 천간. 주기(主氣)·중기(中氣)·여기(餘氣) 3단계. 비율은 백과사전 Vol 2 참조.

### 십성 (十星)
일간 기준 10가지 관계: 비견(比肩)·겁재(劫財)·식신(食神)·상관(傷官)·편재(偏財)·정재(正財)·편관(偏官)·정관(正官)·편인(偏印)·정인(正印).

### 격국 (格局)
사주의 구조적 패턴. 팔정격(八正格) + 외격(外格). 백과사전 Vol 3 참조.

### 용신 (用神)
사주에서 가장 필요한 오행·십성. 5취용법(扶抑·調候·病藥·通關·專旺) 중 하나로 결정.

### 신살 (神煞)
특정 조합이 가진 길흉 이름. 사주500은 주요 20종만 사용.

### 공망 (空亡)
日柱 기준 비어있는 2개의 지지. "비워짐·허함"을 의미.

### 납음 (納音)
60갑자를 5개씩 묶어 분류한 30종의 오행 이름. 해중금·노중화 등.

### 12운성 (十二運星)
일간이 12지지에서 겪는 생애 주기. 장생·목욕·관대·임관·제왕·쇠·병·사·묘·절·태·양.

### 대운 (大運)
10년 주기의 큰 흐름. 성별 + 년간 음양으로 순행·역행 결정.

### 세운 (歲運)
1년 주기의 운. 입춘을 기점으로 교체.

### 진태양시 (眞太陽時)
태양의 실제 위치 기준 시간. 한국 표준시(KST) - 30분. 사주500은 진태양시 기본 적용 `✓`.

### 夜子時·早子時 (야자시·조자시)
자시(子時, 23:00~01:00)의 분할.
- 夜子時 (야자시): 23:00~00:00 = 당일
- 早子時 (조자시): 00:00~01:00 = 다음날

### 합·충·형·파·해 (合·沖·刑·破·害)
지지 간 관계 5종. 합=결합, 충=대립, 형=갈등, 파=깨짐, 해=원망. 백과사전 Vol 5 참조.

### 근묘화실 (根苗花實)
네 기둥의 상징:
- 년주(年柱) = 근(根, 뿌리·조상)
- 월주(月柱) = 묘(苗, 싹·부모)
- 일주(日柱) = 화(花, 꽃·자신과 배우자)
- 시주(時柱) = 실(實, 열매·자녀·말년)

## 3. 기술·데이터 용어

### uid
Firebase Authentication 유저 고유 ID. 모든 Firestore 경로의 기본 키.

### pid (profile id)
프로필 고유 ID. `users/{uid}/profiles/{pid}`.

### rid (report id)
리포트 고유 ID. `users/{uid}/reports/{rid}`.

### 오행 점수 (OheongScore)
사주의 5오행 기운 강도. 0~100 정규화. 인포그래픽 레이더 차트의 소스.

### 만세력 (萬歲曆)
양력·음력·간지를 변환하는 책/라이브러리. 사주500은 `lunar-javascript` npm 패키지 사용.

### 8글자 추출 (Pillar Extraction)
생년월일시 → 4기둥 × 2글자 변환. `src/services/saju/calculator.ts`.

### 프롬프트 빌더 (Prompt Builder)
8글자 + 상황질문 → AI 유저 프롬프트 조립. `src/services/saju/promptBuilder.ts`.

### 리포트 생성 (Report Generation)
Claude API 호출 → JSON 파싱 → 10개 섹션 리포트. `src/services/ai/reportGenerator.ts`.

### 운 잔액 3버킷 (3-Bucket Balance)
- **paid**: 현금 결제로 충전한 운 (환불 대상)
- **bonus**: 프로모션·이벤트로 받은 운 (환불 대상 아님)
- **reward**: 공유·초대로 받은 운 (환불 대상 아님, 어뷰징 방지 한도 있음)

### 소진 우선순위 (Consumption Priority)
reward → bonus → paid 순으로 소진. 현금성이 가장 늦게 쓰임.

### 공유 리워드 (Share Reward)
공유 1회당 0.5운 지급. 월 한도 5운. 중복 방지 로직은 `shareLogs` 컬렉션으로.

### 일일 무료 패스 (Daily Free Pass)
오늘 운세 / 꿈해몽 = 무료 무제한, 사주대화 = 1일 1회 무료.

### 티어 업그레이드 (Tier Upgrade)
기본 500원 리포트 → 프리미엄 5,000원 리포트로 추가 결제하면 기존 분석을 심층 확장.

### 코드 스플리팅 (Code Splitting)
Vite의 dynamic import로 초기 번들 크기 감소. 현재 초기 로드 gzip ~100KB.

### Anonymous Auth
Firebase 익명 인증. 첫 방문 시 자동 생성. 나중에 소셜 로그인과 link 가능.

### linkWithCredential
Firebase Auth 메서드. 익명 계정에 소셜 자격증명을 연결. 멀티 플랫폼 계정 통합의 핵심.

### lunar-javascript
npm 패키지. 양력/음력/간지 변환, 지장간, 납음, 신살, 12운성, 대운 계산 제공.

### TDS (Toss Design System)
`@toss/tds-mobile`. 앱인토스용 UI 컴포넌트 라이브러리. 52px 버튼, #3182F6 등.

### Granite
토스의 프론트엔드 빌드 도구. `granite.config.ts`로 설정.

### PWA Manifest
Progressive Web App 매니페스트. 홈 화면 설치·오프라인 일부 기능 지원.

### Firestore 경로 (Firestore Path)
```
users/{uid}                     — 유저
users/{uid}/profiles/{pid}      — 프로필
users/{uid}/reports/{rid}       — 리포트
users/{uid}/payments/{payid}    — 결제내역
users/{uid}/dailyFortune/{date} — 일일 운세
users/{uid}/chats/{chatId}      — 사주대화 기록
users/{uid}/shareLogs/{logId}   — 공유 리워드 로그
```

### Cloud Functions
Firebase Functions. 현재 5개: Claude 호출 · Gemini 보조 · IAP 검증 · 공유 리워드 지급 · 계정 정리.

### Opus / Sonnet / Haiku
Claude 모델 라인업.
- Opus 4.6: 최고 품질, 느림, 비쌈 → 핵심 리포트
- Sonnet 4.6: 균형, 중간 → 사주대화·요약
- Haiku 4.5: 빠름, 저렴 → 일일 운세·꿈해몽

### A/B 비교 (A/B Comparison)
Opus vs Sonnet 동일 사주로 교차 생성 → 품질 비교. P0 과제.

### 자기 리뷰 2차 호출 (Self-Review 2nd Pass)
1차 생성 → 2차 호출로 리포트를 검수·수정. 품질 바 유지.

### 프롬프트 템플릿 v2.1 (Prompt Template v2.1)
현재 운영 중인 시스템·유저 프롬프트의 공식 버전. `프롬프트템플릿_v2.1.md`.

### 콘텐츠 퀄리티 가이드 (Content Quality Guide)
AI 해석문의 5대 원칙 + 금칙어 + Before/After 예시. `콘텐츠퀄리티가이드.md`.

## 4. UX·디자인 용어

### 톤앤매너 (Tone & Manner)
사주500 브랜드 표현 규칙. "신비 + 고급 + 깔끔 + 모던". 무속인/점집 느낌 금지.

### 디자인 토큰 (Design Token)
CSS 변수 + Tailwind config로 통합한 단일 진실. `디자인토큰.md`.

### 오행 컬러 (Oheong Color)
- 목(木) = #2D8A4E
- 화(火) = #D32F2F
- 토(土) = #F57F17
- 금(金) = #757575
- 수(水) = #1565C0

### 브랜드 컬러
- Primary: #A08B6A (골드브라운)
- Background: #F5F0E8 (크림)
- Text: #3D3427 (다크브라운)
- Surface: #FFFFFF
- Border: #E8E0D4

### 섹션 아코디언 (Section Accordion)
리포트 10개 섹션을 접었다 펼 수 있는 UI 패턴. 첫 섹션은 기본 펼침.

### 티저 블러 (Teaser Blur)
프리미엄 유료 섹션의 미리보기. 2문장 노출 + 나머지 블러.

### 페이드인 애니메이션 (FadeIn Animation)
섹션 확장 시 0.3s ease-out. prefers-reduced-motion 대응.

### 글로벌 BalanceBar
화면 상단에 고정 표시되는 운 잔액 바. 모든 페이지에 공통.

### Toast
오른쪽 하단 2초 알림. 성공·에러·정보.

### ShareModal
공유 모달. 네이티브 공유 API 우선, 실패 시 클립보드 fallback.

### 모바일 퍼스트 (Mobile-First)
max-width 520px 기준. 데스크톱은 중앙 정렬된 모바일 뷰.

### 52px 버튼 규칙 (AIT)
앱인토스 버튼은 높이 52px. TDS 표준. 더 크게는 가능, 작게는 불가.

### 라이트모드 전용 (Light Mode Only)
사주500은 라이트모드만 지원. 앱인토스 규정. 다크모드는 Phase 2 이후 검토.

### 뒤로가기 금지 (No Back in AIT)
앱인토스는 브라우저 뒤로가기 버튼 제거됨. 명시적 닫기 버튼 필수.

## 5. 컴플라이언스·법률 용어

### 개인정보보호법 (PIPA)
한국 개인정보 보호법. 사주500은 이에 따라:
- 비활성 계정 1년 후 분리 보관, 3년 후 삭제
- 계정 삭제 요청 시 5일 이내 삭제
- 개인정보처리방침 필수

### 전자상거래법
결제 기록 5년 보관 의무 근거.

### 전자금융거래법
PG사(토스페이먼츠) 연동 시 준수 의무.

### 환불 정책 (Refund Policy)
- 미사용 운(paid만): 구매 후 7일 이내 전액 환불
- 사용한 운: 환불 불가
- 프로모션 운(bonus·reward): 환불 대상 아님
- 환불 절차: 고객센터 접수 → 검토 → PG사 취소

### 앱인토스 정책 (AIT Policy)
- IAP 의무 사용 (외부 결제 금지)
- 라이트모드 고정
- 뒤로가기 UI 자체 제공
- 52px 버튼
- TDS 준수

### 콘텐츠 면책 (Content Disclaimer)
"본 서비스의 해석은 참고용이며 의학·법률·재무 조언이 아님" 표기 의무. 모든 리포트 하단 고정.

### 광고·홍보성 표현 금지
"100% 적중" "운명 예측" 등 단정적·과장적 카피 금지. 공정거래위원회 가이드.

## 6. 프로세스·운영 용어

### PRD (Product Requirement Document)
본 `/docs/prd/` 폴더의 문서들. 기획·설계·수용기준 포함.

### AC (Acceptance Criteria)
수용기준. 각 PRD의 필수 섹션.

### TC (Test Case)
테스트 케이스. 만세력 TC30 + 페이지별 TC 세트 존재.

### 사람 손떼 (Hands-Off)
코드 수정 없이 유저에게 바로 릴리스해도 문제 없는 상태. `사람손떼_체크리스트.md` 로 검증.

### 콘텐츠 검수 (Content Review)
AI 리포트의 최종 품질 검수. 자기 리뷰 2차 호출 + 사람 샘플링 검수.

### 런칭 바 (Launch Bar)
런칭 최소 요건 집합. `런칭_체크리스트.md`.

### 페이지 감사 (Page Audit)
각 페이지의 UX·성능·접근성·법규 검수. `페이지감사_체크리스트.md`.

### 스모크 테스트 (Smoke Test)
핵심 플로우 1회 수동 점검. 배포 직후 필수.

### A/B 비교 (A/B Comparison)

## 8. 용어 사용 원칙

### 8.1 일관성
- 공식 명칭은 한 가지. "사주500" (O) / "사주 500" "사주500 앱" (X)
- 명리학 용어는 한자 병기 원칙

### 8.2 한자 사용 기준
- **반드시 한자 병기**: 원전 인용, 격국/용신/신살 등 핵심 명리 용어
- **한글 단독 가능**: 대중 노출 카피, 온보딩, 푸시
- **UI 본문**: 첫 등장 한자 병기, 이후 한글 단독
- **이모지와 구분**: 한자는 지식·권위, 이모지는 감정. 섞어 쓰지 말 것

### 8.3 톤 차별화
- 내부 문서: 정확한 명리학 용어
- 랜딩/온보딩: 풀어 쓰기 ("용신" → "당신에게 가장 필요한 기운")
- 리포트 본문: 한자 병기 + 풀이
- 푸시/토스트: 쉬운 말 우선

### 8.4 새 용어 등록 절차
1. `용어집.md` 에 추가
2. 관련 PRD 크로스 링크 업데이트
3. 팀 슬랙 공지 (해당 시)
4. 코드 주석·문서에 반영
