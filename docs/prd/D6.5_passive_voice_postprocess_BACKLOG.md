# D6.5 — 면피체 Client-side Postprocess (Backlog)

**상태**: Backlog (D6 배포 후 1주 prod 로그 관측 → 착수 결정)
**생성**: 2026-04-19 (D6 A안 배포 직후)

## 배경

D6 프롬프트 강화 후 emulator 8회 스모크에서 면피체(passive voice) 발생률:
- R1: 1/8 (12.5%)
- R2: 1/8 (12.5%)
- R3: 1/8 (12.5%) — D4 `opportunities[0].detail`, Dream R2 `interpretation` 필드

Sonnet 4.6 이 프롬프트 지시에도 **확률적으로** "~할 수 있습니다" / "~일 것입니다"
/ "~활용할 수 있습니다" 같은 경계 표현을 생성. 프롬프트만으로는 8회 중 1건 한계.

## 목표

면피체 잔존률 12.5% → **1% 미만**. 비용은 무시 가능 수준 유지.

### 비용 추정

- 면피체 발생률 12.5%, 발생 시 평균 1건 → 호출 중 12.5%만 추가 Sonnet 호출
- 추가 호출은 해당 필드만 (200~500자) → input 8K (원본+detection) + output 1K
- Sonnet 4.6 요금: $3/M input + $15/M output
- 1콜당: 12.5% × ($0.024 + $0.015) = **$0.005 기대**
- 일 1000콜 가정 시 월 **$150** 추가 — 무료 티어 비용 증가분
