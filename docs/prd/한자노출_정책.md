# 한자·전문성 노출 정책 (Hanja & Expertise Surfacing Policy)

> **문서 성격**: 사주500의 모든 유저 출력물에서 한자·전문 명리 용어를 언제·어떻게·얼마나 노출할지 결정하는 단일 정책.
>
> - 근거: 준기 2026-04-18 지시 — "참고서는 한자 많아도 되지만 유저 결과는 쉽게. 중요한 대목에서만 한자/이론을 상징·프레임으로 살짝. 본질은 유저가 쉽게 받아들이는 것."
> - 적용 범위: 리포트·일일운세·사주대화·랜딩·푸시·토스트·공유 카드·궁합 결과 등 **유저가 보는 모든 문자열**
> - 비적용: 내부 PRD·백과사전·레퍼런스풀·팀 커뮤니케이션 — 한자 자유 사용
> - 업데이트 책임: 준기 + AI 팀

---

## 1. 핵심 원칙 (Core Principles)

### 1.1 이원화 (Bifurcation)

| 문서군 | 성격 | 한자 사용 |
|--------|------|-----------|
| 내부 참고서 | 준기의 자산, AI 프롬프트 소스 | **자유** — 원전 인용 OK, 전문 용어 풍부 |
| 유저 출력물 | 비전문가 유저가 읽는 텍스트 | **절제** — 쉬운 풀이 우선, 한자는 상징으로 |

### 1.2 본질 선언

> "결국 유저가 쉽게 받아들여야 한다."

한자를 완전히 빼지 않는 이유는 **약간의 전문성·신비감·권위**를 주기 위함. 그러나 한자가 주인이 아니라 **프레임**이고 **인장(印章)** 이다. 본문은 한국어로 쉽게 흐르고, 한자는 특정 대목에서 **상징처럼** 자리 잡는다.

### 1.3 3대 원칙

1. **쉬운 풀이 우선**: 한자·명리 용어가 등장하면 반드시 한국어 풀이가 **본문 안에 자연스럽게** 녹아 있어야 함. 괄호 병기가 아니라 문장 흐름으로.
2. **한자는 인장·장식**: "이것이 당신의 도장"처럼, 중요한 대목에서만 **작고 정제된 방식**으로 노출. 나머지는 한글 중심.
3. **전문가 만족의 마이크로 디테일**: 사주 좋아하는 유저에게도 "아 이 서비스는 진지하다"는 신호. 과시 아닌 자연스러움.

## 2. 노출 기준 (Surfacing Criteria)

### 2.1 항상 한자 병기 (Always Show Hanja)

아래는 한자가 **정체성**이므로 항상 노출. 단 이해 가능한 풀이 동반.

- **4기둥 카드**: 년·월·일·시의 천간·지지 한자 8글자 (PillarCard 컴포넌트)
  - 표기: `戊寅 (무인 — 양토 위의 호랑이)` 형태로
  - 본문은 한글, 한자는 카드 상단 크게
- **격국 이름**: "정관격(正官格)", "식신격(食神格)" 등
  - 첫 등장 한자 병기, 이후 한글 단독
- **용신 오행 이름**: "수(水) 기운이 당신의 중심입니다" 식으로 오행 한자만 괄호
- **핵심 십성 (섹션 헤더 또는 요약)**: "정인(正印)", "편재(偏財)" 등
  - 섹션 타이틀에만 한자 병기, 본문은 한글 단독

### 2.2 선택적 한자 (Optional Hanja — Frame)

아래는 **필요할 때 프레임처럼** 노출. 본문 흐름을 끊지 않을 때만.

- 신살(神煞) 이름: "천을귀인(天乙貴人)" → 첫 등장만 한자
- 12운성 중 드라마틱 상태: 제왕(帝旺), 장생(長生), 절(絶) 등 — 강조 대목에서만
- 대운 교체기: "경자(庚子) 대운" — 카드 제목에만
- 원전 이름 (선택): "자평진전" — 한자 없이 한글로도 OK, 원전 언급은 최소화

### 2.3 금지 (Never Show Hanja)

아래는 **한자 노출 금지**. 한글만으로도 충분하거나 오히려 장벽.

- 푸시 알림·토스트: 짧은 문자열에 한자는 시각 과부하
- 에러 메시지: 이해를 방해
- 버튼 라벨: CTA는 쉬운 동사만
- 빈 상태·로딩 문구: 따뜻한 한국어
- 공유 카드 제목: 바이럴성 위해 한국어 중심
- 설정 메뉴: 기능명은 한국어

## 3. 유저 페르소나별 적용

### 3.1 초심자 (70%)
- 한자 처음 본다. 사주 용어 모른다.
- 전략: 한자는 시각적 장식으로만. 본문은 "왜 이런 경향인지" 이야기 중심.
- 카피 예시:
  - ❌ "당신은 식신(食神)이 강해 창의성이 높고 식복(食福)이 있습니다."
  - ✅ "당신은 새 아이디어를 잘 만들고, 사람들과 나누면서 삶을 채워가는 사람이에요. 명리학에서는 이런 기운을 '식신'이라고 부릅니다."

### 3.2 중급 (20%)
- 사주 좀 봤다. 대운·세운·용신 정도는 안다.
- 전략: 핵심 명리 용어를 정확히 쓰되 풀이 병기. 상징 대목에 한자 등장.
- 카피 예시:
  - "올해 당신의 대운은 정인(正印) — 학문과 배움이 깊어지는 시기입니다."
  - 한자는 중요한 상태 변화 대목에서만.

### 3.3 전문가 (10%)
- 격국·용신·신살 다 안다. 원전도 본다.
- 전략: 마이크로 디테일로 만족. 카드 한구석의 한자, 원전 출처 링크, 지장간 세부값.
- 페이지: "전문가 모드" 토글로 상세 정보 표출 (Phase 2 고려)

## 4. 출력 포맷 가이드 (Format Guide)

### 4.1 리포트 본문

**원칙**: 섹션당 한자 2~3개 이하. 있을 때는 풀이가 문장 안에 녹아있게.

**Bad**
```
[직업운]
당신은 편관(偏官)·상관(傷官)이 강하고 칠살(七殺)을 제압하는 격(格)입니다. 
신강(身强)한 사주로 관(官)을 쓰는 것이 용신(用神)입니다.
```

**Good**
```
[직업운]
당신은 압박 속에서 빛나는 사람입니다. 도전이 많은 자리일수록 집중력이 오히려
날카로워져요. 명리학에서는 이런 구조를 '칠살을 제압한다'라고 하는데, 
어려운 일을 정면으로 받아들여 내 것으로 만드는 기질이죠.

직장이라면 문제 해결이 본업인 역할 — 감사·법무·위기 대응·비상 프로젝트가 어울려요.
```

### 4.2 4기둥 카드

```
┌─────────────────┐
│   戊 寅          │  ← 한자 8글자 중심 시각
│   무·인          │  ← 한글 병기 작게
│                  │
│   양토 위의      │  ← 쉬운 풀이 1줄
│   호랑이         │
│                  │
│   십성: 비견     │  ← 한글 단독, 작은 글씨
│   운성: 장생     │
└─────────────────┘
```

### 4.3 섹션 헤더

```
1. 총평 — 당신의 큰 그림
2. 성격 — 타고난 결
3. 관계 — 사람과 만나는 방식
4. 일 — 가장 잘 빛나는 자리
5. 돈 — 돈이 들어오고 나가는 패턴
6. 사랑 — 애정의 결
7. 몸 — 건강의 리듬
8. 올해 — 병오(丙午) 해가 주는 흐름  ← 여기서만 한자
9. 과제 — 넘어야 할 산
10. 개운법 — 기운을 트는 작은 루틴
```

### 4.4 일일 운세

**원칙**: 한자는 일진(日辰) 표기에만.

```
오늘은 갑자(甲子)일 — 씨앗을 심는 하루

→ 새로운 시작에 좋은 기운이 흐릅니다. 
  오후 2시~4시 사이 중요한 연락이 올 수 있어요.
  행운 색: 파란색 · 행운 방위: 북쪽
```

### 4.5 사주대화

**원칙**: 대화는 구어체. 한자는 유저가 먼저 쓸 때만 같은 수준으로 응답.

**Bad (AI가 갑자기 전문용어)**
```
User: 올해 연애운은 어때?
AI: 당신의 일지(日支)는 편재(偏財)에 해당하고 세운(歲運)과 합충(合沖)이 일어나...
```

**Good**
```
User: 올해 연애운은 어때?
AI: 올해는 새로운 사람을 만날 가능성이 높은 해예요. 특히 5월과 9월이 
    기운이 모이는 때. 먼저 다가서는 쪽이 잘 풀려요.
```

### 4.6 푸시·토스트

```
푸시: "오늘의 운세가 도착했어요"
      NOT: "今日(금일)의 일진(日辰)이 업데이트되었습니다"

토스트: "공유 완료! 0.5운이 들어왔어요"
        NOT: "공유 완료. 운(運) 0.5가 적립되었습니다"
```

## 5. 언어적 톤 (Linguistic Tone)

### 5.1 금지 어휘 (Avoid)

- 단정형 한문투: "~할 운명이다", "~할 수밖에 없다"
- 점집 톤: "이 부적을 ~하시면"
- 어색한 번역체: "당신의 사주는 ~를 가지고 있다"
- 한자어 과밀: "중정(中正)한 덕(德)을 지닌 ~"

### 5.2 권장 어휘 (Prefer)

- 일상 동사: 쉽다, 편하다, 끌린다, 막힌다, 풀린다
- 경험형: "~해본 적 있으시죠?"
- 조건부: "이럴 때는 ~가 좋아요"
- 비유: "씨앗을 심듯", "파도에 맡기듯"

## 6. 프롬프트 주입 (Prompt Injection)

AI 리포트 생성 시스템 프롬프트에 다음 섹션 추가:

```
[한자·전문용어 사용 규칙]
- 본문은 일상 한국어로 쉽게 풀이. 비전문가 기준.
- 한자는 섹션당 2~3개 이하. 등장 시 문장 흐름에 풀이가 녹아있게.
- 금지: 한문투·점집 톤·어색한 번역체·한자 남발.
- 허용: 핵심 용어(격국명·용신·일진 등)에 첫 등장만 한자 병기.
- 프레임: "명리학에서는 ~라고 합니다" 식으로 한자를 자연스럽게 소개.
- 전문가 만족: 섹션 끝 또는 카드 하단에 "*[전문 용어: 정관격/수용신]*" 마이크로 디테일.
```

## 8. 검증 방법 (Validation)

### 8.1 자동 검증
- AI 2차 자기 리뷰 시 "한자 개수 / 섹션" 체크
- 3개 초과 시 재작성 트리거

### 8.2 수동 검증
- 샘플 리포트 20건 사람 리뷰 시 "이해 쉬움 점수" (1-5)
- 4점 미만이면 프롬프트 조정

### 8.3 A/B
- 한자 2개 vs 0개 vs 5개 버전으로 A/B 테스트 (Phase 2)
- 유료 전환율 / 재방문율로 최적 밸런스 탐색

## 9. 예시 모음 (Reference Examples)

### 9.1 Before / After 10쌍

**1. 성격 섹션 도입**
- Before: "당신의 일간(日干)은 경금(庚金)으로 강건(剛健)한 성품을 나타냅니다."
- After: "당신은 결정을 내리는 데 시간을 오래 끌지 않는 사람입니다. 옳다고 생각하면 바로 움직이는 단단한 기질이에요."

**2. 재물 섹션**
- Before: "편재(偏財)가 투출(透出)되어 재(財)가 움직입니다."
- After: "돈이 한 자리에 머물기보다 이리저리 움직이는 흐름을 타고납니다. 유통·거래·투자처럼 돈을 움직여 돈을 부르는 방식이 맞아요."

**3. 관계 섹션**
- Before: "관성(官星)이 약(弱)하니 배우자궁(配偶者宮)이 허(虛)합니다."
- After: "특정한 이상형 하나를 두고 찾기보다, 만나는 과정에서 점점 마음을 여는 타입입니다."

**4. 건강**
- Before: "수(水) 오행이 태약(太弱)하니 신장(腎臟)·방광(膀胱)을 주의하세요."
- After: "수분·피로 관리가 특히 중요해요. 쉴 때 제대로 쉬는 것이 곧 건강입니다."

**5. 올해**
- Before: "병오년(丙午年) 세운(歲運)에 정화(丁火)가 합(合)하여..."
- After: "올해는 '드러냄'의 해입니다. 한자로는 병오(丙午)라고 부르는 해인데, 태양이 중천에 오른 시기라는 뜻이에요. 숨어있던 노력이 무대 위로 올라오는 흐름이죠."

**6. 대운**
- Before: "현재 임자(壬子) 대운(大運) 진입으로 수기(水氣)가 왕(旺)합니다."
- After: "지금 10년은 물의 기운이 짙은 시기입니다. 본능적으로 끌리는 것과 사색이 많아지는 때예요."

**7. 개운법**
- Before: "목(木)이 용신(用神)이므로 동방(東方)을 향해 명상(冥想)하세요."
- After: "아침에 동쪽 창가에서 3분만 멍하니 하늘을 보세요. 나무 기운이 당신 중심이라, 초록·동쪽·숲이 작은 루틴 재료가 됩니다."

**8. 신살**
- Before: "천을귀인(天乙貴人)이 축(丑)에 있어 위기 시 도움이 있습니다."
- After: "결정적인 순간에 누군가 도와주는 인연이 있습니다. 그 사람이 예상 밖의 자리에서 나타나는 편이에요."

**9. 직업**
- Before: "식신생재(食神生財)의 격(格)으로 창의(創意)를 재물(財物)로 전환합니다."
- After: "창의가 돈으로 바뀌는 사주입니다. 콘텐츠·기획·제품 설계처럼 '만든 것이 팔리는' 일이 가장 잘 맞아요."

**10. 종합**
- Before: "정관격(正官格)에 식신제살(食神制殺)하니 군자(君子)의 상(相)입니다."
- After: "책임지는 자리를 피하지 않는 사람입니다. 압박이 있을 때 오히려 정돈되는 기질이라, 조직의 중심에 있을 때 잘 빛납니다."

## 10. 예외 처리 (Exceptions)

### 10.1 전문가 모드 토글 (Phase 2)

- 설정에서 "전문가 모드" 활성화 시 한자 노출 확대 + 원전 인용 + 지장간 세부값 표출
- 기본값 OFF
- 초심자 UX를 해치지 않음

### 10.2 궁합 결과

- 궁합은 "두 사람의 관계"가 주인공 — 한자는 최소로
- 납음·일간·일지 정도만 언급, 본문은 관계 서사 중심

### 10.3 공유 이미지

- 한자 최소 (디자인 요소로만 사용 가능)
- 바이럴성 위해 "한 줄 요약"이 한자로 덮이지 않게
