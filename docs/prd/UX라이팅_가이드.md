## 0. 이 문서의 목적

사주500의 **모든 UI 문구**(버튼·에러·빈상태·로딩·토스트·푸시·다이얼로그·이메일·푸시·이벤트 카피)의 톤과 표기 기준. AI 리포트 본문은 `콘텐츠퀄리티가이드.md` + `프롬프트템플릿_v2.1.md` 적용. 이 문서는 **그 외 모든 UI 텍스트** 담당.

**원칙**: 사용자가 어디를 봐도 같은 톤의 사람이 말하고 있다고 느끼게.

## 1. 톤 삼각형 (Tone Triangle)

```
        따뜻함 (Warmth)
           /\
          /  \
         /    \
        /      \
   단호함 ────── 신뢰
  (Clarity)    (Trust)
```

- **따뜻함 (Warmth)**: 친한 선배 명리학자. 친구는 아니지만 거리감 없음.
- **단호함 (Clarity)**: 우유부단하지 않고, 한 번에 결정 내려줌.
- **신뢰 (Trust)**: 데이터·근거가 뒤에 있다는 감각.

**3축 균형**: 상황에 따라 중심점이 이동.

| 상황 | 중심 |
|---|---|
| 결제 CTA | 단호 |
| 에러 메시지 | 따뜻 |
| 로딩 카피 | 신뢰 |
| 빈 상태 | 따뜻 |
| 성공 확인 | 단호 |
| 푸시 | 따뜻 |
| 이용약관 · 정책 | 신뢰 |

## 2. 존댓말 기준

**기본: 존댓말 (~요체 중심)**
- "~해요", "~일 거예요", "~하는 편이에요"
- "~입니다", "~습니다"는 필요할 때만 (법적·공지·보안)

**"~요" vs "~습니다" 선택 규칙**:

| 상황 | 어미 |
|---|---|
| 일상 UI 모든 곳 | ~요 |
| 개인정보 처리방침·약관 | ~습니다 |
| 결제 영수증·환불 안내 | ~습니다 |
| 중대 에러 (지불 실패) | ~습니다 |
| 시스템 공지 (점검·장애) | ~습니다 |
| CTA 버튼 | 명사·동사 원형 ("지금 충전", "사주 보기") |

**절대 금지**:
- 반말 (~해, ~야, ~지)
- "~해라", "~하세요" 명령문 — 예외: 보안·법적 필수
- 섞임 ("~해요. ~합니다." 동일 화면 혼용)

## 6. 시나리오별 카피 라이브러리

### 6.1 빈 상태 (Empty State)

**보관함 비어있을 때**:
```
아직 풀어본 사주가 없어요.

500원으로 한 번 만나보실래요?

[사주 보러 가기]
```

**궁합 리포트 없을 때**:
```
궁합 리포트가 없어요.

한 번 본 사주는 언제든 다른 사람과 교차해볼 수 있어요.

[궁합 보기]
```

**채팅 기록 없을 때**:
```
사주 이야기를 나눠본 적 없네요.

리포트를 먼저 보면 대화가 훨씬 재밌어져요.

[리포트 보기]
```

**검색 결과 없을 때**:
```
찾으시는 내용이 없어요.

철자를 다시 확인해보시거나, 다른 키워드를 시도해보세요.
```

### 6.2 에러 메시지

**네트워크 오류**:
```
연결이 잠시 끊겼어요.

Wi-Fi나 데이터 상태를 확인하고 다시 시도해주세요.

[다시 시도]
```

**서버 오류 (5xx)**:
```
잠시 후 다시 시도해주세요.

문제가 계속되면 [고객센터]로 문의해주세요.

[새로고침]
```

**결제 실패 (일반)**:
```
결제가 완료되지 않았어요.

다시 시도하거나 다른 결제수단을 선택해주세요.

[다시 결제] [다른 수단]
```

**결제 실패 (잔액 부족)**:
```
잔액이 부족해요.

다른 카드나 결제수단으로 시도해볼 수 있어요.

[다른 수단]
```

**결제 성공 + 운 충전 실패 (부분 실패)**:
```
결제는 됐는데, 운 충전이 아직 안 됐어요.

잠시 후 자동으로 반영되거나, 5분 내 처리 안 되면 즉시 자동 환불됩니다.

[새로고침]
```

**로그인 실패 (앱인토스)**:
```
토스 로그인이 잠시 불가능해요.

잠시 후 다시 시도해주세요.

[다시 시도]
```

**사주 생성 실패**:
```
사주 풀이를 완성하지 못했어요.

사용된 운은 자동 환불됐습니다. 잠시 후 다시 시도해주세요.

[다시 시도]
```

**입력 검증 실패 (생년월일)**:
```
생년월일을 확인해주세요.

연·월·일 모두 입력돼야 사주를 볼 수 있어요.
```

### 6.3 로딩 카피 (로딩전략 PRD 연동)

**만세력 계산 중**:
```
만세력 계산하는 중이에요…
(생년월일을 천간지지로 옮기고 있어요)

-30분 보정 적용 중
```

```
[다음 →]
```


**스트리밍 중 (고정 카피)**:
```

잠시만요.
```

## 7. 숫자·단위·날짜 표기

- **가격**: `500원`, `5,000원` (쉼표 O, 공백 X)
- **기호 순서**: 숫자 → 단위 (예: `500원`)
- **운(運)**: `1운`, `10운`. 가상화폐. 괄호 병기 생략 가능.
- **시간**: `24시간제` (예: `14:00`). 구어는 `오전/오후` 선택 허용 (`오후 2시`).
- **날짜**: `2026-04-18` 기준. 구어는 `4월 18일` 허용.
- **한자 병기**: 초출 시 `한자(한글음)` 예: `寅時(인시)`. 동일 섹션 내 재등장 시 한글만.
- **나이**: 만 나이. `29세`, `29(만)` 중 문맥 선택.

## 9. 한자 표기 규칙

- **전각**: 천간지지·원전 인용 시 전각 (예: `癸水`, `寅木`).
- **반각**: 코드 상수 (`DAY_GAN.JIA` 등) 한정.
- **병기 규칙**:
  - 초출: `한자(독음/의미)` 예: `상관격(傷官格, 드러내고 표현하는 격)`
  - 재등장 (같은 섹션): `독음`만 예: `상관격`
  - 다른 섹션 재등장: 다시 `한자(독음)`
- **한국어 한자음 기준**: 국립국어원 표준발음법. 사주 용어는 관용 병기 우선 (예: `용신(用神, 도움을 주는 기운)`).
- **이모지 치환 금지**: CLAUDE.md 룰.

---

## 10. 국제화 (i18n) 대비

- 모든 UI 문구 → `src/locale/ko.json` 단일 소스.
- 키 네이밍: `section.location.context` 예: `button.payment.pay500`
- 중복 문구 금지 (같은 문구 다른 키 X).
- 변수 삽입: `{name}`, `{amount}`, `{date}` 형식 유지.
- 한자 병기는 한국어 한정. 영어판은 로마자 표기(예: `Gyeong-geum`).

---

## 11. 접근성 · 스크린리더

- 모든 버튼: `aria-label` 필수.
- 아이콘 단독 버튼: 텍스트 대체 제공.
- 에러는 `role="alert"` 로 선언.
- 로딩 스피너: `aria-live="polite"` + 대체 텍스트 ("사주를 계산하고 있어요").
- 동적 카운트다운 (프로모): 스크린리더에 1초마다 읽히지 않게 (`aria-live="off"`).
- 색상만으로 상태 구분 금지 (예: 오류 빨강 + 경고 아이콘 같이).

## 12. 브랜드 시그니처 문구

자주 등장해서 "사주500스러움"을 만드는 문장 템플릿.

- "한 번 만나보실래요?"
- "500원이면 충분해요."
- "만세력부터 시작합니다."
- "AI가 뽑아드립니다. (하지만 명리학자가 감수했어요.)"
- "오늘 ○時(○~○)가 ○○ 타이밍이에요."
- "이 정도면 감이 오시죠?"
- "한 번 풀어본 사주는 평생 보관돼요."

## 13. 엣지 케이스

1. **유저 이름 미입력**: `준기님` → `고객님` 금지, `○○님` 허용 (예: "○○님의 오늘 운세"). 또는 이름 생략 ("오늘 運이…").
2. **숫자 0 상황**: "보관함이 0개" → "아직 없어요" (0 표기 지양).
3. **예외적 중장년 타겟**: 그대로. 반말·20대 슬랭 금지는 전체 공통.
4. **해외 체류 유저**: 시간대 감지 시 한국 표준시 기준 명시 ("KST 기준 오후 2시").
5. **금액 단위 해외 확장**: ¥, $ 단위 JSON 분기.
6. **법적 필수 안내**: 어미 "~습니다" 강제. 따뜻한 톤보다 정확성 우선.
7. **시스템 점검 중 알림**: 푸시 말고 배너 + 홈 상단 공지. 푸시는 사용자 귀찮게 함.
8. **어뷰저 계정 차단 안내**: 톤 부드럽게, "정책 위반"이라는 단어 노출 금지. "이용이 제한됐어요. 문의 바랍니다."
9. **미성년자 진입**: 결제 전 연령 확인 배너 표시. 톤 사무적.
10. **실명 정보 유출 방지**: 공유·리뷰 UI에서 실명 표기 옵션 기본 OFF + 안내 카피 ("공개하면 첫 글자만 보여요").

## 14. 수용 기준 (AC)

### AC-01: 로케일 단일 소스
- **AC-01.1** 모든 UI 문구 `src/locale/ko.json` 에 존재.
- **AC-01.2** 하드코딩된 한글 문자열 0 (빌드 시 린터로 검증).

### AC-02: 톤 일관성
- **AC-02.1** 어미 "~요" 체 비율 전체 UI 문구 80% 이상.
- **AC-02.2** 법적·공지 영역 제외한 "~습니다" 연속 3회 이상 0건.

### AC-03: 금지어
- **AC-03.1** 금지어 20개 중 어느 것도 UI 문구에 등장 안 함.
- **AC-03.2** 빌드 시 린터가 금지어 감지하면 CI 실패.

### AC-04: 문구 길이
- **AC-04.1** 버튼 라벨 8자 이내.
- **AC-04.2** 토스트 20자 이내.
- **AC-04.3** 푸시 타이틀 15자 이내.

### AC-05: 접근성
- **AC-05.1** 모든 인터랙티브 요소 `aria-label` 존재.
- **AC-05.2** 아이콘 전용 버튼 텍스트 대체 제공.
- **AC-05.3** 에러 요소 `role="alert"` 부여.

### AC-06: 한자 병기
- **AC-06.1** 초출 한자 `한자(독음/의미)` 표기.
- **AC-06.2** 한자 → 이모지 치환 0건.

### AC-07: 이모지 정책
- **AC-07.1** AI 리포트 본문 이모지 섹션당 0~1개.
- **AC-07.2** 에러·결제 CTA 이모지 0.
