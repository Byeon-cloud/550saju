## 0. 이 문서의 목적

사주500이 **왜 존재하는가·누구를 위한가·무엇을 약속하는가**를 단일 서사(narrative)로 정리. 랜딩·소개·마이페이지·SNS·이메일·푸시 등에서 일관된 스토리가 반복돼 브랜드 밀도를 만들어내게 한다.

**핵심 전제**:
- 사용자는 "제품 설명"에 감동하지 않는다. **왜 만들었는가**에 공감한다.
- "500원"은 가격이 아니라 **약속**이다.
- 무속·점집·AI 챗봇 중 어느 것도 아닌, **새로운 범주**를 제시한다.

## 1. 브랜드 탄생 스토리

### 한 줄
> "사주가 비싸서 못 보던 사람에게, 맨 처음 만져볼 수 있는 500원짜리 문(門)을 연다."

### 3단계 내러티브

**1단계 — 관찰 (Why this problem)**
많은 사람이 사주에 호기심을 갖지만, 관문은 둘 중 하나다: 3만원짜리 점집에 예약하거나, 무료 웹 사이트에서 질 낮은 풀이를 보거나. 진심으로 궁금한 사람들은 중간이 없다는 걸 안다. 특히 2030 여성들은 점집의 복장·분위기·노년 남성 상담사 앞에서 위축되고, 친구 추천 점집은 한 번에 5만원이다.

**2단계 — 선택 (Why this price)**
500원은 "호기심을 한 번 확인해볼 수 있는 심리적 관문"이다. 더 낮으면 신뢰가 떨어지고, 더 높으면 처음 고객이 아예 안 들어온다. 한 잔 커피의 1/5, 편의점 음료 1/4. 실패해도 아깝지 않은, 그러나 "공짜는 아닌" 최소 결제선.

**3단계 — 약속 (What we promise)**
- **퀄리티는 점집 이상**: AI가 뽑지만, 명리학자가 감수한 6대 원전 기반 프롬프트로 해석한다.
- **무속 느낌 없음**: "살이 끼었다", "부적 써야 해" 같은 위협 없음.
- **AI 느낌 없음**: "물론이죠", "긍정적인 에너지" 같은 AI 카피 금지.
- **언제든 다시 꺼내볼 수 있음**: 한 번 푼 사주는 평생 보관.

## 2. 브랜드 5대 가치 (The Five)

### Value 1 — 정직 (Honesty)
AI가 쓴다는 사실을 숨기지 않는다. 그러나 **AI + 명리학자 감수**라는 구조를 명시한다. 공포 조장하지 않고, 운명을 단정하지 않는다.

### Value 2 — 접근성 (Accessibility)
500원은 문이다. 로그인이 필요 없다. 한 번 풀이 받기까지 30초. 부담 없이 와서, 진지하게 받아간다.

### Value 3 — 깊이 (Depth)
500원짜리 AI 풀이가 3만원 점집보다 깊을 수 있다. 6대 원전·십성·대운·신살까지 빠짐없이 읽고, 구체 장면으로 번역해준다.

### Value 4 — 세련됨 (Refinement)
디자인·카피·인터랙션에 점집/무속 냄새 제거. 깔끔한 크림 배경, 골드브라운 포인트, 한자는 전각 세리프, 본문은 16px 1.7 라인하이트. 모던하되 차갑지 않다.

### Value 5 — 존중 (Respect)
사용자의 시간·감정·돈을 존중한다. 쓸데없는 팝업 없고, 과잉 사과 없고, 가짜 긴박감 없고, 어뷰저 아니면 의심받지 않는다.

## 3. 브랜드 포지셔닝

### 포지셔닝 스테이트먼트

> "사주500은 운명을 점치는 도구가 아니라, **자기 자신의 타고난 패턴을 들여다보는 500원짜리 거울**이다. 점집보다 깊고, 심리테스트보다 정확하며, AI 챗봇보다 따뜻하다."

### 경쟁 맵 (Positioning Map)

```
          깊이 (↑)
          │
  점집 ●  │
          │  ● 사주500
          │
 ─────────┼─────────→ 세련됨
          │
          │
  무속인 ●│  ● 포스텔러(일부)
          │
          │  ● 헬로우봇 (얕음)
          ↓
```

### 경쟁자 대비 핵심 차이

- vs **점집**: 3만원 → 500원, 예약 → 즉시, 음습함 → 세련됨.
- vs **포스텔러**: AI 퀄리티 ↑, 톤 ↑, 가격 동급 근처.
- vs **헬로우봇**: 심층 ↑, AI 티 ↓, 가격 ↑.
- vs **점신**: 게이미피케이션 스타일 제거, 의미 기반 리텐션.
- vs **무료 사주 웹사이트**: 깊이·퀄리티 모든 면에서 압도.

## 4. 타겟 페르소나 (Persona Core)

### 페르소나 1 — 지은 (28, 여, 사무직)
- 친구 따라 몇 년 전 유명 점집 다녀왔는데 3만원 아깝다고 생각.
- 인스타에서 "사주 정확해" 밈 자주 봄.
- MBTI·심리테스트 좋아함.
- **관문**: 500원이라니까 "한 번만 해볼까".
- **재방문 트리거**: 월간 세운·24절기 푸시, 친구랑 궁합 보기.

### 페르소나 2 — 현수 (32, 남, IT)
- 데이터 기반 사고. 점집 안 감. 하지만 "사주는 통계"라는 말에 끌림.
- Claude/ChatGPT 자주 씀.
- **관문**: "AI로 풀이한다" + "500원"의 기술 + 가격 조합.
- **재방문 트리거**: 자기 리포트 공유, 지인 사주 풀이 의뢰.

### 페르소나 3 — 영희 (45, 여, 자영업)
- 주기적 점집 방문. 월 5~10만원 지출.
- 어머니 세대 명리 용어 익숙.
- **관문**: "어차피 AI 붐인데 한 번 비교해보자".
- **재방문 트리거**: 5,000원 심층 리포트, PDF 저장, 가족 사주 보관.

## 5. 브랜드 목소리 (Brand Voice)

- **따뜻하되 단호**: 친한 선배 명리학자.

```

**서브 블록 — 왜 500원인가**
```
커피 한 잔의 1/5.
고작 500원이지만, 저희는 이 값이 가장 정직한 관문이라고 생각했어요.

무료는 대충인 것 같고,

그 중간에 500원이 있어요.
```

**서브 블록 — 무엇이 다른가**
```
AI가 뽑습니다. 하지만 명리학자가 감수했어요.

6대 원전 — 자평진전·적천수·궁통보감·삼명통회·명리약언·연해자평 —

일간·월지·십성·대운·신살까지 빠짐없이 읽어드립니다.

## 12. 금지 스토리라인

다음은 브랜드에서 **절대 하지 말아야 할** 스토리:

1. **"운명을 바꿀 수 있다" 서사**: 사주500은 운명을 "읽는" 도구. 바꾸는 도구 아님.
2. **점집·무속인 스타일**: "영적 에너지", "전생", "살" 금지.
3. **AI 만능 서사**: "AI가 모든 걸 압니다" 금지. "AI + 명리학자 감수" 구조 강조.
4. **공포 마케팅**: "큰 일 나기 전에 확인하세요" 금지.
5. **비교 폄하**: 경쟁사 직접 공격 금지.
6. **가격 자랑 일색**: "500원이 대단하다"만 반복하지 않음. 깊이·정확성·세련됨 함께 강조.
7. **젊은이 편향**: 중장년 배제 금지. 톤은 공유하되 채널별 앵글 분기.
8. **인플루언서 헌팅 티**: 인플루언서 이름 걸고 홍보 금지 (진정성 훼손).
