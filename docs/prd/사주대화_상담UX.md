## 1. 목적 (Goal)

**"철학관 상담을 다녀온 느낌을 준다."**

사주대화는 리포트를 보고 "더 궁금한 게 있어요"로 진입하는 **후속 상담**이다. 이 상담이 AI 같으면 브랜드가 깎이고, 자연스러우면 리포트의 가치가 다시 올라간다.

**경쟁사 대비 차별 지점:**
- 점신 채팅: 질문→답변 핑퐁, 기계적, 종결 어색.
- 포스텔러 채팅: 짧은 답변, 깊이 부족.
- 사주500: **상담사 호흡 + 명리학 근거 + 자연스러운 종결 + 다음 단계 제안**.

**성공 지표:**
- 첫 상담 완료율 ≥ 70% (중도 이탈 30% 이내).
- 상담 후 NPS ≥ 60.
- 상담 종료 후 24h 내 후속 상품 결제 ≥ 15%.
- "AI 같다" 피드백 비율 ≤ 5%.

## 2. 핵심 결정 (Decisions)

### 2.1 상담 구조

**3단계 플로우:**

1. **진입 (Entry)** — 유저가 고민을 적거나, 리포트 섹션에서 "이 부분 더 물어보기" 클릭.
2. **상담 (Session)** — 3~8 턴 대화, AI가 질문·공감·해석 혼합.
3. **종결 (Closure)** — AI가 먼저 "오늘은 여기까지 얘기해요"로 마무리 + 관련 콘텐츠 추천.

**턴 구조 (대화 리듬):**

| 턴 | 사주500 발화 | 유저 발화 |
|---|---|---|
| T1 | 여는 말 + 맥락 질문 | 고민 서술 |
| T2 | 공감 + 명리학적 힌트 + 추가 질문 | 세부 서술 |
| T3 | 해석 제시 + "어떻게 느껴지세요?" | 감정 반응 |
| T4 | 구체적 조언 + 예상 반응 | 추가 질문 or 수긍 |
| T5~T7 | 깊이 전개 | 자연스러운 끝 |
| T8 (마지막) | **자연스러운 종결 멘트** + 추천 카드 | — |

### 2.2 AI답지 않은 대화 (Anti-AI Feel)

**금지 패턴:**
- "물론이죠!" "좋은 질문이에요!" 시작.
- "~인 것 같아요. 하지만 ~일 수도 있어요." 이중 헤지.
- "도움이 되셨나요?" 기계적 피드백 요청.
- 이모지 남발 (0~1개 허용, 의미 있을 때만).
- 불릿 리스트로 답변 (대화가 아닌 보고서화).

**권장 패턴:**
- **짧고 깊게** — 1턴에 2~4 문장이 이상적.
- **질문으로 여백** — "지금 어떤 느낌이 드세요?" 유저가 말할 공간.
- **침묵 허용** — "…" 로 생각의 호흡 표시.
- **명리학적 근거 1줄** — "당신의 일간이 壬水(임수)라서" 처럼 근거를 슬쩍.
- **구어체 존댓말** — "그러시군요" ↔ "그러세요" 혼합. 딱딱하지 않게.

### 2.3 자연스러운 종결 (Natural Closure)

AI 상담의 가장 어색한 지점은 **종결**이다. 사람 상담사는 "오늘은 이 정도로 하죠"라고 자연스럽게 끝내지만, AI는 유저가 "감사합니다"를 말해야 끝난다.

**사주500의 종결 전략:**

1. **턴 3~4 넘어가면 AI가 먼저 마무리 시그널**:
   - "지금 드린 얘기만 해도 이번 주 내내 곱씹을 만해요."
   - "오늘은 이 정도에서 마음에 담아두세요."
2. **종결 멘트 3개 옵션 랜덤 (템플릿화 방지):**
   - (A) "마지막으로 하나만 드릴게요. [한 줄 통찰]. 오늘은 여기까지예요."
   - (B) "충분히 얘기했어요. 다시 궁금해지면 언제든 오세요."
   - (C) "말씀하신 것만 정리해보면 [요약 한 줄]. 이 정도면 오늘은 충분해요."
3. **종결 후 "상담 끝" 표시** + 관련 콘텐츠 카드 노출.

### 2.4 콘텐츠 추천 카드 (Closing Cards)

종결 후 하단에 자동 노출:

```
┌─────────────────────────────────┐
│  오늘의 대화에서 나온 주제      │
│  ─────────────────────────      │
│                                 │
│  💬 "직업" 에 대해 더 깊이      │
│      500원 · 직업·재능 심층분석 │
│      [열어보기]                 │
│                                 │
│  💬 "배우자 궁합" 에 대해       │
│      5,000원 · 궁합 리포트      │
│      [열어보기]                 │
│                                 │
└─────────────────────────────────┘
```

- 대화 내용을 분석해서 **언급된 주제**를 상품에 매핑.
- 최대 3개 카드.
- 이미 구매한 상품은 제외.
- **우선순위:** 500원 주제 상품 → 5,000원 프리미엄 → 관계 분석 → 절기 상품.

### 2.5 상담 메모리 (Conversation Memory)

**Phase 1 (MVP):**
- 현 세션 내 턴만 기억 (컨텍스트 윈도우).
- 세션 종료 후 요약만 저장 (`chats/{chatId}` 문서).
- 다음 상담 진입 시 "이전 상담에서 '직업'에 대해 얘기했어요" 자동 리마인드.

**Phase 2:**
- 유료 "상담 메모리" 기능. 월 구독으로 이전 상담 전체 열람·검색.

### 2.6 요금 정책

| 구분 | 가격 | 한도 |
|---|---|---|
| 무료 | 0원 | 1일 1회 (최대 5턴) |
| 유료 | 500원 (1운) | 무제한 턴 (세션당) |
| 프리미엄 유저 | 무료 | 1일 3회 |

- 무료 상담은 5턴 도달 시 "더 얘기하려면 500원으로 이어갈까요?" CTA.
- 유료 상담은 30분 무활동 시 자동 종결.

### 2.7 민감 주제 정책

| 주제 | 처리 |
|---|---|
| 자살·자해 | 즉시 상담 전화(1393, 1577-0199) 안내, 사주 해석은 생략 |
| 타인 저주·해악 | 단호히 거절, "사주는 이런 용도가 아닙니다" |
| 미래 확정 예언 요구 | "확정적 예언은 어떤 명리학자도 하지 않습니다"로 리프레임 |
| 연애 집착·스토킹 암시 | 자기 이해 방향으로 전환 |
| 의료·법률 상담 요구 | 해당 전문가 안내, 사주로 판단 금지 |

## 3. UI 명세

### 3.1 대화 화면 레이아웃

```
┌─────────────────────────────────┐
│  ← 닫기              💬 사주대화│
├─────────────────────────────────┤
│                                 │
│  [사주500]                      │
│  안녕하세요, 오늘 어떤 고민이   │
│  있으세요?                      │
│                                 │
│                [ 요즘 일이 안 풀려요 ] │
│                                 │
│  [사주500]                      │
│  일이라 하셨는데 … 지금 어떤    │
│  상태인지 조금 더 얘기해주실래요│
│                                 │
│  ⋯⋯⋯ (생각 중 …)                │
│                                 │
├─────────────────────────────────┤
│  [ 메시지 입력 ]         [보내기]│
└─────────────────────────────────┘
```

- 사주500 말풍선: 좌측, 크림 배경, 골드브라운 테두리.
- 유저 말풍선: 우측, 연한 그레이 배경.
- 입력창: 하단 고정, 멀티라인 자동 확장.
- "생각 중" 플레이스홀더: 점 3개 애니메이션.

### 3.2 종결 후 화면

```
┌─────────────────────────────────┐
│  [사주500]                      │
│  오늘은 이 정도에서 마음에      │
│  담아두세요. 다음에 또 오세요.  │
│                                 │
│  ⋯⋯ 상담 종료 ⋯⋯                │
│                                 │
├─────────────────────────────────┤
│  오늘의 대화에서 나온 주제      │
│  ─────────────────────────      │
│  [직업·재능 심층분석 500원]     │
│  [궁합 리포트 5,000원]          │
└─────────────────────────────────┘
```

### 3.3 "생각 중" 연출

- 응답 전 1~2초 지연 (즉답이 아닌 호흡).
- 점 3개 애니메이션 + 연한 배경 pulse.
- 응답 스트리밍 시작 시 지연 해제.

### 3.4 스트리밍 vs 배치

- **스트리밍** 사용 (글자 단위 점진 렌더).
- 속도: 약 40자/초 (사람 타이핑 속도).
- **너무 빠르면 AI티 남** — 일정 속도 유지.

### 3.5 종결 UI 시그널

- 종결 말풍선 위에 가는 점선 + "상담 종료"
- 입력창 비활성화 (placeholder "대화가 종료되었어요")
- 하단 "새 상담 시작" 버튼 노출.

## 4. 프롬프트 설계 (AI Prompt)

### 4.1 시스템 프롬프트 구조

```
당신은 사주500의 상담사입니다. 명리학 6대 원전(자평진전·적천수 등)에 근거한 해석을 합니다.

대화 원칙:
1. 1턴에 2~4 문장만.
2. "물론이죠" "좋은 질문이에요" 시작 금지.
3. 질문으로 여백을 남기세요.
4. 명리학적 근거(천간·지지·오행·십성)를 자연스럽게 슬쩍 드러내세요.
5. 구어체 존댓말, 딱딱하지 않게.
6. 종결 시그널: 3~4턴 이상 진행되면 자연스럽게 마무리.

유저 사주 정보:
[사주 원국 / 대운 / 일간 / 오행 밸런스 …]

이전 상담 요약:
[있을 경우 삽입]

금지 사항:
- 확정적 예언 ("당신은 반드시 …")
- 타인에 대한 저주성 해석
- 의료·법률 조언
- 이모지 남발
```

### 4.2 턴마다 발화 제약

- 최대 200자, 평균 120자.
- 문장 끝은 다양하게 (~세요, ~군요, ~예요, ~죠, ~네요).
- 같은 문장 끝 3턴 연속 금지.

### 4.3 종결 감지 로직

**턴이 4 이상 + 다음 조건 중 하나:**
- 유저 발화가 수긍형 ("그렇네요" "맞아요")
- 유저 발화가 감정 반응 1줄
- 유저가 "감사합니다" 언급

→ 종결 멘트 3옵션 중 랜덤 선택.

### 4.4 콘텐츠 추천 추출

- 세션 종료 후 AI가 대화 로그 분석 → 언급 주제 추출.
- 매핑 테이블:
  - "직업" / "회사" / "진로" → 직업·재능 심층분석 (500원)
  - "연애" / "결혼" / "배우자" → 애정·결혼 심층분석 (500원) or 궁합 (5,000원)
  - "돈" / "투자" / "재물" → 재물운 심층분석 (500원)
  - "부모" / "자식" / "가족" → 관계망 분석
  - "건강" → 건강 심층분석 (500원)
  - "올해" / "내년" → 올해의 운세 / 프리미엄 월운

## 5. 데이터 모델

```ts
// users/{uid}/chats/{chatId}
{
  chatId: string,
  startedAt: timestamp,
  endedAt?: timestamp,
  status: 'active' | 'ended_natural' | 'ended_timeout' | 'ended_paywall',
  tier: 'free' | 'paid' | 'premium',
  turnCount: number,
  turns: Turn[],
  summary?: string,       // AI가 세션 끝에 자동 요약
  topicsExtracted: string[],
  recommendedProducts: string[],
  endedBy: 'user' | 'ai' | 'system',
}

interface Turn {
  role: 'user' | 'assistant';
  content: string;
  timestamp: timestamp;
  tokenCount?: number;
}

// users/{uid}/chats_index
{
  lastChatAt: timestamp,
  freeUsedToday: boolean,
  freeResetAt: timestamp,  // 매일 00:00 KST
}
```

## 6. 유저 스토리

### US-01. 리포트 → 대화 → 업셀
> *지은(27, 여). 500원 성격분석 읽던 중 "대인관계" 섹션에서 "이 부분 더 물어보기" 클릭. 대화 진입 → 4턴 상담 후 "배우자와의 궁합을 깊이 얘기해보시겠어요?" 추천 → 5,000원 궁합 결제.*

### US-02. 무료 한도 → 유료 전환
> *태현(33, 남). 무료 5턴 사용 후 한도 도달. "더 얘기하려면 500원으로 이어갈까요?" CTA → 결제 → 세션 이어짐.*

### US-03. 자연스러운 종결
> *수아(24, 여). 3턴 상담 후 "그렇네요"로 답. 사주500이 "오늘은 이 정도에서 마음에 담아두세요"로 종결. "어색하지 않다, 진짜 상담 같았다" 피드백.*

### US-04. 민감 주제 대응
> *민준(29, 남). 극단 상황 암시 발화. 사주500이 즉시 사주 해석 중단 + 상담 전화 안내. 유저 안전 확보.*

### US-05. 이전 상담 리마인드
> *지은 다음 날 재방문. 진입 화면에 "지난번에 '직업'에 대해 얘기했어요. 오늘은 어떤 얘기를 해볼까요?" → 연속감 확보.*

## 7. 엣지 케이스

| ID | 상황 | 처리 |
|---|---|---|
| E-01 | 유저가 장문(500자 이상) 발화 | 분할 처리, AI가 공감 후 "조금만 더 구체적으로" 리드 |
| E-02 | 유저가 "종결 안 하고 계속" 요구 | 유료 전환 CTA, 유료면 30분 무활동까지 지속 |
| E-03 | 유저가 타 사이트·경쟁사 언급 | "저희 사이트 얘기만 할게요" 리프레임 |
| E-04 | AI 응답 실패(API 오류) | "잠시 후 다시 와주세요" 폴백, 리워드 차감 없음 |
| E-05 | 유저가 사주 없이 대화 시도 | "먼저 생년월일을 입력해주세요" 유도 |
| E-06 | 유저가 다른 사람 사주로 대화 | 관계망 연결 유도, "그 분을 관계망에 추가해보세요" |
| E-07 | 유저가 욕설·비방 | 1회 경고, 2회 이상 대화 종료 |
| E-08 | 유저가 의료·법률 조언 요구 | 해당 전문가 안내, 사주 해석 생략 |
| E-09 | 자살·자해 키워드 | 즉시 상담 전화 안내, 사주 해석 중단 |
| E-10 | 유료 세션에서 30분 무활동 | 자동 종결, 재개 시 새 세션 |

## 10. 오픈 퀘스천

1. **무료 5턴이 너무 짧은가** — 너무 길면 유료 전환 지연. 3~7턴 A/B 필요.
2. **프리미엄 유저 3회/일은 너무 많은가** — 비용 부담, Claude API 사용량 추정 필요.
3. **이전 상담 요약을 Firestore에 저장할지, 세션 단위 휘발할지** — Phase 1은 90일 저장 기본.
4. **"AI 티 안 난다"의 정량 측정법** — 유저 설문 vs 패턴 분석. 자동화 어려움.
5. **상담사 페르소나를 하나로 고정할지, 옵션 제공할지** — MVP는 하나, Phase 2 검토.
6. **민감 주제 감지 임계** — false positive가 많으면 상담 중단이 과다. 튜닝 필요.
7. **추천 카드 3개가 적절한가** — 너무 많으면 결정 피로, 1~2개로 줄일지.
