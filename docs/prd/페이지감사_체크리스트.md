# 페이지 감사 체크리스트 (Page Audit Checklist)

> **문서 성격**: 사주500의 모든 페이지를 동일한 기준으로 감사하는 단일 체크리스트. QA·릴리스·분기별 감사에 사용.
>
> - 대상 페이지: 12개 (HomePage, InputPage, LoadingPage, ResultPage, DailyPage, CompatPage, StoragePage, ChargePage, MyPage, SharePage, DreamPage, TopicAnalysisPage 등)
> - 감사 주기: 릴리스 전 + 분기별 + 큰 변경 후
> - 원칙: 감사 실패 시 해당 페이지 릴리스 보류
> - 사용: 각 페이지별로 섹션 8개 감사 후 결과 기록

---

## 0. 공통 감사 기준 (모든 페이지)

### 0.1 접근 감사
- [ ] URL 직접 접근 정상 (SPA 라우팅)
- [ ] 비로그인 상태에서 접근 정책 명확 (허용/차단/리다이렉트)
- [ ] 권한 검증 (Firestore Rules로 이중 방어)
- [ ] 404 처리

### 0.2 레이아웃 감사
- [ ] 320px에서 레이아웃 OK
- [ ] 520px에서 레이아웃 OK
- [ ] 1024px+ 중앙 정렬 OK
- [ ] 가로 스크롤 없음
- [ ] 세이프 에어리어 (iOS 노치) 처리
- [ ] 키보드 올라와도 입력 필드 가려지지 않음 (iOS)

### 0.3 인터랙션 감사
- [ ] 터치 타겟 최소 44×44px
- [ ] 버튼 상태 (default·hover·active·disabled)
- [ ] 더블클릭 방지 (결제 등 민감 액션)
- [ ] 롱프레스 대응 (iOS 기본 메뉴 억제 필요 시)
- [ ] 스와이프 제스처 (선택)

### 0.4 성능 감사
- [ ] 페이지 LCP < 2.5s
- [ ] FID < 100ms
- [ ] CLS < 0.1
- [ ] 번들 분석 (해당 페이지 추가 청크 < 50KB)
- [ ] 이미지 최적화 (WebP·lazy load)

### 0.5 접근성 감사
- [ ] Lighthouse a11y 95+
- [ ] 스크린리더 순서 논리적
- [ ] 포커스 가시성
- [ ] 색상 대비 AA
- [ ] prefers-reduced-motion 대응

### 0.6 컴플라이언스 감사
- [ ] 한자 한글 병기 (명리 용어)
- [ ] 금칙어 제로
- [ ] 법적 면책 (필요 페이지)
- [ ] 개인정보 최소 수집

### 0.7 앱인토스 감사 (AIT 전용)
- [ ] `window.confirm`, `alert` 미사용
- [ ] 52px 버튼
- [ ] 라이트모드 고정
- [ ] 뒤로가기 UI 명시
- [ ] 외부 링크 처리 (`openBrowser` 등)

### 0.8 분석 감사
- [ ] 페이지뷰 이벤트
- [ ] 주요 CTA 클릭 이벤트
- [ ] 에러 이벤트 Sentry 기록
- [ ] UTM 파라미터 수집

## 1. HomePage (/ — 메인·랜딩)

### 1.1 목적
신규·재방문자 모두에게 서비스 가치를 명확히 전달하고, 사주 입력으로 유도.

### 1.2 페이지 특화 감사
- [ ] 히어로 섹션 헤드라인 명확 ("500원, 진짜 사주")
- [ ] 서브카피 3줄 이내
- [ ] CTA 버튼 "지금 풀어보기" 최상단 노출
- [ ] 스크롤 1턴 안에 가치 제안 완료
- [ ] 소셜 프루프 최소 3건 (사용자 후기 또는 숫자)
- [ ] "어떻게 다른가" 차별점 3개
- [ ] FAQ 섹션 (최소 5개)
- [ ] 푸터 (회사 정보·약관·개인정보처리방침·사업자등록번호)

### 1.3 성능
- [ ] 히어로 이미지 WebP + lazy 불가 (LCP 대상)
- [ ] 폰트 preload
- [ ] 히어로 LCP < 1.8s

### 1.4 엣지 케이스
- [ ] 이미지 로드 실패 fallback
- [ ] 소셜 프루프가 비어있을 때 숨김 처리

## 2. InputPage (/input — 사주 입력)

### 2.1 목적
생년월일·시·성별·출생지 등을 정확히 수집하여 만세력 계산의 입력으로 전달.

### 2.2 페이지 특화 감사
- [ ] 이름 필드 (한글 1-10자 / 영문 1-30자)
- [ ] 성별 라디오 (남/여)
- [ ] 양력/음력 토글
- [ ] 윤달 체크박스 (음력 선택 시만)
- [ ] 년도 피커 1900~오늘
- [ ] 월·일 피커
- [ ] 시간 피커 (24시간제)
- [ ] 시간 모름 옵션
- [ ] 출생지 선택 (KR 기본, 해외 드롭다운)

### 2.3 검증
- [ ] 빈 필드 제출 시 해당 필드 하이라이트 + 안내
- [ ] 미래 날짜 거부
- [ ] 음력 윤달 유효성
- [ ] 1900년 이전 입력 거부
- [ ] 13시 오류·잘못된 시간 입력 차단

### 2.4 UX 세부
- [ ] 피커는 앱인토스 TDS 기본 피커 (모바일 네이티브 대체)
- [ ] 시간 모름 선택 시 시주 관련 질문 숨김
- [ ] "시간 모르면 어떻게 되나요?" 툴팁
- [ ] 이전 프로필 자동 불러오기 (로그인 유저)
- [ ] 중복 분석 경고 ("이미 분석한 사주입니다")

### 2.5 제출
- [ ] 제출 버튼 로딩 상태
- [ ] 더블클릭 방지
- [ ] 로딩 페이지로 전환 (프로필 생성 후)

### 2.6 엣지 케이스
- [ ] 2월 29일 윤년 처리
- [ ] 子時 경계 (23:00 / 00:00) 입력 시 안내 모달
- [ ] 서머타임 해당 기간 안내

## 3. LoadingPage (/loading — AI 분석 중)

### 3.1 목적
리포트 생성 동안 사용자 이탈 방지 + 기대감 유지.

### 3.2 페이지 특화 감사
- [ ] 진행 단계 표시 (만세력 계산 → 사주 분석 → 상세 풀이 → 마무리)
- [ ] 평균 소요 시간 안내 ("약 1~2분 걸려요")
- [ ] 중간 팁 카드 (사주 관련 미니 지식)
- [ ] 로딩 애니메이션 부드러움 (60fps)
- [ ] prefers-reduced-motion 대응

### 3.3 타임아웃
- [ ] 3분 초과 시 재시도 UI
- [ ] 재시도 시 운 이중 차감 방지
- [ ] 재시도 실패 시 운 환급 + CS 안내

### 3.4 이탈 방지
- [ ] 뒤로가기 방지 경고 (웹 + 앱인토스)
- [ ] 페이지 닫기 시 Firestore 상태 유지 (다시 들어오면 이어감)

### 3.5 엣지 케이스
- [ ] Claude API 5xx 시 자동 재시도
- [ ] 네트워크 끊김 시 안내

## 4. ResultPage (/result/:id — 결과)

### 4.1 목적
AI 리포트를 구조화하여 명확히 전달 + 재방문 동기 + 프리미엄 전환.

### 4.2 페이지 특화 감사
- [ ] 4기둥 카드 렌더링 (년·월·일·시)
- [ ] 각 기둥: 천간+지지 한자, 한글 병기, 십성, 12운성, 납음
- [ ] 시간 미입력 시 시주 카드 점선 + 오버레이
- [ ] 오행 레이더 차트
- [ ] 십성 막대 그래프
- [ ] 대운 타임라인 (현재 대운 하이라이트)
- [ ] 10개 섹션 아코디언
- [ ] 첫 섹션 기본 펼침
- [ ] 공유 버튼
- [ ] 프리미엄 업그레이드 CTA

### 4.3 프리미엄 티저
- [ ] 유료 섹션 2문장 노출 + 나머지 블러
- [ ] 블러 CSS + 노이즈 + 서버 차단 3층
- [ ] 서버 응답에 블러 섹션 본문 포함되지 않음 확인
- [ ] 개발자 도구에서 CSS 해제해도 내용 없음

### 4.4 인터랙션
- [ ] 섹션 확장 시 페이드인 0.3s
- [ ] 스크롤 위치 기억
- [ ] 공유 네이티브 API 우선 / 클립보드 fallback

### 4.5 재방문
- [ ] 같은 리포트 재열람 무료
- [ ] "이 리포트 보관하기" CTA
- [ ] 리포트 ID가 URL에 노출되나 접근은 본인만

### 4.6 보안
- [ ] 다른 uid의 리포트 직접 URL 접근 차단 (Firestore Rules)
- [ ] 공유 링크는 shareId 기반 읽기 전용 뷰
- [ ] 공유 링크 만료 정책 (없음·유효·폐기 중 선택)

### 4.7 엣지 케이스
- [ ] JSON 파싱 실패 리포트 복구 (재생성 버튼)
- [ ] 섹션 10개 미만 리포트 처리
