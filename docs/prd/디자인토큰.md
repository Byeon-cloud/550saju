## 0. 이 문서의 목적

사주500의 모든 시각 속성(색상·타이포·간격·그림자·라운딩·애니메이션 등)을 **단일 소스로 정의**. React 컴포넌트·Tailwind 설정·PDF 생성기·공유 카드 렌더러에서 동일한 토큰을 참조하게 한다.

**원칙**:
- 하드코딩 색상·폰트·간격 0건.
- 모든 토큰은 CSS 변수 + Tailwind 설정으로 동기화.
- 다크모드는 Phase 2 (현재는 라이트 고정 — 앱인토스 정책).

| `--font-caption` | 12px / 0.75rem | 1.5 | 0.01em | 캡션·라벨 |
| `--font-pillar` | 36px / 2.25rem | 1 | 0 | 사주 기둥 한자 표기 |

### 2.3 폰트 굵기

```css
--font-weight-regular: 400;
--font-weight-medium: 500;
--font-weight-semibold: 600;
--font-weight-bold: 700;
```

**원칙**:
- 본문은 400 (regular) 기본.
- 강조는 500 (medium) — 500 → 600 스킵 금지.
- 타이틀은 600 (semibold) 기본, 700은 랜딩 히어로·CTA 전용.
- 800 이상 금지 (AI 카피 느낌).

### 2.4 리딩 (Line Height) 원칙

- 본문: 1.7 (한국어 한자 병기 시 공백 확보).
- 타이틀: 1.2~1.3.
- 캡션: 1.5.
- 라벨: 1.4.

### 2.5 자간 (Letter Spacing)

- 한국어 본문: -0.01em (기본).
- 한자 전용 표시: 0 (전각이라 자간 수정 불필요).
- 영문·숫자 타이틀: -0.02em.

## 5. 그림자 (Elevation)

크림 배경에 얇고 따뜻한 그림자. 파란빛 금지.

```css
--shadow-xs: 0 1px 2px rgba(61, 52, 39, 0.04);
--shadow-sm: 0 2px 4px rgba(61, 52, 39, 0.06);
--shadow-md: 0 4px 12px rgba(61, 52, 39, 0.08);
--shadow-lg: 0 8px 24px rgba(61, 52, 39, 0.10);
--shadow-xl: 0 16px 48px rgba(61, 52, 39, 0.14);
```

**원칙**:
- `rgba(0, 0, 0, X)` 검정 그림자 금지 (한글 색 번짐).
- 호버 시 `--shadow-sm` → `--shadow-md`. 드라마틱 변화 X.
- 과도한 blur·spread 금지.

## 7. 애니메이션

### 7.1 Duration

```css
--duration-fast: 150ms;    /* 호버·포커스 */
--duration-base: 200ms;    /* 기본 트랜지션 */
--duration-slow: 300ms;    /* 모달·드로어 */
--duration-lazy: 500ms;    /* 페이지 전환 */
--duration-stream: 40cps;  /* AI 스트리밍 40 chars/sec */
--duration-unlock: 1500ms; /* 프리미엄 골드 라인 */
```

### 7.2 Easing

```css
--ease-out-soft: cubic-bezier(0.16, 1, 0.3, 1);     /* 주 easing (빠르게 시작해서 천천히 정착) */
--ease-in-out-gentle: cubic-bezier(0.4, 0, 0.2, 1); /* 양방향 */
--ease-in-fast: cubic-bezier(0.4, 0, 1, 1);         /* 사라질 때 */
--ease-out-slow: cubic-bezier(0, 0, 0.2, 1);        /* 나타날 때 */
```

### 7.3 주요 모션 공식

| 패턴 | duration | easing |
|---|---|---|
| 호버 배경 전환 | 150ms | ease-out-soft |
| 버튼 눌림 | 100ms | ease-in-fast |
| 카드 페이드인 | 300ms | ease-out-slow |
| 모달 진입 | 250ms | ease-out-soft |
| 모달 퇴장 | 200ms | ease-in-fast |
| 페이지 전환 | 400ms | ease-in-out-gentle |
| 아코디언 열림 | 300ms | ease-out-soft |
| 골드 라인 언락 | 1500ms | ease-in-out-gentle |
| 토스트 진입 | 250ms | ease-out-soft |

**원칙**:
- 과도한 바운스·오버슈트 금지 (AI스러움).
- prefers-reduced-motion 준수: 모든 애니메이션을 50% 이하로 짧게 or 즉시 상태 변경.
- CTA 버튼에 pulse·bounce 무한 애니메이션 금지.

## 13. 엣지 케이스

1. **다크 모드 요청**: Phase 1 불가 (라이트 고정). 시스템 다크에도 라이트 유지 (앱인토스 정책).
2. **색맹 접근성**: 오행 색상만으로 구분 금지 — 반드시 한자 라벨 병기.
3. **폰트 로딩 실패**: `system-ui` 폴백 체인 준수. FOUT(Flash of Unstyled Text) 허용.
4. **고대비 모드**: prefers-contrast 지원 추가 (Phase 2).
5. **모바일 세로 화면 320px**: xs 브레이크포인트 — 기본 간격 `--space-4` → `--space-3` 축소 적용.
6. **데스크톱 초대형 화면 (2560px+)**: 컨테이너 `max-width: 520px` 유지. 좌우 빈 공간은 캔버스 배경.
7. **한자 전각 표기에서 자간 문제**: `font-family-hanja` 적용 시 letter-spacing 0 강제.
8. **PDF 렌더링**: 웹 폰트 대신 임베드 폰트 (Pretendard 정적) 사용. 토큰은 동일 값.
9. **공유 카드 렌더러**: Canvas 기반. 토큰 값을 JS 상수로도 노출 (`src/constants/tokens.ts`).
10. **브라우저 확대 200%**: 간격·폰트 토큰 기준 그대로. rem 사용하므로 브라우저 설정 존중.
