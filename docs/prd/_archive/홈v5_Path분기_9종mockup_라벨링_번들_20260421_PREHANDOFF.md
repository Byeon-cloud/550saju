## §1. 5 Path 정의

플로우차트 진본 `사주500_flowchart_userflow.html` (2026-04-20, 678 lines, mermaid 6차트) 에서 정의된 유저 상태 분기.

| Path | 이름 | 조건 | 핵심 목표 | 홈 분기 우선순위 |
|------|------|------|----------|-----------------|
| **A** | Cold | 신규 · `hasSaju=false` · 결제 0 | 입력 CTA 진입 | 후기·왜사주500 **강조** |
| **B** | Warm | `hasSaju=true` · 결제 0 | 500원 결제 전환 | 오늘의운세 가치 **강조** (트리거) |
| **C** | Hot | 500원 1+ · 5000원 0 | 주제 교차 + 5000원 업셀 | 섹션 4.5 격상 + 5000원 카드 |
| **D** | Loyal | 5000원 구매 완료 | 리텐션 · 재탐색 | 섹션 4.5 **1순위** · 리텐션 훅 |
| **E** | 예외 | 결제 원자성 오류 · NotFound · 공유 비회원 · 임시저장 | 복구·재진입 | **홈 분기 아님** (토스트/에러 UI 별도) |

**Path A 이탈 포인트** (30 step): 후기 신뢰 · 동의 (개인정보/민감) · 결제 망설임.
**Path B 트리거**: 오늘의운세 개인화 품질 체감 → "내 사주면 500원 결제도 아깝지 않다".
**Path C 업셀**: 다른 주제(연애→재물→직업) 3회 소비 후 5000원 한 번에 더 쌈.
**Path D 리텐션**: 월운·궁합·토정비결 등 확장 풀이 + 관계망 저널(`리텐션_저널관계망.md`).

## §2. §7 인사이트 — 홈에 직결되는 4건

플로우차트 §7 "인사이트 7건" 중 홈 설계에 **즉시 반영 필요**한 것만 추림.

1. **홈은 Path별 동적 분기 필요**
   - 현재 v4는 단일 정적 10섹션 = Path A 맞춤.
   - B/C/D 유저에게는 오버스펙 + 혼란. `hasSaju`·`paidReportCount`·`premiumReportCount` 3 flag 조합으로 분기.

   - Path A 유저에겐 오늘의운세 섹션이 **무의미** (사주 데이터 자체가 없어 placeholder만 노출).
   - 그 자리에 입력 CTA 1개로 치환. 카드 자체 제거 옵션도 검토.

3. **섹션 4.5 = Path D 1순위로 격상**
   - 현재 v4 스펙에는 "다른 풀이 탐색" 섹션이 없거나 5번째.
   - Path D에선 이게 홈의 **주 CTA 블록**. 월운·궁합·토정비결·연관 저널 4 카드.

4. **후기·왜사주500 = Path C+ 에서 숨김**
   - 이미 결제 완료한 유저에게 신뢰 확보 섹션은 중복 · 심지어 "처음 같은 톤" 으로 느껴져 마이너스.
   - Path A/B에선 유지, Path C/D에선 **conditional render false**.

**나머지 3건**은 홈이 아닌 `/input`, `/result`, `/chat` 스펙에 반영 (이 번들 범위 밖).

## §4. 홈 v5 섹션 스택 — Path A/B/C/D 별

### §4-0. 공통 규칙

- **스택 높이 타겟**: Path A 3.0 화면(1920px) / B 2.0(1280px) / C 2.2(1400px) / D 2.5(1600px). Path C·D는 허브 기능이 강해서 오히려 더 김.
- **섹션 ID**: `sec-hero`, `sec-daily`, `sec-dream`, `sec-sinsal`, `sec-products`, `sec-reviews`, `sec-moat`, `sec-explore`(섹션 4.5), `sec-sticky-cta`.
- **조건부 렌더 flag**: `pathVariant` = `"A" | "B" | "C" | "D"` (Firestore `users/{uid}` 에서 derive).
- **첫 진입 3초 룰**: 모든 Path에서 히어로 또는 히어로 대체 블록은 1.5초 안에 first paint.

### §4-1. Path A · Cold (신규)

```
1. sec-hero           [A 강화 — KPI 3줄 + CTA 2개]
2. sec-daily          [신규 버전 — "생년월일·시간만 넣으면..." + 입력 CTA]
3. sec-dream          [무료 미끼 — 미리보기 문장 1줄 + 진행바 38%]
4. sec-sinsal         [브랜드 자산 — 5행]
5. sec-products       [500원 하이라이트 + 경쟁사 ₩32,400 취소선]
6. sec-reviews        [★ 강조 — 5종 후기 캐러셀]
```

```
5. sec-reviews        [압축 3종 — "결제 망설임 해소" 목적]
```
