## 1. v3 → v4 전환 이유

### v3의 실패 진단 (준기 피드백)
- 명조체(Noto Serif KR) 과다 사용 → 모바일 앱에서 "AI 감성"으로 읽힘
- 낙관(`seal-stamp`)·세로 한자(`vertical-hanja`)·한지 노이즈(`bg-hanji`) → 포스터·출판 문법이지 앱 문법 아님
- 모든 카드가 `card-editorial` 동일 레벨 → 위계 평평, 뭐가 중요한지 안 보임
- 본문 13~14px, 자간 0.05~0.15em → 40대 이상 가독성 붕괴
- `drop-cap`·`gold-hairline-symbol` 같은 장식 과다 → "AI 동양풍 클리셰"

### v4 지향점
남녀노소 누구나 불편 없이 쓰는 **한국 대중 앱 문법**.

| 벤치마크 | 차용 요소 |
|---|---|
| **토스** | 52px CTA, 흑백+파랑 일관, 여백, Pretendard Bold/Regular, 카드 위계 명확 |
| **카카오뱅크** | 중립 배경 + 단일 포인트 컬러, 숫자 큼직, 최소 장식 |
| **당근** | 여백 넉넉, 친근한 본문, 이미지 중심, 적당한 라운드 |
| **점신·포스텔러** | 큰 아이콘·카드형, 오행 등 사주 특수 표기는 기능적으로만 |

## 2. 핵심 원칙 7가지

1. **서체 1종 원칙** — Pretendard Variable. 명조체는 **리포트 결과 페이지 최상단 대제목 1곳만** 허용 (그 외 금지).
2. **포인트 컬러 1개** — 골드브라운 `#A08B6A` (= `--brand-gold` 보정판). 토스 파랑과 동일 역할. 오행 5색은 **인포그래픽·기능 요소에만**.
3. **본문 16px 기본** — 14px 금지. 서브텍스트 13px 하한.
4. **자간 0 원칙** — letterSpacing 0 또는 -0.01em. `0.05em~0.15em` 장식성 자간 금지.
5. **카드 3단 위계** — `card-primary` / `card-secondary` / `card-accent` 의미적으로 구분. 모든 카드 같은 레벨 금지.
6. **한자 UI 0%** — 버튼·탭·탭바·섹션 제목·뱃지에 한자 0. 본문 병기는 `자시(子時)` 형태만, 섹션당 2~3개 이내.
7. **CTA 52px 단독 원칙** — 화면당 주 CTA 1개. 토스 표준 높이 고정.

## 4. 타이포 스케일 v4

```css
/* 디스플레이 — 리포트 최상단 1곳만, 명조체 예외 허용 */
--text-display: 28px / 1.3 / 900 / -0.025em;

/* 섹션 헤더 */
.sec-title-lg: 22px / 1.3 / 800 / -0.025em;   /* 대제목 */
.sec-title:    18px / 1.35 / 800 / -0.022em;  /* 중제목 */
.sec-caption:  13px / 1.5 / 500 / -0.005em;   /* 캡션 */
.sec-meta:     12px / 1.4 / 600 / +0.01em;    /* 메타 (골드) */

/* 본문 */
.text-body-lg: 16px / 1.7 / 400;   /* 주 본문 ★ */
.text-body-md: 15px / 1.7 / 400;   /* 보조 본문 */
.text-body-sm: 13px / 1.6 / 400;   /* 밀도 높은 본문 */
```

**자간 원칙**: 16px 이상 본문은 -0.005em, 제목은 -0.022~-0.025em. 11px 이하 라벨만 +0.01~0.02em. 그 외는 0.

**행간 원칙**: 본문 1.7, 제목 1.3~1.4, 라벨 1.4~1.5.

**용도**: 프리미엄 전단계 CTA, 월운·궁합 구매 유도 카드
**규칙**: 화면당 1개 최대. 남용 금지

## 6. 블러 잠금 카드 (프리미엄 전환 핵심)

### 6.1 구조

```html
<div class="card-locked" onClick={onUnlock}>
  <div class="card-locked-blur">
    <!-- 실제 유료 콘텐츠 (서버에서 차단, CSS blur 7px) -->
  </div>
  <div class="card-locked-overlay">
    <div class="card-locked-icon">
      <LockIcon />
    </div>
    <p class="card-locked-title">앞으로의 전망</p>
    <p class="card-locked-sub">3일·1주일 후 흐름까지</p>
    <div class="card-locked-cta">
      <span>1운으로 해제 →</span>
    </div>
  </div>
</div>
```

### 6.2 3층 방어 (`프리미엄_티저블러.md` 연계)

1. **CSS blur(7px) + saturate(1.1)** — 시각 차단
2. **서버 원문 차단** — 실제 유료 필드는 응답에 포함되지 않음. 블러 대상은 **플레이스홀더 텍스트**만
3. **노이즈 오버레이** — `rgba(253,250,242,0.92)` 그라데이션으로 텍스트 판독 불가

### 6.3 CTA 문구 규칙

- ❌ "구매하기" / "결제" → 거래감 과다
- ❌ "업그레이드" → 구독감
- ✅ "1운으로 해제 →" / "500원으로 열기 →" / "자세히 보기 (1운)" — 가상화폐 친근
- **각 잠금 카드마다 다른 문구** (똑같은 문구 반복 금지)

### 6.4 톤 규칙

잠금 영역의 **제목은 공개**, 본문만 블러.
예: "앞으로의 전망" 제목은 보여주되, 본문은 블러 → 유저가 "무엇을 여는지" 알 수 있음.

- 탭 시 플립 애니메이션 → 뒷면에 오행·십성·지장간 2~3줄 요약

### 8.2 오행 가로 바 (`.oheng-row`)

```
목 ████████░░░░░░░░░░  3
화 ██████░░░░░░░░░░░░  2
토 ████████████████░░  7
금 ░░░░░░░░░░░░░░░░░░  0
수 ████░░░░░░░░░░░░░░  1
```

- 40px 라벨 + 1fr 바 + 36px 숫자
- 바 색 = 오행 5색
- 진입 시 좌→우 0.7s 애니메이션
- **오행 비교 변형**: 2개 바 겹쳐 표시 (사주 vs 꿈)

### 8.3 5축 레이더 차트

- recharts `<RadarChart>`
- `tick={{ fontSize: 13, fill: '#1B2A4A', fontFamily: 'Pretendard Variable, sans-serif' }}` — 명조체 금지
- 스트로크 `#C9A96E`, 채움 `#C9A96E22`, 점 `#C9A96E`
- 각 축 탭 시 모달 슬라이드업 (P1)

### 8.4 점수 도넛

- SVG 120×120, 내부 점수 48px/900 골드
- 하단 등급 뱃지 (등급 컬러 박스 + "A등급")
- 진입 시 strokeDashoffset 1.5s 애니메이션

### 8.5 타임라인 3컷

- 가로 스와이프 carousel
- 각 컷: 아이콘(36px) + 제목(15px/700) + 1~2줄 본문(13px)
- 3번째 컷(1주 후)은 `.card-locked` 처리

### 8.6 나침반 (행운의 방위)

- SVG 원형, 8방위 표시
- 오늘의 방위에 골드 바늘 고정
- 유저 드래그로 회전 가능 (재미용, 원래 위치로 스프링 복귀)

## 9. 인터랙션 표준 (framer-motion)

### 9.1 스프링 규격

```js
// 플립·스와이프·드래그 복귀
const spring = { type: 'spring', damping: 18, stiffness: 260 }

// 스크롤 페이드
const fadeUp = {
  initial: { opacity: 0, y: 16 },
  animate: { opacity: 1, y: 0 },
  transition: { duration: 0.4, ease: [0.22, 1, 0.36, 1] }
}

// 탭 피드백
whileTap={{ scale: 0.97 }}
```

- prefers-reduced-motion: reduce 감지 시 스프링 → duration 0.2s 페이드로 다운그레이드
