# 수용기준 체크리스트 (Acceptance Criteria Master)

> **문서 성격**: 사주500 전 기능의 최종 수용기준 마스터. 각 기능이 "완료(Done)" 상태인지 판정하는 단일 기준표.
>
> - 구성: 기능별 AC 묶음 + 전체 AC 합산표
> - 사용: PR 리뷰·QA·배포 전 체크리스트로 사용
> - 원칙: 체크 안 된 항목이 하나라도 있으면 **릴리스 금지**
> - 업데이트: 새 기능 추가 시 본 문서에 AC 추가

---

## 0. 전역 수용기준 (Global AC)

아래는 모든 기능이 공통으로 만족해야 하는 기준이다.

### 0.1 기능 일반
- [ ] 기능이 PRD 명세와 일치
- [ ] 모든 엣지 케이스 처리 (null, 빈 배열, 비정상 입력)
- [ ] 에러 메시지가 유저에게 이해 가능한 형태
- [ ] 로딩 상태 노출 (500ms 이상 소요 시)
- [ ] 성공·실패 피드백 명확

### 0.2 반응형
- [ ] 320px(iPhone SE) ~ 520px 모바일에서 레이아웃 깨짐 없음
- [ ] 521px ~ 1920px 데스크톱에서 중앙 정렬 정상
- [ ] 가로 스크롤 없음 (모바일)
- [ ] 터치 타겟 최소 44×44px (iOS 가이드라인)

### 0.3 성능
- [ ] 초기 로드 gzip 번들 < 150KB (현재 ~100KB)
- [ ] LCP < 2.5s (4G 모바일)
- [ ] FID < 100ms
- [ ] CLS < 0.1

### 0.4 접근성 (a11y)
- [ ] 시맨틱 HTML 사용 (button은 <button>, 링크는 <a>)
- [ ] 모든 인터랙티브 요소에 aria-label 또는 텍스트
- [ ] 키보드 탭 순서 논리적
- [ ] 포커스 가시성 확보 (outline 제거 시 대체 스타일)
- [ ] 색상 대비 WCAG AA (4.5:1 본문, 3:1 UI)
- [ ] prefers-reduced-motion 지원

### 0.5 브라우저 호환
- [ ] Chrome 최신 2버전
- [ ] Safari iOS 15+
- [ ] Samsung Internet 최신
- [ ] 앱인토스 WebView

### 0.6 다크모드
- [ ] 라이트모드 고정 확인 (`color-scheme: only light`)
- [ ] 다크모드 자동 전환 방지

### 0.7 앱인토스 전용
- [ ] `window.confirm()`, `alert()` 미사용 (TDS 모달 사용)
- [ ] 버튼 높이 52px
- [ ] Primary 버튼 컬러 #3182F6 (TDS 표준)
- [ ] 뒤로가기 UI 명시
- [ ] IAP 결제 사용 (외부 PG 금지)

### 0.8 컨텐츠
- [ ] 한자 첫 등장 시 한글 병기
- [ ] 이모지 남용 금지 (한자 유지)
- [ ] 금칙어 통과 (`콘텐츠퀄리티가이드.md` 참조)
- [ ] 법적 면책 표기 (의학·법률·재무 아님)

### 0.9 로깅·분석
- [ ] 핵심 이벤트 트래킹 (`usePageTracking` 등)
- [ ] 에러 Sentry 연동
- [ ] 결제·환불 이벤트 기록

### 0.10 보안
- [ ] PII 암호화 (저장 시)
- [ ] 클라이언트에 시크릿 노출 금지
- [ ] Firebase Security Rules 적용
