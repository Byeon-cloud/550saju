**작성일**: 2026-04-18
**버전**: v1.0
**상태**: 확정 (P0)
**소유자**: 준기 (PM/오너)

**전제**: `디자인토큰.md`의 토큰만 사용. 하드코딩 금지.

## 0. 이 문서의 목적

사주500의 모든 UI 컴포넌트 스펙. Props·variants·states·접근성·예시 코드·스냅샷 기준. 모든 컴포넌트는 **토큰 기반**이고 **TypeScript 타입 엄격**.

**원칙**:
- 한 컴포넌트 = 한 파일 (`src/components/[domain]/[Name].tsx`).
- Props 인터페이스 export.
- 최소 한 가지 storybook-스러운 예시 코드 블록 포함.
- 접근성 요구사항 명시.

## 2. common/Button

### Props

```typescript
interface ButtonProps {
  variant?: 'primary' | 'secondary' | 'ghost' | 'danger' | 'link';
  size?: 'sm' | 'md' | 'lg';
  fullWidth?: boolean;
  loading?: boolean;
  disabled?: boolean;
  leftIcon?: ReactNode;
  rightIcon?: ReactNode;
  onClick?: (e: MouseEvent) => void;
  children: ReactNode;
  'aria-label'?: string;
}
```

### Variants

| variant | 배경 | 텍스트 | 테두리 | 사용처 |
|---|---|---|---|---|
| primary | `brand` | `text-inverse` | — | 메인 CTA (결제, 시작) |
| secondary | `bg-muted` | `text-primary` | — | 보조 액션 |
| ghost | transparent | `text-primary` | `border-default` | 취소·닫기 |
| danger | `error` | `text-inverse` | — | 삭제·파괴적 액션 |
| link | transparent | `text-link` | — | 인라인 링크 |

### Sizes

| size | height | padding-x | font |
|---|---|---|---|
| sm | 36px | 12px | body-sm |
| md | 44px | 16px | body-md |
| lg | 52px | 20px | body-lg |

**앱인토스 정책**: 기본 CTA는 `lg` (52px). TDS 기준.

### States

- `:hover` → 배경 `brand-hover`, 그림자 `sm → md`
- `:active` → 배경 `brand-pressed`, transform 없음 (깊이 느낌만)
- `:focus-visible` → `outline: 2px solid var(--color-border-focus); outline-offset: 2px;`
- `:disabled` → opacity 0.5, cursor not-allowed
- `loading` → 내부 스피너, 텍스트 숨김, disabled 상태

### 접근성

- `role="button"` (button 엘리먼트 기본)
- 아이콘 단독 시 `aria-label` 필수
- 로딩 중 `aria-busy="true"`

### 예시

```tsx
<Button variant="primary" size="lg" fullWidth onClick={handlePay}>
  500원 시작
</Button>

<Button variant="ghost" size="md" leftIcon={<CloseIcon />} aria-label="닫기">
  닫기
</Button>
```

## 3. common/Modal

### Props

```typescript
interface ModalProps {
  open: boolean;
  onClose: () => void;
  title?: string;
  description?: string;
  size?: 'sm' | 'md' | 'lg' | 'full';
  closeOnOverlay?: boolean;
  closeOnEsc?: boolean;
  hideClose?: boolean;
  footer?: ReactNode;
  children: ReactNode;
}
```

### 구조

- 오버레이: `rgba(61, 52, 39, 0.4)` + `backdrop-blur(4px)`
- 컨테이너: 중앙 정렬, max-width `sm=360 | md=440 | lg=520 | full=100vw`
- 상단: 제목 + X 닫기
- 본문: 패딩 `--space-6`
- 하단 (footer): CTA 버튼 1~2개, `--space-4` 패딩

### Variants / 특수형

- **BottomSheet**: 모바일 하단에서 슬라이드업 (`size="full"` + `variant="bottomSheet"` 조합).
- **ConfirmDialog**: 간단 확인용 (`<ConfirmDialog title description confirmText cancelText />`) 래퍼.

### 접근성

- `role="dialog"` + `aria-modal="true"`
- `aria-labelledby={titleId}` + `aria-describedby={descId}`
- 열릴 때 포커스 트랩 적용 (first focusable 엘리먼트로 이동).
- 닫힐 때 이전 포커스 복귀.
- ESC 키로 닫힘 (closeOnEsc=true 기본).

### 앱인토스 분기

- window.confirm·alert 금지.
- 이 Modal 컴포넌트가 TDS 스타일(52px 버튼 + 브랜드 컬러)로 렌더링.

### 예시

```tsx
<Modal open={isOpen} onClose={setClosed} title="정말 삭제할까요?">
  <p>삭제하면 복구할 수 없어요.</p>
</Modal>

<ConfirmDialog
  open={confirmOpen}
  title="결제하시겠어요?"
  description="5,000원 심층 리포트가 바로 열립니다."
  confirmText="결제"
  cancelText="취소"
  onConfirm={handlePay}
  onClose={() => setConfirmOpen(false)}
/>
```

### 사용처

- 버튼 내부 로딩 (`loading` prop).
- 페이지 전환 로딩 (`fullScreen`).
- 리포트 스트리밍 대기.

## 8. saju/PillarCard

사주 기둥(년주/월주/일주/시주) 한 개 카드.

### Props

```typescript
interface PillarCardProps {
  label: '년주' | '월주' | '일주' | '시주';
  gan: string;         // 천간 한자 (甲, 乙, …)
  zhi: string;         // 지지 한자 (子, 丑, …)
  ganElement: Element; // 오행
  zhiElement: Element;
  shiShenGan?: string; // 십성 라벨 (정관, 편재 등)
  shiShenZhi?: string;
  missing?: boolean;   // 시간 미입력
}

type Element = 'wood' | 'fire' | 'earth' | 'metal' | 'water';
```

### 구조

```
┌──────────┐
│   월주    │  ← 작은 라벨 (caption, text-tertiary)
├──────────┤
│    戊     │  ← 천간 (pillar size, 오행 컬러)
│  (무토)   │  ← 독음·의미 (body-sm)
├──────────┤
│    寅     │  ← 지지
│  (인목)   │
├──────────┤
│ 편재·식신 │  ← 십성 (caption)
└──────────┘
```

- 너비: `25%` (4분할).
- 높이: 200px 고정.
- 배경: `bg-surface`.
- 테두리: `border-default`.
- 라운딩: `--radius-md`.
- 오행 컬러: 천간·지지 각각에 적용 (배경이 아닌 텍스트 컬러).

### `missing=true` (시주 미입력)

- 점선 테두리 `border-tertiary`.
- 반투명 오버레이 + "시간 미입력" 라벨.
- 한자 영역 dim.

### 접근성

- `role="img"` + `aria-label="월주: 무토 인목 편재 식신"`.

### 예시

```tsx
<PillarCard
  label="월주"
  gan="戊"
  zhi="寅"
  ganElement="earth"
  zhiElement="wood"
  shiShenGan="편재"
  shiShenZhi="식신"
/>
```

## 27. 전역 접근성 체크

### 키보드 네비게이션

- 모든 인터랙티브 요소 Tab 접근 가능.
- 포커스 순서 논리적 (시각 순서와 일치).
- 모달 열릴 때 포커스 트랩.

### 스크린리더

- 이미지·아이콘 `alt` / `aria-label`.
- 에러 메시지 `role="alert"`.
- 동적 업데이트 `aria-live`.

### 색상 대비

- 본문 ≥ 4.5:1.
- 큰 텍스트 ≥ 3.0:1.
- 비기능 요소 제외 모두 검증.

### 터치 타겟

- 최소 44×44px (iOS HIG).
- 간격 8px 이상.
