## 0. 이 문서의 목적

사주 데이터(만세력 계산 결과)를 **시각적으로 전달하는 모든 차트·도표의 카탈로그**. 리포트·공유 카드·PDF·스토리보드에 공통 사용. 목표는 "숫자/한자만으로는 안 와닿는 정보를 3초 안에 이해시키기".

**원칙**:
- 각 인포그래픽은 명리학 데이터와 1:1 맵핑.
- 한자만 표기 금지 → 독음/의미 병기.
- 색상 단독 구분 금지 → 텍스트 라벨 병기.
- 모든 차트 `aria-label` + 스크린리더 대체.
- 모바일 세로 320px 기준 뷰포트 적합성 우선.

## 2. #1 사주 원국 4기둥

### 목적
출생 정보를 네 개의 한자 기둥으로 요약. 리포트의 정체성.

### 데이터

```typescript
interface PillarData {
  year: { gan: string; zhi: string; ganElement: Element; zhiElement: Element; shiShenGan: string; shiShenZhi: string };
  month: PillarData['year'];
  day: PillarData['year'];
  time: PillarData['year'] | null; // 미입력 시 null
}
```

### 시각

- 4컬럼 그리드, 각 기둥 너비 동일.
- 각 기둥: 상단 라벨 → 천간 → 지지 → 십성.
- 천간지지 전각 한자, 독음 한글 병기.
- 오행 컬러는 한자 **텍스트 컬러**에만 적용 (배경 X).
- 시주 미입력 시 점선 + 오버레이.

### 렌더링 스펙

- 컨테이너: 너비 100%, 최대 520px.
- 기둥 너비: `calc((100% - 24px) / 4)` (gap 8px).
- 기둥 높이: 200px 고정.
- 배경: `bg-surface`.
- 라운딩: `--radius-md`.
- 가로 스크롤 금지 (320px 시 폰트 축소).

### 접근성

- `role="img"`
- `aria-label` 전체 기둥 나열: "년주 갑자 편재 정관, 월주 병인 식신 겁재, 일주 계해 비견 정재, 시주 미입력"

## 3. #2 오행 레이더

### 목적
천간지지 전체에서 오행 비중 시각화. 균형·쏠림을 한눈에.

### 데이터

```typescript
interface ElementDistribution {
  wood: number;    // 0~100 정규화
  fire: number;
  earth: number;
  metal: number;
  water: number;
  highlight?: Element;  // 용신
}
```

### 계산 로직

- 천간 + 지지 + 지장간 가중 합산.
- 천간: 가중치 1.0
- 지지: 가중치 1.0
- 지장간 초기(主氣): 0.6
- 지장간 중기: 0.3
- 지장간 여기: 0.1
- 합산 후 총합 100 정규화.

### 시각

- 5축 레이더 차트.
- 각 꼭짓점: 한자(木/火/土/金/水) + 독음.
- 영역 채우기: 각 꼭짓점 오행 컬러 (opacity 20%).
- 선: 브랜드 컬러.
- `highlight` 지정 시 해당 꼭짓점 ●로 강조 + 오행 컬러 풀.

### 라이브러리

- recharts `<RadarChart>`.

### 접근성

- `aria-label` 예: "오행 분포 — 목 32%, 화 24%, 토 18%, 금 8%, 수 18%, 용신은 금"

## 4. #3 십성 분포 막대

### 목적
10종 십성 비중 시각화. 성격·관계 깊이 해석의 근거.

### 데이터

```typescript
interface ShiShenDistribution {
  비견: number;
  겁재: number;
  식신: number;
  상관: number;
  편재: number;
  정재: number;
  편관: number;
  정관: number;
  편인: number;
  정인: number;
}
```

### 계산

- 년간·월간·일간·시간 + 년지·월지·일지·시지에서 십성 라벨 집계.
- 지장간 포함 계산 (가중치 0.5).

### 시각

- 세로 막대 10개.
- 색상: 음양 쌍 구분 (양=브랜드 진, 음=브랜드 연).
- 순서: 비견→겁재→식신→상관→편재→정재→편관→정관→편인→정인.
- 쌍 사이에 얇은 구분선.

### 렌더링

- 높이: 최대 120px.
- 각 막대 위 라벨: 이름 + 개수.
- 라이브러리: recharts `<BarChart>` 또는 커스텀 SVG.

## 5. #4 12운성 플롯

### 목적
일간이 4기둥 지지에서 어떤 에너지 단계인지 시각화.

### 데이터

```typescript
interface DiShiPlot {
  year: DiShi;
  month: DiShi;
  day: DiShi;
  time: DiShi | null;
}

type DiShi = '장생' | '목욕' | '관대' | '임관' | '제왕' | '쇠' | '병' | '사' | '묘' | '절' | '태' | '양';
```

### 시각

- 12개 라벨이 원형으로 배치 (시계 방향, 장생→양).
- 4기둥의 운성 위치에 각각 아이콘 점 찍기.
- 년=●, 월=▲, 일=■, 시=◆ (도형 구분).
- 색상: 각 기둥 오행 컬러.

### 원형 배치 좌표

```
     장생(0°)
   양(30°)    목욕(330°)
   태(60°)      관대(300°)
   절(90°)         임관(270°)
   묘(120°)          제왕(240°)
   사(150°)        쇠(210°)
     병(180°)
```

### 라이브러리

- 커스텀 SVG 또는 d3-radial.

## 12. #11 점수 링 (종합)

### 목적
리포트 전체 점수 or 섹션별 점수 시각화 (옵션).

### 주의

- **별점 금지 원칙** 유지 (별 아이콘 X).
- 점수 부여 시 AI 점수이며 주관적임을 명시.
- 표기: "72점" + 부가 설명 "평균보다 높음" 수준.
- 낮은 점수에 공포 조장 금지.

### 시각

- `ScoreRing` 컴포넌트 재사용.
- 중앙: 점수 + 보조 라벨.
- 색상 4단계:
  - 0~40: `warning` (완곡 표기)
  - 40~60: `brand-primary`
  - 60~80: `brand-primary`
  - 80~100: `success`

### 금지

- 0~40 구간에 `error` 컬러 금지 — "나쁘다" 신호 최소화.
- 숫자 뒤에 등급 라벨 (F, D, C 등) 금지.

## 15. 접근성 (Accessibility)

### 전체

- 모든 차트 `role="img"` + `aria-label` 전체 요약.
- 데이터 테이블 대체 (`<table>` hidden) 제공.
- 색상만으로 구분 금지 → 텍스트·아이콘 병기.
- 고대비 모드 prefers-contrast 대응.

### 스크린리더 대체 구조

각 인포그래픽 옆 또는 `<details>` 안에 데이터 테이블:

```html
<figure>
  <ElementRadar ... aria-label="오행 분포" />
  <figcaption>
    <details>
      <summary>데이터 보기</summary>
      <table>
        <tr><th>오행</th><th>비중</th></tr>
        <tr><td>목</td><td>32%</td></tr>
        ...
      </table>
    </details>
  </figcaption>
</figure>
```

## 16. 모션·애니메이션

### 진입 애니메이션

- 레이더·막대·링: 0 → 값, 1.2초 `ease-out-soft`.
- 타임라인: 좌에서 우로 fade-in 순차 150ms 간격.
- 히트맵: 셀별 0.05초 지연 페이드인.

### 인터랙션

- 호버: 해당 요소 강조 + 툴팁 200ms fade.
- 탭: 상세 모달 열림 300ms.

### `prefers-reduced-motion`

- 모든 진입 애니메이션 즉시 완료.
- fade-in 대신 즉시 노출.

## 18. 엣지 케이스

1. **시간 미입력**: 원국 4기둥 중 시주 점선 처리. 오행 레이더 계산에서 시주 제외 + 각주 "*시간 미입력으로 추정값 포함".
2. **오행 완전 편중 (1개 오행 80%+)**: 레이더가 한쪽으로 극단 쏠림. 각주 "*특수 사주 — 전왕격 가능".
3. **대운 60세 이상 유저**: 타임라인 전체가 "과거" 표시. 현재 대운은 여전히 하이라이트.
4. **신살 너무 많음 (10개+)**: 상위 5개만 배지 표시 + "더보기" 펼침.
5. **공망 없음**: 표식 영역 숨김.
6. **외국인 출생 (경도 보정)**: 보정된 시간 기반 계산, 원국 카드에 "진태양시 보정됨" 작은 라벨.
7. **음력 윤달**: 만세력 정확 반영. UI 상 특별 표식 없음.
8. **계산 실패 (fallback)**: 빈 스켈레톤 + "사주 데이터를 다시 불러올게요" 메시지.
9. **브라우저 SVG 미지원**: 불가능한 시나리오 (모든 현대 브라우저 지원). 폴백 텍스트만.
10. **아주 낮은 해상도 (240px)**: 오행 레이더 축 라벨 생략, 영역만 표시.
