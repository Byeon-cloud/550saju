# 550사주 UI/UX 상세설계서

> 이 문서가 없으면 개발자(Claude Code)가 화면마다 다른 디자인을 만듦.

# PART 1. IA (Information Architecture)

## 1-1. 전체 화면 구조도

```
550사주 앱
│
├── 🏠 홈 (/)
│   ├── 오늘의 운세 미리보기 카드
│   ├── "내 사주 보기" CTA
│   ├── 최근 본 리포트 (로그인 시)
│   └── 크로스셀 카드 (궁합/대운/연도별)
│
├── 📝 사주 입력 (/input)
│   ├── Step 1: 기본 정보 (이름/관계)
│   ├── Step 2: 생년월일 (양력/음력/윤달)
│   ├── Step 3: 성별
│   ├── Step 4: 출생시간 (있음/없음 → 시간 선택)
│   ├── Step 5: 만세력 미리보기 + 확인
│   └── Step 6: 상황 질문 (연애/직업/고민) — 선택사항
│
├── ⏳ 로딩 (/loading)
│   └── AI 분석 중 애니메이션 + 진행 단계 표시
│
├── 📊 결과 (/result/:id)
│   ├── 만세력 원국 (4기둥 카드)
│   ├── 오행 밸런스 (레이더 + 바 차트)
│   ├── 12운성
│   ├── 운세 종합 점수 (6개 링)
│   ├── 대운 흐름
│   ├── 납음 / 신살 / 공망
│   ├── 상세 풀이 (10개 아코디언)
│   ├── 크로스셀 CTA
│   ├── 공유 버튼
│   └── PDF 다운로드 (프리미엄)
│
├── 🔮 오늘의 운세 (/daily)
│   ├── 감성 질문 3개
│   ├── 오늘의 운세 카드
│   └── "더 깊이 보기" → 사주 입력 전환
│
├── 💕 궁합 (/compat)
│   ├── 내 프로필 선택
│   ├── 상대 프로필 선택/입력
│   ├── 관계 선택 (15가지)
│   └── 궁합 결과 (오행 비교 + 점수 + 풀이)
│
├── 📁 보관함 (/storage)
│   ├── 프로필 목록 (다중 프로필)
│   ├── 리포트 목록 (날짜순)
│   └── 각 리포트 → 결과 페이지 연결
│
├── 💳 운 충전 (/charge)
│   ├── 현재 잔액
│   ├── 충전 패키지 (4종)
│   └── 결제 → 토스페이먼츠/IAP
│
├── 👤 마이페이지 (/my)
│   ├── 프로필 정보
│   ├── 운 잔액 + 내역
│   ├── 결제 내역
│   ├── 환불 요청
│   ├── 이용약관 / 개인정보처리방침
│   └── 로그아웃 / 회원탈퇴
│
└── 🔗 공유 수신 (/share/:id)
    ├── 리포트 미리보기 (일부만)
    └── "내 사주도 보기" CTA
```

## 1-2. 네비게이션 구조

### 하단 탭바 (4개)

| 순서 | 아이콘 | 라벨 | 경로 |
|------|--------|------|------|
| 1 | ☯️ | 홈 | / |
| 2 | 🔮 | 오늘의 운세 | /daily |
| 3 | 📁 | 보관함 | /storage |
| 4 | 👤 | 마이 | /my |

- 탭바 높이: 56px + safe-area-bottom
- 활성 탭: Primary 컬러 (#A08B6A)
- 비활성 탭: #C9B99A
- 배경: #FFFFFF, 상단 1px border (#E8E0D4)

### 헤더

- 높이: 48px + safe-area-top
- 뒤로가기: ← 아이콘 (앱인토스에서는 시스템 백 버튼 사용, 커스텀 버튼 금지)
- 제목: 중앙 정렬, Pretendard 16px 600
- 우측: 상황에 따라 공유/설정 아이콘
- 배경: #FFFFFF 또는 transparent (스크롤 시 blur 전환)

# PART 2. 유저 플로우

## 2-1. 첫 방문 → 첫 결제 플로우

```
[앱 진입]
  ↓
[홈] 오늘의 운세 미리보기 (무료 티저 3줄)
  ↓ "내 사주 보기" 탭
[로그인] (미로그인 시)
  웹: 카카오/네이버/구글
  앱인토스: 토스 자동 로그인
  ↓
[사주 입력] Step 1~6 (약 30초)
  ↓ "분석하기" 버튼
[잔액 확인]
  잔액 ≥ 1운 → 차감 후 로딩
  잔액 < 1운 → 충전 모달
  ↓
[로딩] AI 분석 중 (15~25초)
  ↓
[결과] 리포트 렌더링
  ↓ 스크롤 끝
[크로스셀] "궁합도 볼래요?" / "대운은요?"
  ↓
[공유] 링크 복사 / 카톡 공유
```

## 2-2. 재방문 플로우

```
[앱 진입]
  ↓
[홈] 오늘의 운세 (매일 새로) + 최근 리포트 카드
  ↓ 운세 카드 탭
[오늘의 운세] 감성 질문 3개 → 운세 결과 (무료)
  ↓ "더 깊이 보고 싶다면"
[사주 리포트] 기존 프로필 선택 또는 새로 입력
```

## 2-3. 결제 플로우

```
[결제 트리거] (잔액 부족 시 자동 or 충전 페이지)
  ↓
[충전 모달/페이지]
  패키지 4종 표시 (추천 뱃지: "올해 다 보자")
  ↓ 패키지 선택
[결제]
  웹: 토스페이먼츠 위젯
  앱인토스: 토스 IAP
  ↓ 결제 완료
[잔액 갱신] 바로 사용 가능
```

# PART 3. 디자인 시스템

## 3-1. 기본 원칙

1. **모바일 퍼스트**: 375px 기준 디자인, max-width 520px 중앙 정렬
2. **크림 톤 기반**: 배경은 항상 따뜻한 크림, 카드는 화이트
3. **여백이 고급감**: 컴포넌트 사이 최소 16px, 섹션 사이 24px
4. **한자 + 한국어 병기**: 모든 한자에 한글 읽기 + 의미
5. **부드러운 전환**: 모든 상태 변화에 300ms ease 트랜지션

## 5-2. 만세력 카드 디자인 규칙

```
카드 구조:
┌─────────────────┐
│  라벨 (년주 年柱) │  ← 11px, 600, 진한색
│  설명 (조상·사회) │  ← 10px, 400, 메인색 70%
│                  │
│    戊            │  ← 천간: 32px (4기둥) / 40px (3기둥), 900, 진한색
│   무 · 토        │  ← 12px, 700, 메인색
│  [겁재]          │  ← 10px, 600, pill 뱃지
│                  │
│  ─── 구분선 ───  │  ← gradient: transparent → #C9B99A → transparent
│                  │
│    寅            │  ← 지지: 동일 사이즈
│   인 · 목        │
│  [정관·정인·겁재] │
└─────────────────┘

- 천간 배경: 해당 오행 gradient
- 지지 배경: 해당 오행 gradient

# PART 7. 인터랙션 정의

## 7-1. 페이지 전환

```
진입: slide-in-right (300ms ease-out)
퇴장: slide-out-left (200ms ease-in)
뒤로가기: slide-in-left / slide-out-right (반대 방향)
탭 전환: fade (200ms)
모달: slide-up (300ms ease-out) + overlay fade-in
```

## 7-2. 스크롤 인터랙션

```
FadeIn: 
  트리거: IntersectionObserver (threshold: 0.12)
  시작: opacity 0, translateY(20px)
  끝: opacity 1, translateY(0)
  duration: 600ms, ease: cubic-bezier(0.22, 1, 0.36, 1)
  delay: 각 섹션 50~100ms 순차

만세력 카드:
  카드별 순차 등장 (delay: index × 180ms)
  scale(0.96) → scale(1) + opacity

점수 링:
  SVG stroke-dashoffset 애니메이션
  duration: 1400ms, cubic-bezier(0.4, 0, 0.2, 1)
  delay: 각 링 100ms 순차

숫자 카운트업:
  0 → 타겟 숫자
  duration: 1200ms, cubic-bezier easeOut
  IntersectionObserver 트리거
```

## 7-3. 터치/클릭 피드백

```
버튼: 
  hover → background 10% 어둡게 (150ms)
  active → scale(0.98) + background 20% 어둡게 (100ms)
  
카드:
  hover → shadow-md (200ms)
  active → scale(0.99) (100ms)
  
아코디언:
  열기: height auto (300ms ease), chevron rotate 180deg
  닫기: height 0 (200ms ease), chevron rotate 0
  
탭:
  활성 탭 전환 → 아이콘+텍스트 색상 변경 (200ms)
  하단 인디케이터 bar slide (200ms)
```

## 7-4. 상태별 UI

```
비로그인 → CTA 누르면 로그인 모달 (바텀시트)
잔액 부족 → 자동으로 충전 모달 (바텀시트)
