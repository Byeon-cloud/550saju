## PART 0: 왜 200점이어야 하는가

### 시장 현실
- 사주아이: 990원 × 150만 사용자. "가성비"로 바이럴 성공. 하지만 **텍스트 중심, 시각화 없음, 6~8섹션**
- 포스텔러: 900만 가입자. 하지만 **"사주가 제일 안맞음", "오행부터 잘못 나옴"**
- 점신: 1900만 다운로드. 하지만 **불만족 62%, 광고 피로, 자동답변 동일성**

### 550사주의 포지션
**사주아이의 가성비 + 포스텔러의 시각화 + 점신의 일일 리텐션 — 모든 장점만 취하고, 단점은 전부 제거**

| 경쟁사 약점 | 550사주 해결 |
|------------|-------------|
| 광고 과다 (점신) | 광고 제로. 550원 유료 모델 |
| 정확도 낮음 (포스텔러) | lunar-javascript 정확 계산 + Claude 명리학 특화 |
| 자동답변 동일 (점신/전통앱) | AI 개인화 — 동일인이 없음 |
| 과금 피로 (포스텔러) | 550원 1회 결제, 자동결제 없음 |
| 시각화 없음 (사주아이) | 오행 레이더 + 점수 링 + 대운 타임라인 + 기둥 카드 |
| "좋은 말만 가득" (전체) | 구체적 행동 패턴 묘사 + "왜"의 설명 |
| 촌스러운 디자인 (전통앱) | 라이트 프리미엄, 토스급 세련된 UI |

## PART 1: 제품 핵심

### 1-1. 한 문장 정의
> **"550원에 소름 돋는 사주 리포트. 인포그래픽으로 한눈에."**

### 1-2. 핵심 가치 3가지
1. **소름 돋는 정확도** — "어떻게 알았지?" 반응을 만드는 것이 최우선
2. **550원의 충격** — "이 가격에 이 퀄리티?"가 바이럴 트리거
3. **눈으로 보는 사주** — 텍스트가 아닌 시각화로 "와 이거 뭐야" 반응

### 1-3. 바이럴 설계 원칙
사주아이가 바이럴된 진짜 이유를 분석하면:
- "990원이라길래 고민도 안 하고 결제" → **가격 무저항**
- "성격 분석 진짜 소름" → **첫 섹션에서 "찔리는" 순간**
- "왜 이런 성격인지 설명해줘서 이해가 됨" → **원인 분석**
- "자동결제 없어서 좋음" → **신뢰감**

550사주는 여기에 **시각화 + 인포그래픽**을 추가:
- 결과 화면 캡쳐 → 인스타 스토리에 올리기 좋은 비주얼
- 오행 레이더 차트 → "내 오행 이렇게 생겼어ㅋㅋ" 공유
- 궁합 비교 → 커플/친구 간 자연 공유

### 3-2. "소름 포인트" 설계

사용자가 **"어떻게 알았지?"** 하는 순간을 의도적으로 만든다.

**섹션 2 (성격) 첫 문단 공식:**
```
[사주아이 바이럴 패턴 분석 결과]
→ 첫 2~3문장에서 "찔리는" 구체적 행동 묘사를 넣어야 함
→ "~할 수 있습니다" 금지. "~하는 경향이 강합니다" 사용
→ 예: "회의 중에 말하기 전에 머릿속으로 3번은 정리하고 나서야 입을 여는 타입입니다"
→ 예: "친한 친구한테도 카톡 답장을 30분은 고민하다 보내는 편이에요"
```

**AI 프롬프트에 추가할 "소름 지시":**
```
반드시 각 섹션의 첫 2~3문장은 해당 사주의 사람이 "어떻게 알았지?"라고 느낄 만큼
구체적인 행동 패턴이나 일상 습관을 묘사해주세요.
추상적 성격 분류("당신은 내향적입니다")가 아니라
구체적 장면("친구 모임에서 대화보다 관찰을 먼저 하는 편")을 사용하세요.
```

### 3-3. 각 섹션 상세 콘텐츠 규격

**공통 규칙:**
- 최소 400자, 권장 500~700자 (사주아이보다 2배)
- 첫 2~3문장: "소름 포인트" (구체적 행동 묘사)
- 중반: "왜" 설명 (사주 구조 근거)
- 후반: 보완법/실행 조언
- 한자 나올 때마다 한국어 읽기+의미 병기

**① 사주 총평** (600자+)
- 일간 오행 성격 ("己土 기토 — 부드러운 흙, 모든 것을 품는 에너지")
- 오행 밸런스 요약 ("목이 지나치게 강하고, 수가 완전히 부재합니다")
- 가장 큰 강점 1개 + 가장 큰 과제 1개
- 시각화: OhengFlow (오행 상생상극 화살표 다이어그램)

**② 타고난 성격** (500자+)
- "소름 포인트" 필수 — 일상 행동 3가지 이상 묘사
- 12운성 기반 겉모습 vs 지장간 기반 속마음 대비
- 시각화: JijangganVis (각 기둥의 숨은 천간 그리드)

**③ 대인관계** (500자+)
- 관계 유형 분류 ("소수 깊은 관계형" vs "넓고 얕은 관계형")
- 직장/친구/연인 각각에서의 관계 패턴
- 시각화: RelationshipMap ⭐NEW
  - 3개 영역 (직장/친구/연인)별 점수 + 특성 키워드
  - 예: 직장 72 "배려형 리더" / 친구 85 "묵묵한 조력자" / 연인 60 "조심스러운 표현"

**④ 직업운** (600자+)
- 적합 직업 5가지 (구체적 직종명 + 적합도 %)
- 부적합 직업 2가지 (이유 포함)
- 사업 시기 (대운 기반)
- 시각화: CareerFitVis (5개 직종 가로 바 차트)

**⑤ 재물운** (500자+)
- 돈 버는 경로 (직접 vs 간접)
- 돈 쓰는 패턴 (충동 vs 계획)
- 투자 성향 (공격 vs 안정)
- 시각화: WealthFlow ⭐NEW
  - "벌기 → 쓰기 → 모으기" 3단계 흐름도
  - 각 단계별 강점/약점 표시

**⑥ 애정운** (500자+)
- 연애 스타일 ("느린 시작형" vs "불꽃형")
- 이상형 (사주 구조 기반)
- 주의점 ("이런 상대와는 충돌할 수 있습니다")

**⑦ 건강** (500자+)
- 오행별 장기 매핑 (목=간/눈, 화=심장/혈압, 토=위장, 금=폐/피부, 수=신장/뼈)
- 과다 오행 → 해당 장기 주의
- 부재 오행 → 해당 장기 보강
- 시각화: HealthVis (오행→장기 매핑 그리드)

**⑧ 2026년 운세** (700자+) — 가장 긴 섹션
- 현재 대운 + 2026 세운 조합 분석
- **월별 운세 미니 바** ⭐NEW
  - 12개월 가로 바 (1~12월)
  - 각 월별 점수 (50~100)
  - 주요 이벤트 월 하이라이트
- 상반기/하반기 핵심 조언
- "이 달에는 이것을 조심하세요"

**⑨ 대운의 흐름** (500자+)
- 과거→현재→미래 대운 타임라인
- 현재 대운 상세 해석
- 다음 대운 준비사항
- 시각화: DaeunTimeline (가로 스크롤, 현재 강조)

**⑩ 핵심 과제** (500자+)
- 공망 해석 ("비어있는 곳이 가능성")
- 신살 통합 해석 (길신 활용법 + 흉살 보완법)
- "이 인생에서 가장 중요한 한 가지"

**⑪ 개운법** (600자+)
- 보충해야 할 오행 (구체적 방법)
  - 컬러: "일상에서 파란색 계열을 자주 사용하세요"
  - 방위: "동쪽이 길한 방위입니다"
  - 음식: "검은콩, 미역, 해산물"
  - 운동: "수영, 요가"
  - 명상: "물소리 ASMR 추천"
- 시각화: GaewoonVis (4분할 — 색/방위/음식/운동)

**⑫ 나만의 럭키 프로필** ⭐NEW (사주아이/포스텔러에 없음)
- 행운의 컬러 3개 (HEX 코드 + 컬러칩)
- 행운의 숫자 3개
- 행운의 방위

- 시각화: LuckyProfile (카드 형태, 공유하기 좋은 비주얼)

## PART 6: 기능 명세 (상세)

### 6-1. 인증
**앱인토스:** 토스 계정 자동 로그인
**웹:** 카카오 > 네이버 > 구글 소셜 로그인
**비로그인:** 오늘의 운세만 접근 가능

### 6-2. 사주 입력 (6단계)
Step 1: 이름 (2~10자) + 관계 (본인/친구/가족/연인/직접입력)
Step 2: 생년월일 (양력/음력/윤달) + 년/월/일 피커
Step 3: 성별 (남/여 카드 선택)
Step 4: 출생시간 (알아요→시간피커 / 몰라요→3기둥)
Step 5: 만세력 미리보기 (확인 화면)
Step 6: 상황 질문 (연애/직업/궁금한점 — 선택사항)

### 6-3. 만세력 계산
- 클라이언트: lunar-javascript
- 오행 분포: 천간 1점 + 지지 1점 + 지장간 0.5점 → %
- 3기둥(시간 미입력) / 4기둥(시간 입력) 분기

### 6-4. AI 리포트 생성
- Firebase Function → Claude API
- 기본: claude-sonnet-4-6 / 프리미엄: claude-opus-4-6
- 12섹션 + 점수 6개 + 럭키 프로필 데이터 JSON
- 타임아웃: 25초 기본, 45초 최대
- 실패 시: 운 환불 + 재시도

### 6-5. 오늘의 운세 (무료)
- Claude Haiku (저비용)
- 캐싱: 사주+날짜 기준
- 감성 질문 3개 → 개인화

### 6-6. 궁합 (1운)
- 두 프로필 + 관계 선택
- 오행 레이더 오버레이 비교
- 카테고리별 점수 5개

### 6-7. 보관함
- 프로필 탭 (전체/본인/친구/가족)
- 리포트 카드 리스트
- 빈 상태 CTA

### 6-8. 충전
- 다크 잔액 카드 + 4종 패키지 + 결제 CTA
- 앱인토스: 토스 IAP / 웹: 토스페이먼츠

### 6-9. 마이페이지
- 프로필 + 잔액 + 메뉴 9항목 + 로그아웃/탈퇴

### 6-10. 공유 수신
- 상위 3섹션 미리보기 + 나머지 블러
- "내 사주도 보러 가기" CTA
