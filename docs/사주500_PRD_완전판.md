## 3. 전체 기능 명세

### 3-1. 인증 (Authentication)

**앱인토스:**
- 토스 계정 자동 로그인 (SDK 제공)
- 별도 로그인 UI 불필요
- 토스 uid로 Firebase Auth custom token 발급

**웹:**
- 소셜 로그인: 카카오 (1순위) → 네이버 → 구글
- Firebase Auth 연동
- 비로그인으로도 오늘의 운세는 접근 가능
- 사주 분석 요청 시 로그인 필수

**로그인 플로우:**
```
1. 앱 진입
2. 앱인토스: 자동 로그인 (토스 SDK → Firebase custom auth)
   웹: 메인 화면 표시 (비로그인)
3. CTA 탭 시 로그인 체크
4. 미로그인 → 로그인 모달 (카카오/네이버/구글)
5. 로그인 완료 → 사주 입력 페이지로
6. Firestore users/{uid} 생성 (최초 1회)
```

### 3-2. 사주 입력 (6단계)

**Step 1: 이름 + 관계**
- 이름: 텍스트 입력 (2~10자, 한글/영문)
- 관계: 본인 / 친구 / 가족 / 연인 / 직접입력
- 프로필 저장: users/{uid}/profiles/{pid}

**Step 2: 생년월일**
- 양력/음력/윤달 선택 탭
- 년: 1924~2024 (만 2세 이상)
- 월: 1~12
- 일: 1~28/29/30/31 (월에 따라 동적)
- 음력 선택 시: lunar-javascript로 양력 변환 후 저장

**Step 3: 성별**
- 남성 / 여성 카드 선택
- 대운 계산에 필수 (getYun(1=남, 0=여))

**Step 4: 출생시간**
- "알아요" → 시간 피커 (00:00~23:59) + "정확한 시간인가요?" (정확/대략)
- "몰라요" → 3기둥 분석으로 진행
- 시간 모를 때: 시주 관련 해석 제외, 안내 배너 표시

**Step 5: 만세력 미리보기**
- 입력 정보 요약 카드 (이름/생년월일/성별/띠)
- 만세력 4기둥 미니 프리뷰
- "맞아요, 분석해주세요" CTA
- "다시 입력하기" 링크

**Step 6: 상황 질문 (선택)**
- 연애 상태: 솔로/연애중/결혼/돌싱/직접입력
- 직업 상태: 학생/취준/직장인/자영업/주부/은퇴/직접입력
- 궁금한 점: 자유 텍스트 (100자)
- "건너뛰기" 옵션

**유효성 검사:**
- 이름: 2~10자, 특수문자 제외
- 생년월일: 미래 날짜 불가, 1924년 이전 불가
- 음력→양력 변환 실패 시: "양력으로 입력해주세요" 안내

### 3-3. 만세력 계산 (lunar-javascript)

**클라이언트에서 계산 (서버 부하 없음):**

```typescript
// calculator.ts
import { Solar } from 'lunar-javascript';

export function calculateSaju(input: SajuInput): SajuData {
  const solar = input.hasBirthTime
    ? Solar.fromYmdHms(input.year, input.month, input.day, input.hour, input.minute, 0)
    : Solar.fromYmd(input.year, input.month, input.day);

  const lunar = solar.getLunar();
  const ec = lunar.getEightChar();

  // 기본 기둥 (3~4개)
  const pillars = buildPillars(ec, input.hasBirthTime);

  // 오행 분포 계산
  const elements = calculateElements(pillars);

  // 대운 계산 (성별 필수)
  const gender = input.gender === 'male' ? 1 : 0;
  const yun = ec.getYun(gender);
  const daeun = buildDaeun(yun, input.year);

  // 12운성
  const unyoung12 = build12Unyoung(ec, input.hasBirthTime);

  // 납음
  const napeum = buildNapeum(ec, input.hasBirthTime);

  // 신살
  const gilsin = lunar.getDayJiShen();
  const hyungsal = lunar.getDayXiongSha();

  // 공망
  const gongmang = [
    { pillar: '년주', value: lunar.getYearXunKong() },
    { pillar: '일주', value: lunar.getDayXunKong() },
  ];

  return { pillars, elements, daeun, unyoung12, napeum, gilsin, hyungsal, gongmang };
}
```

**오행 분포 계산 공식:**

```typescript
// 천간 오행 매핑
const CHEONGAN_ELEMENT = {
  '甲': 'wood', '乙': 'wood',
  '丙': 'fire', '丁': 'fire',
  '戊': 'earth', '己': 'earth',
  '庚': 'metal', '辛': 'metal',
  '壬': 'water', '癸': 'water',
};

// 지지 오행 매핑
const JIJI_ELEMENT = {
  '寅': 'wood', '卯': 'wood',
  '巳': 'fire', '午': 'fire',
  '辰': 'earth', '未': 'earth', '丑': 'earth', '戌': 'earth',
  '申': 'metal', '酉': 'metal',
  '子': 'water', '亥': 'water',
};

function calculateElements(pillars) {
  const counts = { wood: 0, fire: 0, earth: 0, metal: 0, water: 0 };

  pillars.forEach(p => {
    // 천간 1점
    counts[CHEONGAN_ELEMENT[p.hanja]] += 1;
    // 지지 1점
    counts[JIJI_ELEMENT[p.branch]] += 1;
    // 지장간 각 0.5점
    p.branchHideGan.forEach(h => {
      counts[CHEONGAN_ELEMENT[h]] += 0.5;
    });
  });

  // 총합 기준 퍼센트 변환
  const total = Object.values(counts).reduce((a, b) => a + b, 0);
  return {
    wood: Math.round((counts.wood / total) * 100),
    fire: Math.round((counts.fire / total) * 100),
    earth: Math.round((counts.earth / total) * 100),
    metal: Math.round((counts.metal / total) * 100),
    water: Math.round((counts.water / total) * 100),
  };
}
```

### 3-4. AI 리포트 생성

**파이프라인:**
```
클라이언트
① 사주 입력 완료
② lunar-javascript로 만세력 계산 (클라이언트)
③ 잔액 확인 (1운 이상?)
④ 부족 시: 충전 모달 → 충전 페이지 → 결제 → 잔액 업데이트
⑤ generateReport Firebase Function 호출

서버 (Firebase Function)
⑥ 잔액 차감 (Firestore transaction)
⑦ 프롬프트 조합:
   - systemPrompt: 명리학 대가 페르소나 + 해석 규칙
   - userPrompt: 사주 데이터 구조화 + 상황 질문
⑧ Claude API 호출:
   - model: claude-sonnet-4-6 (기본) / claude-opus-4-6 (프리미엄)
   - max_tokens: 8000
   - temperature: 0.7
⑨ 응답 파싱: 10개 섹션 분리 + JSON 구조화
⑩ 점수 추출 (AI가 판단 → 숫자로 반환)
⑪ Firestore 저장: users/{uid}/reports/{rid}
⑫ reportId 반환

클라이언트
⑬ /result/{reportId}로 이동
⑭ 리포트 로드 + 렌더링
```

**점수 산출 방식 (AI 판단 기반):**

AI에게 10개 섹션 풀이와 함께 6개 점수를 요청합니다:

```
마지막에 아래 형식으로 점수를 JSON으로 출력해주세요:
{"scores": {"career": 0-100, "love": 0-100, "wealth": 0-100, "social": 0-100, "health": 0-100, "potential": 0-100}}

점수 기준:
- 해당 영역의 사주 구조적 강점/약점
- 현재 대운/세운의 영향
- 보완 가능성 반영
- 90+ : 매우 강함 (구조적 + 대운 모두 유리)
- 70-89 : 양호 (기본 좋으나 일부 약점)
- 50-69 : 보통 (강점과 약점 혼재)
- 30-49 : 약함 (구조적 약점, 보완 필요)
- 30 미만 : 매우 약함 (거의 없음)
```

**타임아웃 처리:**
- 기본 대기: 25초
- 최대 대기: 45초
- 45초 초과 시: "분석에 시간이 더 필요합니다. 완료되면 알림을 보내드릴게요." + 백그라운드 처리
- 리포트 생성 실패 시: 운 환불 + 에러 메시지 + 재시도 버튼

### 3-5. 결과 페이지 (14개 섹션 상세)

스크롤 순서와 각 섹션의 정확한 콘텐츠:

**① 헤더**
- 이름, 생년월일(양력), 성별, 띠, 출생시간
- 공유 버튼 (↗)

**② 시간 미입력 안내 배너** (조건부)
- 크림 배경 + 아이콘
- "출생시간을 입력하면 더 정확한 분석이 가능합니다"
- "시간 추가하기" 링크

**③ "사주팔자란?" 교육 카드**
- 접을 수 있는 카드 (기본 닫힘)
- "사주(四柱)는 태어난 년·월·일·시의 네 기둥"
- "팔자(八字)는 각 기둥의 천간+지지 = 8글자"
- 간단한 도식

**④ 만세력 원국 (4기둥 프리미엄 카드)**
- 강조 카드 (브랜드 컬러 테두리 2px)
- 4기둥 (또는 3기둥) 가로 배치
- 각 기둥 구조:
  - 라벨 (년주 年柱) — 10px SemiBold
  - 천간 한자 — 28-32px Bold + 오행 컬러
  - 천간 한글 읽기 — 11px
  - 십성 뱃지 — pill 라운딩, 오행 light 배경
  - 구분선 (1px 그라디언트)
  - 지지 한자 — 28-32px Bold + 오행 컬러
  - 지지 한글 읽기 — 11px
  - 십성 뱃지
- 일주: ★나 표시 상단 바 (브랜드 골드)
- 시주 미입력: 점선 테두리 + 🕐 + "출생시간 미입력" 오버레이

**⑤ 오행 밸런스**
- 레이더 차트 (Recharts RadarChart) — 5각형
  - 축: 목(木)/화(火)/토(土)/금(金)/수(水)
  - 채움: 브랜드 컬러 20% 투명도
  - 점: 브랜드 다크 3px
- 가로 바 차트 — 각 오행별 퍼센트
  - 바 색상: 해당 오행 메인 컬러
  - 배경: 오행 라이트 컬러
  - 높이: 16px, 라운딩 4px
- 경고 박스 (조건부):
  - 특정 오행 0%: "⚠️ {오행}이(가) 완전히 부재합니다"
  - 특정 오행 50%+: "⚠️ {오행}이(가) 과다합니다"

**⑥ 12운성 (에너지 상태 카드)**
- 각 기둥의 12운성 값 표시
- 색상 구분:
  - 장생/관대/건록/제왕: 초록 (활발)
  - 쇠/병/사/묘: 주황 (주의)
  - 태/양: 파랑 (시작)
  - 절: 보라 (전환)
- 의미 텍스트: "長生(장생) — 끊임없는 재생 에너지"

**⑦ 운세 종합 점수 (6개 SVG 링)**
- 3×2 그리드 배치
- 각 링: 80×80px SVG
  - 배경 원: stroke=#f0ebe3, width=4.5
  - 값 원: stroke=카테고리 컬러, animated
  - 중앙: 이모지 + 점수
- 카테고리별 컬러:
  - 💼 직업: #2563eb
  - 💕 애정: #db2777
  - 💰 재물: #d97706
  - 👥 대인: #7c3aed
  - ❤️ 건강: #059669
  - ⚡ 잠재력: #ea580c
- 애니메이션: 1.4초, staggered 100ms

**⑧ 대운 흐름 (세로 타임라인)**
- 세로 리스트 (또는 가로 스크롤)
- 각 대운 카드:
  - 간지 한자 24px + 한글 12px
  - 나이 범위 + 기간
  - 오행 이모지
- 현재 대운: 강조 테두리 2px + "현재" 뱃지
- 과거 대운: 연한 색상
- 미래 대운: 보통 색상

**⑨ 납음 (아이콘 + 한자 + 설명)**
- 각 기둥별 납음 카드
- 구조: 아이콘 + 한자 + 한국어 읽기 + 설명
- 예: ⛰️ 城头土 성두토 — "성벽 위의 흙, 단단하고 보호적인 에너지"

**⑩ 신살**
- 길신: 초록 배경 + 초록 테두리
  - 각 길신: 한자 + 한국어 + 의미
- 흉살: 주황 배경 + 주황 테두리
  - 각 흉살: 한자 + 한국어 + 의미 + "활용법"
- 흉살에는 반드시 "활용/보완법" 포함

**⑪ 공망 (보라 카드)**
- 년주 공망 + 일주 공망
- 보라 배경 (#7B1FA2 light)
- "공망은 비어있음이 아닌 가능성의 공간"

**⑫ 상세 풀이 (10개 아코디언)**
- 기본 상태: 1~2번 열림, 나머지 닫힘
- 열린 상태: ▼ + 제목 + 본문 (300자+) + 시각화 (있는 경우)
- 닫힌 상태: ▶ + 제목
- 시각화가 있는 섹션:
  - 사주 총평: OhengFlow (오행 상생상극 다이어그램)
  - 타고난 성격: JijangganVis (지장간 그리드)
  - 직업운: CareerFitVis (직업 적합도 바 차트)
  - 건강: HealthVis (오행→장기 매핑)
  - 개운법: GaewoonVis (보충 오행 4분할)

**⑬ 크로스셀 CTA 영역**
- 3개 카드: 궁합 보기(1운) / 대운 상세(1운) / 공유하기(무료)
- 가로 스크롤 또는 3열 그리드

**⑭ 푸터**
- "사주500 · 극상 AI 사주, 500원"
- 이용약관 / 개인정보처리방침 / 고객문의

### 3-6. 오늘의 운세 (무료)

**입력:** 감성 질문 3개 (4지선다)
1. "오늘 기분은 어때요?" — 😊좋아요 / 😐보통 / 😔별로 / 😤짜증나
2. "요즘 가장 신경 쓰이는 건?" — 💼일 / 💕연애 / 💰돈 / 🏥건강
3. "오늘 하루 어떻게 보내고 싶어요?" — 🔥열정적 / 🌿평화롭게 / 👥사람들과 / 🏠조용히

**출력:** 운세 결과 카드 (골드 배경)
- 전체 운세 요약 (3~4줄)
- 카테고리별 미니 점수 (연애/직장/재물/건강) — 바 형태
- 오늘의 행운 아이템/컬러/방위
- 한 줄 조언

**생성:** Claude API (Haiku 모델, 저비용)
- 캐싱: 같은 사주+같은 날짜 = 캐시 히트
- Firestore: users/{uid}/dailyFortune/{date}

### 3-7. 궁합

**입력:**
1. 내 프로필 선택 (저장된 프로필 중)
2. 상대방 프로필 선택 또는 새로 입력
3. 관계 선택: 15가지 칩 (친구/썸/연인/배우자/부모/형제/동료 등)

**출력:**
- 두 사람 만세력 카드 나란히
- 오행 비교 (레이더 차트 오버레이)
- 궁합 점수 (큰 숫자)
- 카테고리별 점수 (연애/우정/직장/가족/총점) — 5개 바
- 상세 풀이 (AI 생성)

**비용:** 1운

### 3-8. 보관함
