# PART 1. 가격 전략 — "550 시리즈"

## 1-1. 티어 구조

| 티어 | 가격 | 상품 | 타겟 |
|------|------|------|------|
| **무료** | 0원 | 오늘의 운세 (매일 1회) | 유입·리텐션 |
| **기본** | 550원 (1운) | AI 사주 리포트 | 대중·첫 결제 |
| **프리미엄** | 5,500원 (10운) | AI 심층 분석 리포트 + PDF | 진지한 유저 |
| **전문가** | 55,000원 | 명리학 전문가 1:1 매칭 상담 | 고가치 유저 |

→ 550 → 5,500 → 55,000 (×10 단위) = 깔끔한 가격 아키텍처
→ "550 시리즈"라는 브랜드 자산이 됨

## 1-2. 각 티어별 상세

### 무료 (0원)
- 오늘의 운세 (매일 1회, 자정 리셋)
- 만세력 원국 확인 (기본)
- 상황 질문 3개로 개인화
- 목적: 앱 진입 + 습관 형성 + 유료 전환 퍼널

### 기본 — 550원 (1운)
- AI 사주 리포트 (10개 섹션)
- 만세력 원국 + 오행 차트 + 점수링 + 대운 흐름
- 인포그래픽 포함 결과 페이지
- 공유 링크 생성
- 목적: 첫 결제 허들 최소화, 바이럴

### 프리미엄 — 5,500원 (10운)
- 기본 리포트 전체 포함
- + 격국·용신 분석 (사주의 구조적 해석)
- + 10년 대운 상세 풀이 (각 대운별 해설)
- + 월운 분석 (올해 12개월 각각)
- + PDF 다운로드 (인쇄용 고품질)
- + 궁합 1회 포함
- 목적: ARPU 상승, 진지한 유저 대응

### 전문가 — 55,000원
- 명리학 전문가가 직접 분석
- 24시간 이내 상세 리포트 발송 (또는 실시간 1:1 상담)
- AI 리포트 + 전문가 소견서
- Phase 3 이후 (유저 안정화 후 전문가 모집)
- 목적: 하이엔드 포지션, 높은 마진

## 1-3. 화폐 시스템

- 화폐: **운(運)**
- 1운 = 550원
- 충전 패키지:

| 패키지 | 운 | 가격 | 개당 | 할인 |
|--------|-----|------|------|------|
| 한 번만 | 1운 | 550원 | 550원 | - |
| 좀 더 보자 | 3운 + 1운 보너스 | 1,650원 | 412원 | 25% |
| 제대로 보자 | 5운 + 2운 보너스 | 2,750원 | 392원 | 29% |
| 올해 다 보자 | 10운 + 4운 보너스 | 5,500원 | 392원 | 29% |

- 프리미엄(5,500원)은 "올해 다 보자" 패키지와 같은 가격 → "그냥 프리미엄 사는 게 낫지 않나?" 전환 유도
- 전문가(55,000원)은 별도 결제 (운 시스템 밖)

## 1-4. 크로스셀 상품 (각 1운)

| 상품 | 가격 | Phase |
|------|------|-------|
| 궁합 | 1운 | MVP |
| 대운 해설 | 1운 | Phase 2 |
| 연도별 운세 | 1운 | Phase 2 |
| 택일 | 1운 | Phase 2 |
| AI 채팅 상담 | 1운/3질문 | Phase 2 |

## 1-5. 무료→유료 전환 퍼널

```
[오늘의 운세] 무료 → 짧은 3~4줄 운세
  ↓ "더 깊이 알고 싶다면"
[사주 리포트] 1운(550원) → 10개 섹션 + 인포그래픽
  ↓ 결과 하단 크로스셀
[궁합] 1운 / [대운] 1운 / [연도별] 1운
  ↓ "전체를 한눈에 보고 싶다면"
[프리미엄] 10운(5,500원) → 전체 + PDF + 월운 + 궁합
  ↓ "전문가의 소견이 필요하다면"
[전문가 매칭] 55,000원 → 1:1 상담
```

# PART 4. API 파이프라인

## 4-1. 사주 리포트 생성 플로우

```
[클라이언트]
  ① 사주 입력 (이름/생년월일/시간/성별/상황질문)
      ↓
  ② lunar-javascript로 만세력 계산 (클라이언트에서)
     → 4기둥 8글자, 오행, 십성, 지장간, 12운성, 납음, 신살, 공망, 대운 전부 추출
      ↓
  ③ 잔액 확인 (1운 이상?)
     → 부족하면 충전 모달
      ↓
  ④ Firebase Function 호출 (generateReport)
     POST /generateReport
     body: { profileId, sajuData, situation, reportType }

[서버 — Firebase Function]
  ⑤ 잔액 차감 (트랜잭션)
      ↓
  ⑥ 프롬프트 조합
     시스템 프롬프트 (명리학 해석 규칙)
     + 사주 데이터 (구조화된 JSON)
     + 상황 질문 정보
     + 출력 형식 지시
      ↓
  ⑦ Claude API 호출
     model: claude-opus-4 (또는 sonnet-4 for 기본)
     max_tokens: 8000
      ↓
  ⑧ 응답 파싱 + 점수 추출
      ↓
  ⑨ Firestore 저장 (reports 컬렉션)
      ↓
  ⑩ reportId 반환

[클라이언트]
  ⑪ /result/{reportId}로 이동
  ⑫ Firestore에서 리포트 로드
  ⑬ 결과 페이지 렌더링 (인포그래픽 + 차트 + 풀이)
```

## 4-3. 만세력 계산 → 데이터 구조화 (클라이언트)

```typescript
// services/saju/calculator.ts

import { Solar } from 'lunar-javascript';

export function calculateSaju(input: SajuInput): SajuData {
  const solar = input.hasBirthTime
    ? Solar.fromYmdHms(input.year, input.month, input.day, input.hour, input.minute, 0)
    : Solar.fromYmd(input.year, input.month, input.day);
  
  const lunar = solar.getLunar();
  const ec = lunar.getEightChar();
  
  return {
    pillars: extractPillars(ec, input.hasBirthTime),
    elements: calculateElements(ec, input.hasBirthTime),
    sipsung: extractSipsung(ec, input.hasBirthTime),
    jijanggan: extractJijanggan(ec, input.hasBirthTime),
    unyoung12: extractUnyoung12(ec, input.hasBirthTime),
    daeun: extractDaeun(ec, input.gender === 'male' ? 1 : 0),
    napeum: extractNapeum(ec, input.hasBirthTime),
    gilsin: lunar.getDayJiShen(),
    hyungsal: lunar.getDayXiongSha(),
    gongmang: extractGongmang(lunar),
    currentDaeun: getCurrentDaeun(ec, input),
    yearlyUn: getYearlyUn(2026),
  };
}
```
