# 광고비 증빙 장부 (2026-10-19 시작)

법인카드와 광고비 증빙을 한곳에 남긴다. 결제나 충전이 생길 때마다 한 줄씩 적고, 영수증 파일은 `docs/finance/receipts/` 에 `날짜_채널_금액.pdf` 이름으로 모은다. 매달 1일에 지난달 영수증이 다 있는지 확인한다.

## 원칙
- 메타: 광고비가 나간 날마다 'VAT 인보이스'(FBADS-...)가 생긴다. 결제 및 청구 > 결제 활동에서 PDF 로 받는다. 인보이스에 찍히는 사업자 정보는 광고 계정 세금 정보를 따른다.
- 네이버: 비즈머니 충전이 결제다. 법인카드로 충전하면 카드 매출전표가 증빙이고, 광고주센터 > 결제 에서 충전 영수증을 받는다. 세금계산서 발행 설정이 있으면 켠다.
- 어느 사업자의 돈인지 섞지 않는다. 2026-10-19 기준 메타 광고 계정(656947689522390)의 세금 정보와 남은 선불 잔액은 예전 사업자(주라벨, 272-32-01546) 것이다. 오너 결정(10-19): 이 잔액(₩218,268)을 사주500 첫 시험에 먼저 쓰고, 다음 충전부터 법인(주라벨 주식회사, 228-88-03113) 광고 계정으로 옮긴다.
