## 1주차 — 시드 (돈 0, 오늘 바로)

### A. 지인 시딩 (가장 중요)
카톡/인스타DM 으로 30~50명에게. 부탁은 "써봐" 가 아니라 **"무료 오늘운세 한 번만 봐줘"** (장벽 최소).
복붙용:
```
나 사주앱 만들었어 ㅎㅎ 토스에서 '사주 500' 검색하면 나와.
오늘의 운세는 무료니까 한 번만 봐줄래? 피드백 주면 개꿀 🙏
[앱인토스 링크]
```

### B. 첫 후기 수집 → 다음 홍보 자산
무료/결제한 지인 5명에게 결과 캡쳐 부탁 → 인스타/스레드에 "실사용 후기"로 재활용.
(앱 안 후기 캐러셀에도 반영 가능)

### C. 출시 프로모션 활용
- 첫 콘텐츠 = **3원 자동 지급** (즉시 보상 = 재방문 훅)
- 7일 연속 출석 = **100원** → "매일 오늘운세 보면 100원" 으로 리텐션 유도
→ 지인에게 "매일 출석하면 100원 줘" 한 줄 추가하면 7일 리텐션 ↑

## SNS 콘텐츠 (선제작 5개 · 복붙)

### 인스타/스레드 — 콘텐츠 시드
1. **"○일간인 사람 특징"** 시리즈 (10천간 × 1개씩 = 10개 콘텐츠 풀)
   ```
   병화(丙火) 일간인 사람은요 ☀️
   — 밝고 활달, 사람을 끌어당기는 태양 같은 기운
   — 단점: 욱하면 다 태움 / 뒷심 부족
   내 일간이 궁금하면 → 사주500 (토스에서 무료)
   ```
2. **"도화살 있으면 생기는 일"** (신살 호기심 자극)
3. **"올해 재물운 터지는 사주 특징"** (시즌성)
4. **"무료로 오늘 운세 보는 법"** (앱 사용법 + 스샷)
5. **"5천원으로 평생 사주 풀이받은 후기"** (가격 대비 가치 + 결과 캡쳐)

> 톤: 신비+고급+깔끔 (점집 X). 한자는 괄호 풀이. 이모지 절제.

## 2주차+ — 데이터 기반 (어드민 보면서)

`/admin` 대시보드로:
- **콘텐츠 인기** → 가장 많이 보는 콘텐츠를 SNS 콘텐츠 주제로
- **전환 퍼널** → 진입 대비 결제 낮으면 그 지점 카피/가격 손보기
- **매출 추이 / 기여이익** → 어떤 콘텐츠가 돈 버는지 → 그걸 밀기
- **이탈 지점** (GA4 유저플로우) → 막힌 화면 개선
