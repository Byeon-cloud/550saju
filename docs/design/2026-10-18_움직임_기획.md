# 사주500 움직임 기획 (2026-10-18)

오너 지시: "클릭하면 좀 촤라락하거나 하는 그런거, 너무 과하지 않다면 넣어 봐도 될 듯. 기획하고 디자인하고 적용해 봐."

## 한 줄 방향

**먹과 종이.** 화려한 앱 효과 대신, 종이에 먹이 배고 도장이 찍히고 두루마리가 펼쳐지는 손맛. v9 수묵 고서 디자인과 같은 말씨로 움직인다.

## 원칙

1. 누를 때, 펼칠 때, 받을 때, 결과가 나올 때만 움직인다. 가만히 있는 화면은 가만히.
2. 짧게 한 번. 누름은 즉시, 등장은 0.3~0.6초, 여덟 글자 펼침은 전체 1초 안. 로딩 말고는 반복하지 않는다.
3. 내용은 기본으로 보인다. 애니메이션이 안 돌아도(구형 기기, 숨은 탭) 화면이 비지 않게 `backwards` 로만 숨긴다. 예전 '빈 화면' CS 를 되풀이하지 않는다.
4. transform, opacity 위주. 흐림은 작은 글자 덩어리에만. 60대 기기에서도 버벅이지 않게.
5. 움직임 줄이기를 켠 기기는 전부 끈다. 이미지 저장(html2canvas) 사본도 끈다.
6. 홈 첫 화면 움직임은 앱을 연 뒤 처음 한 번만.

## 다섯 가지 움직임

| 이름 | 모양 | 어디에 |
|---|---|---|
| 누름 | 눌린 동안 살짝 먹빛(밝기 95%), 큰 카드는 살짝 들어감 | 모든 버튼, 링크 |
| 촤라락 | 글자 칸이 위에서 뒤집혀 내려온다. 년주 → 월주 → 시주, 마지막에 일주(나) | 사주 카드 머리 네 칸, 만세력 표 천간 지지 여덟 칸(표가 보일 때) |
| 먹 스밈 | 흐릿하다가 먹이 배듯 또렷해진다 | 홈 오늘 운세 제목, 사주 카드 일주 두 글자, 결과의 한 줄 풀이 |
| 낙관 | 도장을 찍듯 크게 내려와 자리 잡는다 | 홈 오늘 간지 도장, 한 줄 풀이 끝 도장, 출석 오늘 칸, 리워드 받은 표시 |
| 운 오름 | 잔액 칩이 한 번 부풀고 옆에 '+N운' 이 떠올랐다 사라진다 | 상단 잔액 칩(운이 늘 때만, 충전 뒤 홈에 돌아왔을 때도) |

함께 넣은 작은 움직임

- 형광 밑줄 붓질: 홈 제목의 금색 밑줄이 왼쪽에서 칠해진다.
- 두루마리 펼침: 접힌 칸을 열면 본문이 위에서 아래로(주제운 섹션은 오너가 정한 스켈레톤 뒤에, 대운 전체 표).
- 차례로 떠오름: 운의 흐름 줄, 출석 채운 칸.
- 점수 차오름: 주제운 점수 숫자가 0에서 차오르고 열 칸이 하나씩 찬다.
- 화면 전환: 나가는 화면은 0.12초로 줄여 기다리는 느낌을 덜었다(들어오는 화면 0.25초 그대로).

## 하지 않은 것

- 반짝이, 파티클, 흔들림, 튕기는 버튼, 계속 도는 장식: 점집이나 게임 느낌이라 뺐다.
- 모든 카드 스크롤 등장: 화면마다 다 떠오르면 과해서 결과의 핵심(여덟 글자, 한 줄 풀이, 점수)에만.

## 코드 위치

- 규칙과 모양: `src/styles/motion.css` (`mo-deal`, `mo-ink`, `mo-stamp`, `mo-pop`, `mo-float-up`, `mo-brush`, `mo-unroll`, `mo-rise`, `mo-grow`, 점수 칸 `mo-fill`)
- 부품: `src/components/motion/Motion.tsx` (`MotionScope` 보일 때 켜기, `useCountUp`, `moVars`)
- 잔액 변화 알림: `localStore.BALANCE_CHANGED_EVENT` → `BalanceBar`
- 이미지 저장 사본에서 끄기: `SajuCardExport.prepareCloneForCapture`

새 화면에 넣을 때는 위 다섯 가지 안에서 고른다. 새 움직임을 만들기 전에 이 문서를 먼저 고친다.
