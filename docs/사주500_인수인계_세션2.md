# 다음 세션 실행 순서

## Phase A: 디자인 확정 (피그마)

### A-1. Figma MCP 연결 완료
1. Claude Code 완전 종료 후 재시작
2. Figma 인증 팝업에서 Allow
3. `/mcp`로 연결 확인

### A-2. 브랜드 컬러 최종 확정
- "라이트 프리미엄" 방향은 결정됨
- 구체적 선택지:
  - 크림 동양풍 유지 + 고급 그라디언트 보강
  - 네이비+골드 (토스 느낌)
  - 또는 준기님이 모아온 레퍼런스 기반
- 경쟁앱(포스텔러/점신/사주아이) 스크린샷 보면서 결정

### A-3. 피그마에 핵심 화면 디자인 (5개)
1. 홈 화면 — 풍성하게 (운세 카드, CTA, 크로스셀, 이벤트)
2. 사주 입력 — 6단계 멀티스텝
3. 로딩 — AI 분석 중 몰입감
4. 결과 — v4 프로토타입 기반 (컬러만 최종 팔레트 적용)
5. 충전 — 패키지 선택 + 잔액

### A-4. 나머지 화면 디자인
6. 오늘의 무료운세
7. 궁합 입력/결과
8. 보관함
9. 마이페이지
10. 공유 수신 페이지

## Phase B: 앱인토스 정책 완벽 준수

### 필수 규칙 (리젝 방지)
- window.confirm() / window.alert() 절대 금지
- 커스텀 뒤로가기/홈 버튼 금지
- TDS 모달 규격: 52px 버튼, #3182F6
- 아이콘: 정사각형, 배경 꽉 차게 (투명 불가)
- 빌드: `ait build` (granite build 아님)
- 광고: AdMob (토스 v5.227.0+ 환경에서만)
- IAP: 토스 IAP (결제는 마지막에)

### 레이아웃/마진 확인 필요
- safe-area-top / safe-area-bottom
- 탭바 높이: 56px + safe-area
- 헤더 높이: 48px + safe-area
- 카드 마진/패딩: TDS 규격 참조
- 모달: TDS 바텀시트 규격

## Phase C: 만세력/명리학 프롬프트 강화

### 현재 상태
- 프롬프트 v2 완성 (전체 고급 데이터 포함)
- 준기님 피드백: "용하다 느낌은 모르겠다"
- v1보다 훨씬 나아졌지만 추가 개선 필요

- 사주아이 리포트와 직접 비교 (같은 사주로)
