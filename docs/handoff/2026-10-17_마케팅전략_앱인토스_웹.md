# 마케팅 전략: 앱인토스와 웹 (2026-10-17)

## 공통 원칙
- 판정 기준: 결제한 사람 한 명을 데려오는 데 쓴 돈(결제 한 명당 비용)이 한 명당 매출(앱 약 4,160원)보다 싸면 늘리고, 비싸면 접는다. 웹은 수수료가 카카오페이뿐이라 같은 결제면 앱보다 약 1.2배 남는다.
- 돈 내는 사람: 사주를 넣은 20~30대(20대 입력자 중 27.5% 충전). 포인트 받으러 온 50~60대는 사주를 거의 넣지 않는다(최근 7일 들어온 9,372명 중 입력 1.3%).
- 시즌: 2027 신년운세 얼리버드 7운은 11월 30일까지, 12월 1일 정가 9운, 설(2027년 2월 6일)까지가 성수기. 10~11월에 깔아 둔 검색 페이지와 알림 동의자가 12~1월에 돈이 된다.
- 결과는 성과판(https://claude.ai/artifact/BxyjonRHWSHzXxcxNdGJv3)의 시험 목록과 출처별 표로 본다.

## 1. 앱인토스
현황: 유입의 99%가 토스 앱이고 대부분 혜택탭. 광고성 푸시는 앱인토스가 만들기를 중단했다. 공유 리워드는 10-23 종료, 새 바이럴 기능은 10월 말~11월 공개 예정.

| 순서 | 할 일 | 돈 | 누가 | 판정 |
|---|---|---|---|---|
| A1 | 매일 아침 9시 알림 동의 늘리기(1.5.8) | 0 | Claude | 주 30명 동의, 동의자 재방문 40% |
| A2 | 결과 받은 사람에게 별점 요청(토스 검색 순위, 스토어 신뢰) | 0 | Claude | 별점 수 주 20개 |
| A3 | 궁합 결과 '보내기' + 새 바이럴 기능 나오면 바로 연결 | 0 | Claude | 보낸 10명 중 1명 입력 |
| A4 | 혜택탭을 '방문 지급'에서 '조건부 지급'으로: 사주 넣고 오늘의 운세까지 받으면 20원(서버 지급 기능 있음) | 사흘 2만 원 한도 | Claude 코드, 오너 캠페인 승인 | 지급받은 사람 중 충전 비율로 결제 한 명당 비용 |
| A5 | 토스애즈 배너, 20~39세 여성, '2027 신년운세 얼리버드' | 5만 원 시험 | 오너(광고 계정) | 결제 한 명당 4,160원 미만 |
| A6 | 11월 20~30일 얼리버드 마감: 앱 안 배너와 홈 문구, 알림 동의자는 오늘의 운세 화면 안 배너로 | 0 | Claude | 마감 주 신년운세 결제 |

## 2. 웹 (saju500.app)
현황: 카카오페이만(카드 PG 심사 6월부터 멈춤), 결제 전 로그인, 검색용 띠별 신년운세 13장, 검색엔진 미등록이라 유입 거의 0.

| 순서 | 할 일 | 돈 | 누가 | 판정 |
|---|---|---|---|---|
| W1 | 네이버 서치어드바이저, 구글 서치 콘솔 등록과 사이트맵 | 0 | 오너 로그인, 나머지 Claude | 색인된 쪽 수 |
| W2 | 오늘의 띠별 운세 공개 페이지(서버가 매일 이미 만든다 → 매일 바뀌는 검색 페이지로) | 0 | Claude | 검색 유입 주 100명 |

| W4 | 띠 궁합 78쌍 페이지(쥐띠 소띠 궁합 등) → 궁합 3운 | AI 원가 수천 원 | Claude | 궁합 결제 |
| W5 | 스레드 봇(moon.dal_note) 글을 웹 페이지로, 링크에 출처 표시 | 0 | Claude | 스레드 유입과 충전 |
| W6 | PDF 메일 수신 동의자에게 11월 28일 얼리버드 마감 메일 | 0 | Claude(오너 문구 확인) | 메일 결제 |
| W7 | 네이버 검색광고 '2027 신년운세', '신년운세', '궁합' 하루 5천 원 일주일 | 3.5만 원 | 오너(광고 계정) | 결제 한 명당 비용 |
| W8 | 인스타 광고, 20~34세 여성, 연애운과 궁합 소재 | 5만 원 | 오너(광고 계정) | 결제 한 명당 비용 |
| W9 | 카드 결제 열기: 이니시스, KPN 심사 재촉 | 0 | 오너(전화 한 통, pgs@portone.io 참조) | 카드 결제 오픈 |
