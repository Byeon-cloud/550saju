## 1. 전자상거래법 — 사업자 신원정보 표시 (제10조)
출처: [easylaw 인터넷쇼핑몰 표시의무](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=25&ccfNo=3&cciNo=1&cnpClsNo=1) · [국가법령정보센터](https://www.law.go.kr/lsInfoP.do?lsId=009318)

**초기화면(또는 전 페이지 푸터)에 표시 필수:**
- 상호 및 대표자 성명
- 영업소 소재지 주소 (소비자 불만처리 장소 포함)
- 전화번호 · 전자우편주소
- 사업자등록번호
- **통신판매업 신고번호** (통신판매업 신고 후 발급)
- 이용약관 (링크)
- (권장) 호스팅 사업자 정보, 개인정보보호책임자

**위반 과태료**: 최대 500만원 (1차 100 / 2차 200 / 3차 500).
**→ 구현**: `BUSINESS_INFO` 상수(준기 실데이터) + 전 페이지 푸터 + `/business` 사업자정보 공개페이지.

## 2. 디지털콘텐츠 청약철회·환불 (제17조)
출처: [easylaw 반품·환불](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?csmSeq=835&ccfNo=4&cciNo=1&cnpClsNo=2)

- **디지털콘텐츠 제공(분석 생성)이 개시되면 청약철회 불가** (제17조2항5호).
- 단 사업자는 ① **청약철회 불가 사실을 결제 전 명확히 표시** + ② **시험사용(무료체험) 제공**으로 권리행사 방해 금지 (제17조6항).
  → 무료체험(오늘운세·꿈해몽 무료)이 ②를 충족.
- **미사용분**은 청약철회 가능 → 7일내 미사용 운 환불.
- 환불 기한: 청약철회일로부터 **3영업일 이내** 환급.
- **→ 구현**: 결제 직전 "충전 후 분석에 사용하면 해당 운은 환불 불가, 미사용분만 7일내 환불" 명시 + 동의. 환불 처리 3영업일.

## 3. 개인정보보호법 — 수집·이용 동의 (제15조)
출처: [easylaw 개인정보 수집·이용](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1257&ccfNo=2&cciNo=1&cnpClsNo=1)

**동의 시 4요소 명시 필수:**
1. 수집·이용 목적  2. 수집 항목  3. 보유·이용 기간  4. 동의 거부권 + 거부 시 불이익
- **필수 / 선택 구분.** 마케팅 동의는 **선택·별도**.
- 인터넷 홈페이지에 동의내용 게재 + **체크박스로 동의 표시** = 유효.
- 생년월일·시: 일반 개인정보 (고유식별정보·민감정보 아님 → 별도동의 불필요, 단 수집동의엔 포함).
- **→ 구현**: 첫 로그인 시 동의 모달 — [필수] 이용약관 + [필수] 개인정보 수집·이용 + [선택] 마케팅. "간주 동의"(현재 방식)는 명시적 체크로 강화.

## 4. 회원탈퇴 / 파기 (개인정보보호법 제21조·제36조)
- 회원탈퇴(계정삭제) 경로 **필수** 제공. 탈퇴 시 개인정보 지체없이 파기.
- 단 전자상거래법상 **결제·계약 기록은 5년 보존** (탈퇴해도 거래기록은 법정기간 보관 후 파기).
- **→ 구현**: `/my` 회원탈퇴 + Cloud Function `deleteAccount` (Firestore 유저데이터 삭제 + Auth deleteUser, 단 payments는 법정보존 분리).
