# 검색 수요 원자료

마케팅 판단용으로 모은 검색 수요 원자료다. 이 문서는 `node scripts/marketing/summarize.cjs` 가 파일을 읽어 만든다(숫자는 전부 파일에서 계산, 손으로 고치면 다음 실행 때 덮어쓴다). 마지막 요약: 2026-10-20 수집분.

## 파일

| 파일 | 뜻 |
|---|---|
| `naver_keywords_20261020.json` | 네이버 검색광고 키워드 도구. 우리 키워드(힌트) 255개의 월간 검색수(PC, 모바일), 월평균 클릭수, 클릭률, 노출 광고 수, 경쟁정도. 묶음별 연관 키워드(검색량 상위 30, 운세 말 상위 30), 새로 노릴 후보 20, 모바일 1~5위 예상 입찰가 56개. |
| `naver_keywords_20261020.csv` | 위 JSON 의 힌트와 연관 키워드를 한 표로. UTF-8 BOM 이라 엑셀에서 바로 열린다. |
| `naver_trend_20261020.json` | 네이버 데이터랩 검색어 트렌드(2023-01-01~, 주 단위, 대표 그룹, 나이대, 성별). 상태: **blocked** |
| `google_trends_20261020.json` | 구글 트렌드(한국, 2023-01-01~, 주 단위, 5개씩 비교). 상태: **ok** |
| `search_summary_YYYYMMDD.json` | 아래 핵심 숫자만 모은 것(성과판 대시보드용). |

## 다시 돌리기

```
node scripts/marketing/naver_keywords.cjs   # 1~2분. 네이버 검색광고 API, 읽기만(캠페인, 입찰 안 바꿈)
node scripts/marketing/naver_datalab.cjs    # 네이버 앱에 데이터랩 API 가 켜진 뒤
node scripts/marketing/google_trends.cjs    # 막히면(429) 하루 뒤 다시. 반복해서 두드리지 않는다
node scripts/marketing/summarize.cjs        # 이 문서와 search_summary 다시 만들기
```

키워드 목록과 묶음, 트렌드 대표 그룹, 운세 말 판정 규칙은 `scripts/marketing/keywords.cjs` 에 있다. 파일 이름의 날짜는 한국 시각 수집일이다. 같은 날 다시 돌리면 덮어쓴다.

## 데이터 한계

- **키워드 도구는 최근 30일 기준 월간 값이다.** 이번 값은 10월 중순 기준이라 신년운세, 토정비결, 수능처럼 철이 있는 말은 정점(12월 말~1월 초)보다 훨씬 작게 잡혀 있다. 시즌 크기는 4번 곡선으로 따로 본다.
- 검색수가 '< 10' 이면 5 로 바꿔 더했다. 묶음 합은 키워드끼리 겹치는 사람(예: '오늘의운세'와 '띠별운세'를 둘 다 친 사람)을 빼지 못한 단순 합이다.
- 경쟁정도(낮음, 중간, 높음)는 광고 입찰 경쟁이지 검색 결과 경쟁이 아니다. 예상 입찰가는 네이버 추정치라 실제 낙찰가와 다를 수 있다. 70원으로 나온 칸은 최저 입찰가 수준이다.
- 데이터랩 값은 요청 하나 안에서 기간 중 최대값을 100 으로 둔 상대값이다. 나이대, 성별은 요청마다 따로 100 이라 크기를 서로 비교하면 안 되고 곡선 모양만 비교한다.
- 구글 트렌드도 상대값이고 표본 추출이라 다시 받으면 조금씩 다르다. 한국은 네이버 검색 비중이 커서 구글 표본이 작고, 작은 말은 0 이 많다.
- 연관 키워드의 운세 말 판정과 후보 20 은 규칙으로 고른 것이라 운세를 찾는 말이 아닌 것도 섞일 수 있다(예: 퇴사, 동지, 오행팔찌 같은 말).
- 같은 연관 키워드가 여러 묶음에서 나오면 묶음마다 한 줄씩 들어간다(CSV 와 JSON related). 연관 키워드 검색량을 더할 때는 키워드로 한 번만 센다.
