§5. 내가 모르는 것 (PC 조사 필수)

이 항목들 답 없이는 다음 IA 안 나온다. PC에게 한 번에 조사 요청.

Q-1 입력·결제·결과 flow
/input에서 사주 입력 → /loading → /result/:id. 중간에 결제 단계는 어디서 끼는지? /charge가 결제인지 단순 충전인지? 500원 = 10운 1개 차감 구조인지?
Q-2 /chat 첫 진입
사주 입력 안 한 신규 유저가 /chat 들어가면 어떻게 되나? 입력 유도? 일반 챗봇? 기능 자체는 어떤 모델 쓰나?
Q-3 /storage 보관 대상
과거 풀이 결과? 저장된 사주 프로필? 둘 다? 삭제·수정·내보내기 가능?
Q-4 /my 기능 목록
결제 이력? 운 잔액 상세? 알림 설정? 계정(로그인 방식)? 로그아웃/탈퇴?
Q-5 /compat 입력 flow
궁합은 2명 입력 필요. 이미 저장된 프로필 재활용? 즉석 입력?
Q-6 /daeun, /monthly, /tojung 입력·결과
각각 이미 저장된 사주 사용? 결제 필요? 결과 분량?
Q-7 /topic 주제 종류
topicId가 뭐뭐 있나? 연애·재물·직장? 고정 enum인지 동적인지?
Q-8 /terms, /privacy 접근 경로
현재 홈·/my·/input 어디서 링크가 있는지? 푸터 존재? 입력 페이지 동의 체크박스?
Q-9 /share/:id 생성 경로
어디에서 "공유하기" 버튼이 뜨나? /result에서? /daily에서? OG 카드 노출?
Q-10 /result 업셀·재방문 포인트
500원 풀이 결과 보는 중 5000원 업셀 어디서? 블러잠금 L1~L4 구조 위치?
Q-11 NotFoundPage 디자인
지금 디자인·카피 어떻게 생겼나? 홈으로 복귀 버튼만? (준기가 봤던 404 화면)
Q-12 BalanceBar
App.tsx 상단에 고정된 BalanceBar는 모든 페이지에 노출? 어떤 데이터? 운 잔액 말고 뭐 더?

§6. 내가 빼먹었을 가능성 (기획 갭)

이미 드러난 것 + 드러날 가능성이 높은 것. PC 조사 후 확정.

✓ 복구됨 · 섹션 4.5 대운·월운·궁합·토정·주제별 입구
방금 PC 2차 paste로 추가.
? 정책 페이지 푸터 링크
홈 또는 /my 하단에 이용약관·개인정보처리방침 링크 유무 확인. 앱인토스 심사 체크리스트 필수.
? 공유 CTA (/share/:id)
결과 페이지에서 공유 버튼 있는지, OG 카드 예쁜지. 바이럴 경로.
? 5000원 upgrade 지점
결과 페이지 L4 블러잠금에서 5000원 업셀이 홈 섹션 5와 어떻게 연결되는지.
? 알림·푸시 설정
"오늘의 운세 매일 알림" 옵션 있는지. /my 안에 있을 가능성.
? 온보딩 (최초 진입)
앱 첫 실행 시 튜토리얼/인트로 있나? 아니면 바로 홈?
? 프로필 다중 관리
본인 외 가족·지인 프로필 저장·조회·삭제 흐름. /storage 또는 /input 안에 있을 가능성.
? 로그인·계정 연동
현재 익명? 카카오·구글 소셜 있나? 기기 간 동기화?
? 리워드·3원 적립 구조
메모리상 "블러잠금 후기·3원 리워드" 있음. UI 어디서 노출되는지 확인.
? 에러 상태 (네트워크·결제 실패)
로딩 중 네트워크 끊김, 결제 실패 시 UX. 리트라이 흐름.
