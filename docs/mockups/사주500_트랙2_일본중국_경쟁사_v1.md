## 1. LINE占い (일본)

### 카테고리·접근 방식
- **하이브리드 마켓플레이스**. AI 자동 풀이가 아니라 실제 점술가(人間의 鑑定師)와의 1:1 상담이 핵심. 전화·채팅·메시지·비디오 대면의 4가지 채널을 LINE 앱 UI 위에 얹은 구조.
- 정통 명리보다는 "대중 고민 상담" 포지셔닝. 연애·불륜·직업 고민이 주요 카테고리. 매일운세·12별자리 같은 무료 가벼운 콘텐츠를 미끼로 유료 상담으로 유도.

### 가격·수익 모델
- **1분 단위 과금** 중심. 채팅 1분 110엔~, 전화 1분 130엔~, 메시지 1통 3,300엔~, 비디오 2,800엔~.
- 점술가는 BASIC·GOLD·PLATINUM·DIAMOND·BLACK 5등급으로 가격 차등. 등록료·지명료·예약료는 없음.
- **첫 10분 무료** (채팅·전화 한정)가 강력한 퍼널 후크.
- 결제는 LINE 티켓 또는 신용카드.

### 콘텐츠 철학
- 분량은 상담사가 정하는 실시간 대화. 톤은 친근한 구어체(LINE 메신저 네이티브).
- 한자·전통 용어는 상담사 재량. 매일운세 쪽은 완전히 현대화된 대중 친화 카피.
- 현대화 정도는 매우 높음. "엄숙한 점집" 느낌을 완전히 탈피.

### UI·UX 포인트
- LINE 메신저 그대로의 톡 UI. 별도 학습 없이 즉시 상담 가능한 것이 최대 강점.
- 상담사 프로필은 사진·경력·분당요금·평점·리뷰 수를 카드형으로 나열(식당 앱 포맷).
- 시각 요소는 보수적. 애니메이션·3D 없음.

### 리텐션·게이미피케이션
- **미션 클리어 → 코인 지급** 시스템. 매일의 운세 확인, 프로필 완성 등으로 코인을 모아 유료 상담에 사용. 다만 코인 자동 부여가 폐지되어 게이미피케이션은 약화 추세.
- 좋아하는 점술가를 "배신 리스트"에 등록하면 해당 시간에 푸시 알림. 팬덤형 리텐션.

### 사주500이 벤치마킹할 3 / 피해야 할 1
- 벤치마킹: ①첫 10분/첫 3분 무료 후크, ②상담사 카드형 프로필 UX, ③미션-코인-충전 루프.
- 피해야 할: 1분 과금 방식은 500원 단건·5000원 프리미엄 구조와 충돌. 상담 마켓플레이스로의 확장 유혹을 경계.

## 2. ココロニプロロ (Cocoloni PROLO) (일본)

### 카테고리·접근 방식
- **미디어 + 콘텐츠 포털**. 2012년 오픈한 "연애×점술 미디어"로 출발. 유명 점술가(鏡リュウジ·石井ゆかり 등) 칼럼과 점술 콘텐츠를 모은 웹 포털.
- 별도 그룹 브랜드 "cocoloni 占い館 Moon"은 11,000개 이상의 유료 감정 메뉴를 디지털 콘텐츠로 제공. 235명의 감수 점술가.
- AI 자동 풀이가 아니라 **유명 점술가 감수 대본을 알고리즘이 분기해 풀어주는 방식**. 정통보다는 "유명인 브랜드 점술" 포지셔닝.

### 가격·수익 모델
- 무료 점술 + 유료 감정 하이브리드. 유료는 건별 구매 또는 프라임 회원 구독.
- 프라임 회원: 라이트·스탠더드·프리미엄 3등급. 등급별 선택 메뉴 수·쿠폰 매수 차등.
- "유료 점술이 무제한 무료" 혜택이 구독 핵심 가치.

### 콘텐츠 철학
- 여성 타깃(연애·결혼·불륜 고민 중심). 톤은 친근한 에세이·칼럼 문체와 감수 점술가의 진지한 풀이 양립.
- 한자·전통 용어는 점술가 감수 메뉴 안에서 적절히 섞임. 현대화된 프레임 + 전통 용어 해설의 조합.
- 분량은 메뉴별 상이. 수천 자 장편 리딩부터 짧은 운세까지.

### UI·UX 포인트
- 잡지 스타일 레이아웃. 큰 썸네일 + 리드 카피 + 점술가 얼굴 사진. "연애 매거진을 넘기는" 감각.
- 점술가 브랜드별로 독립 세계관 UI. 별자리·수상·궁합 등 툴박스 정렬이 깔끔.

### 리텐션·게이미피케이션
- 이번 달의 개운 캘린더, 행운 번호·라키 아이템 월별 대기화면 다운로드 등 "매월 재방문 이유" 배치.
- 프라임 회원 한정 쿠폰으로 재결제 유도.

### 사주500이 벤치마킹할 3 / 피해야 할 1
- 벤치마킹: ①점술가 브랜드별 독립 세계관 UI, ②월 단위 개운 캘린더 + 대기화면 다운로드, ③"유료 무제한" 구독 가치 제안.
- 피해야 할: 11,000개의 메뉴 과잉 → 사주500은 "작은 카탈로그, 깊은 품질" 원칙을 지킬 것.

## 3. ゲッターズ飯田 公式 占い (일본)

### 카테고리·접근 방식
- **유명 점술가 1인 브랜드 앱**. 테레비에서 "연예계 최강"으로 소개된 이이다 개인의 독자 체계 "五星三心占い"를 전용 앱으로 제공.
- "오행(목·화·토·금·수) + 음양 = 10 × 三心(天·海·地) × 金銀 = 12 → 120타입"의 독자 분류. 중국 전통 오행에 기반하나 브랜드화·재네이밍됨.
- AI 자동 풀이. 상담사 연결 없음.

### 가격·수익 모델
- 부분 무료 + 프리미엄 월 구독 모델.
- **월 500엔 / 3개월 1,200엔 / 6개월 1,800엔**. 초회 2주 무료 트라이얼.
- 무료: 그날의 종합운 한 줄. 프리미엄: 연애운·일운·월간 운기 마크 일괄 확인·캘린더 앱 연동·개운 3가지.
- ※ 참고: 사주500 프리미엄 5000원 단건과 가격대가 유사(600~1,000엔 급). 단건 vs 월정액의 차이.

### 콘텐츠 철학
- 분량은 중편 중심. 톤은 친근한 일상어. 이이다 본인의 어투를 강하게 재현.
- 한자·전통 용어보다 "金의 시계" "銀의 시계" 등 브랜드 재명명 용어 사용. 현대화가 매우 강함.

### UI·UX 포인트
- **운기 그래프**와 **운기 캘린더**가 핵심 자산. "결단에 좋은 날" "쇼핑에 좋은 날" "새 시작에 좋은 날"을 아이콘으로 표시.
- 일 단위 마이크로 운세 → 월·년 장기 운세를 한 앱에서 연속 소비하게 설계.
- 착장 옷(기세가에) 기능. 개인화 꾸미기 요소.

### 리텐션·게이미피케이션
- **운기 캘린더가 리텐션 엔진**. 매일 캘린더 아이콘을 확인하러 앱을 열게 됨.
- 운기 그래프는 1년·3년 전망을 한 화면에 시각화해 앱 삭제 비용을 높임(장기 개인 데이터화).

### 사주500이 벤치마킹할 3 / 피해야 할 1
- 벤치마킹: ①운기 캘린더(개운일 아이콘), ②운기 그래프(1년 장기 시각화), ③브랜드 고유 명명법(도화살·천을귀인 그대로 쓰되 브랜드화).
- 피해야 할: 1인 점술가 브랜드 전면화 → 사주500은 브랜드 = "사주500" 그 자체로 가야 함. 특정 인물 얼굴에 묶이는 의존도 경계.

## 4. 测测 (Cece / Cylingo) (중국)

### 카테고리·접근 방식
- **AI 범심리 온라인 커뮤니티**. 2024년 6월 Cylingo Group으로 리브랜딩하며 "AI 팬심리(泛心理)"로 전환. 2025년 3월 기준 등록 사용자 4,600만, 그중 85%가 여성.
- 서양 점성술·MBTI·타로·팔자를 모두 취급하되, **"심리학의 탈을 쓴 점술"** 포지셔닝이 핵심. "과학과 신비의 다리" 자칭.
- AI 가상 상담사 + 2만 명 이상의 실제 인증 상담사 혼합. 3D 심리 사상판(모래상자) 기능.

### 가격·수익 모델
- **구독 + 건별 상담**. 월 멤버십 초회 9.9위안 → 월 25위안. 분기 58위안/월, 연 178위안/월.
- 30분 마스터 통화 60위안(≒1만원대 초반). 일반 치료 앱 대비 1/5 가격으로 "저렴한 심리 치료" 포지셔닝.
- 주간 타로·월간 별점 리포트 반복 구독 상품 판매.

### 콘텐츠 철학
- 분량은 심리테스트 50종 이상, 결과 리포트는 중편 분량의 전문용어 + 친근 해설 병용.
- 한자 전통 용어는 팔자·자미 메뉴에서만 제한적 사용. 메인 UX는 MBTI·별자리처럼 서양식 프레임.
- **감정 수용 중심 톤**. "AI 나무구멍(树洞)"이라는 별명처럼 들어주기·위로에 치중.

### UI·UX 포인트
- AI 아바타 캐릭터화. 채팅방 UI로 상담 진행.
- 3D 심리 사상판(모래상자)은 차별화 자산. 사용자가 오브젝트를 배치하면 전문가가 해석.
- MBTI 듀얼 분석(WeChat 친구 2인 대조), 친구 간 MBTI 분포도 등 소셜 그래프 연동.

### 리텐션·게이미피케이션
- 여성 85% 유저를 기반으로 "고백·토론·감정 공유" 커뮤니티 라이브(女性情感傾诉直播). 야간 리텐션 강점.
- 구독 회원에게 매일 심리 헬스 팁 푸시.

### 사주500이 벤치마킹할 3 / 피해야 할 1
- 벤치마킹: ①"심리 + 운세" 하이브리드 포지셔닝(AI 같지 않은 친밀감), ②결과 리포트에 친구 듀얼 비교 기능, ③감정 수용 중심의 라이팅 톤(위로 베이스).
- 피해야 할: 2만 인증 상담사 마켓플레이스화 → 사주500의 단건·프리미엄 구조에 부담. 커뮤니티 라이브는 별도 모더레이션 부담이 과대.

## 5. 哪吒运势 (Nezha Fortune) / 중국 팔자 앱 카테고리 (중국)

### 카테고리·접근 방식
- ※ "哪吒运势"라는 정확한 명칭의 앱은 공개 자료로 확인 불가. 본 섹션은 중국 八字(팔자) 카테고리의 대표 앱 3종(批八字算命, 八字排盘-算命大师, 易奇八字)을 묶어서 분석.
- 포지셔닝: **정통 명리(팔자·오행·대운·유년)의 대중화**. 생년월일시 기반 자동 배반 + AI/알고리즘 해설.
- 상담사 마켓플레이스가 아니라 **자동 생성형 리포트**가 주력.

### 가격·수익 모델
- **무료 배반 + 프리미엄 리포트 구매** 모델이 지배적.
- "황가(皇家) 리포트" "인연 주머니" "재운 리포트" "사업 리포트" 등 테마별 유료 상품. 수십 위안 단위.
- 일부 앱은 가상화폐(금콩·코인) 충전 후 VIP·유료 전문 칼럼·강의 구매 구조.

### 콘텐츠 철학
- 한자·전통 용어 전면 노출. 十神·大运·流年·神煞·五行旺衰 등 술어를 그대로 쓰고 용어집으로 보완.
- 분량은 장편. 유료 리포트 1건당 수만 자가 흔함. "두꺼운 책 한 권" 감각.
- 톤은 격식체·권위형. 사주500 브랜드 보이스(격식체 두텁게)와 정확히 맞닿음.

### UI·UX 포인트
- 팔자 배반표를 메인으로 크게 배치. 연주·월주·일주·시주의 4개 기둥 + 天干·地支·藏干·十神 표가 화면 최상단.
- 대운·유년 테이블은 가로 스크롤 긴 표. 전통식 포맷을 거의 그대로 재현.
- 시각화 부족(표 위주). 젊은 층에게는 진입장벽.

### 리텐션·게이미피케이션
- 매일 운세 알림, 매일 签到(체크인) 포인트 → 포인트 몰에서 유료 리포트 할인 교환.
- 주공해몽·성명 오행·혼인 궁합 등 보조 툴로 재방문 명분 창출.

### 사주500이 벤치마킹할 3 / 피해야 할 1
- 벤치마킹: ①테마별 프리미엄 리포트 카탈로그(재운·인연·사업), ②격식체·권위형 라이팅, ③签到-포인트-할인 루프.
- 피해야 할: 한자·전통 용어 전면 노출은 사주500 이원화 원칙(유저 출력물은 쉬운 풀이)과 충돌. "지식 깊이는 참고서에, 유저 화면은 쉬운 풀이"를 고수할 것.

## 6. 文墨天机 紫微斗数 (ZWDS, 중국)
