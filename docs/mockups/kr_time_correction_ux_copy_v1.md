# KR 시간 보정 UX 카피 v1

**배경:** 한국 출생 시간은 역사적 시간대 변경(1954·1961·1988 KST/KDT 이력)으로 ±30분 보정이 필요할 수 있음. 홍성민 지적 반영.
**원칙:** 유저가 "내가 잘못 알았나?" 불안해지지 않게. 시스템이 알아서 처리한다는 신뢰감.
**위치:** 시간 입력 폼, "시간 모름" 모달, 결과 페이지 안내 배너, 재계산 토스트 4지점.

---

## 1. 시간 입력란 — 마이크로카피 (하단 고정)

**위치:** 출생 시간 선택 드롭다운 바로 아래. 회색 작은 글자.

```
한국 출생 시간은 1908~1961년 사이 시간대 이력이 있어요.
시각을 정확히 모르면 30분 단위로 근사 입력해도 괜찮아요.
우리가 자동으로 유력한 시주(時柱)를 계산합니다.
```

**UI 참고:**
- 폰트: `text-xs text-gray-500`
- 줄바꿈: 3줄 유지 (모바일에서 끊김 방지)
- 아이콘: 왼쪽 ⓘ 16px

---

## 2. "시간 모름" 옵션 — 모달

**트리거:** 드롭다운에 "시간 모름" 옵션 선택 시.

### 모달 제목
> 시간을 모르면 어떻게 되나요?

### 본문
```
사주는 4개의 기둥(年 · 月 · 日 · 時)으로 구성돼요.

시간을 모르면 시주(時柱) 한 개만 계산에서 빠지고,
나머지 연·월·일 3개 기둥의 해석은 정상 작동합니다.

단, 일간 상세·재물 세부·궁합 일부는 덜 정밀해져요.
```

### 선택지 (라디오 3개)

**① "대략만 기억해요" (권장)**
> 새벽/아침/점심/오후/저녁/밤 중 하나 선택.
> 범위 내 최유력 시주를 자동 계산합니다.

**② "1~2시간 오차 안에서 추정해요"**
> 예상 시간대를 시작과 끝으로 입력.
> 범위 안에서 가장 유력한 시주를 계산합니다.

**③ "전혀 기억 안 나요"**
> 시주 제외, 3개 기둥으로 해석합니다.
> 전체 해석 품질의 75% 선에서 진행됩니다.

### CTA 버튼
- `이 옵션으로 보기` (primary)
- `시간 다시 입력하기` (secondary)

---

## 3. 결과 페이지 — 보정 안내 배너

**위치:** 결과 최상단 또는 "시주" 섹션 진입 직전.
**노출 조건:** 입력 시각이 KST 기준 00:00~00:59 구간 또는 23:00~23:59 구간일 때만 (시간대 혼동 위험 구간).

```
ⓘ 입력하신 시간이 한국 표준시 자정 전후에 있어요.
과거 시간대 이력을 반영해 시주를 다시 계산할 수 있습니다.
```

### 버튼
- `정확한 시주로 재계산` (primary, 한 번만 노출)
- `이대로 보기` (secondary)

### 토스트 (버튼 클릭 후)
```
한국 시간대 이력을 반영해 시주를 다시 계산했어요.
(±30분 범위 탐색 완료)
```

---

## 4. 시간대 보정 결과 표기 — 결과 내부

**위치:** 시주(時柱) 섹션 헤더 옆 작은 뱃지.

### 패턴 A — 자동 보정 적용됨
```
[뱃지] 한국 시간대 보정 적용
```
**툴팁:** "입력하신 시각(HH:MM KST)을 기준으로 역사적 시간대 변경을 반영해 계산했습니다."

### 패턴 B — 사용자 재계산 요청
```
[뱃지] 재계산됨 · ±30분 탐색
```
**툴팁:** "요청에 따라 ±30분 범위를 탐색해 가장 유력한 시주를 적용했습니다."

### 패턴 C — 시주 제외 케이스 ("전혀 기억 안 나요" 선택)
```
[뱃지] 시주 제외
```
**툴팁:** "시간 정보가 없어 시주는 해석에서 제외됐습니다. 연·월·일 기둥 기준으로 분석했습니다."

## 5. 에러·예외 카피

### 5-1. 보정 탐색 실패
```
한국 시간대 이력에서 유력한 시주를 찾지 못했어요.
입력하신 시각 그대로 계산해 드립니다.
```

### 5-2. 시간 입력 범위 초과
```
시간은 00:00부터 23:59까지 입력해 주세요.
```

### 5-3. 년도가 1908년 이전인 경우 (드문 케이스)
```
1908년 이전 출생은 한국 표준시 이력 기록이 제한적이에요.
입력 시각 그대로 계산하되, 시주 해석은 참고용으로 봐 주세요.
```

## 6. 퀄리티 체크리스트

- [ ] 모든 카피가 "한자 풀이" 원칙 준수 (시주·時柱 같은 한자는 괄호 안 또는 풀이 동반)
- [ ] 면피체 0건 ("~할 수 있습니다" 등)
- [ ] 사용자가 자기 잘못이라고 느끼게 하는 표현 0건
- [ ] 시스템 행동이 능동태로 명확 ("우리가 계산합니다", "재계산했어요")
- [ ] 선택지는 항상 기본값 + 대안 제시 (혼자 덩그러니 에러 노출 금지)

## 7. QA 테스트 케이스 (개발 연계)

**TC-KR-01:** 입력 시각 00:15 KST → 보정 안내 배너 노출 확인.
**TC-KR-02:** "시간 모름" → "대략만 기억해요" 선택 → 새벽~밤 6구간 중 1개 선택 가능.
**TC-KR-03:** 1954년 이전 출생 + 시각 23:30 → 시간대 이력 반영 로직 발동 확인.
**TC-KR-04:** 1988년 KDT(서머타임) 적용 기간 출생 → 자동 보정 뱃지 노출.
**TC-KR-05:** 입력 시각 13:00 → 보정 안내 배너 노출 안 됨 (혼동 위험 구간 밖).
**TC-KR-06:** "전혀 기억 안 나요" → 시주 제외 뱃지 + 75% 품질 안내.

→ 이 6개는 홍성민 지적 "TC 추가 필수" 대응 시작점. 추가 케이스는 QA 세션에서 확장.

---

## 8. 남은 결정 (준기 확인 필요)

1. **75% 품질 숫자 — 실측 기반인가, 임의인가?**
   - 임의면 "상당 부분"으로 바꿀지, 실측 잡아둘지 결정.
2. **"대략만 기억해요" 6구간 경계 시각 확정**
   - 예: 새벽 03~05 / 아침 05~09 / 점심 11~13 / ...
3. **재계산 버튼 노출 조건 구체화**
   - "1회만" 노출인지 항시 노출인지. 1회 권장 (UX 노이즈 방지).
