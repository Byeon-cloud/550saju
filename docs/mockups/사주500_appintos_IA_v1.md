## 4. 보관함 (`/storage`)

### 4-1. 사주팔자 정보 (프로필 카드)
- **있을 때**: 카드 노출 + 클릭 시 사주분석 풀이 결과 페이지로 이동
- **있을 때**: "새 숫자(사주) 입력하기" 버튼 → 사주분석 페이지 이동
- **없을 때**: "사주팔자 입력하기" CTA → 사주분석 페이지 이동
- **버그**: 현재 사주팔자 정보 카드 **삭제 불가** → 삭제 UX 추가 (스와이프 + 휴지통 아이콘 둘 다 지원)
- **데이터 정책**: 이용기록과 별도. 사주 정보 삭제해도 이용기록 유지. 이용기록 모두 지워도 사주 정보 유지.

### 4-2. 상세분석 받기 → "프리미엄 종합 사주 분석"으로 이름 변경
- 클릭 시 분기:
  - 10운 있음 → 확인 모달 ("10운 차감하고 종합사주 보시겠어요?") → 확인 → 로딩 → 프리미엄 종합사주 결과
  - 10운 없음 → "운이 부족해요" 안내 → 운 충전 페이지로 이동

### 4-3. 이용기록
- 각 항목 클릭 → 해당 콘텐츠 결과 페이지로 이동
- **없을 때**: "기록이 없어요" + "사주 분석하기" CTA → 해당 콘텐츠 풀이 페이지 (누구의 사주를 볼지 선택 페이지)
- **버그**: 이용기록 모두 삭제 시 연결된 사주팔자 정보가 자동으로 사라짐 → cascade delete 제거 필요
- **버그**: 이용기록 다 지운 뒤 "첫 사주 입력하기" 클릭하면 이전 입력 데이터가 그대로 남아있음 → 데이터 진짜 삭제 검증 필요

### 4-4. 저장 (스크린샷)
- 페이지 스크린샷
- **단**: 하단 캐러셀/바텀바 제외, "정보"만 캡처

### 4-5. 친구에게 공유하고 1운 받기
- 위 운 충전 페이지의 공유 리워드와 동일 (ID: `a56725a6-...`)

## 7. 홈 (`/`) — 전면 리뉴얼 필요

### 7-1. 현재 상태 (준기 평가)
> "지금 배치 구조가 너무 매력이 떨어지는 구조야. 이대로 가면 CTA 겁나 떨어질 거 같아. 각각의 콘텐츠가 너무 근본 없고 매력 없이 생겼어. 어떤 콘텐츠가 메인인지 강약 조절도 안 되어 있고."

**문제점:**
- 강약 조절 부재 (모든 섹션이 동일 가중치)
- 각 콘텐츠 카드가 매력 없음 ("근본 없음")
- 어떤 게 메인 콘텐츠인지 시각적으로 안 보임

### 7-2. 후기 캐러셀 (즉시 적용 필요)
- 총 **16개** 후기
- 분포: 여 13 + 남 3
- 남성 = 40·50·60대 (20·30대 남자 후기 X)
- 여성 = 20·30·40·50·60대 분포
- **이름 제거** — "20대 여성"·"50대 여성"·"40대 남성" 식 표기만
- 캐러셀 = 우→좌 자동 흐름
- 카피 톤 예시: "한 달에 한 번 사주 봐서 5만 원 쓰는데, 이거 시작하고 돈 아끼는 기분이에요"
- 주작 느낌 안 나게 자연스러운 어투
- 가격 직접 언급 금지 ("돈 아끼는 기분"·"가성비"까지만 OK)

### 7-3. 버그
- 홈에서 "주제별 심층 500원 풀이" 클릭하면 잘못된 곳으로 이동 → 라우트 오류 확인 필요

### 7-4. 듀얼 메인 전략 (Q1 결정 반영)

**Pillar (메인 대형 카드)** — 사용자 인지 메인:
- 오늘의 운세 (무료)
- 사주 연계 꿈해몽 (무료)

**Body (중형 카드)** — 비즈니스 메인:
- 프리미엄 종합 사주 분석 (10운) — 자연스럽게 노출하되 대문짝 X
- 주제별 심층 분석 (1운)

**Caption (소형 카드)**:
- 대운·월운·궁합·토정비결 (섹션 4.5 기존 5개)

**홈 가격 표기 (Q3 결정 반영)**:
- 콘텐츠 카드에 금액(원) 절대 노출 X — "1운"·"10운"만
- "1운 = 500원" 환산은 **운 충전 페이지 한 곳에서만**
