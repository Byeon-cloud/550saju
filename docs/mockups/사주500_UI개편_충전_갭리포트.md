## 2. 항목별 상세

### 2-1. 🔴 "내 사주 풀이" 비용 = 10운 (프리미엄)

**현재**: "내 사주 풀이 1운"으로 안내.
**스펙**: 프리미엄 풀이는 10운. 1운은 "주제별"(재물·연애·건강 등 개별 주제) 한 건.
**왜 치명적**:
- 유저가 "1운이면 내 사주 풀이 된다"로 오인 → 실제 진입 시 10운 paywall 등장 → 신뢰 붕괴.
- 패키지 설명 "프리미엄 1번 가능해요"(10운 카드)와 직접 충돌.

**수정안**:
```
내 사주 풀이 — 10운 / 1회 (프리미엄 종합 리포트)
주제별 풀이 — 1운 / 1회 (재물·연애·건강·직장 등)
사주 상담   — 1운 = 3회 (대화 크레딧 3개)
대운        — 1운 / 1회
월별        — 1운 / 1회
궁합        — 1운 / 1회
```

PC 참고 상수: `PAID_CONTENT_COSTS` / `UN_TO_CHAT_TICKETS = 3`

### 2-3. 🟡 HeroBar에 "1운 = 500원" 명시

**현재**: 누락.
**스펙**: HeroBar 104px 영역에 반드시 표기.
```
H2 "운으로 사주를 봐요"
Body "1운 = 500원으로 충전돼요"
Caption "콘텐츠는 모두 운 단위로 보여드려요"
```
**왜 필요**:
- 사주500 전체 UI에서 **원화 표기가 허용되는 유일한 투명 지점**이라는 선언. 이 페이지 외엔 전부 "운" 단위만 노출.
- PC에게도 `grep -rn "원\|₩\|KRW" src/pages/ --exclude-dir=charge` 검수 기준이 됨.

### 2-4. 🟡 패키지 4종 → 5종 (확정 스펙)

| id | 운 | 결제액 | 보너스 | 라벨 | 유도 문구 |
|----|---|----|----|----|----|
| p1 | 1운 | 500원 | - | - | 주제 하나 가볍게 |
| p5 | 5운 | 2,500원 | - | - | 주제별 5번 해볼 수 있어요 |
| p10 | 10운 | 5,000원 | - | **가장 인기** | 프리미엄 1번 가능해요 |

**현재**: "한 번만 / 좀 더 보자 / 제대로 보자 / 올해 다 보자" 4종 감성 라벨.
**결정 근거**: 스펙이 더 최신·확정본. 감성 라벨은 유지하고 싶은 요소가 있으면 `guide` 필드에 흡수 가능하지만 **라벨 위치(상단)는 "가장 인기 / 최대 혜택" 두 개만 허용**.
