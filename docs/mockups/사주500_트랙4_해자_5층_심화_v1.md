## 0. 해자 원칙 (재확인)

- **원칙 1.** Aha는 무료에서 터져야 한다. 차별화 모멘트가 무료에 있어야 해자가 된다.
- **원칙 2.** AI 비용은 변명이 안 된다. CAC 2,000~5,000원 대비 무료 꿈해몽 30~50원은 허용 범위다.
- **원칙 3.** 해자는 단일 기능이 아니라 **5층의 상호강화 구조**일 때만 복제 난이도가 올라간다.
- **원칙 4.** 복제 난이도가 "쉬움"인 층은 해자가 아니다. 그 자리는 **가격·속도·브랜드 중 하나로 덮는다.**

## 1. 5층 구조 요약표

| # | 층 | 정의 한 줄 | 현 상태 | 복제 난이도 | 강화 우선순위 |
|---|---|---|---|---|---|
| 1 | 데이터 해자 | 유저 사주·꿈·선호 기록의 누적 | 약 (런칭 전) | 쉬움 → 중 | 중기 |
| 2 | 지식 해자 | 6대 원전 + 신살 고유명사 RAG | 중 (프롬프트 단계) | 중 | **최상위** |
| 3 | UX 해자 | ±30분 보정 + 한자 이원화 + 듀얼 톤 | 중-상 | 중-어려움 | 상위 |
| 4 | 가격 해자 | 500원 1티어 심리적 진입점 | 상 | 쉬움(복제) → 어려움(지속) | 상위 |
| 5 | 브랜드 해자 | 신살 고유명사 · 브랜드 골드 · 격식체 | 약-중 | 어려움 | 중기 |

**주석:**
- "복제 난이도 쉬움 → 중"의 의미: 기능 자체 복제는 쉽지만 "누적되면" 중간 난이도가 된다. 시간 해자다.
- 지식 해자를 "최상위"로 올린 이유: RAG만 제대로 꽂혀도 무료 Aha가 차별화되고, 이는 원칙 1을 직접 충족한다.

## 2. 1층 — 데이터 해자

### 정의
유저가 **반복 방문할수록** 사주500에만 쌓이는 데이터. 경쟁사가 훔칠 수 없는 **시간의 함수**.

### 지표
- 사주 등록 수 (본인 + 가족 + 지인)
- 꿈해몽 이력 (월별 누적 건수, 평균 length)
- 오늘의 운세 연속 방문일수 (streak)
- 주제별 심층 구매 이력 (취향 프로파일링)
- 대화 턴 수 (사주 대화 기능)

### 현재 상태 (2026-04-21)
- 런칭 전. 실데이터 0.
- Firestore 스키마는 [보관함 데이터 분리](project_storage_data_model.md)에 따라 **사주 정보 vs 이용기록 별도 테이블** 확정.
- cascade delete 금지 원칙으로 이용기록 보존.

### 복제 난이도
**쉬움 → (누적되면) 중.** 기능 단위로는 어느 앱이든 동일 구조 복제 가능. 하지만 유저가 3개월~1년간 꿈·운세·질문을 쌓은 뒤에는 **"이걸 다시 처음부터 옮기기 싫다"**가 발생한다. = 심리적 잠금(switching cost).

### 강화 액션
1. **가족 사주 저장** — 1개 계정에 본인 + 배우자/부모/자녀 사주 저장. 가족 운세 비교 리포트 유료 옵션으로 확장. (점신·포스텔러 대비 우위 가능.)
2. **대운 timeline 트래킹** — 10년 주기 대운·연운이 "내 인생 타임라인"으로 축적. 과거 기록까지 소급해 보여주면 이탈 방지.
3. **꿈 일기 아카이브** — 월별·연도별 검색 가능. "내가 3년 전에 꾼 뱀 꿈" 다시 찾을 수 있게. 유저가 데이터를 **자기 자산**으로 인식하는 순간 해자가 된다.
4. **취향 프로파일링** — 주제별 심층(재물·사랑·건강·이직·학업 등) 구매 이력으로 푸시 추천. 재방문 CTA 개인화.

### 측정 지표 (KPI)
- D30 보관함 1건 이상 저장 유저 비율 ≥ 40%
- D90 streak 3일 이상 유지 유저 비율 ≥ 15%
- 가족 사주 평균 저장 수 (런칭 6개월 후) ≥ 1.3건/유저

### 락인(Lock-in) 효과
- 고->저: 대운 timeline > 가족 사주 > 꿈 일기 > 취향 프로파일
- "앱 삭제 시 3년치 꿈 기록이 사라진다"는 심리가 가장 강력.

### 리스크
- **개인정보 누적 = 보안 리스크.** 런칭 시점부터 암호화 · 최소수집 원칙 · 삭제 플로우 설계.
- [보관함 데이터 분리](project_storage_data_model.md) 원칙 재확인: 사주 정보와 이용기록을 분리 저장해야 GDPR·개인정보보호법 대응 유연.

## 3. 2층 — 지식 해자 ★ 최상위

### 정의
"AI 꿈해몽 + 6대 원전 명리 연계"는 **사주500 유일 모트**. 경쟁사는 대부분 GPT/Gemini 프롬프트에 "명리 기본"만 넣어 쓰는 수준. 사주500은 원전 인용 + 신살 고유명사를 체계적으로 동원한다.

### 6대 원전 (RAG 기반 지식)
1. 『적천수(滴天髓)』 — 명리 논리의 뼈대
2. 『궁통보감(窮通寶鑑)』 — 월별 조후(調候) 판단
3. 『자평진전(子平眞詮)』 — 격국(格局) 체계
4. 『연해자평(淵海子評)』 — 실전 간명 사례
5. 『삼명통회(三命通會)』 — 신살·대운 해석
6. 『명리정종(命理正宗)』 — 근대 정리된 종합본

### 브랜드 자산 용어 (유저 출력물에 남길 것)
- **신살:** 도화살·화개살·역마살·천을귀인·공망·귀문관살
- **십신:** 비견·겁재·식신·상관·편재·정재·편관·정관·편인·정인
- **오행·천간·지지:** 본체는 한자 아이콘 + 풀이는 한글

[feedback_shinsal_terms.md](feedback_shinsal_terms.md) 근거: "도화살·화개살·역마살·천을귀인·공망은 브랜드 자산, 금지어 아님."

### 현재 상태
- **중.** 프롬프트 v3 단계에서 원전 인용 포맷 확정. 실제 RAG(벡터 DB 조회)는 미구현.
- 원전 텍스트 JSON 형태로 가공 시 토큰 ~300K. prompt caching (`cache_control: ephemeral`)로 입력 토큰 -90% 가능 → Opus 마진 3원 → 30~50원 회복 [project_loading_ux_strategy.md 참조].

### 복제 난이도
**중.** 원전 텍스트 자체는 공개 도메인. 하지만 **어느 원전을 언제 인용할지**의 결정 로직과 프롬프트 엔지니어링은 암묵지. 경쟁사가 따라잡는 데 최소 6개월.

### 강화 액션
1. **원전 RAG 구축** — 6대 원전 한글 번역본을 청크화 → 벡터 DB 인덱싱 → 질의 시점에 top-k 인용. 프리미엄 10운·꿈해몽 심층에서 원전 각주로 노출 (학술적 신뢰도).
2. **신살 사전 UX** — 신살 고유명사 hover/tap 시 1~2문장 정의 툴팁. 유저는 "도화살이 뭔지 여기서 처음 제대로 배웠다"고 느낀다.
3. **AI 같지 않은 해석 풀(pool)** — 모범 해석 50~100개 시드를 분야별로 확보. 신규 생성물의 품질 하한 유지.
4. **꿈 상징 DB** — 주공해몽 + 한국 민속 + 심리학 3축 매트릭스. 경쟁사(점신·測測·LINE占い)는 단일 축. [feedback_dream_visualization.md 참조로 SVG 50~100개 시각 라이브러리와 연동]

### 측정 지표
- 프리미엄 콘텐츠 내 원전 인용 평균 ≥ 2.5건/리포트
- 신살 용어 정확 해석율 (자체 샘플 감사) ≥ 95%
- "이 앱이 진짜 사주를 아는 것 같다" 설문 긍정 응답율 ≥ 70% (런칭 후 2주)

### 락인 효과
- 유저가 "정인이 강해서..."를 일상 대화에서 쓰기 시작하면 **언어 습관 = 락인**.
- 원전 인용에 익숙해진 유저는 타 앱의 밋밋한 풀이로 돌아가지 못한다.

### 리스크
- 원전 해석 오류 = 브랜드 치명타. **콘텐츠 심사 루브릭(문서 12)으로 출시 전 15건 전수 감사.**

## 4. 3층 — UX 해자

### 정의
**±30분 진태양시 보정 + 한자 이원화 + 듀얼 톤(격식체+친근체) + 3티어 로딩 UX**. 단일 기능이 아니라 UX 원칙의 복합체.

### 구성 요소

**(a) ±30분 진태양시 보정** [project_kr_saju_time_correction.md]
- 한국 경도(126.97°E)와 표준시(135°E) 기준 약 -32분 차이.
- 경쟁사 중 진태양시 보정을 **UX 카피로 설명하는 앱은 거의 없음** (트랙 1 리서치 확인: 만세력 천을귀인은 기능은 있으나 UX 설명 약함).
- 사주500 UX 카피 v1에서 입력 단계에 "정확한 사주는 ±30분 진태양시 보정이 필요합니다" 명시.

**(b) 한자 이원화** [feedback_hanja_ux_principle.md]
- 유저 출력물 본문: 쉬운 한글 풀이 + 한자는 **상징·프레임으로 살짝**.
- 참고서·지식 모듈: 한자 풍부 OK.
- 한국 3사 공통은 "한자 안 씀"이지만 사주500은 **한자를 디자인 요소로** 재활용. 트랙 1 UI 문법 8가지 중 "한자 안 씀" 원칙을 창의적으로 비틈.

**(c) 듀얼 톤(격식체 + 친근체)** [feedback_brand_voice_tone.md]
- 격식체 50% 이상 + 친근체 30~40% 보조. 프리미엄일수록 격식체 ↑.
- 트랙 2 인사이트: LINE占い는 AI 말투 압도적, ゲッターズ飯田는 인물 특유 구어체. 사주500은 **둘의 중간에 의도적으로 포지셔닝**.

**(d) 3티어 로딩 UX** [project_loading_ux_strategy.md]
- Tier A(0~3s) 스켈레톤 · Tier B(3~10s) 섹션 스트리밍 · Tier C(10~60s) 풀스크린 5층 한자 + 50개 로테이션 문구.
- 무료 앱 중 "기다림을 콘텐츠로" 만든 곳은 없음 → 명확한 UX 차별.

### 현재 상태
**중-상.** (a)(b)(c)는 목업 및 스펙 문서 확정. (d)는 D-1 PC 인계 작업 4건 남음.

### 복제 난이도
**중-어려움.** 각 요소는 복제 가능하지만 **4개가 동시에 맞물려 돌아가는 UX 철학**은 브랜드 거버넌스가 흔들리면 무너진다. = 운영 해자.

### 강화 액션
1. **±30분 보정 교육 유튜브 쇼츠 2~3개** — 런칭 직후 Threads/X 공유 (무료 마케팅). 차별화 포인트를 **유저가 친구에게 설명할 수 있게** 만든다.
2. **한자 토글** — 유료 리포트 상단에 "한자 강조 보기" 토글. 전문가형·초보자형 유저 동시 만족.
3. **브랜드 보이스 가드레일** — 콘텐츠 심사 루브릭 ①톤 축 + 금지어 사전. 운영자·Claude가 매주 10건 스폿체크.
4. **로딩 UX 50개 문구 매 분기 업데이트** — 계절·명절·운기에 맞춘 문구로 매번 새로 보이게. 재방문 유저가 로딩 화면 스크린샷을 SNS에 올리는 단계까지.

### 측정 지표
- 첫 사주 입력 완료율 ≥ 80% (±30분 보정이 이탈 요인이 되지 않았다는 증거)
- 브랜드 보이스 루브릭 ①톤 축 평균 ≥ 1.7/2
- 로딩 중 이탈률 < 5%
- "UI가 예쁘다/고급스럽다" 자유 응답 비율 ≥ 30%

### 락인 효과
- UX 일관성에 익숙해진 유저는 "다른 앱은 어수선하다"를 체감한다.
- **브랜드 팔레트 #B8965A 골드 + Noto Serif + Pretendard 조합은 이미 시각적 자산**.

### 리스크
- 1인 오너 운영 → UX 가드레일이 느슨해지기 쉬움. 루브릭·체크리스트로 **속도 대신 표준화**.

## 5. 4층 — 가격 해자

### 정의
**500원 1티어**는 심리적 마찰을 최소화하는 진입점. 커피 1/4잔 가격. 결제 저항이 거의 없다. 무료 Aha에서 유료로 넘어가는 **가장 낮은 허들**.

### 상품 구조 [project_pricing_v3.1.md]
| 티어 | 가격 | 내용 | 마진 |
|---|---|---|---|
| 무료 | 0원 | 오늘의 운세 · 꿈해몽 (1일 1회) | 광고 + 업셀 유도 |
| 500원 | 1운 | 주제별 심층 · 꿈해몽 심층 | Opus 3원 ~ Sonnet 345원 |
| 5000원 | 10운 | 10운 종합 리포트 + PDF | 유지 마진 |
| 공유 리워드 | +3운/일 | 앱인토스 공유로 3회/일 획득 | 0원 (마케팅 비용) |

### 현재 상태
**상.** 상품 구조 확정. UI는 원화 금액 노출 금지, "운" 단위로만 표기 [project_pricing_hide_amount.md].

### 복제 난이도
**쉬움(복제) → 어려움(지속).** 가격 자체는 경쟁사가 즉시 따라할 수 있다. 하지만 500원 마진으로 Opus를 돌리려면 **prompt caching + 1인 운영 + 광고 매출 보강**이 모두 필요. 3개월 버티다 대부분 포기한다.

### 강화 액션
1. **운 단위 UI 정착** — "3,000원 충전" 대신 "6운 충전". 유저 인식 단위를 내부 단위(운)로 이동. 가격 비교를 어렵게 만든다.
2. **공유 리워드 루프** — 앱인토스 공유 1회 = 1운(1일 3회). 이 구조가 CAC를 내부화한다. 외부 광고비 없이 친구→친구 전파.
3. **블러잠금 티저 연속성** [feedback_lock_teaser_continuity.md] — 무료에서 본 티저가 유료 결제 후에도 이어져야. 잠금 해제가 **연속된 한 편의 글**이 될 때 결제 저항이 사라진다.
4. **월 정액 플랜 실험** (선택) — 19,900원/월 무제한. 헤비 유저만 대상. 트랙 2 LINE占い 관찰에 따라 구독 유지율이 단건보다 높음.

### 측정 지표
- 무료 → 500원 전환율 ≥ 3%
- 500원 → 5000원 업셀율 ≥ 15%
- 공유 리워드로 받은 운 사용률 ≥ 60%
- 결제 이탈 포인트(충전 페이지) 이탈률 < 40%

### 락인 효과
- "운"이라는 내부 화폐에 익숙해지면 타 앱 원화 비교가 귀찮다.
- 충전 잔액 보유 유저는 자연스럽게 재방문.

### 리스크
- **경쟁사가 500원 카피 시 실제 해자는 지식+UX**에 달려 있다. 가격은 **유인이지 해자의 본체가 아니다.**

## 6. 5층 — 브랜드 해자

### 정의
**신살 고유명사 자산화 + 브랜드 골드(#B8965A) + 격식체 보이스**. 경쟁사가 같은 톤·색·용어를 쓰려 해도 **이미 사주500이 선점**되어 있는 상태를 만드는 것.

### 브랜드 자산

**(a) 용어 자산**
- 신살(도화살·화개살·역마살·천을귀인·공망·귀문관살) · 십신 10개.
- 유저가 일상 대화에서 "내 천을귀인이" 같은 표현을 쓰면 = 브랜드화 완성.

**(b) 시각 자산**
- **브랜드 골드 #B8965A + 베이지 브라운.** 머스타드 #b8941f는 전 페이지 0건 원칙 [project_brand_palette.md].
- **Noto Serif KR 900 + Pretendard Variable.** 명조체 안 쓰는 한국 UI 공통 문법을 **"프리미엄 키워드에만 명조"**로 뒤집음.
- **한자 카드 + 운(運) 로딩 한자 5층 레이어** — 고유한 로딩 경험.

**(c) 언어 자산**
- 격식체 두텁게 + 친근체 보조. AI같지 않은 UX 카피.
- 카피북 8장 금지어 사전 유지.

### 현재 상태
**약-중.** 자산은 정의됐으나 **인지도 0**. 런칭 후 3~6개월 누적 필요.

### 복제 난이도
**어려움.** 시각·언어 자산은 상표·저작권으로 얕게 보호되지만, **유저 인지 선점**은 시간 해자다. 경쟁사가 똑같은 골드톤을 써도 "사주500 느낌"이라는 인상은 못 만든다.

### 강화 액션
1. **신살 사전 콘텐츠 시리즈** — Threads/X에 주 2회 "도화살이 뭐예요?" 같은 카드 뉴스. 검색 유입 + 브랜드 각인. [project_marketing_channels.md]
2. **후기 캐러셀** [feedback_home_reviews_style.md] — 홈 16개, 이름 제거, 연령/성별만. 자연 어투. 유저 증언 자체가 브랜드.
3. **퀄리티 바 유지** [feedback_pre_launch_quality_bar.md] — AI같지 않은 디자인·UX 라이팅·섹션 리듬·지식 기반. 어느 한 축도 깨지면 브랜드 누수.
4. **브랜드 이름 `사주500`의 숫자 기억성 극대화** — "500원에 운명을 본다"의 내러티브. 랜딩·앱인토스 카피 1줄에 고정.

### 측정 지표
- 브랜드명 검색량 (Google Trends, 네이버 검색) 월간 성장율 ≥ 15%
- Threads/X 브랜드 언급 월 ≥ 50건 (런칭 3개월 후)
- 후기 자연유입(앱스토어 평점 포함) 월 ≥ 100건 (런칭 6개월 후)
- 신살 관련 콘텐츠 공유 수 ≥ 1,000건/월

### 락인 효과
- 브랜드 해자는 **다른 4층의 결과물**이지 원인이 아니다. 1~4층이 탄탄해야 브랜드가 선다.
- 역으로, 브랜드가 서면 1~4층의 약점을 일부 덮어준다.

### 리스크
- **속도 < 퀄리티 원칙** 반대로 가면 브랜드 누수 즉발. 내부 모니터링 주간 리뷰.

## 7. Cross-layer 시너지

| 조합 | 시너지 내용 |
|---|---|
| 1 × 2 | 누적 사주·꿈 데이터 + 원전 RAG = 개인화 해석의 정확도 복리 |
| 2 × 3 | 원전 인용 + 한자 이원화 = 지식의 시각적 전달 |
| 2 × 5 | 신살 고유명사 = 브랜드 용어 자산 (지식이 브랜드가 되는 접점) |
| 3 × 4 | 3티어 로딩 + 500원 = 체감 속도 해소하며 저가 진입 유지 |
| 3 × 5 | 듀얼 톤 + 브랜드 보이스 = 카피가 그대로 자산 |
| 1 × 4 | 보관함 데이터 누적 + 운 화폐 = 잔액·기록 둘 다 이탈 마찰 |
| 4 × 5 | 500원 진입 + 사주500이라는 이름 = 상품·브랜드 일치 |

### 시너지 매트릭스 인사이트

가장 강력한 페어는 **2 × 3 (지식 × UX)**. 원전 인용을 한자 이원화로 보여주면 "AI같지 않은 전문성"이 체감된다 → 이것이 바로 **원칙 1 "Aha는 무료에서 터져야 한다"의 구현체**.

가장 약한 페어는 **1 × 5 (데이터 × 브랜드)**. 런칭 초 데이터가 없어서 브랜드 서사를 데이터로 뒷받침할 수 없다. 6개월 후에야 "1,000명의 사주를 해석한 AI"식 서사 구사 가능.

## 8. 취약점 · 약한 고리

### 약한 고리 3개
1. **데이터 해자(1층)** — 런칭 전 0. 경쟁사 점신(수년 누적)에 비해 명백 열위.
2. **브랜드 해자(5층)** — 인지도 0. 런칭 후 6개월 버퍼 필요.
3. **가격 해자(4층)의 마진** — Opus 마진 3원은 위태. [project_unit_economics_pending.md] A/B 실측 필수.

### 대응책
- **1층 약점**은 **2층(지식) + 3층(UX)으로 상쇄.** 유저가 첫 1분 안에 Aha를 느끼면 데이터 누적 단계로 진입.
- **5층 약점**은 **3층(UX) + 4층(가격)으로 상쇄.** 카피·팔레트·500원 진입점 3개가 입소문을 만든다.
- **4층 마진 리스크**는 **prompt caching + Sonnet 다운그레이드 옵션(대안 B)** 확정 플랜 유지. A/B 실측 후 결정.

## 10. 결론 · 1인 오너 행동 지침

1. **당장 6주(런칭 전 + 런칭 후 2주):** 2층(지식)과 3층(UX)의 완성도에 시간의 80% 투입. 1층·5층은 자연 누적.
2. **런칭 후 1~3개월:** 데이터 누적 지표 주간 트래킹. 4층 마진 실측.
3. **런칭 후 3~6개월:** 원전 RAG 정식 · 신살 사전 정식 · 가족 사주·대운 timeline 런칭.
4. **런칭 후 6~12개월:** 브랜드 자산 SNS 외부화. 후기·언급·검색량 세 지표 동시 관찰.

**핵심 전제:** "해자는 한 번에 완성되지 않는다. 5층 중 2~3개에 집중하면 나머지는 따라온다. 지금 가장 중요한 2개는 **지식(2층) + UX(3층)**."
