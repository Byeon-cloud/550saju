## 1. 대운흐름 `/daewoon/:id`

### 1-1. 핵심 UX
- **상단 가로 타임라인**: 출생~+80년 = 8~10대운 (10년 단위) 가로 스크롤
- 각 대운 블록: 시작 나이 / 간지 한자 2자 / 오행 색 배경
- 현재 대운: 골드 테두리 + pulse 애니메이션 (느린 1.5s)
- 탭 시 아래 **상세 섹션** 로드 (스크롤 위로)

### 1-2. 타임라인 시각
```
[1세~10세] [11세~20세] [21세~30세] [현재 31세~40세] [41세~50세] [51세~60세] ...
  목(木)     화(火)       토(土)      [★ 금(金) ★]      수(水)       목(木)
```
- 각 블록 폭 80px · 높이 56
- 현재 블록만 90px (살짝 크게)
- 위쪽 도트: 과거·현재·미래 색 구분

### 1-3. ResultBody — L1~L4 (5,000자)
- **L1 (800자)**: 전체 대운 아크 조감 — "당신의 80년은 [금→수→목] 큰 세 호흡으로 흐릅니다"
- **L2 (1,800자)**: 선택된 대운 1개 집중 해설 — 4 문단
  - 소제목: "이 대운이 가진 기운" · "관계와 커리어에 미치는 결" · "주의할 지점" · "기회의 시기"
- **L3 (1,800자)**: 다음 대운 미리보기 (500자) + 과거 대운 회고 (700자) + 대운-세운 결합 해석 (600자) + 타임라인 차트
- **L4 (600자)**: 이 대운 안에서 해야 할 3 체크리스트 + 오늘의 한 줄

### 1-4. 차트 (L3)
- **대운 × 세운 매트릭스** (가로 대운 · 세로 세운) heatmap
- 색: 길(吉) 초록 · 평(平) 회색 · 신중(愼) 황토
- Recharts ScatterChart + 커스텀 Cell

### 1-5. UpsellCard
- "대운의 흐름을 사주 전체와 묶어 보실래요?" → 프리미엄 10운

## 2. 월운(이번달) `/wolun/:id`

### 2-1. 핵심 UX
- **상단 이번 달 캘린더** — 2026.7월 30일 그리드
- 일별 오행 색 배경 tint (연하게)
- 오늘 하이라이트 · 미래/과거 색 구분
- 탭 시 해당 날짜 상세 (아래 섹션 스크롤)

### 2-2. 구성
- 상단 배너: "7월, 당신의 결" 제목 + 이 달 오행 요약 1줄
- 캘린더 (Recharts grid or 커스텀 CSS grid 7×5)
- 하단 주간 요약 4 카드 (1주차 / 2주차 / 3주차 / 4주차)
- 각 주간 카드 120px 높이: 주 타이틀 + 2~3줄 해설 + 추천 행동 1개

### 2-3. ResultBody — L1~L4 (2,500자)
- **L1 (400자)**: 이 달의 전체 기운 요약
- **L2 (900자)**: 주차별 4문단 각 200자 + 소제목
  - "1주 · 씨 뿌리는 시기" · "2주 · 가지 뻗는 시기" · "3주 · 열매 다듬는 시기" · "4주 · 갈무리의 시기"
- **L3 (900자)**: 특정 일 피크/주의일 (3~5일 구체 날짜) + 달력 차트
- **L4 (300자)**: 이 달 체크리스트 3 + 오늘의 한 줄

### 2-4. 갱신 로직
- 매월 1일 00:00 KST 자동 생성 트리거 (`onSchedule(cron: "0 0 1 * *")`)
- 전월 결과는 보관함에 "2026.6월" 라벨로 남김
- 이번 달 재열람은 무료 (1운 재소비 X)

## 3. 궁합보기 `/gunghap/:id`

### 3-1. 핵심 UX 차이점
- **2인 입력** 필요 — 본인 (active profile 자동) + 상대 (별도 입력 or 보관함 선택)
- 입력 화면 진입 시 "상대를 보관함에 저장할까요?" 토글
- 저장 시 `users/{uid}/sajuProfiles`에 `type: 'partner'`로 기록

### 3-2. 결과 레이아웃
```
┌─────────┬─────────┐
│ 좌: 나  │ 우: 상대│   ← 사주 카드 2개 병치 (높이 180)
├─────────┴─────────┤
│ 중앙: 결 평가 원형 │   ← 오행 궁합 레이더 (60% / 95% 등 수치 없음 - "조화로움 / 서로 보완" 텍스트)
├────────────────────┤
│ L1 요약            │
│ L2 오행 궁합        │
│ L3 십성 궁합        │
│ L4 액션            │
└────────────────────┘
```

### 3-3. 핵심 UI 디테일
- 나 / 상대 카드에 이름 + 생년월일 + 일간 한자
- 중앙 평가는 **퍼센트 수치 금지** (궁합 N점 식 지양). 대신 5단계 텍스트:
  - "결이 깊게 맞닿음 / 서로 보완됨 / 흐름이 교차함 / 속도 차가 있음 / 결이 다른 자리"
- 색: 깊게 맞닿음 #B8965A · 다른 자리 #9BAAC2

### 3-4. ResultBody — L1~L4 (3,800자)
- **L1 (600자)**: 두 사주의 큰 그림 — "당신의 불과 상대의 물이 만나, 생활의 온도를 맞춰갑니다"
- **L2 (1,200자)**: 오행 궁합 — 4 문단
  - "서로의 강함이 닿는 자리" · "서로의 부드러움이 닿는 자리" · "부딪힐 때의 결" · "거리의 조절"
- **L3 (1,400자)**: 십성 궁합 + 관계 타임라인 차트 (1년 12개월 펄스)
- **L4 (600자)**: 이번 달·다음 달 구체 행동 3 + 관계 한 줄

### 3-5. 프라이버시
- 상대 사주 보관 선택 시에만 저장. 비저장 시 결과 생성 직후 프로필 삭제
- 결과 자체는 uid 본인에 귀속 (상대 uid와 무관)

### 3-6. 가격 근거
- 3운 = 자기 사주(기본) 1운 + 상대 사주 1운 + 궁합 결합 해석 1운 = 3운 (운 환율 메모리 반영)
- 프리미엄 10운 사용자는 상대 1명 무료 · 추가 상대는 3운 차감

## 4. 토정비결 `/tojeong/:id`

### 4-1. 핵심 UX
- 2026년판 · 2027년판 분리
- 매년 12월 말 다음해판 오픈 · 전년판은 "지난해 되짚기" 읽기 전용
- 상단 배너: "2026 한 해를 여는 토정비결"

### 4-2. 결과 레이아웃
```
┌──────────────────────┐
│ 상단: 이 해의 큰 그림  │  ← H1 + 오행 심볼 + 한자 표어 1줄
├──────────────────────┤
│ 12월 아코디언          │  ← 1월 ~ 12월 각 300자
│  ▸ 1월 · 봄의 시작     │
│  ▸ 2월 · 자리 잡기     │
│  ...                  │
│  ▾ 7월 (현재·펼침 기본)│
│    [본문 300자]        │
│  ▸ 8월 · 여름 절정     │
│  ...                  │
├──────────────────────┤
│ 연간 요약 · 500자       │
└──────────────────────┘
```

### 4-3. 12개월 각 300자 · 소제목 고정
| 월 | 소제목 템플릿 |
|---|---|
| 1월 | 봄의 시작 · 씨 뿌리는 달 |
| 2월 | 자리 잡기 · 흐름 읽는 달 |
| 3월 | 기지개 · 관계 트이는 달 |
| 4월 | 안정 · 다짐을 다듬는 달 |
| 5월 | 여름의 입구 · 열기 오르는 달 |
| 6월 | 풍성 · 재물·인연 절정의 달 |
| 7월 | 조율 · 속도를 낮추는 달 |
| 8월 | 반환점 · 점검의 달 |
| 9월 | 가을 · 갈무리 시작의 달 |
| 10월 | 결실 · 맺음을 거두는 달 |
| 11월 | 준비 · 다음해를 그리는 달 |
| 12월 | 쉼 · 기운을 거두는 달 |

### 4-4. ResultBody — L1~L4 (6,000자)
- **L1 (600자)**: 한 해 표어 + 오행 흐름 요약 + 핵심 키워드 3개
- **L2 (3,600자)**: 12월 × 300자 = 3,600자 (아코디언 전체 펼침)
- **L3 (1,500자)**: 관운(官) / 재운(財) / 인운(印) / 관계(桃) / 건강(壽) 5 축 연간 흐름 차트 (라인)
- **L4 (300자)**: 올해 꼭 해볼 것 3 + 올해의 한 줄

### 4-5. 특별 UI
- 현재 월 아코디언 기본 펼침
- 지난 월은 투명도 0.6
- 미래 월은 접힘 상태 + 탭 시 펼침
- 12월 완독 시 "올해를 한 번에 되짚기" 버튼 → L3 풀스크린 차트
- 연간 요약 카드 "내년 토정비결 예약하기" (12월 15일 이후 활성)

### 4-6. 가격 근거
- 2운 = 연 1회 소비. 2026판 재열람 무료. 2027판은 별도 2운
- 프리미엄 10운에 해당 해 토정비결 포함

## 5. 코드 구조 제안

### 5-1. 라우팅
```ts
// src/routes.tsx
<Route path="/daewoon/:id" element={<DaewoonPage />} />
<Route path="/wolun/:id" element={<WolunPage />} />
<Route path="/gunghap/new" element={<GunghapInputPage />} />
<Route path="/gunghap/:id" element={<GunghapResultPage />} />
<Route path="/tojeong/:id" element={<TojeongPage />} />
```

### 5-2. Firebase Functions
```
functions/src/ai/
  generateDaewoon.ts      ← 대운 전체 + 현재 대운 심층
  generateWolun.ts        ← 이번 달 월운 (cron: monthly)
  generateGunghap.ts      ← 2인 궁합 (상대 사주 input 필수)
  generateTojeong.ts      ← 연간 토정비결 (cron: yearly)
```

### 5-3. 프롬프트 파일
```
functions/src/ai/prompts/
  daewoon.md
  wolun.md
  gunghap.md
  tojeong.md
```

각 프롬프트는 `14_주제별심층` 공용 base.md 상속 + 주제 특화 룰 추가.
