# Track A — 홈 카피덱 v1 (2026-04-21)

**목적:** 홈 화면 UI 완성도를 "가치 중심" 카피로 전면 재편. v3 목업의 "500원/5000원" 가격 중심 표기와 뭉뚱한 CTA를 교체.

**제약 조건 (기존 메모리 반영):**
- 금액 원화 노출 금지 (가격 금액 노출 금지) · UI엔 "운" 단위만. 5000원·500원 문구는 /charge 페이지에만.
- 듀얼 메인 전략 (사용자 메인=무료 / 비즈니스 메인=프리미엄)
- 브랜드 팔레트: 골드 #B8965A · 베이지 #F8F5EE · 네이비 #1D2D4A
- 격식체 50%+ · 친근체 30~40% 보조 · 프리미엄일수록 격식체 ↑
- 이모지 0건 · 신살 고유명사(천을귀인·도화살·화개살·역마살·공망) 허용
- 후기 16개: 이름 제거 · 연령·성별만 · 우→좌 자동 캐러셀

## A1. 카드 네이밍 (가치 중심 재편)

v3 목업의 카드 타이틀이 "기능명"에 가까움. 가치·경험 중심으로 다시 씀.

| 카드 | v3 (기능명) | v4 초안 (가치명) | 이유 |
|---|---|---|---|
| 무료 · 오늘의 운세 | "오늘의 운세" | **"오늘의 하루, 한눈에"** | 속도·즉시성 강조 · "운세"는 부제로 내림 |
| 무료 · 꿈해몽 | "꿈해몽" | **"어젯밤 꿈, 해석해드립니다"** | 경험 회상 + 격식체 |
| 500원 · 주제별 | "1운 주제별 해석" | **"오늘 제일 궁금한 한 가지"** | 1운의 "집중" 가치 · 주제 선택을 자연화 |
| 5000원 · 프리미엄 | "5000원 프리미엄 종합" | **"올해 내 삶, 한 권의 명리"** | 원화 제거 · 책 비유 + 연단위 시간감 |
| 사주대화 | "AI 사주대화" | **"물어보고 싶은 만큼, 귀인처럼"** | AI 단어 제거 · 대화 품질 시그널 |
| 보관함 | "내 보관함" | **"지금까지의 해석, 차곡히"** | 축적감 · 재방문 유인 |
| 이벤트 | "이벤트" | **"오늘 받을 복"** | 동사형 · 출석+초대+누적 포괄 |
| 내정보 | "내정보" | **"내 사주·기록"** | 앱인토스 정책 맞춰 축소(웹앱과 다름) |

### 카드 서브타이틀 규칙
- 16~20자 내외 1줄
- 문장 끝 마침표 생략 (카피 리듬)
- 예: "오늘의 하루, 한눈에" → 서브 "3분 안에 받아보는 일진 해설"

## A3. 프리미엄 카드 카피 (가치 not 가격)

v3: **"5000원 · 프리미엄 10운 종합"**
→ v4: **"올해 내 삶, 한 권의 명리"**

### 카드 전체 구조 (확정안)

```
┌──────────────────────────────────┐
│  프리미엄 · 이달의 깊이           │ ← 상단 작은 라벨 (골드)
│                                  │
│  올해 내 삶, 한 권의 명리         │ ← 큰 타이틀 Noto Serif KR 22pt
│                                  │
│  격국·용신·대운·세운을 엮어       │
│  한 해를 통째로 풀어드립니다.     │ ← 서브 2줄 · 격식체
│                                  │
│  [포함] 10대 주제 · 18000자      │
│         · 30초 로딩 · PDF 저장    │ ← 구성 요소 명시
│                                  │
│  [받아보기 →]                    │ ← CTA 버튼 (원화 없음)
└──────────────────────────────────┘
```

### 카피 규칙 (A3 세부)
- 숫자는 "10대 주제", "18000자" 등 **구성의 밀도**만 표기 (가격 0건)
- "AI", "GPT", "모델" 등 기술어 **0건**
- "종합" → "통째로", "풀이" → "풀어드립니다"
- 상단 라벨 "프리미엄 · 이달의 깊이" · "이달의"가 월 1회 소비 유도 (리텐션)

### 결제 후 이어질 페이지 프리뷰 (A3 부록)
블록 상단 → 타이틀 → "이달의 귀인은 누구인가", "관계의 결", "재물·직업의 흐름" 등 **목차 3~4줄** 미리보기로 "구매 전 가치 체감". 잠금 티저 연속성 메모리 원칙 준수.
