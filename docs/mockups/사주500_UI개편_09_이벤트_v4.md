## 3. 블록 2 — 3일 연속 출석 (streak, v4 신설 별도 위젯)

**핵심 규칙:**
- **연속 3일** 출석 시 1운 지급
- 중간에 하루라도 빠지면 **즉시 리셋** (streak = 0)
- 달성 후 다음 연속 3일 다시 시작 가능 (무한 반복 OK)
- 월요일 0시 리셋과 **무관** (독립 트래킹)

### UI — 이동윈도우 (sliding window)

**핵심 원칙:** 도트 3칸의 라벨은 현재 streak 진행도에 따라 **매일 왼쪽으로 밀린다**. 왼쪽이 과거(체크됨), 오른쪽이 미래(대기).

| 상태 | 도트 라벨 (왼→우) | 체크 상태 | 안내 카피 |
|---|---|---|---|
| **Day 0** (idle · 리셋 직후 · 오늘 아직 미체크) | 오늘 · 내일 · 모레 | ○ ○ ○ | "오늘 결과 하나 보면 시작돼요" |
| **Day 1** (streak=1 · 오늘 체크 완료) | 오늘 · 내일 · 모레 | ✓ ○ ○ | "이틀만 더 이어지면 운 1" |
| **Day 2** (streak=2 · 어제+오늘 체크) | 어제 · 오늘 · 내일 | ✓ ✓ ○ | "내일까지 이어지면 운 1 받아요" |
| **Day 3** (streak=3 · 그제·어제·오늘 체크) | 그제 · 어제 · 오늘 | ✓ ✓ ✓ | "운 1 지급 완료 · 다시 이어가봐요" → 1초 후 Day 0으로 리셋 |
| **끊김** (어제 빠짐) | 그제 · 어제 · 오늘 | ○ ✗ ✓ or ○ ✗ ○ | "어제는 빠졌어요 · 오늘부터 다시 시작" |

**라벨 회전 규칙:**
- `streak ∈ {0, 1}` → 라벨 `[오늘, 내일, 모레]` (미래형)
- `streak == 2` → 라벨 `[어제, 오늘, 내일]` (과거 1 + 현재 + 미래 1)
- `streak == 3` → 라벨 `[그제, 어제, 오늘]` (모두 과거형, 달성 직전/직후 0.8초만 노출)

**시각 디자인:**
- 체크 도트: 골드 배경 #B8965A + 흰 체크 SVG
- 대기 도트: 대시 테두리 #E5E5E0
- 끊김 도트: 빨간 테두리 #C0392B (opacity 0.6)
- "오늘" 도트는 약간 더 진한 골드 #9A7D47 테두리로 강조
- Day 3 달성 순간: 1.2초 펄스 애니메이션 후 Tier A 토스트 + 리셋

### Firestore 스키마
```
/users/{uid}/streakAttendance/current
  {
    startDate: "2026-04-19",
    currentStreak: 2,
    lastAttendedDate: "2026-04-20",
    claims: [{ startDate, endDate, claimedAt }]
  }
```

### 판정 로직 (의사코드)
```typescript
function updateStreak(uid: string, today: string) {
  const doc = get('streakAttendance/current');
  const yesterday = addDays(today, -1);
  
  if (doc.lastAttendedDate === today) return; // 중복 방지
  if (doc.lastAttendedDate === yesterday) {
    doc.currentStreak += 1;
  } else {
    doc.currentStreak = 1; // 끊겼으니 리셋
    doc.startDate = today;
  }
  doc.lastAttendedDate = today;
  
  if (doc.currentStreak === 3) {
    grantUn(uid, 1, 'streak3');
    doc.claims.push({ startDate: doc.startDate, endDate: today, claimedAt: now });
    doc.currentStreak = 0; // 다시 처음부터
    doc.startDate = null;
  }
}
```

## 4. 블록 3 — 이번 주 출석 (7일 모두, cumulative · 토스포인트 100원)

**핵심 규칙:**
- **월~일 7일 전부** 체크 시 **토스포인트 100원** 지급 (주 1회 한정)
- 월요일 0시 리셋
- 중간에 빠져도 남은 날 전부 출석하면 여전히 가능
- 3일 연속(블록 2)과 **독립 트래킹**
- **보상 변경 이유**: 앱인토스 "랜덤 보상 금지" 정책 하에서 확률형 박스는 불가. 대신 **고정 현금성(토스포인트 100원)** 으로 유저 체감가치 ↑, 유닛이코노믹스 ↓ (운 2=1,000원 내부가치 → 100원 현금 = 90% 절감).
- 토스포인트 지급은 앱인토스 개발자 콘솔 "적립형 리워드" API 경로로 처리 (UAC 프로모션과 별개 예산).

### UI
```

  월 화 수 목 금 토 일
  ✓  ✓  ○  ○  ○  ○  ○
  ↑        ↑
 달성    오늘

진행률 바:
  [■■░░░░░] 2/7일

상태 라벨:
- 0/7: "이번 주 시작! 7일 모두 모으면 100원 받아요"
- 1~6/7: "N일째 · 남은 M일 더 모으면 토스포인트 100원"
- 7/7: "이번 주 완성 · 토스포인트 100원 지급 완료"
```

- 토스포인트 API 실패 시 자동 재시도 3회 · 그래도 실패면 운 2로 폴백 + 운영 알림

## 9. Cloud Functions 4종 (v3 grantTossPoint 재도입)
