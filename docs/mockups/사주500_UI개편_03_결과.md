## 3. ResultBody — 4-Layer 구조 (L1~L4)

기존 `project_aha_moment_v41.md` 구조 계승 + UI 토큰 갱신.

### 3-1. L1 — 요약 (Hook)
- 3~5문장, 문단 1개
- 배경 `paper`, padding 20
- 글자 Body 16/500, `ink`
- 상단에 한자 심볼 1개 (예: 연애 = 桃, 재물 = 財) · 32px · `gold-brown-dark`
- 읽기 시작 1초 안에 "내 이야기다" 느낌 나야 함

### 3-2. L2 — 본문 (Expansion)
- 5~8문단, 문단 간 12px
- 각 문단 앞에 신살·십성·오행 소제목 (Label 13/600 `gold-brown-dark`)
- 글자 Body 16/500 · line-height 1.75
- 문단 내 키워드는 `gold-brown-dark` + weight 700 (문단 당 최대 2개)
- **금지**: 한자 반복 덩어리 투척 · 사전식 정의

### 3-3. L3 — 심층 (Depth)
- 3~4문단, 차트·도표 1개 포함 가능
  - 오행 밸런스 원형 그래프 (Recharts PieChart, 5색)
  - 십성 비중 바 그래프
  - 대운 타임라인 (가로 막대)
- 텍스트는 L2보다 한 단계 구체적 ("2027년 초여름에…" 처럼 시기 특정)

### 3-4. L4 — 액션 (Verdict)
- "이번 주 해보면 좋을 것" 3~4개 체크리스트
- 각 아이템: 아이콘 18 (lucide `check-circle-2`) + Body 15/500 · padding 8 vertical
- 하단에 인용구 스타일 "오늘의 한 줄" — Caption 13/500 italic + 좌 border 2px `gold-brown`

### 3-5. 블러 잠금 (무료 결과 only)
- L3·L4 섹션에 `filter: blur(6px)` + `pointer-events:none`
- 블러 위에 중앙 오버레이:
  - 상단 `Lock` 아이콘 32px `gold-brown-dark`
  - H3 "여기서부터 더 깊은 풀이"
  - Body-sm "전체 해석은 프리미엄에서 볼 수 있어요"
  - Primary 버튼 "10운으로 해제하기" (폭 풀, 높이 52)
  - Ghost 버튼 "한 주제만 먼저 볼래요 (1운)"
- 오버레이 배경: `rgba(248,245,238,0.88)` + 상단 fade gradient

## 9. 프리미엄 결과 고유 섹션

프리미엄은 단순 L1~L4가 아닌 7-섹션 구조. (내부 생성 목표 길이 8,000~10,000자, **사용자에게는 글자수 노출 금지**)

1. **요약 카드** (L1 역할) — 3문장 + 일간 오행 뱃지
2. **천간·지지 파트** — 사주 원국 시각화 + 각 글자 해설
3. **십성 파트** — 비중 바 그래프 + 스토리
4. **대운 파트** — 10년 단위 타임라인 + 현재 위치 표식
5. **연운 파트** — 올해 + 내년 예측
6. **신살 파트** — 있는 신살만 골라 해설 (도화·화개·역마·천을 등)
7. **실천 파트** (L4 역할) — 분기별 실천 체크리스트

각 섹션 사이 32px 간격 + 구분선 1px `gray-line` (opacity 0.5)

## 12. 블러 해제 애니메이션

결제 완료 → 같은 URL의 `tier=paid`로 리다이렉트 또는 `locked=false`로 state 업데이트.

- 블러 레이어 opacity 1 → 0 (600ms ease-out)
- L3·L4 실제 텍스트는 translate-y 12→0 + opacity 0→1 (동시)
- 오버레이 `Lock` 아이콘은 `Unlock`으로 교체되며 회전 120deg fade-out (400ms)
- 상단에 토스트 "풀이가 모두 열렸어요" 표시 (success 톤 3초)
- 광고 배너는 조건부 언마운트 (즉시 사라짐, 레이아웃 시프트는 fade-out 처리)

- 블러 영역은 `aria-hidden="true"`, 오버레이 CTA는 실제 포커스 타깃

- 모든 섹션은 `<section aria-labelledby="...">`

```ts
    };
    tier: 'free' | 'paid';
    generatedAt: string;
  };
  locked: boolean;            // L3/L4 블러 여부 (free + 무결제)
  adEligible: boolean;        // 광고 노출 여부
};
```

- **서버 응답 원칙**: 무료 결과는 L1·L2만 본문 포함, L3·L4는 placeholder. 결제 후 같은 endpoint + `tier=paid`로 재호출해 전체 payload 받음.
- **보안**: 클라이언트 locked=false로 바꿔도 L3·L4 텍스트가 비어있어야 함. 서버 게이트 필수.
