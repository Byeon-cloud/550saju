# 사주500 UI 개편 — 06 사주대화 (`/chat`)

> 마스터 스펙 토큰 기반.
> 환율: **1운 = 3대화권**. 공유 1일 3회 = 3운 = 9대화권.
> "AI 챗봇 클리셰" 피하는 게 제1원칙 — UX 라이팅·디자인 톤 전통+절제 유지.

---

## 0. 결정 반영 요약

| 항목 | 정책 |
|----|----|
| 환율 | 1운 = 3대화권 (Q4) |
| 충전 모달 카피 | "운 ○개를 대화권 (○×3)개로 변경할까요?" |
| 대화권 부족 시 | 운 → 대화권 변환 모달 → 운도 없으면 `/charge` |
| 사주 선택 | 보관함 프로필 기반, 선택 후 대화 시작 |
| 이전 대화 | 계속 이어가기 가능 |
| 광고 | 노출 안 함 (유료 기능) |
| 비로그인 | 운이 있으면 사용 가능 (공유 리워드) |

## 5. 대화 충전 모달

### 5-1. 기본 변환 모달
- 바텀 시트, 높이 auto, radius-top 24
- 헤더 H2 "운을 대화권으로 바꿀까요?"
- 본문 Body `ink-soft`:
  > "운 {n}개를 대화권 {n × 3}개로 변경할까요?"
- 변환량 슬라이더 (최소 1운 ~ 최대 잔액 운)
  - 슬라이더 값 변경 시 "○×3 = ○대화권" 실시간 표기
- 하단 stack:
  - Primary 버튼 "바꾸기" (높이 52)
  - Ghost 버튼 "취소"

### 5-2. 대화 중 대화권 부족
- 메시지 전송 시 대화권 -1 → 0 되면 다음 전송 시 자동 모달:
- 헤더 H3 "대화권이 0개예요"
- 본문 "남은 운 {k}개 → 대화권 {k×3}개로 바꾸면 이어서 질문할 수 있어요"
- Primary "{k}운 → {k×3}대화권 바꾸기"
- 운도 0이면:
  - 헤더 "운도 대화권도 없어요"
  - 본문 "운 충전하거나 친구에게 공유하고 받을 수 있어요"
  - Primary "운 충전하기" → `/charge?redirect=/chat/:id`
  - Secondary "공유하고 1운 받기"

### 5-3. 비로그인 + 운 0
- "로그인하면 공유 리워드로 운을 받을 수 있어요"
- Primary "로그인하고 1운 받기" → 로그인 모달 → 성공 시 공유 리워드 시트

## 7. MessageStream

### 7-1. 공통
- 배경 `paper`
- 메시지 사이 gap 8
- 새 메시지 도착 시 자동 스크롤 (사용자가 위로 스크롤 중이면 멈춤)

### 7-2. 시스템 인사 (대화 시작 시 자동)
- 중앙 정렬, Caption 12/500 `gray-500`
- 예: "변준기님 사주로 대화를 시작합니다. 편하게 물어보세요."
- 이후 AI 첫 메시지 자동 생성 (인사 + 사주 한 줄 요약)

### 7-3. AI 버블 (사주 답변)
- 좌측 정렬, 최대 폭 80%
- 배경 `#FFFFFF`, border 1px `gray-line`, radius 16 (좌하단은 4)
- padding 14 16
- 상단 Caption 11/500 `gold-brown-dark` "사주 풀이" (AI가 아니라 사주 관점임을 명시)
- Body 15/500 `ink`, line-height 1.7
- 긴 답변은 섹션 헤더(Label `gold-brown-dark`) 포함 허용
- 하단 Caption 11/500 `gray-500` + 시각 "14:22"
- 롱프레스: 복사·저장·신고 시트

### 7-4. 사용자 버블
- 우측 정렬, 최대 폭 80%
- 배경 `ink`, text `paper`, radius 16 (우하단 4)
- padding 12 14
- Body 15/500
- 하단 시각 (Caption `ink` 70% opacity)

### 7-5. 입력 대기 (AI 응답 생성 중)
- 좌측에 "사주를 살피는 중…" Caption + 점 애니메이션 3개 (opacity 순차 변경, shimmer 금지)
- 실제 답변은 일괄 렌더 (스트리밍 안 함 — "AI 같지 않게" 원칙)
- 3~8초 예상. 오래 걸리면 "정성 들여 풀이 중이에요" 카피 교체.

### 7-6. 추천 질문 칩 (첫 진입 + 상황별)
- AI 첫 메시지 아래에 가로 스크롤 칩 3~5개
- 높이 32, pill, `gold-brown-soft` bg, `ink` text, border 1px `gray-line`
- 예: "올해 재물운 어때요?" / "연애 운은요?" / "이직 타이밍 궁금해요"
- 탭 시 질문으로 전송 + 칩 사라짐

## 9. Composer (입력 영역)

- 하단 sticky, 배경 `paper`, 상단 1px `gray-line`, padding 12 16
- safe-area 고려
- 구성:
  - 좌측 아이콘 버튼 (선택, 향후 음성 입력) — 현재 단계는 생략
  - 가운데 인풋 영역:
    - 높이 최소 40, 최대 120 (자동 grow), radius 20
    - 배경 `#FFFFFF`, border 1px `gray-line`, padding 10 14
    - placeholder: "사주에 궁금한 걸 편하게 물어보세요"
  - 우측 전송 버튼 (아이콘 `send` 20)
    - 활성: bg `ink`, text `paper`, 원형 40×40
    - 비활성: `gray-line` bg, `gray-500` text
- 전송 시 대화권 1개 차감 → 남은 대화권 배너에 반영

### 9-1. 전송 게이트
- 입력 빈칸이면 비활성
- 대화권 0 + 운 0 이면 비활성 + 탭 시 안내 토스트 "대화권이 없어요. 운 충전이 필요해요."
- 대화권 0 + 운 있음 → 전송 시 자동으로 §5-2 모달 표시
- 네트워크 에러 → 메시지 재전송 버튼 + "전송 실패. 다시 보내기"

## 10. 대화 메뉴 (C 상단 우측 ⋮)

- 바텀 시트 메뉴:
  1. 대화 요약 보기 (선택, 향후)
  2. 이 사주 결과 페이지 열기 → 해당 프로필의 최근 풀이
  3. 사주 바꾸기 → `/chat/new` (현재 세션은 유지)
  4. 대화 삭제 (빨강 텍스트)
- 탭 시 확인 모달 → 삭제 확인

## 11. 데이터 구조 (PC 참고)

```ts
type ChatSession = {
  id: string;
  profileId: string;
  createdAt: string;
  updatedAt: string;
  messageCount: number;
  lastMessagePreview?: string;
};

type ChatMessage = {
  id: string;
  sessionId: string;
  role: 'user' | 'assistant' | 'system';
  content: string;            // 마크다운 OK
  createdAt: string;
  tokensUsed?: number;        // 대화권 1개 = 1 메시지 (토큰 무관)
  relatedRecommendation?: {
    type: 'topic' | 'premium' | 'daily';
    targetId?: string;
  };
};

type Balance = {
  un: number;
  chatTickets: number;        // 대화권
};
```

- 대화권 소비 정책: **사용자 메시지 1건 = 대화권 1개**. AI 응답은 별도 차감 없음.
- 서버에서 대화권 잔액 실시간 검증 (클라이언트 조작 방지)

- "AI가 분석합니다"

## 16. 접근성

- 메시지 버블 = `role="article"` + role별 `aria-label`
- 인풋 = `aria-label="질문 입력"` + `aria-describedby` 로 대화권 잔액 연결
- 추천 질문 칩 = `<button>` 순서대로
- 대화권 잔액 변경 = `aria-live="polite"` 로 스크린 리더 통지
