# KR 시간 보정 UX 카피 v2 — 3결정 적용

**상황:** 런칭 D-2 (오늘 2026-04-20). v1의 3개 미정 사항을 기본값으로 확정. 코드 반영은 D-Day 전 필수.
**원칙:** 홍성민 지적("사주 시간이 지역·시대에 따라 다름") 대응 + 한자·전문성은 쉬운 풀이로 흡수 + 면피체 금지.

---

## 결정 1 — 75% 품질 수치 → **"상당 부분"** (문장형)

**Why:** 수치는 근거 요구 발생. 75%의 출처가 없으면 민원·환불 리스크. 문장형이 오히려 전문성 느낌.

**적용 후 카피:**

- v1 (❌): "시간 모르면 **75% 품질**로 풀어드립니다."
- v2 (✅): "시간 모르면 **하루의 큰 흐름**까지는 정확히 풀립니다. 시(時)까지 있으면 **개인별 미세 조율**이 더해집니다."

**추가 룰:** 수치를 쓰고 싶을 땐 "몇 % 품질"이 아니라 "몇 섹션이 더 풀린다"처럼 **명시적 구조 비교**로. 예: "시 입력 시 → 12섹션 / 시 미입력 시 → 10섹션."

---

## 결정 2 — 6구간 경계 **시각 기준 고정**

**Why:** 12지시(子丑寅卯…) 경계는 사람마다 체감이 다름. 시각 범위로 먼저 고정 후 내부적으로 12지시 매핑.

**6구간 (사용자 노출):**

| 구간 | 시각 범위 | 매핑 12지시 |
|---|---|---|
| 새벽 | 03:00 ~ 05:00 | 寅 (범시) |
| 아침 | 05:00 ~ 09:00 | 卯·辰 (토끼·용시) |
| 오전~정오 | 09:00 ~ 12:00 | 巳 (뱀시) |
| 오후 | 12:00 ~ 18:00 | 午·未 (말·양시) |
| 저녁 | 18:00 ~ 22:00 | 申·酉 (원숭이·닭시) |
| 밤 | 22:00 ~ 03:00 (익일) | 戌·亥·子·丑 (개·돼지·쥐·소시) |

**사용자 선택 UI:**

```
시간을 정확히 모르시나요? 대략이라도 고르면 더 정밀해져요.

  ○ 새벽 (03~05시)
  ○ 아침 (05~09시)
  ○ 오전~정오 (09~12시)
  ○ 오후 (12~18시)
  ○ 저녁 (18~22시)
  ○ 밤 (22~03시)
  ○ 전혀 모름 — 큰 흐름만 풀어드릴게요
```

**내부 처리:** 구간 선택 시 **중간값 시각**을 서버에 전달 (예: "아침" = 07:00).

---

## 결정 3 — 재계산 버튼 **결과 화면 1회만 노출**

**Why:** 결과 페이지 2~3회 노출 시 재계산 루프 빠지는 유저 있음 (점신 사례). 1회 제한이 신뢰도 유지에 유리.

**위치:** 결과 화면 상단 "시간 보정 배너" 내에만.

**카피:**

```
┌──────────────────────────────────────────┐
│ 🕐 태어난 시간이 04:40이에요.            │
│    한국은 시대에 따라 실제 태양시가       │
│    ±30분 차이났어요.                     │
│                                          │
│    시간을 다시 적거나, 대략 구간을 골라  │
│    결과를 다시 받아볼 수 있어요.          │
│                                          │
│    [ 시간 다시 설정 ] ← 1회만 노출       │
└──────────────────────────────────────────┘
```

**로직:**
- 한 세션에서 재계산 1회 사용 시 → 버튼 비활성화 ("이미 다시 계산했어요").
- 24시간 후 재접속 시 리셋.
- 결제 후에는 재계산 버튼 **비노출** (결제 유효성 보호).

## 테스트 케이스 확정 (TC-KR-01~06)

| TC | 입력 | 기대 출력 |
|---|---|---|
| TC-KR-01 | 1950년 3월 서울 04:40 | ±30분 보정 적용, 경계 시 별표 표시 |
| TC-KR-02 | 1988년 서울 17:20 | 서머타임 적용 확인 |
| TC-KR-03 | 2010년 부산 00:15 | 일자 경계 보정 확인 |
| TC-KR-04 | 시 미입력 + "아침" 선택 | 07:00 기준 해석, 10섹션 출력 |
| TC-KR-05 | 시 미입력 + "전혀 모름" | "큰 흐름" 모드 10섹션, 재계산 버튼 비활성 |
| TC-KR-06 | 결제 후 재계산 시도 | 버튼 비노출, 결제 결과 유지 |

## D-Day 전 필요한 작업

1. **프론트 구현** — 시간 입력 하단 + 6구간 라디오 + 결과 배너. 2시간 예상.
2. **서버 로직** — 구간→중간값 매핑, 재계산 세션 관리. 1시간 예상.
3. **카피 반영** — v2 카피 그대로 적용. 수치 75% 흔적 제거.
4. **홍성민 대응 메모** — 런칭 후 DM 오면 "시간 보정 적용됨 + 구간 선택 추가"로 응답.

**총 3~4시간 작업.** D-2 저녁 또는 D-1 오전까지 가능.
