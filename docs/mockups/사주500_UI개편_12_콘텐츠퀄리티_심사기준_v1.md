# 사주500 콘텐츠 퀄리티 심사 기준 v1

**작성:** 2026-04-20 · **런칭:** 2026-04-22 앱인토스
**목적:** 런칭 전 콘텐츠 산출물 15건 샘플에 대해 "AI 같지 않은 프리미엄 퀄리티" 합격·불합격을 객관 판정한다.
**원칙 (메모리 인계):**
- 퀄리티 > 속도 1순위. 가격 대비 최상 퀄리티 원칙.
- 격식체 50% 이상 + 친근체 30~40% 보조. 프리미엄일수록 격식체 비중 ↑.
- 유저 출력물에서는 한자 쉽게(풀이 + 상징·프레임용만). 한자 나열 금지.
- 신살 고유명사(도화살·화개살·역마살·천을귀인·공망)는 브랜드 자산 — 금지어 아님.
- 무료 결과 페이지만 광고. 유료 결제 후엔 광고 없음.

## 1. 심사 8축 — 공통 적용

축별 0 / 1 / 2 점. 2 = 통과, 1 = 재작성, 0 = 불합격.

| # | 축 | 2점 (통과) | 1점 (재작성) | 0점 (불합격) |
|---|---|---|---|---|
| 1 | **브랜드 톤** | 격식체 50%+ / 친근체 30~40% / AI 면피체 0건 | 격식체 30~49% or 친근체 50%+ | 면피체 1건+ (가능성이 있·할 수 있어요·분석 중) |
| 2 | **한자 사용** | 풀이 먼저, 한자는 상징·고유명사로 최소 | 한자 풀이 없이 2개+ | 한자 나열·의미 없는 배치 |
| 3 | **섹션 리듬** | 결론 → 근거 → 실용 조언, 도입 2줄 이내 | 도입 4줄+ or 섹션 간 중복 | 결론 불분명, 흐름 붕괴 |
| 4 | **사실성** | 천간지지·오행·십신·대운·신살 학적 근거 일치 | 부분 일치, 1~2건 모호 | 임의 해석·점성술 혼용·사주학과 충돌 |
| 5 | **지식 깊이** | 용어 정의 후 사용, 근거 맥락 | 용어 정의 없이 사용 | 피상적 단어 나열, 교과서 복붙 톤 |
| 6 | **분량·페이스** | 티어별 기준 범위 내 ±10% | 기준 ±20% 이탈 | 기준 ±30% 이상 이탈 |
| 7 | **CTA 연결** | 티어별 적절한 CTA 자연스럽게 | CTA 있으나 맥락 엉킴 | CTA 누락 or 과다 반복 |
| 8 | **금지어** | 0건 | 경고어 1건(히지만 등) | 금지어 1건+ |

**합산:** 16점 만점. **14점 이상 통과 · 11~13점 재작성 · 10점 이하 불합격.**

### 1-1. 금지어·경고어 사전 (런칭 기준 고정)

**절대 금지 (자동 불합격 조건 — 1건만 있어도 0점):**
- "잠시만 기다려주세요" / "곧 완료됩니다" / "분석 중입니다" / "로딩 중"
- "AI가 분석해드려요" / "인공지능이 읽어드려요" / "AI 모델이"
- "~할 가능성이 있습니다" / "~할 수도 있어요" (면피체)
- "운이 나쁘면" / "불행이 닥칠" (공포 마케팅)
- "100% 확실히" / "반드시 ~합니다" (단정 과잉)

**경고어 (허용되나 빈도·맥락 체크):**
- "~인 것 같아요" → 격식체 "~습니다"로 전환 권장
- "여러분" → "당신"으로
- "쉽게 말해" → 바로 설명으로
- "간단히 정리하면" → 섹션 헤더로 대체

**브랜드 자산 (금지어 아님 — 쓸 것):**
- 신살 고유명사: 도화살·화개살·역마살·천을귀인·공망·귀문관살
- 십신 용어: 비견·겁재·식신·상관·편재·정재·편관·정관·편인·정인
- 오행·천간지지 한자 (의미 풀이와 함께)

## 4. 합격·불합격 실제 예시

### 4-1. ❌ 불합격 예 — 오늘의 운세

> "오늘 당신의 운은 좋을 가능성이 높아요! 화가 잠시 오르겠지만 곧 가라앉을 수 있어요. AI가 분석한 결과 오후에는 좋은 일이 있을 것 같아요. 열심히 살아보세요!"

**심사 결과: 2/16 — 0점 불합격**
- 브랜드 톤(0) — 친근체 100%, 면피체 "가능성이 높아요/할 수 있어요"
- 사실성(0) — 일진 근거 0, "좋은 일이 있을 것 같아요" 사주 학적 근거 없음
- 지식 깊이(0) — "화가 잠시 오른다" 개념 미정의
- 금지어(0) — "AI가 분석", "가능성이 높아요"
- 분량·페이스(1) — 짧기만 함

### 4-2. ✅ 합격 예 — 오늘의 운세

> "오늘의 일진은 **임오(壬午)**. 차가운 물(임수)이 뜨거운 말(오화)을 올라탄 날입니다. 판단력보다 감정이 앞서기 쉬워, 중요한 결정은 아침에 두십시오. 오전 10~12시 사이에 문서·계약을 마무리하면 결이 수월하고, 오후 2시 이후로는 충동적 의사결정을 미뤄두는 편이 안전합니다. 오늘의 색은 **검·청**, 방위는 **북쪽**. 수(水)가 약한 분이라면 물을 자주 드시고, 북쪽 방위를 등지지 마십시오."

**심사 결과: 15/16 — 통과**
- 브랜드 톤(2) — 격식체 위주(~십시오·~합니다·~니다) 약 70%, 친근체 30%
- 한자 사용(2) — 임오 1개 + 풀이("차가운 물이 뜨거운 말을 올라탄 날")
- 섹션 리듬(2) — 결 → 근거 → 실용(시간대·색·방위)
- 사실성(2) — 일진 정확, 수화 상생·상극 반영
- 지식 깊이(2) — 임수·오화 의미 풀이, 수 약한 경우 조언
- 분량·페이스(2) — 약 220자 (오늘의 운세 중 일부 섹션 예시이므로 full은 800+)
- CTA(1) — CTA 미포함(예시 한정, full에는 포함 필요)
- 금지어(2) — 0건

## 8. 축 1 (브랜드 톤) 격식체 비중 측정 법

**"격식체 50%+" 객관 측정:**
1. 문장을 `.` `!` `?`로 분할
2. 종결어미 분류:
   - **격식체:** 습니다 · 입니다 · 됩니다 · 십시오 · 십니다 · 는다 · 다
   - **친근체:** 해요 · 예요 · 어요 · 아요 · 이에요
   - **중립:** 용어 단독, 숫자 등
3. `격식체 문장 수 / (격식체 + 친근체)` ≥ 0.5
4. 프리미엄 5000원은 ≥ 0.7

**자동화:** PC가 간단 스크립트로 측정 → `심사_v1.xlsx`의 축1 점수 자동 기입 (사람은 확인만)
