# 앱인토스 콘솔에서 준기가 뽑아올 것 (토스포인트 지급 운영)

> **용도**: 이벤트 탭 v4.1 "7일 완주 토스포인트 100원" 실 지급 스위치.
> **지금은 STUB 모드로 PC가 먼저 배선** → 아래 1~5번이 다 준비되면 환경변수 주입으로 LIVE 전환.
> **선후**: 1→2→3→4→5. 1번 없으면 나머지 전부 막힘.

## 1. 프로모션 등록 (심사 2~3영업일)

**경로**: 콘솔 로그인 → 워크스페이스 → 미니앱 `사주 500` → 좌측 `프로모션` 탭 → `+ 등록하기`

**입력 값** (아래 그대로 복붙 권장):

| 필드 | 값 |
|---|---|
| 프로모션 이름 | `사주500 · 7일 출석 완주 리워드` |
| 종료일 | `2026-12-31` (1차 임시. 캠페인 상시 운영) |
| 혜택탭 노출 | `노출` |
| 미션 이름 | `한 주 모두 출석하고 토스포인트 100원 받기` |
| 지급 방식 | **`고정형`** (랜덤/최대형 쓰지 말 것) |
| 지급 금액 | `100원` |
| 이동 URL | `https://saju500.com/events` (웹앱) or 미니앱 내부 딥링크 |
| 예산 | **일단 비워두고 2번(비즈월렛) 먼저 충전** |

**제출 → 심사 대기 2~3영업일**

**뽑아올 것**:
- 심사 통과 후 **실 프로모션코드** (예: `PROMO_01K9...`)
- → PC에게 `APPINTOS_PROMOTION_CODE` 환경변수로 전달

## 2. 비즈월렛 충전

**경로**: 콘솔 → `비즈월렛` 탭

**초기 충전 금액**: **3만원** (런칭 1개월 7일 완주 500명 × 100원 = 5만원, 여유 포함해 3만원으로 시작)

**지불 방법**: 가상계좌 or 법인카드 (본인 사업자 카드)

**뽑아올 것**:
- 충전 완료 확인 (잔액 표시 스샷 1장)
- → 준기 로컬 보관. PC에 넘길 필요 없음.

**알림 설정**: 콘솔에서 **"예산 80% 소진 시 이메일 알림" 자동 기본값** — 별도 설정 불필요.

## 3. mTLS 인증서 발급

**경로**: 콘솔 → 미니앱 `사주 500` 선택 → `mTLS 인증서` 탭 → `+ 발급받기`

**다운로드 파일 2개**:
- `client-cert.pem` (클라이언트 공개 인증서)
- `client-key.pem` (클라이언트 비밀키)

**보관**:
- D드라이브 어딘가 안전하게 (이메일·슬랙에 절대 첨부 금지)
- Git 커밋 금지 (`.gitignore`에 이미 있을 것 — PC가 체크)
- 파일 내용 그대로 **Firebase Functions Secret에 주입** (아래 4번)

**만료**: 인증서 발급 화면에 표시된 **유효기간을 캘린더에 등록** (만료 30일 전 갱신 알람)

**뽑아올 것**:
- `client-cert.pem` 파일 경로
- `client-key.pem` 파일 경로
- 유효기간 (캘린더용)

## 4. Firebase Functions Secret 주입

**사전**: Firebase CLI 설치 · 로그인 확인 (이미 되어 있음 · D:\550saju에서 이전에 배포 해봤을 것).

**명령어** (PowerShell or cmd):

```powershell
cd D:\550saju

firebase functions:secrets:set APPINTOS_MTLS_CERT < "C:\path\client-cert.pem"
firebase functions:secrets:set APPINTOS_MTLS_KEY  < "C:\path\client-key.pem"
firebase functions:secrets:set APPINTOS_PROMOTION_CODE
# ↑ 위 명령어 실행하면 프롬프트가 뜬다 → 1번에서 받은 PROMO_01K9... 붙여넣기 → Enter
```

**확인**:
```powershell
firebase functions:secrets:access APPINTOS_PROMOTION_CODE
# 값 출력되면 성공
```

**뽑아올 것**:
- 세 Secret 등록 완료 메시지 스샷 1장 → PC에게 전달

## 6. 최종 LIVE 스위치

1~5번 전부 완료 후 PC에게 이 한 줄 전달:
> **"토스포인트 실지급 스위치 ON. Secrets 주입 완료. TEST_ 검증 OK."**

PC는:
- Functions 재배포 (Secrets 바인딩 반영)
- STUB 코드 경로 비활성 (환경변수 존재 시 자동 live 모드)
- 카나리 1건 지급 후 rewardClaims 문서 검증
- 문제없으면 전체 공개

## 8. 자주 헷갈리는 포인트

| 의심 | 정답 |
|---|---|
| "랜덤으로 100원~500원 주면 안 돼?" | **안 됨**. 사주500 랜덤 보상 금지 정책 + 유닛이코노믹스 예측 불가. `고정형` 100원 딱. |
| "프로모션 등록은 미니앱 배포 후에?" | **동시 진행 가능**. 미니앱 심사와 프로모션 심사는 별개 라인. |
| "비즈월렛 0원인데 등록해도 돼?" | **심사는 통과**, 지급은 실패. 심사 제출 전 충전 권장. |
| "인증서 이미 있는데 또 발급?" | 동시 복수 등록 가능. 만료 전에 새 거 발급해두고 무중단 교체. |
| "심사 반려 사유?" | 프로모션 이름에 금지어(경품·추첨·뽑기·랜덤) 있거나, 이동 URL이 미니앱 아닐 때. 위 가이드대로면 통과. |
