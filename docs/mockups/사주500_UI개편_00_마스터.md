## 1. 브랜드 포지션 (복기)

- "**예쁨 + 퀄리티 + 500원**" — 점신 등 국내 1위가 못 차지한 빈 자리
- 한국 전통(사주) × 모던 감성 — 60대도 20대도 부담 없이
- AI 같지 않게 — "이거 그냥 챗GPT 아님"이 바로 읽혀야 함
- 광고·업셀은 조용히 (무료 페이지만 광고. 결제 후엔 없음)

## 3. 강약 3-tier 시스템

모든 카드·섹션은 3단계 중 하나에 속함. 시각 가중치를 이 단계로만 통제.

| Tier | 용도 | 크기 | 예시 |
|------|----|----|----|
| **Pillar** | 사용자 인지 메인 (최상위) | 풀 폭 · 높이 200~240 · 풀 컬러/그라디언트 배경 | 히어로(오늘의 운세) · 사주 연계 꿈해몽 |
| **Body** | 비즈니스 메인 · 주요 보조 | 풀 폭 또는 2열 그리드 · 높이 140~160 · 단색/미묘 배경 | 프리미엄 종합사주 · 주제별 심층 |
| **Caption** | 보조·링크·부가 정보 | 2열 또는 3열 그리드 · 높이 96~112 · flat | 대운·월운·궁합·FAQ 링크 |

홈 배치는 Pillar → Body → Caption 역피라미드가 기본. 단, Path별 동적 재배치 가능.

## 4. 컴포넌트 베이스

### 4-1. 버튼

| 종류 | 배경 | 텍스트 | 보더 | 높이 | 비고 |
|------|----|----|----|----|----|
| Primary | `ink` | `paper` | 없음 | 52 | CTA (결제·제출·시작) |
| Secondary | `paper` | `ink` | `gold-brown` 1px | 52 | 보조 액션 |
| Ghost | transparent | `gold-brown-dark` | 없음 | 44 | 텍스트 링크 |
| Danger | `danger` | `#fff` | 없음 | 52 | 삭제 확인 |
| Icon-only | transparent | `ink` | 없음 | 44×44 | 아이콘 단독 버튼 |

- border-radius 12
- font: Label 13/600
- tap feedback: `scale(0.97)` 150ms
- disabled: opacity 0.4, pointer-events none

### 4-2. 인풋

- 높이 52, border 1px `gray-line`, border-radius 12
- 포커스: border `gold-brown`, ring 2px `gold-brown`/20% opacity
- 에러: border `danger`, 하단 12px `danger` 텍스트
- placeholder: `gray-500`
- label: Label 13/600, 위에 8px 여백

### 4-3. 카드

- 배경 `paper` 또는 `#fff`
- padding 16~24
- border 1px `gray-line` (선택)
- radius 16
- 그림자 sm~md

### 4-4. 모달 / 바텀 시트

- 바텀 시트 기본 (iOS·Android 네이티브 느낌)
- 배경 `paper`, radius-top 24
- 드래그 핸들 (회색 막대 36×4, 상단 12px padding)
- 닫기: 배경 탭 또는 위→아래 스와이프
- 오버레이: `rgba(0,0,0,0.4)`, fade 200ms

### 4-5. 토스트

- 하단 고정 (TabBar 위), padding 12×16, radius 12
- success: `success` 배경 + 흰 텍스트
- info: `ink` 배경 + 흰 텍스트
- error: `danger` 배경 + 흰 텍스트
- 3초 자동 닫힘

### 4-6. BalanceBar (상단 고정)

- 높이 48, 배경 `paper`, 하단 border 1px `gray-line`
- 좌: 로고 "사주500" (Label 13 + 세리프 느낌)
- 우: 운 아이콘 + 숫자 (예: "3운") · 탭 시 `/charge`
- **원화 표기 금지**

### 4-7. TabBar (하단 고정) — 2026-04-21 개정

- 높이 64 + safe-area
- **5탭: 홈 / 이벤트 / 사주대화 (중앙, 약간 올라감) / 보관함 / 내정보**
- 2026-04-21 변경: `사주분석` 탭 제거 → `이벤트` 탭 신설. 사주 등록은 3지점(홈·보관함·콘텐츠 시작) 분산.
- 아이콘 + Label(12/600)
- 활성: `ink` / 비활성: `gray-500`
- 사주대화 = 중앙에 원형 버튼 (56×56, bg `ink`, 흰 아이콘)
- 이벤트 탭 빨간점 뱃지: 출석 미수령·주간 미션 잔여·절기 오픈 시. 런칭 2주는 상시 노출, D+14 후 상태 기반

## 5. 상태 패턴

### 5-1. Loading
- Skeleton: 회색 정적 박스 (`#EEE8DC`) — shimmer 금지
- "AI 같은 느낌" 줄이기 위해 빠른 fade + 실제 콘텐츠 점진 교체
- 인풋 제출 후 페이지 이동 시 = 풀스크린 로딩 (뒤에 설명)

### 5-2. Empty state
- 가운데 정렬, 위→아래: 심볼 아이콘(48~64) → H3 → Body-sm 1~2줄 → Ghost 버튼
- 심볼은 신살 기호(공망·화개·도화 등) 활용 가능 (브랜드 자산)

### 5-3. Error
- 인라인: 인풋 바로 아래 빨간 Caption
- 토스트: 네트워크·일시적 오류
- 풀스크린: 404 / 치명 오류 — 심볼 + H3 + CTA

### 5-4. 풀스크린 로딩 (AI 풀이 생성 중)
- 배경 `paper`
- 중앙: 심볼 또는 간단한 SVG 애니메이션 (회전 느린 오행 윈)
- H3 "당신의 기운을 읽고 있어요"
- 진행률 텍스트 "만세력 계산 중…" → "일간 해석…" → "신살 배치…" (10~30초)
- 완충 UX: 속도 대신 "정성 들여 쓰는 느낌" 연출
