결정 포인트 1 · 브랜드 코드
점신·헬로우봇 같은 상대는 모두 중앙 올림을 씀. 사주500이 이걸 따라가면 “또 하나의 사주앱”, 안 따라가면 “절제된 전통 사주 브랜드”. 준기 브랜드 포지션(“예쁨+퀄리티+500원”·AI 같지 않게) 기준 B가 브랜드 코드 상 더 안전하지만 전환 시 사주대화가 묻힘 리스크 있음.
결정 포인트 2 · 핵심 기능 발견률
사주대화는 반복 방문 + 대화권 소비의 핵심. 발견률이 약해지면 대화권 결제 유입 체감 감소. 데이터 없이 판단할 거면 A가 보수적, B는 브랜드 프리미엄 투자.
결정 포인트 3 · 향후 확장성
A로 가면 중앙 슬롯은 “사주대화”에 고정됨. B는 향후 주요 CTA를 중앙 탭에 할당·스왑 가능 (예: 이벤트 기간 ‘오늘의 운세’ 강조).
결정 포인트 4 · 제작 비용
A가 살짝 더 복잡함(원형 float + safe-area). B는 표준 TabBar로 구현·유지보수 양쪽 더 가벼움.
