# 사주500 UI 개편 — 05 보관함 (`/storage`)

> 마스터 스펙 토큰 기반.
> **핵심**: 사주팔자 정보 ↔ 이용기록 **데이터 완전 분리** (cascade delete 금지).
> 삭제 UX = 스와이프 + 휴지통 아이콘 둘 다 지원.

---

## 0. 결정 반영 요약

| 결정 | 반영 |
|----|----|
| 사주팔자 정보 삭제 UX | **스와이프 + 휴지통 아이콘** 둘 다 (Q5) |
| 데이터 모델 | 사주 정보 별도 / 이용기록 별도. 한쪽 삭제가 다른 쪽 영향 X |
| 분석기록 메뉴 일원화 | 내정보의 분석기록 메뉴 삭제 → 보관함에서만 |
| 비로그인 접근 | 가능 (단, 로그인 안 하면 디바이스 로컬 저장만) |
| 광고 | 노출 안 함 (탐색 페이지) |

## 2. Section A — 사주팔자 정보

### 2-1. 섹션 헤더
- padding 16 20 8
- 좌: H2 20/700 "사주팔자 정보"
- 우: 텍스트 버튼 "+ 새 사주 추가" (Label 13/600 `gold-brown-dark`)

### 2-2. 프로필 카드

```
┌───────────────────────────────────┐
│ ●  변준기                          │ ← 휴지통(우상단)
│    1995.05.12 (양) · 묘시         │
│    일간 갑(甲) · 목(木)            │
│    풀이 12건 · 대화 4건            │
└───────────────────────────────────┘
```

- 높이 116, padding 16, 배경 `#FFFFFF`, border 1px `gray-line`, radius 16
- 좌 원형 심볼 48 (오행 색 + 한자) — 일간 오행에 따라 달라짐
- 중 텍스트 stack:
  - Body 16/700 이름
  - Caption 12/500 `gray-500` 생년월일·캘린더·시
  - Caption 12/500 `gold-brown-dark` 일간·오행
  - Caption 11/500 `gray-500` "풀이 N건 · 대화 N건"
- 우상단: 휴지통 아이콘 18 `gray-500` (탭 시 삭제 확인 모달)
- **탭(휴지통 외 영역)**: 가장 최근 풀이 결과로 이동 (`/result/:lastResultId`)
  - 풀이 기록이 없으면 → "이 사주로 분석 시작하기" 모달 (`/input?profileId=...`)

### 2-3. 스와이프 삭제 (Q5 - 둘 다 지원)
- 카드를 좌→우 또는 우→좌 스와이프 시 (drag threshold 80px)
- 카드 뒤편에서 빨간 영역(폭 96, 높이 116) 슬라이드 노출
  - 배경 `danger`, 가운데 휴지통 아이콘 24 `#fff`
- 스와이프 손 떼면:
  - 80px 미만: 원위치 (200ms ease-out)
  - 80~160px: 빨간 영역 노출 유지 (탭 시 삭제 확인)
  - 160px 이상: 즉시 삭제 확인 모달
- 라이브러리: `react-swipeable-list` 또는 자체 구현 (touchEvent + transform)

### 2-4. 삭제 확인 모달
- 바텀 시트, 높이 auto, radius-top 24, 배경 `paper`
- 헤더 H3 "변준기님의 사주 정보를 삭제할까요?"
- 본문 Body-sm `ink-soft`:
  > "사주 정보만 삭제됩니다. 지금까지 본 풀이 12건과 대화 4건은 그대로 보관함에 남아있어요."
- 하단:
  - Primary `danger` 버튼 "삭제하기" (높이 52)
  - Ghost 버튼 "취소" (높이 44)
- 삭제 성공 → 토스트 "사주 정보가 삭제됐어요"
- 삭제 후 이용기록은 **이름이 지워진 상태**로 유지 ("(삭제된 사주)" 라벨)

### 2-5. Empty State (프로필 0개)
- 가운데 정렬, 위→아래:
  1. 심볼 64 `gold-brown-dark` (신살 기호 추상)
  2. H3 "아직 등록된 사주가 없어요"
  3. Body-sm `ink-soft` "생년월일과 시간을 입력하면 모든 풀이가 한곳에 모여요"

## 5. 데이터 모델 (버그 2·3·4 핵심)

### 5-1. 분리 원칙

| 저장소 키 | 데이터 | 삭제 시 영향 |
|----|----|----|
| `saju500.profiles` | 사주팔자 정보 (id, name, birthDate, hour, calendar, 일간, 오행) | 다른 키에 영향 X |
| `saju500.history` | 이용 기록 (id, profileId(FK), type, contentId, createdAt, unCost) | 다른 키에 영향 X |
| `saju500.lastInput` | 최근 입력 폼 캐시 | 명시적 삭제 시 함께 제거 |
| `saju500.balance` | 운·대화권 잔액 | 별도 |

### 5-2. 삭제 함수 동작

| 액션 | profiles | history | lastInput |
|----|----|----|----|
| 단일 프로필 삭제 | 해당 항목 삭제 | profileId만 null 처리 (본체 유지) | 영향 X |
| 단일 기록 삭제 | 영향 X | 해당 항목 삭제 | 영향 X |
| 기록 일괄 삭제 | 영향 X | 선택 항목만 삭제 | 영향 X |
| "모든 데이터 초기화" (운영자용) | 전체 삭제 | 전체 삭제 | 전체 삭제 |

### 5-3. 마이그레이션 (구버전 사용자)
- 기존 cascade delete 로직 제거 시:
  - 앱 첫 실행 마이그레이션에서 `saju500.history.profileId` 유효성 검사
  - 참조 깨진 항목은 "(삭제된 사주)" 라벨로 살림
  - localStorage 스키마 변경 = **반드시 사전 보고** (`PC_BUGLIST_APPINTOS.md` 공통 지침)

### 5-4. lastInput 잔존 버그 (버그 4) 처리
- `/input` 페이지 진입 시 초기값:
  - URL에 `?profileId=` 있음 → 해당 프로필 데이터 prefill
  - 없음 → **빈 폼**으로 시작 (lastInput 자동 복원 X)
- "이전 입력값 불러오기" Ghost 버튼은 별도로 두되, 명시 액션일 때만 lastInput 사용
- "보관함 모두 삭제" 함수가 호출되면 lastInput도 함께 제거

## 7. 상태 패턴

### 7-1. 로딩
- 프로필 카드 영역: skeleton 카드 1개 (높이 116, 회색 정적)
- 이용기록: skeleton 카드 3개

### 7-2. 동기화 (로그인 + 서버 보관)
- 비로그인 = 디바이스 로컬만 (localStorage)
- 로그인 = 서버 동기화 (디바이스 ↔ 서버 머지)
- 동기화 중 우상단 작은 회전 아이콘 (`Loader2` 16) + Caption "동기화 중"

### 7-3. 오류
- 카드 영역 위에 inline 에러 바: `warning` bg + Caption "기록을 불러오지 못했어요. [다시 시도]"

- 스와이프 액션은 키보드 사용자 위해 휴지통 버튼 항상 노출 (다중 진입로)

## 9. 데이터 구조 (PC 참고)

```ts
type Profile = {
  id: string;            // uuid
  name: string;
  birthDate: string;     // ISO YYYY-MM-DD
  calendar: 'solar' | 'lunar';
  hour?: number;         // 0~23 (모르면 undefined)
  gender?: 'male' | 'female';
  ilgan?: string;        // 일간 한자
  ohaeng?: '목'|'화'|'토'|'금'|'수';
  createdAt: string;
};

type HistoryItem = {
  id: string;
  profileId: string | null;   // 삭제된 프로필이면 null
  type: 'daily'|'dream'|'result'|'premium'|'topic'|'daewoon'|'wolun'|'gunghap'|'tojeong'|'chat';
  contentId: string;          // 결과 페이지 id 또는 chat 세션 id
  title?: string;
  unCost: number;
  createdAt: string;
};
```
