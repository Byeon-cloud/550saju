읽는 법

  • 실선 → = 확인된 링크 (신규 HomePage 기준)
  • 점선 -.-> = 추정 링크 (실제 존재 여부 확인 필요)
  • 빨간 점선 = PC 조사 필수 항목 (IA 대시보드 §5·§6 참조)
  • 사각 박스 색 — 갈색=TabBar / 크림=홈진입 / 파랑=Flow / 회색=정책/에러

지금 명확히 빠진 것

  • /share/:id 공유 버튼이 어디에 박혀있는지 (결과? 오늘운세? 둘 다?)
  • /charge 업셀 진입점 (결과 페이지 L4 블러? 상품 매트릭스만?)
  • /storage에서 저장된 풀이 클릭 시 /result/:id로 돌아가는지
  • /my에서 /terms, /privacy로의 링크 실제 존재 여부
  • /chat 첫 진입 시 방 없을 때 행동
  • BalanceBar는 모든 페이지에 있지만 그림엔 포함 안 됨 (별도 global 요소)
