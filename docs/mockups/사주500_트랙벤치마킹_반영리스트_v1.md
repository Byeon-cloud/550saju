## 1. 런칭 당일 반영 가능(D+0 · 2026-04-22 이전) — A급

기획·콘텐츠 수정만으로 가능. 코드 대규모 변경 없음.

### A-1. 무료 결과 첫 3줄 = 감정 수용 고정 패턴
- **출처:** 测测 Cece(트랙2) · "AI 같지 않음" 듀얼 레이어
- **적용:** 오늘의 운세·꿈해몽 결과 페이지 도입부 3줄을 **격식체 분석 X → 친근체 감정 수용 O**로 고정
- **공수:** 콘텐츠 프롬프트 수정 1시간 · PC 인계에 포함
- **예:**
  - Before: "오늘 당신의 일주 정화(丁火)는 왕성한 흐름을 보입니다."
  - After: "오늘은 마음이 조금 분주할 수 있는 하루입니다. 아래 풀이를 천천히 읽어 보세요."

### A-2. 신살 고유명사 툴팁 2차 라인업 (기 합의 · D+0 가능분만)
- **출처:** 해자 2층(지식 해자) · 트랙1 천을귀인 참고서 포지션
- **적용:** 천을귀인·문창귀인·도화살·화개살·역마살·공망 6종에 대해 **툴팁 or 짧은 설명 1문장** 고정. 유저 출력물 안에서 단어 탭 시 얕은 해설.
- **공수:** 사전 JSON 30분 + 프론트 레이어 2시간
- **주의:** 본문은 한자 풍부 X · 툴팁만 한자 + 쉬운 풀이

### A-3. 프리미엄 PDF 하단에 12궁·14주성 약식 차트 1장 추가
- **출처:** 文墨天机(트랙2) 12궁 차트 · 프리미엄 PDF 방향(기존 계획)
- **적용:** 5000원 프리미엄 PDF 마지막 페이지에 사주 원국 + 12운성 원형 차트 1장 추가. SVG 생성 서버 측.
- **공수:** 디자인 1일 · 서버 Puppeteer 차트 삽입 4시간
- **판정:** D+0 전에 끼우기 빠듯하면 **D+7로 밀기 허용** — 우선순위는 이벤트 탭 v3 마감

### A-4. "AI 꿈해몽 + 6대 원전 인용" 배지 홈·결과 노출
- **출처:** 해자 2층 · 트랙4 원칙 1(Aha는 무료에서 터져야)
- **적용:** 홈 상단 & 무료 꿈해몽 결과 상단에 **"주공해몽·周公解夢 등 6대 원전 참고"** 1줄 서브 타이틀
- **공수:** 카피 수정 10분 · 홈·결과 2개 컴포넌트 텍스트 교체
- **이유:** 점신·포스텔러가 "200p" "1,900만"으로 사회적 증거를 잡고 있을 때, 사주500은 **지식 깊이 한 줄로 차별화** 필요

## 2. 런칭 직후 D+7 이내 — B급

1주일 내 가능. 코드 소규모.

### B-1. "운기 캘린더" 이번 달 개운일 하이라이트 (홈 카드 1개)
- **출처:** ゲッターズ飯田 · cocoloni PROLO(트랙2) — 리텐션 1순위 자산
- **적용:** 홈에 **"이번 달 개운 캘린더"** 카드 1개 추가. 월별 달력 + 아이콘(결단·쇼핑·이사·계약·휴식 5종) + "오늘은 X에 좋은 날" 1줄
- **공수:** 달력 컴포넌트 1일 · 개운일 판정 로직(간지 기반 단순 규칙) 2일
- **리텐션 측정:** D7 재방문율 +3%p 가정
- **연동:** 이벤트 탭 출석과 별개 경로 · 개운 캘린더를 본 뒤 "이 날 사주 풀이" CTA로 유입

### B-2. 첫 회 프리미엄 핵심 섹션 1개 맛보기 무료
- **출처:** LINE占い 첫 10분 무료(트랙2) 변형
- **적용:** 5000원 프리미엄 중 **"올해의 총운" 1섹션만** 첫 회 무료로 열어두고, 나머지 9섹션은 결제 유도. 블러잠금 티저 연속성 원칙과 합체.
- **공수:** 결제 플로우 분기 1일 · 프론트 잠금 토글 반나절
- **주의:** 유저 본인 계정 1회 한정 · 재구매 시 정상 과금

### B-3. 가족 사주 저장 (본인 + 1명 · v1 제한)
- **출처:** 해자 1층(데이터) · 점신·포스텔러 미커버(트랙1·4)
- **적용:** 보관함에 본인 사주 외 가족 사주 1명 등록 가능. 가족 운세 비교 리포트는 **D+30 이후** — 우선 저장만.
- **공수:** 보관함 UI 추가 + 입력 재사용 반나절
- **이유:** "1개월 뒤 3명 등록" 데이터 해자 초석. 런칭 초기부터 유도

## 3. D+30 이내 — C급 (이벤트 탭 로드맵과 동기)

### C-1. 대운 timeline (10년 주기) — 홈·프리미엄 결과

### C-2. 한자 토글 "참고서 뷰" (5000원 프리미엄 전용)

- **적용:** 5000원 프리미엄 결과 상단 토글 "쉬운 풀이" ↔ "참고서 뷰(한자·신살 한자 표기)" · 무료·500원은 쉬운 풀이만

### C-3. 꿈 일기 아카이브 (월별·연도별 검색)

- **적용:** 보관함 하위 "꿈 일기" 섹션. 월별 썸네일 + 키워드 검색

### C-4. 점술가형 "이번 달 대기화면" 월 1회 배포

## 4. D+90 이내 — D급 (전략 레벨)

### D-1. 테마별 프리미엄 카탈로그 확장
- **출처:** 哪吒运势/팔자 앱(트랙2) · 포스텔러 46주제(트랙1)
- **적용:** 5000원 종합 프리미엄 외에 **재운·인연·사업** 3개 테마별 단건(각 3,000원대). 품질 1순위 원칙 엄수 — 메뉴 폭발 금지, 3개로 제한.
- **공수:** 테마별 콘텐츠 프롬프트·산출물 3주
- **주의:** 포스텔러 46개 폭 X · 사주500은 "작은 카탈로그, 깊은 품질" 원칙 고수

### D-2. 사주대화 기능 강화 + AI 프롬프트 자동 생성
- **출처:** 万세력 천을귀인 "사주 → ChatGPT/Gemini 연동"(트랙1)
- **적용:** 사주대화 탭에서 현재 사주 요약 → ChatGPT/Gemini용 프롬프트 자동 생성 복사 기능. 유저가 외부 AI로도 확장해 쓸 수 있게.
- **공수:** 프롬프트 템플릿 2일
- **반향적 주의:** 외부 이탈 유도로 비칠 수 있으므로, 내장 사주대화를 먼저 강화해 "내장이 낫다"는 품질 우위 잡은 후 노출

### D-3. 복주머니형 누적 실물 리워드 (런칭 후 데이터 보고 결정)

- **적용 검토:** 이벤트 탭 v3 운 시스템 위에 **"30회 공유 = 실물 스티커 or 부적 카드"** 누적형 보상 검토
- **공수:** 실물 배송 플로우 신설 2주 · 원가 유저당 500원 이내
- **주의:** D+30 데이터(리텐션·공유 루프 사용률) 보고 **"필요하면"** 추가. 런칭 전에는 구현 X
