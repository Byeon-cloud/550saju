## 1. 운영 심사 (정책·개인정보·콘텐츠)

### 1-1. 🔴 AI 채팅·상담 카테고리 — 사주대화에 직접 해당

앱인토스 공식 주의사항이 "AI 채팅·상담"을 별도 카테고리로 다룸. 사주500의 **사주대화** 기능이 여기 해당.

**필수 가드**:
- [ ] 자살·자해 방법 질문 → 가드 응답 (구체 방법 제공 금지)
- [ ] 마약 사용·제조 질문 → 차단 응답
- [ ] 범죄 수행 방법 질문 → 차단 응답
- [ ] 우회 요청 대응 — "만약에", "소설 속에서", "외국어로" 등 표현 형식 변경도 차단
- [ ] 가드 발동 시 대체 응답 문안 확정 ("사주 관점에서 이 주제는 풀이가 어려워요. 전문가 상담을 권해드립니다." + 1388/129/1577-0199 연락처 제시 여부)

**PC 확인 작업**:
- 현재 `/chat` (사주대화) 라우트에 safety guard가 시스템 프롬프트에 있는지
- 프롬프트 인젝션 우회 테스트 10~20건 통과하는지
- 가드 발동 시 토큰·운 소비 여부 (소비하지 말 것)

### 1-2. 🟡 개인정보 정책

- [ ] 수집 항목: 이름, 성별, 생년월일, 출생 시간, (선택) 출생지 — **최소 수집 원칙** 준수 문구 기재
- [ ] 암호화 저장 여부 (PC 확인)
- [ ] 탈퇴 시 즉시 삭제 — `/settings/delete-account` 플로우 존재 확인
- [ ] 민감정보 명시적 동의 — 생년월일·시간은 "민감정보"는 아니지만, 체크박스 UX 권장
- [ ] 개인정보처리방침 · 이용약관 URL 연결 (현재 `/charge` Notice에 링크 있음)

### 1-3. 🟡 환불·결제 정책

- [ ] 결제 화면에서 환불 정책 명시 (`/charge` Notice 블록에 "구매한 운은 환불되지 않음" 문구 존재 ✓)
- [ ] 결제 한도 기본값 확인 (앱인토스가 전금법 제6조 준수 요구)
- [ ] 결제 실패 시 복구 플로우 명확

### 1-4. 🟢 광고

- [ ] "과도한 광고" 금지 — 사주500은 무료 페이지에만 1건씩 노출. 정책 준수.

## 2. 디자인 심사 (TDS + 해상도)

### 2-1. 🟡 해상도

**앱인토스 기준**:
- 세로형 논리 해상도: 360×640 ~ 420×740
- 트래픽 70~80%가 세로 360~420 폭에 집중
- 에셋: 1x + 2x (선택적 3x)
- Safe Area: 노치·카메라 홀·Dynamic Island 대응 필수

**현재 상태**:
- 모든 목업이 `width:428px` 기준 (iPhone 14 Pro/15 Pro 뷰포트)
- 428은 앱인토스 권장 상한 420을 살짝 넘김

**조치**:
- [ ] CSS `max-width: 428px`는 유지하되 `min-width: 360px`도 테스트
- [ ] 360×640 기기에서 레이아웃 깨짐 없는지 실기기 테스트 (PC·준기)
- [ ] Safe Area — `env(safe-area-inset-top/bottom)` 사용 여부 점검
- [ ] 가로 뷰포트는 미대응 — 세로 고정 OK이지만 명시 필요

### 2-2. 🟡 TDS (토스 디자인 시스템) v2

**공식 컴포넌트 11종**: Badge, Border, BottomCTA, Button, Asset, ListRow, ListHeader, Navigation, Paragraph, Tab, Top

**현재 사주500**: 전부 커스텀 컴포넌트 (브랜드 팔레트 #B8965A 베이지 브라운, Noto Serif KR 세리프)

**현실적 판단**:
- TDS "준수 의무"는 명시돼 있으나 **완전 강제는 아님** — 많은 미니앱이 자체 브랜드 디자인 유지
- 핵심은 **앱인토스 네이티브 UX를 해치지 않음** (뒤로가기 중복 노출 금지, 토스 로그인 모달 표준 등)

**조치**:
- [ ] 뒤로가기 버튼 중복 — 앱인토스가 상단에 네이티브 뒤로가기 제공하는지 확인 후, 중복되면 충전 페이지 TopBack 숨김 처리
- [ ] 토스 로그인은 앱인토스 SDK 표준 사용 — 커스텀 금지
- [ ] BottomCTA 패턴만이라도 TDS 가이드에 가깝게 (높이 56, padding safe-area 대응)
- [ ] 터치 타겟 최소 44×44pt

### 2-3. 🟡 인트로 페이지

**반려 사례**: "서비스 설명 없이 즉시 토스 로그인 유도"

**조치**:
- [ ] 앱 첫 진입 시 토스 로그인 모달 즉시 호출 **금지**
- [ ] 인트로/홈에서 사주500이 뭘 하는 앱인지 명확히 보여주고, 결제·보관 등 로그인 필요 액션에서만 로그인 모달 호출
- [ ] 현재 홈 v3는 이 원칙 준수 ✓ (듀얼 메인 콘텐츠 + 주제 카드 먼저 노출, 로그인은 결제 진입 시)

### 2-4. 🟢 다크모드

- 사주500은 라이트 페이퍼 테마(#F8F5EE) 고정 — 다크모드 미지원. 명시만 하면 됨.

### 4-1. 🔴 eval() 및 동적 코드 실행 전면 금지

**공식 규정**: "eval 및 유사 코드는 보안상 허용되지 않음. 주석 처리해도 스캐너에 검출됨."

**조치**:
- [ ] `grep -rn "eval(" src/ dist/ build/` → 0건이어야 함
- [ ] `new Function(...)`, `setTimeout("문자열", ...)` 등 유사 패턴도 제거
- [ ] 3rd-party 라이브러리 번들에 eval 포함 여부 확인 (예: lodash의 `_.template`, Vue runtime 등)
