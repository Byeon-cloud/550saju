## 3. ActiveProfile Switcher (프로필 2개 이상일 때만)

**용도**: 홈의 모든 개인화 카피가 바라보는 "현재 활성 프로필" 교체.

- 높이 44, 좌우 padding 16
- 배경 `gold-brown-soft`, radius 12
- 좌: "지금 보는 사주 →" Caption 12/500 `ink-soft`
- 중: active profile 이름 + 생년 축약 (예: "변준기 · 1995")
  - 이름 뒤 `ChevronDown` 16px
- 탭 시 바텀 시트 열림 → 프로필 목록 + "프로필 추가하기" CTA
- 프로필이 **1개뿐**이거나 **비로그인 + 프로필 없음** → 이 컴포넌트 **숨김**

### 3-1. 프로필 선택 바텀 시트
- 높이 auto, radius-top 24, 배경 `paper`
- 헤더: H3 "어느 분의 사주를 볼까요?"
- 각 프로필 카드 (높이 64):
  - 좌: 원형 심볼(신살 기호 추상화) 40×40
  - 중: 이름 (Body 16/700) + 생년월일 시 (Caption 12/500 `gray-500`)
  - 우: active이면 체크 아이콘 `gold-brown`
- 하단: "+ 새 사주 추가하기" Ghost 버튼 → `/input`

## 4. Pillar #1 — 오늘의 운세 (무료)

### 4-1. 시각 디자인
- 풀 폭, 높이 220, radius 20, padding 20
- 배경 그라디언트: **일자별 오행 동적**
  - 목(木) 날: `linear-gradient(135deg, #3B7A4B 0%, #264F32 100%)`
  - 화(火) 날: `linear-gradient(135deg, #B5441F 0%, #7B2E15 100%)`
  - 토(土) 날: `linear-gradient(135deg, #8B6914 0%, #5C450C 100%)`
  - 금(金) 날: `linear-gradient(135deg, #9C9388 0%, #6B655D 100%)`
  - 수(水) 날: `linear-gradient(135deg, #2F4B7C 0%, #1A2E50 100%)`
- 텍스트 색: `#F8F5EE` (paper)
- 우상단: 날짜 Caption "4월 20일 월요일 · 병진일"
- 중앙 좌측: H1 "{name}님의 오늘"
  - (비로그인 + 프로필 없으면) "오늘의 운세"
- 하단: Body-sm 2줄 해석 미리보기 (AI 생성)
  - 예: "재물 기운이 천천히 움직이는 하루예요. 서두르지 말고 한 걸음씩 쌓아가세요."
- 좌하단: 오행 한자 심볼 32px `rgba(255,255,255,0.35)` 워터마크

### 4-2. 상호작용
- 탭 시 `/daily?profileId={activeId}` 이동
- 푸시 로딩 후 풀 결과 페이지 (무료 + 광고 노출)

### 4-3. 카피 톤
- "오늘 하루, 이렇게 쓰세요" 같은 실용 톤
- 점괘 느낌 과하지 않게
- AI 같지 않은 필치 (마스터 스펙 §1 브랜드 포지션)

## 5. Pillar #2 — 사주 연계 꿈해몽 (무료)

### 5-1. 시각 디자인
- 풀 폭, 높이 220, radius 20, padding 20

- 텍스트 색: `paper`
- 우상단 뱃지: "무료" · pill · `gold-brown-soft` bg · `ink` text
- 중앙: H1 "어젯밤 꿈, 내 사주로 풀어드려요"
- 하단: Body-sm "꿈 단어를 적으면 {name}님 사주에 맞춰 해석해드려요"
  - (프로필 없으면) "꿈 단어를 적으면 사주 기반으로 해석해드려요"
- 좌하단: 입력 힌트 placeholder가 보이는 미니 인풋 느낌 UI (실제 입력은 `/dream`에서)

### 5-2. 상호작용
- 탭 시 `/dream?profileId={activeId}` 이동
- 프로필 없으면 → `/dream` (일반 해석 폴백)

### 5-3. 왜 Pillar 2개인가
- 준기 Q1 결정: **사용자 인지 메인 = 무료 콘텐츠**
- 오늘의 운세 = 매일 재방문 훅
- 꿈해몽 = 세션당 재진입 훅 (아침에 자주)
- 둘 다 Pillar로 시각 동등 취급. 프리미엄·주제별은 Body로 한 단계 낮춤.

## 6. Body #1 — 프리미엄 종합 사주 분석 (10운)

### 6-1. 시각 디자인
- 풀 폭, 높이 156, radius 16, padding 20
- 배경 `#FFFFFF` + border 1px `gold-brown`/40% opacity
- 좌상단 뱃지: "10운" · pill · `ink` bg · `paper` text (Label 12/700)
- 메인 카피: H2 "사주 전체를 깊게 읽어드려요"
  - Body-sm 보조: "천간·지지·대운·신살까지, 당신이라는 사람 전부"
- 우하단: "10운으로 시작하기" Ghost 버튼 + `ArrowRight` 16px
- 배경 우측 희미한 한자 "命" (명) 80px · opacity 0.06

### 6-2. 상호작용
- 탭 시 → 로그인 상태 + 운 10개 이상이면 확인 모달
  - "10운으로 프리미엄 종합사주 시작할까요?"
  - "10운 소진 후 결과는 보관함에 영구 저장됩니다"
- 운 부족 → `/charge?redirect=/premium&need=10`
- 비로그인 → 로그인 모달 → 로그인 후 위 플로우

### 6-3. 1운과의 차별화 (A+B 복합 메시지)
- "**주제 하나**만 깊게 vs **사주 전체**를 깊게"
- 범위(A): 전체 vs 한 주제
- 깊이(B): 천간·지지·대운·신살까지 = 한 주제보다 5~10배 분량

## 11. TabBar (하단 고정)

- 본 스펙은 **옵션 A(중앙 올림)** 가정. 옵션 B는 HTML 목업에서 비교.

### 11-1. 옵션 A — 중앙 올림 (점신 패턴)
- 높이 64 + safe-area
- 5탭: 홈 / 사주분석 / **사주대화(중앙, 위로 8px)** / 보관함 / 내정보
- 중앙: 원형 버튼 56×56, bg `ink`, 흰색 `MessageCircle` 아이콘 24px
  - 원형 버튼은 TabBar 상단을 8px 넘어 위로 튀어나옴 (float 효과)
  - 아래 Label "사주대화" (12/600)
- 나머지 4탭: 아이콘 24 + Label 12/600
  - 활성: `ink` / 비활성: `gray-500`
- 탭 피드백: scale 0.95

### 11-2. 옵션 B — 평등 5탭 (일반 패턴)
- 높이 64 + safe-area
- 5탭 모두 동일 크기·정렬
- 아이콘 24 + Label 12/600
- 활성: `ink` + 하단 2px `gold-brown` 선 / 비활성: `gray-500`

### 11-3. 두 옵션 선택 기준 (준기 판단용 포인트)
- A 장점: 사주대화가 프리미엄 핵심 기능임을 시각적으로 즉시 전달. 점신·이미 익숙한 UX 관례.
- A 단점: AI 챗봇 앱 클리셰. 브랜드 차별화 약화 가능성.
- B 장점: 전통적·단정·"사주"다운 절제. 탭 동등 취급이 오히려 브랜드 품격.
- B 단점: 사주대화 발견율↓. 신규 사용자에겐 그냥 하나의 탭일 뿐.

## 12. 이름 개인화 카피 매핑 (multi-profile)

Active profile = `state.activeProfile` (최초: 본인 또는 가장 최근 조회 프로필)

| 위치 | 템플릿 | 예시 (본인=변준기) | 예시 (친구=영희) | 예시 (없음/비로그인) |
|----|------|------|------|------|
| Pillar #1 헤드 | `{name}님의 오늘` | 변준기님의 오늘 | 영희님의 오늘 | 오늘의 운세 |
| Pillar #2 서브 | `{name}님 사주에 맞춰` | 변준기님 사주에 맞춰 | 영희님 사주에 맞춰 | 사주 기반으로 |
| Body #1 CTA | `{name}님 사주 전체, 한 번에` | 변준기님 사주 전체, 한 번에 | 영희님 사주 전체, 한 번에 | 사주 전체, 한 번에 |
| 후기 영역 헤드 | (고정) | "먼저 써본 분들의 말" | - | - |
| ActiveProfile 스위처 | `지금 보는 사주 → {name} · {birthYear}` | 지금 보는 사주 → 변준기 · 1995 | 지금 보는 사주 → 영희 · 1998 | (숨김) |

### 12-1. 개인화 엣지 케이스
- 이름 > 4자: `...` ellipsis (풀네임은 바텀시트에서)
- 한자·영문 이름: 그대로 노출
- 이름 없이 저장된 프로필: "친구1" 자동 부여 + 이름 수정 버튼 제공

## 14. 로딩·빈 상태

### 14-1. 로딩 (초기 진입)
- BalanceBar 즉시 표시
- Pillar 2개 skeleton (회색 정적 박스, shimmer 없음)
