# 앱인토스 UAC 프로모션 등록 초안 v1

**작성:** 2026-04-21 · **대상:** 앱인토스 관리자 콘솔 → 프로모션 등록
**맥락:** 이벤트 탭 v2에서 7일차 확률 박스 토스포인트 5% 지급을 계획했으나 "랜덤 보상 금지" 정책과 충돌 → 토스포인트 지급 경로를 UAC(신규 설치) 프로모션으로 완전 분리.

---

## 1. 콘솔 입력 양식 (이미지 기준)

| 필드 | 권장 입력 값 | 주의 |
|---|---|---|
| 미션 이름 | `서비스 이용하기` | "가입"·"signup"·"회원가입"·"로그인" 단어 금지 · 앱인토스에 가입 개념 없음 |
| 지급 방식 | 고정 금액 | "랜덤"·"확률"·"차등" 불가 |
| 1인당 지급 금액 | **1,000원** | 평균 CAC 대역 · 신규 설치 후 1회 고정 |
| 이동 URL | `intoss://saju-500` | 앱인토스 미니앱 딥링크 · 등록 전 앱인토스에 사주500 URL 스킴 확정 필요 |
| 전체 예산 | **3,000,000원** | 현재 비즈월렛 잔액 237,947원 → **2,762,053원 추가 충전 필요** |
| 소진 전략 | 선착순 3,000명까지 자동 지급 · 예산 소진 시 자동 종료 |
| 시작일 | 2026-04-22 (런칭일 당일) |
| 종료일 | 예산 소진 시점 or 2026-05-22 (D+30) 중 빠른 시점 |

## 2. 미션 조건 문구 (심사 통과용)

**제목:** 서비스 이용하기

**본문 (유저에게 노출될 설명):**
> 사주500에서 사주 분석 1회를 완료하면 1,000원을 드려요.
> 설치 후 앱을 실행하여 홈에서 원하는 분석을 하나 완료해 주세요.
> 분석 완료 후 최대 24시간 내 자동 지급됩니다.

**통과 기준 근거:**
- "사주 분석 1회 완료" = 실사용 증명 가능한 구체 행위 (결과 페이지 렌더 트래킹 이벤트로 증빙)
- "설치 후 앱 실행" = 앱인토스에서 추적 가능한 범위
- 지급 시점 명시 ("24시간 내 자동 지급") — 심사에서 선호

## 3. 금지어 체크리스트 (심사 반려 방지)

전체 문구·제목·조건 설명에서 다음 단어 0건:

- [ ] 당첨 / 랜덤 / 뽑기 / 추첨 / 확률 / 로또 / 잭팟 / 박스 오픈
- [ ] 가입 / 회원가입 / 회원 등록 / signup / sign up
- [ ] 포인트 (커스텀 재화 용어 · "운"은 앱 내 전용이므로 프로모션 설명에는 미사용)
- [ ] "꼭" / "반드시" / "100%" — 단정 과잉
- [ ] "기회" / "한정 특가" — 과장 마케팅 지양

## 4. 코드 경로 — 앱 내 구현 없음

- 앱인토스가 설치 → 실행 → 1회 분석 완료 자동 체크
- 사주500 앱 코드베이스에 `grantPromotionReward` 호출 **없음** (서버리스)
- 유저에게 "1,000원 받으세요" 별도 UI 노출도 **없음** — 앱인토스 측이 알림 처리
- 이벤트 탭과 완전 독립 · 이벤트 탭 상단 "런칭 축하 3운"과 혼동 금지

---

## 5. 예산·ROI 감각

- 3,000명 × 1,000원 = 3,000,000원
- 3,000명 설치 중 전환율(분석 완료) 가정 60% = 1,800명 실제 지급 = 1,800,000원 실비
- 전환 1명당 앱인토스 노출 CAC 환산 ≈ 1,600원~2,000원 (프로모션 효율 가정)
- 1,800명 신규 유저 중 5,000원 프리미엄 전환율 2% 가정 = 36명 × 5,000원 = 180,000원 회수
- 단기 ROI 음수 · 리텐션·공유 루프로 6개월 LTV 확장 의존

## 6. D-1 실행 순서

1. 앱인토스 개발자 콘솔 로그인
2. 미니앱 관리 → 딥링크 URL 스킴 `intoss://saju-500` 등록·검증 (필요 시)
3. 프로모션 → 신규 등록 → 위 1번 표 그대로 입력
4. 심사 제출 → 승인 리드타임 확인 (통상 1~3영업일 · 일요일 제외)
5. 비즈월렛 2,762,053원 추가 충전
6. 승인 완료 후 시작일 2026-04-22 자동 활성 확인
