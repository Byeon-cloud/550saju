## 🚨 LOCK 정책 (절대 룰)

### 1. 회귀 금지
- 본 폴더의 파일들은 **시각 디자인·IA·카피·시각화 완성본**.
- AI/Claude/개발자 임의 변경 절대 금지.
- 변경 필요 시: 사용자한테 명시 컨펌 → 컨펌 후에만 수정.

### 2. 변경 시 절차
```
1. 사용자한테 변경 제안 + 이유 명시
2. 사용자 컨펌 ("OK 변경해" 등 명시 동의)
3. 변경 후 본 README 의 변경 이력에 기록
4. 변경 후 _LOCKED/ 안 파일 갱신 + 원본 파일도 동기화
```

### 3. 참조 우선순위
- 락 파일이 **단일 진본 (Single Source of Truth)**
- 다른 mockup·코드는 락 파일 따름
- 충돌 시 락 파일 우선
