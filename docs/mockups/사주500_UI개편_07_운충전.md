# 사주500 UI 개편 — 07 운 충전 (`/charge`)

> 마스터 스펙 + 내정보 §5 확장판. 원화 표기 허용되는 **유일한** 페이지.
> 앱인토스 정책: 결제 = 로그인 필수. 비로그인은 공유 리워드만 가능.

---

## 0. 페이지 성격 요약

| 항목 | 정책 |
|----|----|
| 원화 노출 | **허용** — 패키지 카드·헤로바·결제 확인에 한함 |
| 로그인 필요 | 결제 기능만 로그인 필수. 공유 리워드는 비로그인 가능. |
| 진입 경로 | 내정보 · 홈 BalanceBar · 결과 페이지 PaywallBar · 사주대화 잔액 배너 · 어디서든 "운 부족" 상황 |
| 리턴 처리 | URL `?redirect=/...&need=10`으로 결제 완료 후 원 복귀 |
| 광고 | 노출 안 함 |

## 4. RedirectHint (선택 노출)

URL에 `redirect=...&need=N` 있을 때만 렌더.

- 높이 60, 배경 `#FFFFFF`, border 1px `gray-line`, radius 12, margin 16
- 좌 아이콘 `info` 18 `gold-brown-dark`

  - "10운이 필요한 프리미엄 풀이로 돌아가요" (PaywallBar에서 왔을 때)

## 5. ChargePackages

### 5-1. 그리드
- 2열, 카드 높이 128, gap 10, padding 0 16

### 5-2. 카드 구성
```
┌──────────────────────┐
│ [라벨]        [보너스]│ ← 상단
│ 10운                 │ ← H1
│ 5,000원              │ ← 결제액
│ 프리미엄 1번 해볼 수 있어요 │ ← 유도 문구
└──────────────────────┘
```

- 배경 `#FFFFFF`, border 1px `gray-line`, radius 16
- 상단 좌: Caption 라벨 (예: "가장 인기"), `gold-brown-dark`, 없을 수도
- 상단 우: 보너스 뱃지 (있을 시) — pill `success` bg, `paper` text, "+1운"
- 중앙 수평: H1 24/800 "10운" · `ink`
- 중앙 보조: Body-sm 15/600 `gold-brown-dark` "5,000원"
- 하단: Caption 12/500 `ink-soft` "프리미엄 1번 해볼 수 있어요"

### 5-3. 선택 상태
- border 2px `gold-brown`
- 배경 `gold-brown-soft`
- 체크 아이콘 16 `gold-brown-dark` 우상단 (보너스 뱃지와 겹치면 보너스 우선)

### 5-4. 패키지 5종 (확정)

| 라벨 | 운 | 결제액(원) | 보너스 | 유도 문구 |
|----|----|----|----|----|
| (없음) | 1운 | 500원 | - | "주제 하나 가볍게" |
| (없음) | 5운 | 2,500원 | - | "주제별 5번 해볼 수 있어요" |
| "가장 인기" | 10운 | 5,000원 | - | "프리미엄 1번 가능해요" |
| (없음) | 30운 | 14,000원 | +1운 | "넉넉하게, 부담 없이" |
| "최대 혜택" | 50운 | 22,000원 | +3운 | "한 달은 풍족하게" |

- 패키지 4와 5는 보너스 운 자동 지급 (+1운 / +3운)
- 가격 표기는 원화 허용 (이 페이지에 한해)

## 7. ShareRewardCard (상시 노출)

**공유 리워드로 1운 적립 가능.** 비로그인도 가능.

### 7-1. 시각
- 높이 140, margin 0 16, padding 18 20
- 배경 `paper`, border 1px `gold-brown`, radius 16
- 좌 stack:
  - H3 "친구에게 공유하고 1운 받기"
  - Caption `ink-soft` "하루 3번까지, 총 3운(=1,500원치)까지 받을 수 있어요"
- 우 stack:
  - 카운터: pill `gold-brown-soft` "오늘 N/3회"
  - Primary 버튼 "공유하기" (높이 40, 폭 96)
- 공유 ID: `a56725a6-4c52-40e5-b68b-2f752caf0a94`

### 7-2. 공유 시트
- 카카오톡 / 링크 복사 / 이미지 저장 3종
- 공유 완료 콜백 → 서버에서 +1운 적립 → 토스트 "1운이 적립됐어요"

### 7-3. 어뷰징 가드
- 디바이스 ID + 로그인 시 계정 ID 기준 중복 체크
- 1시간 쿨다운 (같은 디바이스·계정에서 연속 적립 불가)
- 감지 시 Caption 문구 "잠시 뒤 다시 공유해주세요"

## 9. CheckoutBar (하단 sticky)

패키지 선택 전: 숨김.
패키지 선택 시: slide-up 애니메이션 노출 (200ms ease-out).

### 9-1. 시각
- 높이 80, 배경 `ink`, text `paper`, padding 14 20
- 좌 stack:
  - Label 13/600 "선택한 패키지"
  - Body 16/700 "10운 + 5,000원"
- 우: Primary 버튼 "결제하기" (bg `paper`, text `ink`, 높이 48, 폭 140)

### 9-2. 결제 흐름 (앱인토스)
1. 비로그인 → 로그인 모달 → 로그인 성공 후 이어서 결제
2. 로그인 상태 → **토스페이** 결제 모듈 호출 (앱인토스 검수 §3-1 — 외부 결제 모듈 불가. 웹앱 빌드에서만 카카오·네이버페이 유지)
3. 결제 성공 → 서버 운 잔액 업데이트 → 토스트 "10운 충전 완료"
4. redirect 파라미터 있으면 해당 URL로 자동 복귀
5. 없으면 `/charge` 유지하고 Hero에 성공 상태 배지

## 10. 상태 패턴

### 10-1. 로딩
- 패키지 그리드 skeleton 5개 (회색 정적)
- 공유 카운터는 즉시 렌더

### 10-2. 결제 진행 중
- 풀스크린 로더 (paper bg, 중앙 로더 + "결제를 진행하고 있어요")
- 취소 버튼(Ghost) 하단 — 사용자 빠져나올 출구

### 10-3. 결제 실패
- 모달: "결제에 실패했어요. 다시 시도하거나 다른 결제 수단을 골라주세요."
- 에러 코드 Caption `gray-500` (디버깅용)
- 운 차감 절대 금지 (서버에서 idempotency 처리)

### 10-4. 결제 성공
- 확인 시트 (radius-top 24, 높이 auto):
  - 큰 체크 아이콘 48 `success`
  - H2 "충전 완료"
  - Body "●3운 → ●13운 (+10운)"
  - Primary "돌아가기" (redirect 있을 시 "풀이로 돌아가기")

## 12. 접근성

- 패키지 카드 = `<button aria-label="10운 패키지, 5000원, 가장 인기">`
- 라디오 그룹 의미로 `role="radiogroup"` 래퍼 + 각 카드 `role="radio" aria-checked="true|false"`
- 체크아웃 바는 `aria-live="polite"` 로 선택 변경 시 스크린 리더 읽음
- 결제 모듈은 외부 시스템이라 focus trap 필요 (복귀 시 원래 포커스 위치로)

## 15. 원화 검수 화이트리스트

이 페이지는 원화 표기가 **허용**되는 **유일한** 곳.

- 허용 위치:
  - HeroBar "1운 = 500원"
  - ChargePackages 각 카드 결제액 ("5,000원")
  - CheckoutBar 선택 요약 ("10운 + 5,000원")
  - 결제 확인 시트 ("5,000원 결제 완료")
  - Notice (환불 정책 등 법적 표기)
- 금지 위치:
  - 이 페이지 외 전 화면 (홈·결과·보관함·내정보·사주대화·입력 등)

**grep 검수 규칙 (PC용)**:
```
# 이 파일 외에는 "원" 단어가 나오면 안 됨
grep -rn "원\|₩\|KRW" src/pages/ \
  --exclude-dir=charge \
  --exclude-dir=legal
```
