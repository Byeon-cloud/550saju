3단계 / 전체 5단계
사주는 운명이 아니라 사용설명서입니다. 쓰는 사람에 따라 결과가 다릅니다.
일간(日干)은 태양을 뜻합니다. 내 기운의 본체이자 세상을 마주하는 얼굴입니다.
천간은 의지와 방향, 지지는 환경과 자리입니다. 같은 갑목도 寅에 있느냐 午에 있느냐로 달라집니다.
대운은 10년을 지배하지만, 세운이 대운을 비틉니다. 큰 강 위의 파도 같은 원리입니다.
관성이 강한 사주는 조직 적합형, 상관이 강한 사주는 독립·예술 적합형입니다.
용신은 부족한 오행이 아니라, 지금 가장 필요로 하는 오행입니다.
충은 부딪힘, 극은 제어, 합은 묶임, 형은 갈등. 인생의 네 가지 마찰입니다.
삼합이 성립한 해는 관계의 문이 열리는 해입니다. 애쓰지 않아도 인연이 옵니다.
공망은 '그 자리가 비어 있다'는 뜻입니다. 나쁘기보다 선택의 여백에 가깝습니다.
재성이 많아도 활용 가능한 자리에 있어야 실제로 쓸 수 있는 돈이 됩니다.
약한 오행은 숨기지 말고 빌려 쓰세요. 목이 약하면 목을 가진 사람 곁에 있으면 됩니다.
사주에 없는 글자는 단점이 아니라 '탐하지 않아도 되는 영역'입니다.
돈은 재성에서 오지만, 쌓이는 자리는 일지입니다. 배우자와 함께 쌓인다는 뜻입니다.
길신이 없어도 괜찮습니다. 흉신이 없다면 그것도 귀한 사주입니다.
천간이 지지를 끌어주면 이상주의, 지지가 천간을 받치면 현실주의입니다.
사주는 태어난 날씨입니다. 맑은 날은 덜 준비해도 되고, 흐린 날은 우산을 챙기면 됩니다.
격국은 사주의 직업 적성입니다. 격을 따르면 자연스럽게 쌓입니다.
신강은 나를 지지하는 힘, 신약은 나를 지키려는 감각. 둘 다 쓸모가 있습니다.
정인은 어머니의 자리, 편인은 스승의 자리. 비슷해 보여도 결이 다릅니다.
계약·중요한 결정은 일간이 강한 날에 두는 편이 수월합니다.
이사·이직은 삼합년·삼합월에 맞추면 정착이 쉽습니다.
색상은 오행 보완의 도구입니다. 화가 약하면 붉은색, 수가 약하면 검·청색을 가까이 두세요.
방향도 같은 원리입니다. 목이 약하면 동쪽을 등지지 마세요.
생일과 가까운 절기의 기운이 평생 영향을 줍니다.
배우자의 일간과 내 일간이 합 관계면 서로 끌어당기는 인연입니다.
아이의 태어난 시는 부모가 줄 수 있는 첫 선물이자, 평생 남는 설계입니다.
신살은 절대적 판결이 아니라 '색깔' 정도로 받아들이는 편이 정확합니다.
동양 역법은 24시간이 12시진입니다. 하루 흐름이 크게 여섯 번 바뀝니다.
만세력에서 보이는 공망일은 중요한 결정을 미루기 좋은 날입니다.
사주에 없는 것을 부러워하지 마십시오. 있는 것을 쓰는 사람이 잘 사는 사람입니다.
대운이 바뀌는 해는 삶의 결이 통째로 바뀝니다. 40세, 50세 즈음의 변화는 자연스럽습니다.
좋은 사주는 없습니다. '내가 잘 쓰는 사주'만 있습니다.
점은 순간의 기운, 사주는 평생의 설계도입니다.
오행이 모두 있는 사주를 오행구전이라 합니다. 드물지만 반드시 길한 것만은 아닙니다.
귀문관살은 예민함의 표시입니다. 예술·상담·치유 직업과 잘 맞습니다.
일지에 도화살이 있으면 매력의 기운이 있다는 뜻입니다. 부끄러워할 일이 아닙니다.
역마살은 이동 운입니다. 한 곳에 오래 있기보다 움직이며 사는 편이 어울립니다.
화개살은 고독한 빛입니다. 학문·종교·예술에 깊이 들어가는 기질입니다.
천을귀인이 있으면 인생의 결정적인 순간에 도움을 받게 됩니다.
풀이는 예언이 아닙니다. 당신이 이미 알고 있는 것을 단어로 꺼내 보여드립니다.
사주를 공부하는 사람은 겸허해집니다. 선택의 여지가 얼마나 많은지 알게 되기 때문입니다.
운명론자는 사주를 핑계로 삼고, 자유의지론자는 사주를 재료로 삼습니다.
같은 사주를 가진 사람도 삶이 다른 이유는, 환경과 선택이 다르기 때문입니다.
좋은 운이 왔을 때 더 일하고, 궂은 운이 왔을 때 공부하세요. 어느 쪽이든 쌓입니다.
사주를 처음 들여다본 날, 당신은 이미 한 발짝 앞으로 나와 있습니다.
결은 빨리 드러나지 않습니다. 대운 10년은 길지만, 돌아보면 짧습니다.
풀이의 마지막 말은 늘 같습니다. "선택은 당신의 몫입니다."
오늘 사주를 들여다보는 이 시간은, 당신이 자신을 아끼는 시간입니다.
같은 정관이라도 월지에 있으면 본업이고, 시지에 있으면 말년의 자리입니다.
격이 없는 사람도 결이 있습니다. 격보다 결을 먼저 보세요.

구현 핵심 — 서버 측 지연 단축

① 스트리밍 — Anthropic API stream: true. Firestore에 섹션별 incremental update. 체감 대기 1초 이내.
② Prompt Caching — cache_control: { type: "ephemeral" }로 사주 베이스 컨텍스트 캐싱. 입력 토큰 비용 -90%, Opus 마진 3원 → 30~50원 회복.
③ 병렬 섹션 생성 — 주제별 심층/꿈해몽 무료는 3~5섹션 병렬. 전체 생성 시간 -60%. 프리미엄은 일관성 위해 단일 호출 유지.
④ 결과 Firestore 캐시 — 동일 사주 + 날짜 + 주제는 재생성 금지. 재방문 Tier A 진입.
⑤ Keep-alive ping — Cloud Scheduler 1분마다 /health 호출. warm 인스턴스보다 저렴(월 $1 미만), 콜드 스타트 5초 → 1초.
