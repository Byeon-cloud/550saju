### [01] Hero Pillar — 오늘의 하루, 한눈에

**구조**:

## 4. 섹션 간 전환 리듬

- Pillar → Pillar (01→02): 배경색 대비 강 (밝은 오행 → 짙은 ink) · 시선 충돌 의도
- Pillar → Body (02→03): 배경 ink → gold-brown-soft · 분위기 전환 명확
- Body → Body (03→04): 같은 tier이나 배경 paper / soft 교차
- Body → Caption (04→05): 시각 가중치 하락 · 카드 크기 축소
- Caption → Body (05→06): 네이비 배경으로 긴장감 재도입
- Body → Caption → Pillar (06→07→08): 후기 → 철학 순서 필수. 증거 → 가치관 흐름
- Pillar → Caption → Footer (08→09→10): 감정 해제 → 발견성 → 종결

- [01]·[02] Hero: 폭 풀 · 높이 고정 220 / 180
