## 0. 공통 원칙 (5종 동일)

### 0-1. 구조
- `ResultHeader` (140) — 오행 그라디언트 + 한자 심볼 + 프로필 뱃지
- `ResultBody` L1~L4 (3,600자 고정 = 600+1200+1400+400)
- `PaywallBar` — **유료 결과이므로 렌더 X**
- `ResultActions` — 공유·저장·대화
- `UpsellCard` — "사주 전체도 볼래요?" → 프리미엄 10운
- `AdBanner` — **유료이므로 렌더 X**
- `FooterLinks` · `TabBar`

### 0-2. 분량 고정 (±10% 허용)
- L1 요약 (Hook): 600자 · 문단 1개
- L2 본문 (Expansion): 1,200자 · 문단 3~4개 + 각 소제목
- L3 심층 (Depth): 1,400자 · 문단 3개 + Recharts 차트 1개
- L4 액션 (Verdict): 400자 · 체크리스트 3~4 + 오늘의 한 줄
- **합계 3,600자** (프리미엄 10,000자 대비 36% 볼륨 — "한 주제 집중" 체감 OK)

### 0-3. 톤
- 격식체 60% + 친근체 30% + 격언체 10% (메모리 `feedback_brand_voice_tone.md`)
- "~입니다 / ~습니다" 기본 · "~네요 / ~어요" 감정 블록에서 허용
- AI·GPT·챗 등 기술어 0건
- 이모지 0건

### 0-4. 한자 정책
- L1 상단에 **심볼 1개만** (위 테이블 참조)
- 본문 한자 반복 금지. 필요시 괄호 안 (예: "관성(官星)") 1회 제한
- 원전 인용은 L3 끝에 `─ 『적천수』` 1회만 (정책 확정 후)

### 0-5. 금지
- 확률·뽑기·랜덤·카드플립 금지
- "운명" "팔자" "결정된" 등 숙명론 단어 금지 (결 · 흐름 · 결정의 참고로 완화)
- 의료·법률·투자 특정 자문 금지

## 2. 콘텐츠 골격 — 주제별 상세

각 주제마다 L1~L4가 **같은 카피 구조**를 따라야 톤이 통일됨.

### 2-1. L1 요약 템플릿 (600자 · 공통 구조)

```
[오행 현황 1줄]
[해당 주제 키워드 2-3개로 사주 요약]
[현재 시기 (대운·세운) 한 문장]
[이 풀이에서 앞으로 나올 포인트 1문장 예고]
```

**예시 (연애 · love)**:
```
변준기님은 기토(己土) 일간으로, 사주에 관성(官星)이 한 점 또렷하여 관계에서 주도권보다 
선택의 자리에 서시는 분입니다. 연월에 도화(桃花) 기운이 엮여 있어 사람을 끌어당기는 힘은 
타고났으나, 일지(日支)가 편재(偏財) 성향이라 감정의 속도와 이성의 판단이 부딪칠 때가 있으십니다.
지금은 2026년 정미(丁未) 세운의 여름 초입. 불기운이 사주의 관성을 자극해, 
관계의 결이 평소보다 더 선명하게 드러나는 시기입니다. 
이번 풀이에서는 타고난 관계 성향, 올해의 연애 리듬, 그리고 이번 달 구체적인 조언까지 
세 축으로 천천히 풀어드립니다.
```

### 2-2. L2 본문 템플릿 (1,200자 · 3~4 문단)

소제목 4종 고정 (주제별 치환):

| slug | 소제목 1 | 소제목 2 | 소제목 3 | 소제목 4 |
|---|---|---|---|---|
| love | 관계를 움직이는 축 | 끌림의 결 · 반발의 결 | 역할 · 거리 · 속도 | 지금의 사람, 다음의 사람 |
| wealth | 돈이 들고 나는 축 | 버는 결 · 쓰는 결 | 직업재 · 투자재 · 현금재 | 이번 해의 돈맥 |
| job | 직업을 택하는 축 | 격국이 말하는 직업 | 조직형 · 전문형 · 창업형 | 다음 이직의 시기 |
| health | 몸의 균형 축 | 약한 오행의 신호 | 계절 · 시간대 · 음식 | 이번 철의 주의점 |
| study | 배움의 축 | 정인 · 편인의 역할 | 공부 스타일 매칭 | 올해의 시험·자격 리듬 |

**각 소제목 아래 300자 내외 문단**. 키워드는 `gold-brown-dark` bold (문단 당 최대 2개).

### 2-3. L3 심층 템플릿 (1,400자 · 차트 1개 + 3 문단)

**문단 구조**:
1. 차트 해석 (300자) — "위 차트를 보시면…"
2. 시기 특정 (500자) — 특정 월·특정 연도 · 구체 날짜 범위
3. 원전 연결 (600자) — 『적천수』·『자평진전』·『연해자평』 중 1개 인용 (정책 확정 후)

**차트 스펙 (주제별)**:

| slug | 차트 | x축 | y축 | 색 |
|---|---|---|---|---|
| love | 가로 타임라인 | 2026.1 ~ 2026.12 | 관계 강도 (-100 ~ +100) | #C88A95 |
| wealth | 라인 + 영역 | 2026.1 ~ 2026.12 | 재물 흐름 index | #B8965A |
| job | 도넛 | 격국 구성 5색 | % | 오행 팔레트 |
| health | 레이더 5각 | 목·화·토·금·수 | 밸런스 0~10 | #8BA88F |
| study | 수평 바 | 정인·편인·식신·상관·비견 | % | #6B7AA3 + 회색 |

### 2-4. L4 액션 템플릿 (400자 · 체크리스트 3~4 + 인용구)

```
이번 달 해보시면 좋을 것

☑ [구체 행동 1 — 90~110자]
☑ [구체 행동 2 — 90~110자]
☑ [구체 행동 3 — 90~110자]

"[오늘의 한 줄 — 격언체 · 20~30자]"
                                                  — 사주 500
```

**주제별 예시**:

- love: "☑ 2026년 6월 중순, 평소라면 미뤘을 만남 하나 수락해보기"
- wealth: "☑ 6월 말까지 고정 지출 10% 가볍게 정리. 쓰는 결을 먼저 다듬기"
- job: "☑ 7월 초 이력서·포트폴리오 업데이트. 이직은 아니어도 시장을 보는 달"
- health: "☑ 수기운이 약한 달. 저녁 수분 · 충분한 수면 · 차가운 과일 한 입"
- study: "☑ 7월 중순까지 80분 단위 집중 · 10분 걷기 사이클 3주 유지"

**오늘의 한 줄 예**:
- "결은 바꾸지 못해도 방향은 고를 수 있습니다."
- "급한 달이 아니라, 밀린 결을 다듬는 달입니다."
- "흐름은 물결이고, 당신은 방향키입니다."

## 3. 코드 구조 제안 (PC 참고)

### 3-2. Firebase Functions
```ts
// functions/src/ai/generateTopicResult.ts
export const generateTopicResult = onCall({ region: 'asia-northeast3', secrets: [ANTHROPIC_API_KEY] }, async (req) => {
  const { profileId, slug } = req.data;
  const profile = await loadSajuProfile(profileId);
  
  // 프롬프트 템플릿 로드
  const template = await loadTopicPromptTemplate(slug);  // src/ai/prompts/topic_{slug}.md
  
  const result = await anthropic.messages.create({
    model: 'claude-sonnet-4-5-20250929',
    messages: [{ role: 'user', content: buildPrompt(template, profile) }],
    system: BRAND_VOICE_SYSTEM_PROMPT,
    max_tokens: 8000,
  });
  
  // L1~L4 split + 차트 데이터 반환
  return parseTopicResult(result);
});
```

### 3-3. 프롬프트 5개 공용 베이스 + 주제 치환
```
src/ai/prompts/
  topic_base.md       ← L1~L4 구조·톤·금지어·분량 (공통)
  topic_love.md       ← 연애 주제 특화 십성·신살·한자
  topic_wealth.md     ← 재물 특화
  topic_job.md        ← 직업 특화
  topic_health.md     ← 건강 특화
  topic_study.md      ← 공부 특화
```

base + 주제별 파일을 concat 후 프롬프트 완성. 공통 변경은 base만 수정.

- [ ] 분량: 3,600 ± 360자 (±10%)

- [ ] 차트 데이터 유의미 (랜덤 수치 X)
