- 조사일: 2026-04-21
- 대상: 점신(Jeomsin) · 포스텔러(Forceteller) · 만세력 천을귀인(FourPillarsD)

## 점신 (Jeomsin)

### 홈 / 첫인상
- 앱스토어 문구: "소름 돋는 정확도! 2026년 병오년(丙午年) 운세". 평점 4.3~4.7/5, 리뷰 9.8만~11만, 누적 1,900만 가입 · 다운로드 500만+ (국내 카테고리 1위급).
- 슬로건·한자 병기(丙午年)로 "전통 권위 + 대중성" 포지션. 신년운세 시즌에 맞춰 매년 리브랜딩된 연도별 앱(2025 점신 → 2026 점신)을 출시해 스토어 차트 상위 유지.
- CTA 우선순위: ① 무료 신년운세(홈 상단 배너) → ② 전문가 전화상담("첫 3분 무료") → ③ 타로 · 관상 AI → ④ 복주머니/부적 굿즈.

### 입력 (사주 정보 수집)
- 양력/음력 선택 수집. 출생 시간 필수 권장(정확도 강조).
- 출생지 수집(날씨·위치 연동 명분). 성별 수집.
- 시간 보정: 공식 설명에 진태양시·서머타임 문구 없음 → "확인 불가"이나, 만세력 탭에 오행 흐름 시각화만 제공. 사주500 대비 보정 기능은 후방.

### 결과 (콘텐츠 구성)
- 무료: 오늘의 운세(시간대별), 신년운세 요약, 바이오리듬, 코디·음식 추천. 분량은 카드 단위 스낵 포맷(문단 3~5개 수준).
- 유료: 정통사주 · 토정비결 · 인맥 궁합 · 부적. 200페이지급 장문은 아니며, 구성은 주제별 숏 카드 반복형.
- 섹션 타이틀 예: "오늘의 총운", "시간별 흐름", "애정/금전/건강운", "행운 아이템", "인맥 보고서".
- 한자: 중간. "丙午年·大運·歲運·五行" 정도를 장식적으로 병기, 본문은 한글 중심.
- 시각: 카드형 대시보드, 색 코디 아이콘, 바이오리듬 선 그래프. 과한 인포그래픽은 없음.

### 결제 / 플랜
- 무료(광고 포함) 기본. 인앱: 월정액 행운패스 2,900~7,500원(광고 제거) + 소원카드 4,400~39,000원.
- 전화 상담: 분당 과금, 사전 결제 시 최대 25% 할인, PRO 버전 별도.
- 무료-유료 경계: 단건 결제 + 상담 과금 혼합. 블러/티저보다는 "상담으로 넘기는" 퍼널이 강함.

### 리텐션
- **복주머니 시스템**: 매일 운세를 열면 랜덤 복주머니 드랍 → 누적 교환으로 실물 상품 수령. 점신의 최강 훅.
- 매일 새로 업데이트되는 오늘의 운세 · 시간대별 흐름(하루 수 차례 재방문 유도).
- 연간 리브랜딩: "2026 병오년" 식으로 신년 시즌 push.
- 푸시 알림: 운세 업데이트/복주머니/상담 프로모션. 리뷰상 "광고가 너무 심함" 불만 다수.

### UI 문법
- 어두운 네이비/보라 + 포인트 골드, 복주머니·부적 아이콘은 민속 일러스트. 카드 위계는 얕은 편(홈에 기능 타일 8~12개 나열).
- 폰트: 기본 Sans, 중제목에 명조/장식체 부분 사용. 정보 밀도 높고 광고 유닛이 카드 사이에 삽입.

### 사주500 관점 · 시사점
- 배워야 할 것: (1) 복주머니 누적 교환(실물 리워드)로 재방문 습관화, (2) 연도 리브랜딩으로 앱스토어 ASO 매년 초기화, (3) 상담 퍼널(사주 풀이 → 상담 유도) = LTV 최장.
- 사주500이 이기고 있는 것: (1) 광고 밀도(무료 결과만 광고 정책) → UX 깨끗함, (2) ±30분 진태양시 보정 · 홍성민 지적 대응으로 정확도 신뢰, (3) 무료 L1~L4 블러 + 유료 연속성(잠금 티저 연속성 원칙)으로 콘텐츠 "스낵화" 아닌 "장편" 제공.
- 위협: 복주머니 vs 사주500 "공유 1운 + 3원 리워드"의 훅 세기 차. 점신이 더 "즉시·누적·실물" 보상이라 D1~D7 리텐션 압도 가능.

## 포스텔러 (Forceteller)

- 첫인상 키워드: **프리미엄 전문성 + 캐릭터 친근감**. 십이지 동물 캐릭터가 가이드하는 따뜻한 톤 + "자미두수·주역·점성술" 등 정통 라인업.
- CTA 우선순위: ① 2026 신년운세(200p 유료 메인 상품) → ② 일일 운세 점수 · 운세 캘린더 → ③ 사주/타로/점성술/궁합 → ④ 길일 추천 · 부적.

- 섹션 타이틀 예: "올해의 총운", "재물·커리어", "인연·궁합", "건강·가족", "길일 캘린더", "액막이 부적".

- 카드 위계 3단(홈 타일 → 카테고리 → 상세), 정보 밀도는 중간. 한글 세리프·고딕 믹스.

### 사주500 관점 · 시사점
- 배워야 할 것: (1) 200p 초장문 프리미엄 티어 = "가격 정당화"의 교과서, (2) 운세 캘린더 = 단순 사주 → **실행 가능한 길일 툴**로 변환, (3) 십이지 캐릭터 = 사주500의 "AI같지 않은 디자인"에 직접 인사이트.
- 사주500이 이기고 있는 것: (1) 가격 포지션(5,000원 vs 20,000원대) = **1/4 가격 프리미엄** 가능, (2) 한자 이원화(참고서 O · 유저 출력물 X) → 포스텔러보다 가독성 우위, (3) AI 꿈해몽 + SVG 시각화는 포스텔러 미커버 카테고리.
- 위협: 포스텔러는 "전문성 + 따뜻함"을 이미 선점. 사주500이 "격식체 + 친근체"로 차별화하려면 톤 완성도 더 높여야 함.

## 만세력 천을귀인 (FourPillarsD)

### 홈 / 첫인상
- 앱스토어(플레이스토어) 문구: "정통 명리학 기반의 정밀 만세력", "데이터 왜곡 없는 정확한 사주 계산". 평점 4.1/5(플레이, 리뷰 1.76천) · 3.6/5(앱스토어, 리뷰 792), 100만+ 다운로드.
- 첫인상: **프로 지향 · 도구 앱(tool-first)**. 상담·운세 콘텐츠보다 "만세력 조회기"로 포지션. 사주 강사·역술가·공부인이 타깃.
- CTA 우선순위: ① 사주 입력 → 만세력 표 → ② 신살·오행·공망 토글 → ③ AI 프롬프트 생성(ChatGPT/Gemini 연동) → ④ 궁합.

### 입력 (사주 정보 수집)
- 양력/음력 선택. 생년월일 + 출생 시간(시주). **출생지(경도 보정용)**.
- 시간 보정: **동경 127.5도 기준 경도 보정 + 서머타임 자동 보정 + 진태양시 옵션 + 야자시/조자시 선택**. 보정 기능만 놓고 보면 국내 최강급.
- 성별 수집. 이름은 선택(보조).

### 결과 (콘텐츠 구성)
- 본 앱은 "풀이"가 아닌 "만세력 표 + 해석 단서" 중심. 분량: 페이지 장문 X, 표 + 용어 해설 O.
- 섹션 타이틀 예: "사주팔자", "육친", "지장간", "형충회합", "12운성", "납음오행", "공망", "20종 신살(천을귀인·문창귀인…)", "대운·세운·월운", "토정비결", "12신살 나침반".
- 한자: **매우 높음**. 간지·신살 전부 한자 병기. "참고서" 포지션.
- 시각: 사주 표(8~10칸 매트릭스), 12신살 나침반(원형 차트), 대운 타임라인. 인포그래픽 건조하지만 전문가에겐 "읽을 거리" 많음.

### 결제 / 플랜
- 무료(광고 포함). 별도 프리미엄 티어 "확인 불가" — 광고 지원 단일 모델로 추정.
- 결제 단위: 코인/구독 없음. 인앱 결제가 전면 노출되지 않음(부분 제거/추가 테마 수준일 가능성).
- 무료-유료 경계: 거의 없음. 블러·미리보기 패턴 부재.

### 리텐션
- 일일 운세/미션/랜덤박스 **없음**. 게이미피케이션 제로.
- 재방문 훅: 저장·그룹 관리(여러 명 사주 북마크), 유명인 사주 콘텐츠, 궁합 신기능.
- 푸시 알림: "확인 불가"(공격적 push 부재가 오히려 장점).
- 사용자층: 매일 쓰는 앱보다는 "필요할 때 꺼내쓰는 공구함".

### UI 문법
- 화이트·라이트 그레이 + 검정/감색 텍스트. 전통 한자 서체 일부. 카드보다는 **표(table)·리스트** 위계.
- 폰트: 한글 고딕 + 한자 명조 혼용. 정보 밀도 매우 높음(광고가 하단에 고정되는 형태).

### 사주500 관점 · 시사점
- 배워야 할 것: (1) **경도 127.5도 + 서머타임 자동 보정 + 야자시/조자시 옵션**의 완성도 — 사주500 KR 시간 보정 로직의 레퍼런스 수준. (2) AI 프롬프트 자동 생성 기능 = "사주 → LLM" 퍼널을 이미 상용화한 선례(사주500의 사주대화 기능과 정면 중첩). (3) 데이터 보관 로컬 온리 · 개인정보 무수집 = 신뢰 메시지 카피.
- 사주500이 이기고 있는 것: (1) "참고서 vs 해석서" 축에서 사주500은 해석/스토리/개운 가이드까지 제공(천을귀인은 표만), (2) UX 라이팅·톤 완성도(격식체 + 친근체) 월등, (3) 게이미피케이션(복주머니·공유 운·미션) 완비 vs 천을귀인 0. 재방문 룩 압도.
- 위협: 한자 고수 유저층은 천을귀인을 "정확도의 기준"으로 삼음 → 사주500이 "쉬운 풀이"로만 가면 전문가층에선 "가벼운 앱"으로 폄하당할 위험. **참고서 뷰(한자 풍부)** 토글을 유료 티어에 숨겨두는 이원화는 기획 원칙상 이미 있음 — 실제 구현 우선순위 올려야 함.

## 종합 결론 — 사주500 포지셔닝 3줄

1. **가격 1/4 · 정확도 동급 · 톤 위**: 포스텔러 20,000원대 프리미엄 vs 사주500 5,000원, 천을귀인급 진태양시 보정 + 이원화된 쉬운 풀이 + 격식체 50% 톤으로 "프리미엄급을 1/4 가격에" 포지션.
2. **복주머니는 따라가야 함**: 점신 대비 리텐션 훅(공유 1운·3원 리워드)이 약함. 앱인토스 런칭 후 D7~D30 데이터 보며 "누적 실물 리워드" 또는 "스트릭 보상" 추가 검토.
3. **한자 이원화 토글을 유료에 심어라**: 천을귀인은 한자 풍부 전문가층을 잡고 있음. 사주500은 기본 "쉬운 풀이"로 가되, 5,000원 프리미엄에 "참고서 뷰(한자 + 신살 한자)" 토글을 넣으면 전문가층 이탈 방어 + 객단가 정당화 동시 가능.
