### 1-1. 입력 v1 — "정확도가 약 25% 낮아집니다"
**파일:** `사주500_UI개편_목업_입력_v1.html` L284
**위반:** 카피북 0장 제5조 — "75% 품질" 같은 근거 없는 수치 금지. 문장형 대체.

**Before:**
> 시주가 빠지면 전체 풀이의 정확도가 약 **25% 낮아집니다**.

**After:**
> 시주가 없어도 **하루의 큰 흐름**은 정확히 풀리지만, 시주가 있으면 **개인별 미세 결**까지 읽어드립니다.

**근거:** 25%는 소스가 없는 수치. 기존 카피는 시간 모름 체크를 눌렀을 때 부정적 인상을 심었지만, 실제 제품 방침은 "시(時) 없이 큰 흐름으로 풀어드립니다"(카피북 토스트). 방침 톤에 맞춰 재작성.

## 3. 🟢 경미 (PC 인계 — 프롬프트·가드에 반영)

### 3-1. 결과프리미엄 v2 판단 조언에 modal 조동사 사용
**파일:** `사주500_UI개편_목업_결과프리미엄_v2.html` L1430, 1929
- L1430: "답답**할 수 있습니다**"
- L1929: "방해**할 수 있습니다**"

**판단:** 주의·경고 조언 맥락의 modal 조동사 `수 있다`는 면피체 범주 밖. 단정으로 바꾸면 오히려 과잉 경고("방해합니다")가 됨. **유지**.

**PC 가드:** 단, 설명·결론 맥락(판단문)에서 `수 있다`가 반복 등장하면 감사에서 플래그. 프롬프트에 "판단문에서는 단정, 조언문에서만 `수 있다` 허용" 한 줄 추가 권장.

### 3-2. 결과프리미엄 v2 — "가능성이 높습니다"
**파일:** `사주500_UI개편_목업_결과프리미엄_v2.html` L1926
> 특히 **6월**에 새로운 수익 채널 하나가 손에 잡힐 **가능성이 높습니다**.

**판단:** `가능성이 높다`는 긍정 예측어 — `가능성이 있다` 회피와 다름. 다만 결론 톤을 더 단단하게 가져가려면:
**대안:** "6월에 새로운 수익 채널 하나가 **손에 잡힙니다**." (단정형)

**결정:** 연간운 예측은 겸손이 덕목. **유지**. 단 콘텐츠 프롬프트에서 월별·연간 예측 섹션은 단정 70% / 확률형 30% 분포 가이드 추가.

## 5. 축적된 PC 인계 항목 (이번 감사 기준 5건)

**프롬프트·가드 업데이트 (콘텐츠 생성 로직):**

1. **판단문 vs 조언문 톤 분리 지시** — 결과 페이지 프롬프트에 "판단·결론 문장은 단정형(~입니다), 조언·경고 문장은 modal(~할 수 있습니다) 허용" 명시.
2. **근거 없는 % 수치 금지 가드** — `\d+%` 정규식이 나오는 콘텐츠는 사주 원국·운기 계산 파생값에서만 허용. 임의 생성 차단. `scripts/check-copy.ts`에 추가.
3. **"가능성이 있" 패턴 금지** — 프롬프트에 추가 + CI grep.
4. **면피체 블랙리스트 확장** — `할 것입니다`, `것처럼 보`, `것으로 보입니다`, `것으로 판단` 전부 grep 0건 목표.
5. **월별·연간 예측 섹션 단정:확률형 = 70:30** — 너무 단정이면 오만, 너무 확률이면 AI스러움. 분포 가이드.

**콘텐츠 생성 프롬프트 파일 (PC가 고칠 위치):**
- `functions/src/content/today/prompt.ts`

- `functions/src/content/topic/prompt.ts`
- `functions/src/content/premium/prompt.ts`
