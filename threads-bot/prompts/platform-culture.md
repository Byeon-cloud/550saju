# 플랫폼 문화 가이드 — 스레드 vs X (한국, 2026-06 조사)

> BRAIN 프롬프트/변환 로직의 근거 문서. 출처: 나무위키 X(SNS)/용어·Threads/대한민국, 업계 분석.

## 호칭 (확정)
- **스레드**: 스친(스레드 친구), 스팔(스레드 팔로우), 스하리(스팔+하트+리포스트)
- **X**: **트친** (리브랜딩 후에도 유지. "X친소"도 "트친소"로 읽힘. '엑친'은 비주류) → adaptForX의 스친이→트친 변환 유효

## 문화 차이
| | 스레드 | X |
|---|---|---|
| 기본 톤 | 반말·일상수다·친근, 맞팔 후함 | 팬덤·덕질 중심, 더 익명적, 드립 건조·날카로움 |
| 계정 문화 | 본계 하나로 수다 | "~계" 분화(덕질계·우울계 등) |
| 확산 | 좋아요·팔로우·알고리즘 | **알티(RT)·인용**이 왕 |
| 포맷 | 줄글 수다, 댓글 유도 | 짧고 펀치, **타래**(답글 체인) 네이티브 |
| 사주 콘텐츠 승리공식 | 공감형, 댓글사주, 저장각 | **확정형 리스트 + 이모지 시각화**(🟢🔴 오행 유형표) = RT각. 레퍼런스: @dohwadore_saju (10만뷰, RT 215) |

## 우리 운영 원칙
1. 글 생성은 스레드 기준 → X 발행 시 adaptForX(스친이→트친, 스레드→여기) + URL 제거($0.2 방지)
2. X 링크는 준기가 앱에서 직접 대댓 (API 비용 0)
3. (예정) X 네이티브 생성 모드: 처음부터 RT각 리스트+이모지 포맷으로
